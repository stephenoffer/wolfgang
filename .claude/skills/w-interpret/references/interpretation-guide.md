# Interpretation Guide — w-interpret

## Image to Music Mapping

### Color to Tonality

| Color Property       | Musical Parameter    | Mapping                                      |
|----------------------|----------------------|----------------------------------------------|
| Warm (red/orange)    | Mode                 | Major, Lydian                                |
| Cool (blue/green)    | Mode                 | Minor, Dorian, Aeolian                       |
| Saturated/vivid      | Chromaticism         | Chromatic, augmented, altered dominants       |
| Muted/desaturated    | Chromaticism         | Modal, diatonic, pentatonic                  |
| Monochrome           | Texture              | Sparse, monophonic or simple homophonic      |
| High contrast        | Dynamic range        | Wide (pp-ff), dramatic shifts                |
| Low contrast         | Dynamic range        | Narrow (mp-mf), subtle gradation             |
| Dark tones dominant  | Register             | Low register, bass-heavy orchestration       |
| Light tones dominant | Register             | High register, treble-focused                |
| Mixed warm + cool    | Tonal ambiguity      | Mode mixture, borrowed chords                |

### Composition to Form

| Visual Composition   | Musical Form                 | Rationale                           |
|----------------------|------------------------------|-------------------------------------|
| Panoramic landscape  | Extended sonata or rondo     | Expansive, journey-like             |
| Intimate portrait    | ABA, song form               | Focused, personal, contained        |
| Symmetrical          | Palindrome, arch form        | Mirror structure                    |
| Asymmetrical         | Through-composed             | Unpredictable, organic              |
| Repeating pattern    | Theme and variations         | Pattern with evolution              |
| Triptych / panels    | Three-movement suite         | Distinct but related sections       |
| Spiral / recursive   | Rondo or passacaglia         | Return with transformation          |
| Grid / geometric     | Fugue, canon                 | Systematic, contrapuntal            |
| Chaotic / abstract   | Free form, aleatoric         | Unpredictable, textural             |
| Layered / depth      | Orchestral, thick texture    | Multiple simultaneous elements      |

## Existing Piece Reference Handling

### Identification Steps

1. Parse input for: title, composer, opus/catalog number, movement
2. If ambiguous, search for most famous match
3. Extract key characteristics:

| Characteristic     | How to Identify                                    |
|--------------------|----------------------------------------------------|
| Key                | From title or catalog; research if not stated      |
| Form               | Standard for genre; research if non-standard       |
| Instrumentation    | Standard for genre; research for unusual scoring   |
| Tempo/character    | From movement titles, tempo markings               |
| Period/style       | From composer dates and style evolution             |
| Themes             | Research main thematic material                    |

### Derivative Work Spectrum

| Type              | Relationship to Original            | How to Handle                    |
|-------------------|--------------------------------------|----------------------------------|
| "In the style of" | Same techniques, new material       | Extract style parameters only    |
| "Inspired by"     | Emotional/structural similarity     | Borrow form + mood, new themes   |
| "Homage to"       | Recognizable references             | Quote 1-2 motifs, transform them |
| "Variations on"   | Theme preserved, elaborated         | Use original theme, vary freely  |
| "Reimagining"     | Same program, new treatment         | Keep narrative, new music        |
| "Arrangement"     | Same music, different forces        | Use w-reduce for re-scoring      |

## Style Mixing Guidelines

### Compatibility Matrix (higher = more compatible)

| Mix                        | Compat. | Strategy                                   |
|----------------------------|---------|---------------------------------------------|
| Baroque + Classical        | High    | Share tonal language; blend textures         |
| Classical + Romantic       | High    | Expand Classical forms with Romantic harmony |
| Romantic + Impressionist   | Medium  | Chromatic common ground; different voicing   |
| Baroque + Romantic         | Medium  | Counterpoint + expression; careful balance   |
| Classical + Modern         | Low     | Neoclassical approach; form + new language   |
| Romantic + Minimalist      | Low     | Emotional content + repetitive structure     |
| Impressionist + Minimalist | Medium  | Color + repetition; shared static quality    |
| Any period + Film Score    | High    | Film absorbs all styles readily              |

### Conflict Resolution

| Conflict                          | Resolution Strategy                          |
|-----------------------------------|----------------------------------------------|
| Different harmonic languages      | Use one as primary, other for color moments  |
| Different phrase structures       | Alternate by section; or nest one inside other|
| Different rhythmic feels          | Layer them (polyrhythm) or alternate         |
| Different orchestration norms     | Use larger ensemble, mix timbres by section  |
| Different formal expectations     | Choose one form, decorate with other's style |
| Different dynamic norms           | Use wider range to encompass both            |

### Creating Hybrid Parameters

Process:
1. List all parameters from Style A
2. List all parameters from Style B
3. For each parameter, choose one of:
   - **Blend**: average/interpolate (e.g., phrase length: A=4, B=8, use both)
   - **Alternate**: use A in some sections, B in others
   - **Layer**: apply simultaneously (e.g., A's melody + B's accompaniment)
   - **Prioritize**: user preference or primary style wins

Output hybrid as standard parameters JSON for downstream skills.
