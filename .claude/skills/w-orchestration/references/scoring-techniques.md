# Scoring Techniques Reference

## Doubling Techniques

### Unison Doubling
| Combination | Effect | Use Case |
|---|---|---|
| Fl + Ob | Bright, focused, slightly reedy | Classical melodies |
| Fl + Cl | Smooth, blended, hollow | Lyrical passages |
| Ob + Cl | Rich, warm, full | Sustained melodies |
| Vln1 + Fl | Brilliant, shimmering | High lyrical lines |
| Vln1 + Ob | Poignant, cutting | Expressive melodies |
| Vc + Bsn | Dark, rich, woody | Bass lines, tenor melodies |
| Hn + Vc | Noble, warm, blended | Romantic melodies |
| Tpt + Ob | Bright, heroic, piercing | Fanfare, strong themes |

### Octave Doubling
| Combination | Effect | Use Case |
|---|---|---|
| Fl 8va + Ob | Reinforced brightness | Principal theme forte |
| Vln + Vc (8vb) | Rich, full string melody | Big lyrical passages |
| Fl + Cl (8vb) | Warm column of sound | Woodwind theme |
| Ob + Bsn (8vb) | Reedy, pastoral | Folk-like melodies |
| Vln + Fl (8va) | Brilliant extension | Climactic melodies |
| Vc + Cb (8vb) | Powerful bass | Strong bass lines |

### Two-Octave Doubling
| Combination | Effect |
|---|---|
| Picc + Fl + Ob (8vb) + Cl (8vb) | Massive woodwind melody, extreme projection |
| Fl + Vln1 + Vla (8vb) + Vc (2x8vb) | Full string/wind column |
| Picc + Fl + Vln1 + Vln2 (8vb) | Brilliant top-heavy sound |

### Mixed Timbre Doubling
Combining different instrument families creates new composite timbres:
- **Fl + Hn:** Veiled, mysterious warmth
- **Cl + Vla:** Dark, introspective
- **Ob + Vln (solo):** Singing, intense
- **Bsn + Hn + Vc:** Deep, heroic nobility
- **Picc + Glock:** Sparkling, crystalline

## Choir Scoring

### String Choir (4-5 parts)
```abc
% Typical string choir voicing
V:Vln1 clef=treble name="Vln I"
[e'c'a] |
V:Vln2 clef=treble name="Vln II"
[c'a] |
V:Vla clef=alto name="Vla"
[ea] |
V:Vc clef=bass name="Vc"
[A,E] |
V:Cb clef=bass name="Cb"
[A,,] |
```

| Texture | Voicing | Character |
|---|---|---|
| Close position | All parts within an octave | Warm, blended, intimate |
| Open position | Spread across 2+ octaves | Full, spacious, orchestral |
| Divisi | Sections split (div. a2, a3) | Lush, thick, Romantic |
| Melody + tremolo | Upper strings melody, lower tremolo | Dramatic, agitated |
| Melody + pizz. | Melody arco, accompaniment pizz. | Light, dance-like |

### Woodwind Choir (pairs: 2Fl, 2Ob, 2Cl, 2Bsn)
| Texture | Assignment | Character |
|---|---|---|
| Homophonic chorale | All pairs in harmony | Warm, pastoral, hymn-like |
| Paired thirds | Each pair plays in 3rds/6ths | Sweet, Classical |
| Solo + sustain | One solo, others hold chords | Expressive, chamber |
| Stacked octaves | Fl-Ob-Cl-Bsn in octaves | Full, powerful column |
| Cross-family arpeggios | Interlocking figures | Sparkling, fluid |

### Brass Choir (4Hn, 2-3Tpt, 2-3Tbn, Tuba)
| Texture | Assignment | Character |
|---|---|---|
| Chorale | 4-part harmony, all families | Noble, majestic, hymnlike |
| Fanfare | Tpt melody, Hn sustain, low brass punctuation | Heroic, ceremonial |
| Soft brass | Horns only, or Hn + muted Tpt | Warm, distant, atmospheric |
| Power pyramid | Tuba root, Tbn 5th/3rd, Hn fill, Tpt melody | Massive, triumphant |
| Antiphonal | Tpt vs Hn, Tbn responds | Spatial, dramatic |

## Orchestral Textures

### Texture Types
| Texture | Description | Typical Assignment |
|---|---|---|
| Melody + bass | Two-voice framework | Vln1 melody, Vc+Cb bass |
| Melody + countermelody + bass | Three-layer | Fl melody, Hn countermld, Vc+Cb bass |
| Homophonic | Chordal, rhythmically unified | Full orchestra or single choir |
| Contrapuntal | Independent melodic lines | Strings or mixed — fugue, canon |
| Heterophonic | Same melody, varied simultaneously | Ethnic/folk-inspired, impressionist |
| Pointillistic | Fragmented, notes distributed across instruments | 20th century, delicate textures |
| Monophonic | Single line, unison or octaves | Dramatic openings, unison passages |
| Melody + ostinato | Repeated pattern underneath melody | Ravel, minimalist, dramatic buildup |
| Layered | Independent rhythmic/melodic layers | Complex textures, polystylistic |

### Accompaniment Patterns by Family

**Strings:**
| Pattern | Notation/Description | Character |
|---|---|---|
| Alberti bass | `C,E,G,E,C,E,G,E` arpeggiated | Classical, light |
| Tremolo | `[CE]16[CE]16...` repeated | Dramatic, suspenseful |
| Pizzicato bass | Plucked quarter/half notes | Light, rhythmic, dance |
| Sustained pads | Long tied notes, divisi | Warm bed, Romantic |
| Broken octaves | Alternating octave notes | Energetic, Beethoven-like |
| Bariolage | Rapid alternation open/stopped string | Shimmering, virtuosic |

**Woodwinds:**
| Pattern | Description | Character |
|---|---|---|
| Sustained chords | Pairs hold harmony notes | Warm harmonic fill |
| Repeated notes | Staccato repeated figures | Rhythmic drive |
| Arpeggiated figures | Flowing 16th-note arpeggios | Sparkling, fluid |
| Pedal tones | Single held note (usually Bsn/Cl) | Grounding, tension |

**Brass:**
| Pattern | Description | Character |
|---|---|---|
| Sustained pads | Long chord tones, Hn especially | Warm foundation |
| Sforzando punctuation | Short accented chords | Dramatic accent |
| Rhythmic fanfare | Dotted rhythms, repeated notes | Heroic, march-like |
| Horn calls | Arpeggiated fifths/octaves | Pastoral, hunting |

## Textural Buildup and Reduction

### Buildup Sequence (pp to ff)
1. **Solo instrument** (pp) — single line
2. **Add second voice** — countermelody or bass
3. **Add instrument family** (mp) — strings enter with sustained notes
4. **Thicken harmony** — woodwinds add inner voices
5. **Rhythmic activation** (mf) — accompaniment becomes more active
6. **Double melody** — octave doublings accumulate
7. **Brass enters** (f) — horns, then trumpets
8. **Full tutti** (ff) — all forces, percussion, doublings at multiple octaves

### Reduction Sequence (ff to pp)
Reverse order, or sudden drops. Common techniques:
- **Subtractive:** Remove families one at a time
- **Sudden drop:** Full tutti to solo instrument (dramatic contrast)
- **Fadeout:** Gradual dynamic decrease, instruments drop out irregularly
- **Thinning:** Reduce doublings, simplify rhythms, widen spacing

## Balance Considerations

### Relative Dynamic Power (ff, approximate)
| Instrument/Group | Power Level | Notes |
|---|---|---|
| Full brass choir | 10 | Dominates everything |
| Trumpet (1) | 7 | Penetrating, covers most instruments |
| Trombone (1) | 7 | Powerful, dense |
| Horn (1) | 5 | Blends well, moderate power |
| Timpani roll | 7 | Foundational, adds weight |
| Full string section | 6 | 60+ players needed to match brass |
| Oboe (1) | 5 | Penetrating, nasal quality cuts through |
| Clarinet (1) | 4 | Moderate, blends easily |
| Flute (1) | 3-6 | Weak low register, strong high |
| Bassoon (1) | 3 | Easily covered, double for balance |
| Solo violin | 3 | Needs reduced accompaniment |
| Harp | 2 | Only in quiet passages or with arpeggios |

### Balance Adjustment Rules
- Brass f = Strings ff (mark brass one dynamic softer for balance)
- Solo woodwind needs strings at p/mp to be heard
- Solo string needs orchestra at pp/p
- Horns blend with everything; use as "glue" between families
- Timpani at mf balances with full orchestra at f
- Harp is inaudible in tutti; use in chamber textures or with arpeggiated figures

| Picc + Glock | Sparkling, icy |
| Tpt + Ob | Heroic brightness |

|---|---|

| Hn + Vc | Noble warmth |

## Historical Orchestration by Period

| Period | Typical Forces | Characteristics |
|---|---|---|
| Baroque (1600-1750) | Strings + continuo, optional winds | Terraced dynamics, continuo bass, solo/ripieno contrast |
| Classical (1750-1820) | Strings + paired winds (2,2,2,2) + 2Hn + 2Tpt + Timp | Clear textures, balanced choirs, Alberti bass, dialogue |
| Early Romantic (1820-1850) | + Tbn, expanded Hn to 4, Picc, Eng Hn | Richer doublings, more expressive, wider dynamic range |
| Romantic (1850-1900) | + Tuba, Harp, 3Tbn, expanded perc | Lush strings, massive climaxes, chromatic color |
| Late Romantic (1880-1910) | Triple/quad winds, 8Hn, expanded perc, celesta | Huge forces, extreme dynamics, continuous texture |
| Impressionist (1890-1920) | Standard orch, divided strings, expanded perc | Transparency, color mixing, solo timbres, muted brass |
| Early Modern (1900-1950) | Variable, chamber to massive | Extreme registers, percussive use of instruments |
| Minimalist (1960-present) | Variable, often reduced | Repetitive patterns, gradual transformation |
| Film Score (1930-present) | Late Romantic base + synth/electronics | Leitmotif, lush strings, brass power, hybrid timbres |
