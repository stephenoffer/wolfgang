# /w-reduce -- Arrange Between Instrumentations

You are creating an arrangement of a Wolfgang composition, either reducing a larger ensemble to a smaller one or orchestrating a smaller ensemble to a larger one. Parse the arguments to extract the piece-id, direction (reduce or orchestrate), and target instrumentation.

---

## Mode A: Reduction (e.g., Orchestra to Piano)

### Step 1: Read Source Material

Read all ABC files for the piece from `workspace/<piece-id>/abc/`. Also read:
- `workspace/<piece-id>/plan.json` for structure and form information
- `workspace/<piece-id>/themes.json` for theme definitions
- `workspace/<piece-id>/continuity.json` for current state

### Step 2: Analyze Voices

For each section of the source, identify and categorize the essential voices:

1. **Primary melody** -- the principal melodic line at any given moment. Track which instrument carries it and when it transfers.
2. **Bass line** -- the lowest sounding voice providing harmonic foundation.
3. **Inner harmony** -- chordal fill, sustained harmonies, accompaniment patterns.
4. **Countermelody** -- secondary melodic lines of structural importance (not mere doublings).
5. **Rhythmic figuration** -- ostinati, accompaniment patterns, rhythmic drive elements.
6. **Color/effect** -- tremolos, trills, pizzicato textures, pedal points that define the character.

Rank these by structural importance. The reduction must preserve #1 and #2 absolutely, #3 and #4 as much as possible, and #5 and #6 where the target instrument can accommodate them.

### Step 3: Reduce to Target Instrumentation

For **piano (two hands)**:
- **Right hand**: Primary melody at all times. Add countermelody fragments at critical structural moments (theme entries, climaxes) where the hand can manage both. When melody is in a low register, RH may take inner harmony instead.
- **Left hand**: Bass line at all times. Fill harmonic content between bass notes using:
  - Alberti bass or broken chord patterns for Classical style
  - Arpeggiated figures for Romantic style
  - Block chords for dramatic/forte passages
  - Octave bass + chord for climactic moments
- **Preserve absolutely**: All themes in their complete form, all harmonic content (every chord must be represented), the full dynamic arc from pp to ff, key rhythmic patterns that define sections.
- **Idiomatic piano writing**: Keep hand spans within a 10th maximum (prefer octave). Use pedal markings to sustain bass while hands move. Avoid awkward leaps that break the musical line. Use piano-specific techniques: rolled chords for harp arpeggios, tremolos for string tremolo, grace notes for wind ornaments.

For **piano four hands / two pianos**:
- Primo: melody + countermelody + upper harmony
- Secondo: bass + lower harmony + rhythmic figuration
- More orchestral detail can be preserved than two-hand reduction

For **string quartet**:
- Violin I: primary melody
- Violin II: countermelody or upper harmony
- Viola: inner harmony, occasionally melody
- Cello: bass line, occasionally melody
- Preserve contrapuntal elements more faithfully than piano reduction

For **other targets**: Apply similar voice-assignment logic appropriate to the ensemble. Always prioritize melody and bass, then fill remaining voices with harmony and countermelody based on available instruments.

### Step 4: Write Reduced ABC Files

Write new ABC files to `workspace/<piece-id>/abc-reduced/<target>/` preserving:
- All section boundaries and rehearsal marks from the original
- All tempo markings and changes
- All dynamic markings
- All key signatures and changes
- All repeat structures

Each file should have a header comment noting it is a reduction:
```
% Reduction of [original instrumentation] to [target instrumentation]
% Generated by /w-reduce from piece <piece-id>
```

### Step 5: Verify Reduction Quality

Self-check the reduction against these criteria:
- [ ] Every theme from themes.json appears in the reduction
- [ ] No harmonic content is lost (every chord root and quality preserved)
- [ ] Dynamic arc matches the original
- [ ] All key changes preserved
- [ ] Idiomatic for target instrument (no impossible stretches, reasonable page-turn points)
- [ ] Rhythmic character of each section preserved
- [ ] Critical countermelody moments retained

## Mode B: Orchestration (e.g., Piano to Orchestra)

### Step 1: Read Source Material

Read all ABC files for the piece from `workspace/<piece-id>/abc/`. Also read:
- `workspace/<piece-id>/plan.json` for structure, form, and style/era information
- `workspace/<piece-id>/themes.json` for theme definitions
- `workspace/<piece-id>/continuity.json` for current state

### Step 2: Analyze the Source

For each section, identify:
1. **Melody**: the primary melodic line (usually the highest voice or most active line)
2. **Bass**: the lowest voice
3. **Harmony**: chordal content between melody and bass
4. **Texture changes**: where the writing shifts from thick to thin, legato to staccato, etc.
5. **Dynamic shape**: the intensity curve
6. **Register usage**: which parts of the keyboard are active when

### Step 3: Assign to Orchestral Forces

Determine the target orchestration from the argument. If not fully specified, use a standard orchestra appropriate to the style:
- **Classical (Haydn/Mozart era)**: 2222 / 2200 / timpani / strings
- **Early Romantic**: 2222 / 4230 / timpani+perc / strings
- **Full Romantic**: 3333 / 4331 / timpani+perc+harp / strings
- **Late Romantic/Modern**: expanded winds, larger brass, extended percussion

Apply these orchestration principles:

**Melody assignment:**
| Character | Primary Choice | Doubling |
|-----------|---------------|----------|
| Lyrical, singing | Violin I, or solo woodwind (oboe, clarinet) | Flute octave above for brightness |
| Heroic, bold | Horns in unison, or trumpet | Strings doubling for body |
| Plaintive, dark | Oboe, English horn, or cello | Bassoon support |
| Light, playful | Flute, or pizzicato strings | Clarinet response |
| Majestic, broad | Full strings unison/octaves | Brass support at climax |

**Bass assignment:**
| Context | Primary Choice | Support |
|---------|---------------|---------|
| Sustained foundation | Cello + bass | Bassoon doubling |
| Moving bass line | Cello (bass follows) | Bassoon in lighter passages |
| Dramatic pedal point | Low brass (trombone, tuba) | Timpani roll |
| Light texture | Pizzicato cello + bass | None |

**Harmony/inner voices:**
- Horns for sustained harmonic fill (their natural role)
- Clarinets and bassoons for woodwind harmony
- Violas and second violins for string harmony
- Combine families for fuller sound at forte dynamics

**Texture and color:**
- **pp passages**: Solo instruments or single section, minimal doubling
- **p passages**: One family (strings alone, or woodwinds alone)
- **mf passages**: Two families combined
- **f passages**: Full orchestra minus some reserves
- **ff passages**: Full orchestra, strategic doublings, timpani
- **fff climaxes**: Everything, with brass and percussion at full force

**Orchestral devices to add:**
- Tremolo strings for tension and sustained energy
- Pizzicato for rhythmic punctuation
- Woodwind solos for color and contrast in lyrical passages
- Brass punctuation (sfz chords, fanfare figures)
- Harp arpeggios for shimmering textures (Romantic and later)
- Timpani rolls for pedal points and crescendo support
- Divisi strings for rich harmony at climaxes
- Muted brass or strings for special color effects

### Step 4: Write Orchestral ABC Files

Write new ABC files to `workspace/<piece-id>/abc-orchestrated/<target>/`, one file per instrument or section. Use standard ABC voice notation for multi-voice scores.

Each file should have a header comment:
```
% Orchestration of [original instrumentation] to [target instrumentation]
% Generated by /w-reduce from piece <piece-id>
```

### Step 5: Verify Orchestration Quality

Self-check:
- [ ] All melodic content from the source is present in the orchestration
- [ ] All harmonic content preserved
- [ ] All instruments stay within their standard ranges
- [ ] No instrument has unreasonable rests (pages of nothing) or unreasonable continuous playing
- [ ] Dynamics are orchestrationally supported (doublings increase at forte, thin at piano)
- [ ] Style-appropriate instrumentation (no tuba in a Mozart orchestration)
- [ ] Transitions between sections have smooth orchestral handoffs
- [ ] Balance: no single instrument section overwhelms others inappropriately

---

## Step 6: Post-Processing

After writing the arranged files:

1. **Invoke /w-review** on the result to check for technical errors (range violations, voice leading issues, etc.).

2. **Invoke /w-assemble** to produce a combined MusicXML file from the new ABC files.

3. Report any issues found by /w-review that need attention.

---

## Output Summary

Print a report:
- Source instrumentation and target instrumentation
- Direction (reduction or orchestration)
- Number of sections processed
- Key arrangement decisions made (e.g., "Assigned opening theme to solo oboe for pastoral character")
- Any compromises made (e.g., "Countermelody in bars 34-38 omitted in piano reduction due to hand span constraints")
- Location of output files
- Results of /w-review and /w-assemble
