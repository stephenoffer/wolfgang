# Olivier Messiaen — Melodic Style

Messiaen's melodies come from three sources: birdsong (transcribed from nature with scientific precision), plainchant (the medieval liturgical tradition), and the modes of limited transposition (which generate modal melodies unlike any tonal or atonal tradition). All three produce melodies that are rhythmically free, non-periodic, and outside the European Classical phrase tradition.

## Core Melodic Sources

| Source | Character | Register | Rhythm | Where It Appears |
|--------|-----------|----------|--------|-----------------|
| Birdsong | Rapid, ornamental, irregular | Very high (C5–C7) | Unmeasured, natural | Catalogue d'oiseaux, Chronochromie, all late works |
| Plainchant | Stepwise, narrow range, modal | Middle (C3–C5) | Free, speech-like | Organ works, Quartet Mvt. 5, Saint Francois |
| Modal (Modes of LT) | Chromatic, symmetrical, wide | Variable | Added-value rhythms | Turangalila themes, Vingt regards |
| Hindu rhythmic pattern | Rhythmic cell as melodic generator | Variable | Specific named patterns | Turangalila, Chronochromie |

## Birdsong Transcription

Messiaen transcribed birdsong in the field using his ear and notation. The musical result is specific to each species.

| Bird | Pitch Character | Rhythm Character | Instrument (typical) |
|------|----------------|------------------|---------------------|
| Blackbird (merle noir) | Fluty, moderate register, flowing | Rapid phrases with pauses | Flute, piano treble |
| Song thrush (grive musicienne) | Repeated motifs, middle-high | Short phrases, each repeated 2–3× | Clarinet, piano |
| Garden warbler (fauvette des jardins) | Complex, rapid, continuous stream | Long unbroken phrases, very fast | Piano treble, flute |
| Golden oriole (loriot) | Descending glissando, pure tone | Single calls with long silences | Flute, oboe |
| Skylark (alouette des champs) | Extremely high, continuous trill | Sustained, hovering | High woodwinds, piano |
| Nightingale (rossignol) | Brilliant, varied, dramatic | Mixed long and short phrases | Piano, woodwinds |

```abc
X:1
T:Blackbird Song — Fluty, Flowing (Catalogue d'oiseaux character)
M:4/4
L:1/32
K:C
%% Rapid, high-register, irregular phrasing — the blackbird's evening song
!mf!e'4 d'c'b c'8 z4|a4 g2f2 e4 z4 e'4|d'4 c'b a g4 f8|
%% Not metrically regular — the bird's natural speech rhythm
```

```abc
X:2
T:Song Thrush — Repeated Motifs (each phrase stated twice)
M:4/4
L:1/16
K:C
%% Each motif repeated — the thrush's signature: say it, say it again
!f!g2a2b2 z2 g2a2b2 z2|e2f2g2 z2 e2f2g2 z2|
%% Short cells, each immediately repeated, then a new cell
```

## Plainchant Melody

Messiaen's liturgical melodies draw from Gregorian chant: stepwise motion, free rhythm, narrow range, modal color.

| Feature | Description | Chant Model |
|---------|-------------|-------------|
| Narrow range | Melody within a 5th or 6th | Authentic and plagal modes |
| Stepwise motion | Mostly seconds; rare leaps | Syllabic chant |
| Free rhythm | No regular meter; speech-based | Accentus and concentus |
| Modal basis | Modes 2, 3, or church modes | Medieval modal system |
| No bar-line regularity | Phrases end when the text ends | Neumes, not measures |

```abc
X:3
T:Plainchant-Derived Melody — Free Rhythm, Narrow Range
M:4/4
L:1/8
K:C
%% Stepwise, modal, free — Gregorian chant through Messiaen's ear
!p!C2 D2 E F E2|D2 C2 D E D2|C4 z4|
%% No syncopation, no leaps, no chromaticism — ancient simplicity
```

## Modal Melody (Modes of Limited Transposition)

| Mode | Melodic Character | Typical Use |
|------|-------------------|------------|
| Mode 2 | Dark, symmetrical, whole-half alternation | Supernatural themes; Turangalila |
| Mode 3 | Prismatic, rich, 9 pitches per octave | Luminous themes; Vingt regards |
| Mode 4 | Exotic, clustered + gapped | Rare; specific color passages |
| Mode 6 | Flexible, between whole-tone and octatonic | Moderate passages; transitional |

```abc
X:4
T:Mode 3 Melody — Prismatic, Luminous
M:4/4
L:1/8
K:C
%% All pitches from Mode 3: C D Eb E F# G Ab A B
!mf!C D _E E ^F G|_A A B c D _E|E2 ^F2 G2|
%% The richness of 9 available pitches per octave — more than major or minor
```

## Rhythmic Melody — Added Values and Hindu Rhythms

Messiaen's melodic rhythm is inseparable from his rhythmic innovations. Melodies are shaped by added values, non-retrogradable rhythms, and named Hindu/Greek patterns.

| Technique | Description | Melodic Effect |
|-----------|-------------|---------------|
| Added value | One note lengthened by a dot or sixteenth | Phrase becomes asymmetric; lilt |
| Non-retrogradable rhythm | Palindrome: reads same forwards and backwards | Symmetrical phrase shape |
| Augmentation by addition | Note values grow by adding a unit (q → q+e → h) | Gradual expansion |
| Hindu patterns (deciTalas) | Named rhythmic cells from Indian tradition | Specific rhythmic characters |

| Named Pattern | Rhythm | Character |
|--------------|--------|-----------|
| Ragavardhana | q qd e q | Expanding |
| Candrakala | e q e qd | Lilting, asymmetric |
| Lakskmica | q e q q e | Processional |

```abc
X:5
T:Added-Value Rhythm — Asymmetric Lilt
M:4/4
L:1/16
K:C
%% Regular pattern: C4 D4 E4 F4 (4 quarter notes)
%% With added value on 2nd note: C4 D6 E4 F4 (4.5 beats total)
!p!C4 D6 E4 F4|G4 A6 B4 c4|
%% The dot on D and A creates Messiaen's characteristic asymmetric lilt
```

## Melodic Intervals — Signature Shapes

| Interval | Messiaen's Use | Context |
|----------|---------------|---------|
| Minor 2nd | Mode 2 primary interval; chromatic neighbor | Supernatural passages |
| Major 2nd | Stepwise plainchant; Mode 3 | Liturgical melody |
| Minor 3rd | Mode 2 secondary interval | Dark, octatonic color |
| Major 3rd | Color chord arpeggio; warmth | Turangalila love theme |
| Augmented 4th | Mode 2 structural interval (tritone) | Tension, mystery |
| Perfect 5th | Rare in melody; more in harmony | Open, resonant |
| Octave + | Birdsong leaps between registers | Extreme bird calls |

## Phrase Structure

| Type | Description | Where |
|------|-------------|-------|
| Bird-phrase | Irregular length; determined by the bird's call | Catalogue, Chronochromie |
| Chant-phrase | Free length; determined by text or liturgical gesture | Organ works, vocal |
| Added-value phrase | Regular phrase + one added rhythmic value = asymmetric | Throughout |
| Non-retrogradable phrase | Palindrome: second half mirrors first | Quartet Mvt 1, Turangalila |
| Color-chord phrase | Melody as arpeggiated chord tones | Vingt regards |
