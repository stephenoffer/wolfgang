# Composer Profile: Sergei Prokofiev (1891–1953)

## Style Overview

| Element | Prokofiev's Approach |
|---------|---------------------|
| Self-described lines | Classical, Modern, Toccata, Lyrical, Grotesque |
| Harmonic language | Extended tonality, "wrong-note" displacements |
| Melody | Long-breathed lyrical lines amid dissonance |
| Rhythm | Driving motor rhythms, toccata energy |
| Form | Neo-classical frameworks, clear sections |
| Orchestration | Brilliant, transparent, precise colors |
| Character | Wit, humor, sarcasm alongside genuine lyricism |

## The Five Lines (Prokofiev's Self-Analysis)

| Line | Description | Example Works |
|------|-------------|--------------|
| Classical | Neo-classical forms, Haydn/Mozart clarity | Classical Symphony, Piano Sonata 9 |
| Modern | Dissonance, bold harmony, experimentation | Piano Concerto 2, Scythian Suite |
| Toccata | Percussive, motoric, driving energy | Toccata Op.11, Piano Concerto 3 |
| Lyrical | Long singing melody, deep expression | Romeo and Juliet, Piano Concerto 3 (II) |
| Grotesque | Humor, irony, sarcasm, caricature | Love for Three Oranges, Lt. Kije |

## "Wrong-Note" Technique

| Type | Mechanism | Effect |
|------|-----------|--------|
| Chromatic displacement | Expected scale degree shifted by semitone | Surprise, humor |
| Approach-note error | Leading tone goes "wrong" direction | Anti-conventional |
| Harmonized wrong note | Wrong note gets full chord support | Bold, confident |
| Modal mixture + shift | Unexpected mode switch mid-phrase | Color surprise |
| Chromatic sidestep | Entire phrase displaced by semitone | Disorientation |

```abc
X:1
T:Wrong-Note Technique - Expected vs. Actual
M:4/4
L:1/8
K:C
"^Expected"CDEF GABc |
"^Prokofiev 'wrong note'"CDE^F GA_Bc |
```

```abc
X:2
T:Wrong-Note Melody (Classical Symphony style)
M:2/2
L:1/8
K:D
D2FA d2^c2 | _B2AG FGAB | _d2cB A2^G2 | A4 D4 |
```

### Application Rules

| Rule | Description |
|------|-------------|
| Displace by m2 | Move one note by semitone from expected |
| Support with conviction | Don't treat as passing — harmonize fully |
| Resolution optional | Wrong note may become new right note |
| Limit per phrase | 1-2 wrong notes per phrase, not more |
| Target strong beats | Wrong notes on beats 1 and 3 most effective |
| Diatonic context | Surrounding material clearly tonal for contrast |

## Driving Motor Rhythms

| Pattern | Meter | Character |
|---------|-------|-----------|
| Straight 8ths, accented | 4/4 | Relentless, mechanical |
| Toccata 16ths | 4/4 | Virtuosic, brilliant |
| Dotted rhythms | 2/4, 4/4 | March-like, aggressive |
| Syncopated ostinato | Various | Edgy, propulsive |
| Galloping | 6/8, 2/4 | Energetic, playful |

## Lyrical Melody

| Characteristic | Description |
|---------------|-------------|
| Wide range | Melodies span 1.5-2 octaves |
| Long phrases | 8-16 bar phrases, singing quality |
| Stepwise + leaps | Mostly stepwise with expressive leaps |
| Unexpected intervals | Aug 4th, dim 5th in lyrical context |
| Accompaniment | Simple, allowing melody to sing |
| Orchestration | Strings, cello solo, or clarinet solo |

## Classical Symphony Neo-Classicism

| Feature | Treatment |
|---------|-----------|
| Form | Standard Classical: Allegro, Larghetto, Gavotte, Finale |
| Harmony | Mostly diatonic with chromatic surprises |
| Orchestration | Classical-sized orchestra (Haydn proportions) |
| Texture | Homophonic, clear melody + accompaniment |
| Phrasing | Regular 4-bar and 8-bar phrases |
| Wrong notes | Sparing, witty displacement |
| Tempo | Energetic outer movements, graceful middle |

```abc
X:6
T:Classical Symphony Type Theme (Gavotte)
M:4/4
L:1/8
K:D
D2 D2 ^FA df | e2 d2 ^cB AF | D2 D2 ^FA df | e2 d2 d4 |
```

## Characteristic Humor and Grotesque

| Device | Mechanism | Effect |
|--------|-----------|--------|
| Exaggerated march | March distorted with wrong notes | Military satire |
| Extreme register | Melody in absurdly high/low octave | Comedy |
| Sudden dynamic shifts | fff to ppp without transition | Surprise, shock |
| Mechanical repetition | Obsessive ostinato, puppet-like | Caricature |
| Chromatic runs | Fast chromatic scales in unexpected places | Manic energy |
| Bassoon/tuba melody | Awkward-range solo | Clumsy, humorous |

```abc
X:7
T:Grotesque March (Love for Three Oranges style)
M:2/4
L:1/16
K:C
!ff!CDEF GABc | !p!_d_edc _BAG^F | !ff!CDEF GABc | !sfz!_d4 z4 |
```

## Orchestration

### Prokofiev's Orchestral Palette

| Instrument Group | Characteristic Use |
|-----------------|-------------------|
| Strings | Lyrical melody, driving ostinato, divided for color |
| Flutes | High bright melody, running passages |
| Oboe | Lyrical solo, pastoral |
| Clarinet | Warm melody, grotesque low register |
| Bassoon | Comic solo, lyrical tenor register |
| Horns | Heroic calls, sustained harmony |
| Trumpets | Brilliant fanfare, march melody |
| Trombones | Grotesque, powerful climax, menacing |
| Tuba | Dark bass, comic solo |
| Percussion | Snare for march, xylophone for grotesque |
| Piano (in orchestra) | Percussive, brilliant, motoric |
| Harp | Glissandi, arpeggiated color |

### Orchestration Principles

| Principle | Application |
|-----------|-------------|
| Transparency | Individual lines clearly audible |
| Bright colors | Preference for bright, vivid timbres |
| Anti-Romantic doubling | Fewer unison doublings than Romantic |
| Contrasting blocks | Sections of distinct orchestral color |
| Solo exposure | Frequent solo instrument passages |
| Brass prominence | Brass more prominent than in Romantic norm |
| Percussion precision | Percussion as structural, not decorative |

## Style Markers for Generation

| Parameter | Setting |
|-----------|---------|
| Tonality | Clear tonal center, chromatic embellishment |
| Wrong notes | 1-2 per phrase, on strong beats |
| Rhythm | Motor 8ths/16ths for fast; long notes for lyrical |
| Melody | Wide-ranging, singing, stepwise base + leaps |
| Dynamics | Wide range, sudden shifts |
| Articulation | Crisp staccato, marcato; or pure legato |
| Form | Classical models, clear sections |
| Humor | Through register, dynamics, wrong notes |
| Orchestration | Transparent, solo-friendly, bright |

## Compositional Fingerprints

| Fingerprint | Description |
|-------------|-------------|
| Semitone displacement | The "wrong note" — single note shifted by m2 |
| Toccata energy | Relentless 16th-note passages |
| Lyrical breadth | Long, singing melodies in any context |
| March distortion | Military march with chromatic warping |
| Major-minor flicker | Rapid alternation between major and minor 3rd |
| Galloping bass | Energetic bass patterns in fast movements |
| Resolving into clarity | Dissonant passages arriving at pure triad |
| Snare drum march | Military percussion underpinning |
| Bitonal approach | Brief polytonal clashes resolving to tonality |
