# Sergei Prokofiev — Melodic Style

Prokofiev is one of the great melodists of the 20th century. His melodies are immediately recognizable: angular yet singing, sardonic yet beautiful, mechanically precise in fast music yet genuinely tender in slow music. He writes real tunes — not cells, not fragments, not rows. His melodies have beginnings, middles, and ends. What makes them Prokofiev is the unexpected leap, the "wrong" interval, the way a lyrical line suddenly snaps into something angular.

## Core Melodic Character

| Feature | Fast/Motoric | Slow/Lyrical | Grotesque/March |
|---------|-------------|-------------|-----------------|
| Range | Wide (2 octaves); angular leaps | Moderate (octave); stepwise | Narrow; repetitive; confined |
| Contour | Jagged; up-down-up; no smooth curve | Arched; rises, peaks, descends gently | Flat or descending; lurching |
| Phrase length | 4 bars; regular; motoric | 8–16 bars; long, breathing | 4 bars; square; marchlike |
| Signature interval | Augmented 4th, major 7th | Major 2nd, perfect 4th | Minor 2nd (chromatic neighbor) |
| Articulation | Staccato, marcato | Legato, cantabile | Staccato, accented |
| Expression | No sentiment; kinetic energy | Genuine tenderness | Sardonic grin; leering |

## Melodic Techniques

| Technique | Description | Where It Appears |
|-----------|-------------|-----------------|
| Angular leap | Wide interval (7th, tritone) in middle of stepwise line | Piano Sonata No. 7, first movement |
| Fairy-tale melody | Simple, diatonic, childlike — then one "wrong" note | *Peter and the Wolf*, *Cinderella* |
| Motoric scale | Rapid ascending or descending scale, ff, staccato | Toccata Op. 11, Piano Concerto No. 3 |
| Sardonic march | Simple march tune with chromatic neighbor inflections | *Love for Three Oranges* March |
| Lyrical cantabile | Long, singing melody; stepwise; genuine beauty | *Romeo and Juliet* love theme |
| Ostinato melody | Short melodic cell repeated mechanically | Scythian Suite, War Sonatas |
| Octave displacement | Expected note displaced by an octave (leaps up where step expected) | Piano Sonata No. 6 |

```abc
X:1
T:Prokofiev Lyrical Melody — Romeo and Juliet Character
M:4/4
L:1/8
K:G
%% Long, stepwise, arched — the genuine Prokofiev tenderness
!p!B,2 D2 G2 A2|B4 A2 G2|F2 E2 D2 E2|D6 z2|
B,2 D2 G2 B2|d4 c2 B2|A2 G2 F2 E2|G6 z2|
%% 16-bar arch: rises to D5, descends; no wrong notes — pure lyricism
```

```abc
X:2
T:Prokofiev Angular Melody — Motoric Character
M:4/4
L:1/16
K:Dm
%% Relentless, angular, staccato — the Scythian Prokofiev
!ff!d2c2 d2^f2 a2g2 f2e2|d2_B2 A2G2 F2E2 D4|
d2c2 d2^f2 a2_b2 ^g2e2|d8 z8|
%% The augmented 4th (d-f#) and the minor 2nd (a-bb) are Prokofiev signatures
```

## Melodic Intervals — Signature Shapes

| Interval | Usage | Character |
|----------|-------|-----------|
| Minor 2nd | Chromatic neighbor; the "wrong" note | Sardonic, slightly sinister |
| Major 2nd | Stepwise lyrical motion | Warmth, simplicity |
| Minor 3rd | Folk-derived; Russian character | Nostalgic, plaintive |
| Perfect 4th | Opening leap; horn-call; heroic | Brightness, clarity |
| Augmented 4th (tritone) | Angular shock in mid-phrase | The Prokofiev stab — jarring, deliberate |
| Perfect 5th | Opening gesture; fanfare | Classical clarity |
| Major 7th | Wide angular leap in fast passages | Disorienting, aggressive |
| Octave | Displaced register; the note is "right" but in wrong octave | Surprising, witty |

## Melody Types by Context

### The Fairy-Tale Melody
Simple, diatonic, childlike — the kind of tune a child might hum. Then one chromatic note appears: the wolf's theme, the witch's shadow.

```abc
X:3
T:Fairy-Tale Melody — Peter and the Wolf Character
M:4/4
L:1/8
K:C
%% Simple, bright, C major — a child's tune
!mf!C2 E2 G2 c2|B2 A2 G2 E2|F2 A2 G2 ^F2|G6 z2|
%% Bar 3: F# (the "wrong" note in C major) — a flash of something not quite safe
```

### The Sardonic March
A march that grins too wide. The melody is simple, the rhythm is square — but the intervals leer.

```abc
X:4
T:Sardonic March — Love for Three Oranges Character
M:4/4
L:1/8
K:C
%% Bright, staccato, loud — the grotesque march
!ff!c2c2 B2c2|d2^d2 e4|c2c2 _B2A2|G2^G2 A4|
%% D#/Eb chromatic neighbors — each one grins a little wider
```

### The Lyrical Cantabile
Genuine beauty. No irony, no distortion. These moments are Prokofiev's emotional core.

| Feature | Description |
|---------|-------------|
| Tempo | Andante or Andante cantabile |
| Range | One octave; centered on middle register |
| Motion | Predominantly stepwise; one expressive leap per phrase |
| Dynamic | p to mp; never louder |
| Accompaniment | Simple chords or arpeggios; no competition |

## Phrase Structure

| Pattern | Context | Description |
|---------|---------|-------------|
| 4+4 (regular) | March, toccata | Square, mechanical; motoric |
| 4+4+8 (sentence) | Lyrical themes | Two short statements, one long response |
| 8+8 (period) | Ballet themes | Classical balance; Romeo and Juliet |
| Irregular (3+5, 5+3) | Grotesque passages | Asymmetric; lurching, off-balance |
| 2+2+2+2 (motoric cell) | Toccata, perpetuum mobile | Relentless repetition |

## Thematic Transformation

| Technique | Description | Where Used |
|-----------|-------------|-----------|
| Mode change | Major theme restated in minor (or reverse) | Symphony No. 5, Romeo and Juliet |
| Register shift | Theme moved up 2 octaves — becomes shrill | Scherzo movements |
| Rhythmic diminution | Theme at double speed — becomes motoric | Development sections |
| Grotesque distortion | Lyrical theme with "wrong" intervals added | Ballet character transformations |
| Orchestral recoloring | Same melody, different instrument = different character | *Peter and the Wolf* (each character = instrument) |
