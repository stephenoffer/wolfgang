# Composer Profile: Bela Bartok (1881–1945)

## Style Overview

| Element | Bartok's Approach |
|---------|-------------------|
| Harmonic language | Chromatic system rooted in folk modes |
| Melodic source | Hungarian, Romanian, Slovak, Bulgarian folk music |
| Structural principle | Symmetry: arch form, golden section, axis system |
| Rhythmic character | Bulgarian additive meters, folk dance patterns |
| Texture | Contrapuntal, often canonic; night music clusters |
| Orchestration | Percussion-influenced, transparent, virtuosic strings |
| Piano writing | Piano as percussion instrument |

## Folk Music Integration

### Collection and Transformation

| Approach | Description | Example |
|----------|-------------|---------|
| Direct quotation | Actual folk tune, harmonized | Romanian Folk Dances |
| Synthesized folk | New melody in folk idiom | Concerto for Orchestra |
| Abstracted folk | Folk intervals/modes, no melody | String Quartets 4-6 |
| Rhythmic borrowing | Bulgarian/Aksak rhythms used freely | SQ 5 Scherzo |
| Modal distillation | Folk modes become harmonic basis | Music for Strings |

## Symmetrical Structures

### Arch Form

| Work | Movement Layout | Symmetry Center |
|------|----------------|-----------------|
| String Quartet No. 4 | I=V, II=IV, III=center | III: Night Music |
| String Quartet No. 5 | I=V, II=IV, III=center | III: Scherzo alla bulgarese |
| Concerto for Orchestra | I=V, II=IV, III=center | III: Elegia |
| Music for Strings, Perc, Celesta | Fugue-Sonata-Adagio-Rondo | Palindromic fugue (Mvt I) |

### Golden Section Proportions

| Principle | Application |
|-----------|-------------|
| Climax placement | Main climax at ~0.618 of total duration |
| Section boundaries | Divisions follow Fibonacci ratios |
| Dynamic arch | Loudest point at golden ratio |
| MSPSC Mvt I | 89 bars, climax at bar 55 (Fibonacci) |

### Axis System (Erno Lendvai)

| Axis | Tonic (T) | Subdominant (S) | Dominant (D) |
|------|-----------|-----------------|--------------|
| Primary | C | F | G |
| Counterpole | F# | B | C# |
| Secondary | Eb/A | Ab/D | Bb/E |
| Relationship | Tritone-related keys are equivalent | Minor 3rd related are secondary |

```
Tonic axis:      C --- Eb --- F# --- A
Subdominant axis: F --- Ab --- B  --- D
Dominant axis:    G --- Bb --- C# --- E
```

## Chromatic System

| Technique | Description |
|-----------|-------------|
| Chromatic compression | Folk mode intervals compressed to semitones |
| Polymodal chromaticism | Two modes on same root, combined fill chromatic |
| Interval expansion | Motif gradually widens intervals |
| Wedge motion | Voices move outward/inward by semitone from center |
| Mirror writing | Melody + its inversion simultaneously |

## Night Music

| Characteristic | Description |
|---------------|-------------|
| Atmosphere | Nocturnal, mysterious, nature sounds |
| Texture | Sparse, pointillistic, whispered |
| Dynamics | pppp to pp, with sudden sf interruptions |
| Pitch content | Chromatic clusters, isolated notes, wide leaps |
| Timbre | Sul ponticello, harmonics, col legno |
| Program | Insect sounds, bird calls, night landscape |
| Works | SQ 3-5 slow movements, Out of Doors, Piano Concerto 3 |


## Key Orchestral Techniques

| Technique | Application |
|-----------|-------------|
| Divisi strings | Each desk on different pitch (cluster) |
| Percussion centrality | Timpani, xylophone, snare prominent |
| Celesta | Night music, ethereal color |
| Piano in orchestra | Percussive role, not Romantic soloist |
| String glissandi | Mass sliding, portamento effects |
| Brass chorale | Solemn, folk-hymn style |
| Fugal writing | Orchestral fugue (MSPSC Mvt I) |

## Style Markers for Generation

| Parameter | Early (to 1920) | Middle (1926-1939) | Late (1940-1945) |
|-----------|-----------------|-------------------|-------------------|
| Harmony | Folk modes, some tonal | Chromatic, axis system | Accessible, tonal return |
| Rhythm | Folk dance, regular | Bulgarian, complex | Moderate complexity |
| Texture | Homophonic, dance | Contrapuntal, night music | Clear, concerto-like |
| Form | Suite, short pieces | Arch form, concentrated | Concerto, classical forms |
| Expression | Folk, direct | Abstract, intense | Lyrical, nostalgic |
| Orchestration | Chamber, piano | String quartet, percussion | Full orchestra, brilliant |

## Compositional Fingerprints

| Fingerprint | Description |
|-------------|-------------|
| Folk + chromatic synthesis | Folk modes compressed into chromatic language |
| Symmetry obsession | Arch form, palindrome, golden section |
| Night music | Unique nocturnal texture type |
| Percussive piano | Keyboard as struck instrument |
| Bulgarian rhythm | Additive meters: 2+3, 3+2+3, 2+2+2+3 |
| Wedge/mirror | Expanding/contracting chromatic voice pairs |
| Interval cycles | Motifs based on repeating interval patterns |
| Nature imagery | Birds, insects, landscape in abstract music |
