# Bela Bartok — Melodic Style

Bartok's melodies come from the field. Thousands of hours recording peasant singers gave him a melodic vocabulary that is narrow in range, modal in pitch, and rhythmically free or asymmetrically patterned. These folk cells are not quoted — they are internalized and recomposed. The mature Bartok melody sounds like folk music but cannot be traced to any specific song. The folk language became his native tongue.

## Core Melodic Character

| Feature | Description | Where It Appears |
|---------|-------------|-----------------|
| Folk-derived cells | Pentatonic (C-D-F-G-A), modal (Lydian, Phrygian, Dorian) | All mature works |
| Narrow range | Melodies span a 4th, 5th, or at most an octave | Folk-character themes |
| Descending contour | Most folk melodies descend: high opening pitch falls to final | Concerto for Orchestra mvt 1, string quartets |
| Asymmetric phrase | 5-bar, 7-bar, or 9-bar phrases (not 4 or 8) | Throughout |
| Parlando-rubato | Free rhythmic delivery following speech inflection; no regular pulse | Slow movements, vocal works |
| Tempo giusto | Strict metric dance rhythm; the opposite of parlando | Fast movements, folk dances |
| Arch melody | Melody rises to a peak and descends symmetrically | Arch-form works; String Quartet No. 5 |

## Two Rhythmic Types

The fundamental duality of Hungarian and Romanian folk music, which Bartok maps onto all his work:

| Type | Rhythm | Character | Where It Appears |
|------|--------|-----------|-----------------|
| Parlando-rubato | Free, speech-like, no regular meter; pauses between phrases | Slow movements: laments, night music, contemplation |
| Tempo giusto | Strict, dance-like, asymmetric meter (5/8, 7/8); no rubato | Fast movements: folk dances, allegro barbaro, scherzi |

```abc
X:1
T:Parlando-Rubato — Free Folk Lament
M:none
L:1/8
K:Dm
%% No bar lines; speech rhythm; the melody follows the singer's breath
!p!D2 F3 E D2|A,3 C2 D4||F2 E D2 A,4||
%% Irregular groupings, pauses between phrases — this is not "composed" rhythm
```

```abc
X:2
T:Tempo Giusto — Bulgarian Dance Rhythm (7/8)
M:7/8
L:1/8
K:Dm
%% Strict 7/8 (2+2+3); dance energy; percussive attack
!f!D2 E2 FGA|D2 E2 FGA|A2 G2 FED|D4 z2z|
%% Fixed meter, regular accent — the opposite of parlando
```

## Melodic Intervals — Signature Shapes

| Interval | Frequency | Expressive Use | Source |
|----------|-----------|---------------|--------|
| Major 2nd | Very common | Primary stepwise motion; folk melody DNA | Pentatonic scale |
| Minor 3rd | Very common | Pentatonic; the "folk" interval | Hungarian folk |
| Perfect 4th | Common | Open, call-like; rising 4th = folk exclamation | All folk traditions |
| Perfect 5th | Common | Structural; framing interval of pentatonic cell | Open strings; folk |
| Minor 2nd | Moderate | Chromatic inflection; lament character | Romanian/Balkan folk |
| Tritone | Moderate | Axis-system structural; tension without resolution | Mature harmonic language |
| Augmented 2nd | Moderate | Hungarian "gypsy" scale; exotic color | Magyar folk; used sparingly |
| Major 7th / minor 9th | Rare | Extreme tension; night music | Climaxes, expressionist passages |

## Folk Melody Construction Principles

| Principle | Description | Example |
|-----------|-------------|---------|
| Descending 4-line form | ABBA or ABCD; each line descends; final line lowest | Hungarian folk song standard |
| Pentatonic transposition | Line 1 at pitch level X; Line 3 a 5th lower | Ancient pentatonic folk structure |
| Narrow ambitus | Each line spans a 4th or 5th maximum | Concentrated expression |
| Final note = lowest | The melody "sinks" to its conclusion | Gravitational pull downward |
| Ornamental variation | Repeated lines vary by adding grace notes, changing rhythm | Not structural variation — surface decoration |

```abc
X:3
T:Hungarian Folk Melody Structure — 4-Line Descending
M:2/4
L:1/8
K:Am
%% Line A (high): pentatonic
!mf!A2 c2|d2 c2|A2 G2|E4|
%% Line B (middle):
F2 A2|c2 A2|G2 E2|D4|
%% Line A' (high, varied):
A2 c2|d2 cB|A2 G2|E4|
%% Line C (lowest — final descent):
D2 E2|G2 E2|D2 C2|A,4|
```

## Arch Melody

In arch-form works, the melody itself arches: rising from a low starting point to a peak, then descending symmetrically. The melodic contour mirrors the formal structure.

| Element | Description |
|---------|-------------|
| Opening | Low register, quiet, narrow intervals |
| Ascending phase | Wider intervals, rising register, increasing dynamics |
| Peak | Highest pitch, maximum dynamic, widest interval |
| Descending phase | Mirror of ascending; narrowing intervals, falling register |
| Close | Returns to opening register and dynamic |

```abc
X:4
T:Arch Melody — Rise and Symmetrical Descent
M:4/4
L:1/8
K:Dm
%% Ascending phase:
!p!D2 F2 A2 c2|!mf!d2 f2 a2 c'2|
%% Peak:
!ff!d'4 c'2 a2|
%% Descending phase (mirror):
!mf!f2 d2 c2 A2|!p!F2 D2 A,2 D,2|
%% The contour is a palindrome — up then down symmetrically
```

## Melodic Transformation Techniques

| Technique | How It Works | Where It Appears |
|-----------|-------------|-----------------|
| Inversion | Ascending intervals become descending (and vice versa) | Arch forms; fugue subjects (Music for Strings) |
| Retrograde | Melody played backwards | Music for Strings mvt 3 |
| Augmentation | Note values doubled; melody slows | Slow movements; thematic return |
| Diminution | Note values halved; melody speeds | Development sections; acceleration |
| Chromatic filling | Pentatonic cell expanded by adding chromatic passing tones | Movement from folk clarity to chromatic density |
| Modal transposition | Same melody in a different mode (Dorian becomes Phrygian) | Section contrasts within movements |

## Phrase Structure

| Pattern | Description | Frequency |
|---------|-------------|-----------|
| 5-bar phrase (4+1) | 4-bar core + 1-bar extension or coda | Very common in folk-derived passages |
| 7-bar phrase (4+3) | 4-bar core + 3-bar extension | Common |
| 4-line descending | ABBA or ABCD; each line a phrase; total = 16 bars | Hungarian folk song form |
| Asymmetric grouping | 3+2+3 or 2+3+2 within a phrase | Bulgarian rhythm sections |
| Elided phrase | New phrase begins on last note of previous | Development sections |
