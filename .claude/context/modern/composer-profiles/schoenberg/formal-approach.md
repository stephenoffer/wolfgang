# Arnold Schoenberg — Formal Approach

Schoenberg believed that the greatest formal principle in music is developing variation — a motif stated, then transformed through inversion, augmentation, fragmentation, and recombination to generate an entire movement. He inherited this from Brahms and applied it across all three periods. In the Late Romantic period, developing variation operates within sonata form. In the atonal period, it generates compressed miniatures. In the twelve-tone period, it combines with serial technique to inhabit classical formal containers.

## Core Formal Philosophy

| Principle | Description | Contrast with Stravinsky |
|-----------|-------------|--------------------------|
| Developing variation | A motif is continuously transformed; nothing is static | Stravinsky: repetition without development |
| Classical forms re-inhabited | Sonata, rondo, fugue, variation — used in all periods | Stravinsky: block form, ritual, no classical forms (Russian period) |
| Organic growth | Form grows from within, like a plant from a seed | Stravinsky: form is architectural, assembled from blocks |
| Motivic unity | Every element derives from a core motif (or row) | Stravinsky: contrasting blocks share nothing |
| Continuous development | Music never repeats literally; always transforming | Stravinsky: music repeats literally; ostinato |

## Form Types by Period

### Late Romantic: Large-Scale Tonal Forms

| Form | How Schoenberg Uses It | Where |
|------|----------------------|-------|
| Tone poem | Through-composed narrative; chromatic | Pelleas und Melisande, Verklarte Nacht |
| Sonata | Exposition-Development-Recapitulation; chromatic key relationships | Chamber Symphony No. 1 (single-movement sonata) |
| Rondo | Recurring theme with episodes | Gurrelieder sections |
| Passacaglia | Ground bass with variations | Pelleas sections |

```abc
X:1
T:Late Romantic Sonata — Chromatic Development (Chamber Symphony character)
M:4/4
L:1/8
K:C
%% Developing variation: motif (E-F-Ab) transformed through the passage
!f!E2 F2 _A2 G2|E _A G E F2 _A2|_A G E F _A G ^F E|
%% The 3-note cell E-F-Ab generates every melodic event through variation
```

### Atonal: Compressed Miniatures

| Form | Description | Where |
|------|-------------|-------|
| Aphorism | Complete movement in 10–30 seconds | Six Little Piano Pieces Op. 19 |
| Monodrama | Single continuous scene; through-composed | Erwartung (30 minutes, no repetition) |
| Melodrama | Sprechstimme + chamber ensemble; song cycles | Pierrot Lunaire (21 songs, 3 × 7) |
| Free form | No classical form; motivic coherence provides unity | Five Orchestral Pieces Op. 16 |

| Why compressed? | Explanation |
|----------------|-------------|
| No tonal architecture | Without key relationships, sonata form loses its harmonic logic |
| No repetition | Atonal language resists exact repetition (it would sound random, not structured) |
| Motivic density | Every note carries maximum information; nothing is filler |
| Expressionist intensity | Extreme psychological states cannot sustain for long |

```abc
X:2
T:Atonal Miniature — Complete in 8 Bars (Op. 19 No. 2 character)
M:3/4
L:1/8
K:C clef=treble
%% The entire piece: 8 bars of compressed motivic work
!pp!G2 _B ^F|z E _D2|^C z B, z|_E D _A z|
!p!^G z F2|_B,2 z E|C _D z ^F|G4 z2|
%% Complete: no development section because the piece IS development
```

### Twelve-Tone: Classical Forms with Serial Content

| Form | How the Row Inhabits It | Where |
|------|------------------------|-------|
| Sonata form | Exposition: P-0 and I-5; Development: row fragments and transformations; Recap: P-0 returns | String Quartet No. 4 |
| Suite (dance) | Gavotte, Musette, Intermezzo, Gigue — each using the row differently | Piano Suite Op. 25 |
| Variation | Theme = row; each variation = different row form (R, I, RI) or different harmonization | Variations for Orchestra Op. 31 |
| Concerto | Solo instrument presents row; orchestra develops; classical formal plan | Violin Concerto Op. 36 |
| Fugue | Subject = row; answer = transposed row; stretto, augmentation apply | Variations Op. 31 (finale) |

```abc
X:3
T:Twelve-Tone Sonata Exposition (String Quartet No. 4 character)
M:4/4
L:1/8
K:C clef=treble
V:1 name="Violin 1 (P-0)"
%% First theme: row in original form
!mf!D ^C A _B ^F _E E' C ^G B F _A|
V:2 name="Violin 2 (I-5)" clef=treble
%% Second theme: row inverted at the 5th
!mf!z4 z4|_A A ^C C' _E ^F _B D F E _G B|
%% Classical sonata layout: two themes, two row forms
```

## Developing Variation — The Fundamental Technique

| Stage | Description | Example (3-note cell: C-Db-F) |
|-------|-------------|-------------------------------|
| Statement | Motif stated plainly | C-Db-F |
| Inversion | Intervals flipped | C-B-G |
| Retrograde | Played backwards | F-Db-C |
| Augmentation | Note values doubled | C...Db...F (slower) |
| Diminution | Note values halved | CDbF (faster) |
| Intervallic expansion | Semitone → whole tone; P4 → P5 | C-D-G (expanded) |
| Fragmentation | Only part of the motif used | C-Db (just the first 2 notes) |
| Recombination | Fragments from different transformations joined | C-Db (original) + G (from inversion) |

## Proportional Balance

| Period | Movement Lengths | Principle |
|--------|-----------------|-----------|
| Late Romantic | 10–40 minutes per movement | Wagnerian scale; continuous |
| Atonal | 10 seconds – 30 minutes | Extreme range: aphorism to monodrama |
| Twelve-Tone | 3–15 minutes per movement | Classical proportions; balanced |

## Multi-Movement Architecture

| Work | Movements | Formal Plan |
|------|-----------|-------------|
| Verklarte Nacht | 1 movement (5 sections) | Tone poem: mirrors the poem's 5 stanzas |
| Pierrot Lunaire | 21 songs (3 × 7) | Symmetrical grouping; Pierrot themes cycle |
| Piano Suite Op. 25 | 6 movements | Dance suite: Prelude, Gavotte, Musette, Intermezzo, Menuett, Gigue |
| String Quartet No. 4 | 4 movements | Classical: Allegro (sonata) — Comodo — Largo — Allegro (rondo) |
| Violin Concerto | 3 movements | Classical: Poco allegro — Andante — Finale (Allegro) |

## How Form Serves Expression

| Formal Strategy | Expressive Effect |
|----------------|-----------------|
| Developing variation | Organic growth; the music is alive, always becoming |
| Compressed miniature | Intensity; nothing wasted; every note essential |
| Classical container + serial content | The familiar made strange; old forms with new language |
| Row completion as punctuation | Formal clarity within atonal landscape |
| Continuous development | Restlessness; the music never settles; Expressionist anxiety |
