# Arnold Schoenberg — Melodic Style

Schoenberg's melody evolves from Romantic lyricism through Expressionist fragmentation to twelve-tone rigor. The Late Romantic melodies are long, chromatic, Wagnerian arcs. The Atonal melodies are short, wide-leaping, psychologically charged fragments. The Twelve-Tone melodies are row statements — the fixed order of 12 pitches as a melodic line, with all the expressive possibilities that particular row design allows.

## Core Melodic Character by Period

| Feature | Late Romantic (1899–1908) | Atonal (1908–23) | Twelve-Tone (1923–51) |
|---------|--------------------------|-------------------|-----------------------|
| Source | Wagnerian lyricism + Brahmsian motifs | Expressionist impulse; psychological state | Tone row; fixed pitch order |
| Range | Wide (2 octaves+); long arcs | Very wide; extreme leaps | Row-determined; often wide |
| Contour | Arching, yearning, chromatic ascent | Angular, fragmented, disjunct | Row contour (designed for interest) |
| Phrase length | Long (8–16 bars); Romantic | Very short (1–4 bars); compressed | Row-length (12 pitches = 1 phrase) |
| Development | Brahmsian developing variation | Motivic cells, fragmented | Row transformation (P, R, I, RI) |
| Expression | Passionate, yearning | Extreme psychological states | Varied (from austere to lyrical) |

## Late Romantic Melody (1899–1908)

Long, chromatic, arching lines. The melody yearns chromatically upward, defers resolution, and eventually arrives — but the journey is the point.

| Technique | Description | Where |
|-----------|-------------|-------|
| Chromatic ascent | Melody rises by semitones: C-C#-D-D#-E | Verklarte Nacht opening |
| Deferred resolution | Melody approaches tonic but veers away | Gurrelieder |
| Wide arcs | Phrases span 2+ octaves | Pelleas und Melisande |
| Motivic transformation | Short motif (3–4 notes) developed through augmentation, inversion, sequence | Throughout |
| Expressive leaps | Ascending 6ths, 7ths — Romantic intensity | Verklarte Nacht climaxes |

```abc
X:1
T:Late Romantic Melody — Chromatic Yearning (Verklarte Nacht character)
M:4/4
L:1/8
K:Dm
%% Long, arching, chromatic — a Romantic melody at the breaking point
!p!D2 ^F2 A2 c2|^c2 d2 _e2 d2|^c2 c2 B2 _B2|A4 z4|
%% Chromatic passing tones (C#, Eb) stretch the tonal framework to its limit
```

## Atonal Melody (1908–1923)

Short, compressed, angular. Melodies leap across extreme intervals — minor 9ths, major 7ths — and are fragmented across registers. The effect is psychological intensity: the melody mirrors an unquiet mind.

| Technique | Description | Where |
|-----------|-------------|-------|
| Wide leaps | Minor 9th, major 7th, tritone as primary intervals | Op. 11, Op. 16 |
| Extreme compression | Entire phrase in 3–5 notes | Pierrot Lunaire songs |
| Register extremes | Notes jump from C2 to B5 and back | Five Orchestral Pieces |
| Sprechstimme | Speech-song: voice rises toward pitch, falls away | Pierrot Lunaire |
| Motivic cell | 3-note cell (e.g., semitone + tritone) as generating unit | Op. 11 opening |

```abc
X:2
T:Atonal Melody — Wide Leaps, Compressed (Pierrot Lunaire character)
M:3/4
L:1/8
K:C clef=treble
%% Extreme intervals: minor 9th, major 7th; no tonal reference
!p!C z _B' z|E, z ^G z|_D' z F z|B,2 z4|
%% Each interval is different; each note in a different register; 6 notes, 3 bars
```

### Sprechstimme

| Feature | Description |
|---------|-------------|
| Notation | Pitch notated with an 'x' through the stem |
| Performance | Voice rises toward notated pitch, then immediately falls away |
| Not singing | The pitch is approximate; the rhythm is exact |
| Not speaking | There is a melodic contour; it is not ordinary speech |
| Expression | The voice in extremis — between control and abandon |

```abc
X:3
T:Sprechstimme Melody — Between Speech and Song (Pierrot character)
M:3/4
L:1/8
K:C clef=treble
%% Notated pitches — in performance, these are approached and abandoned
!mp!E2 ^G _B|z ^C _E2|G,2 B ^D|z _A, C2|
%% Rhythm exact; pitch approximate; somewhere between singing and speaking
```

## Twelve-Tone Melody (1923–1951)

The row IS the melody. The composer designs a row with interesting intervallic relationships, and the row's fixed order generates all melodic material.

| Row Design Principle | Description | Melodic Effect |
|--------------------|-------------|---------------|
| Distinctive opening interval | First interval is memorable (m9, A4, P5) | Recognizable melodic identity |
| Internal motifs | Subgroups within the row form recognizable shapes | Motivic coherence |
| Intervallic variety | Each adjacent interval different | Maximally varied melody |
| Range planning | Row designed to span specific range | Controlled melodic contour |
| Combinatoriality | Row paired with its inversion to fill chromatic space | Harmonic density control |

```abc
X:4
T:Twelve-Tone Melody — Complete Row Statement (Op. 25 character)
M:4/4
L:1/8
K:C clef=treble
%% 12 pitches, each used once, in a fixed order
E F G _D|^G _E _A D|B ^F _B C|
%% The row has internal logic: semitone pairs (E-F, B-C), tritone (D-Ab)
```

### Row as Melodic Idea

| Strategy | Description | Where |
|----------|-------------|-------|
| Row as lyrical line | Row stated slowly, with rhythmic interest; sings | Violin Concerto slow movement |
| Row as angular gesture | Row stated rapidly, with wide leaps; aggressive | Piano Suite Op. 25, Gigue |
| Row fragmented | 3–4 notes of the row as a melodic cell; rest in harmony | Most twelve-tone works |
| Row as canon | Two voices stating the same row, staggered entry | String Quartet No. 4 |

## Melodic Intervals — Signature Shapes by Period

| Interval | Late Romantic | Atonal | Twelve-Tone |
|----------|--------------|--------|-------------|
| Minor 2nd | Chromatic passing; yearning | Primary intensity interval | Row-determined |
| Major 7th | Inverted minor 2nd; expressive leap | Signature atonal leap | Common in angular rows |
| Minor 9th | Extreme yearning (Romantic) | Extreme compression | Row-designed |
| Tritone | Harmonic tension (diminished) | Structural axis | Often in row design |
| Perfect 5th | Tonal reference (cadential) | Avoided (too tonal) | Acceptable in row |
| Octave | Melodic climax | Rare (too "simple") | Row-determined |

## Developing Variation

Schoenberg's fundamental compositional technique across ALL periods: a short motif is continuously varied through inversion, augmentation, diminution, retrograde, and intervallic expansion — producing organic growth from a single cell.

| Transformation | Description | Example |
|---------------|-------------|---------|
| Inversion | Intervals flipped (ascending 3rd → descending 3rd) | Universal |
| Augmentation | Note values doubled | Development sections |
| Diminution | Note values halved | Faster passages |
| Intervallic expansion | Same direction, larger intervals | Climactic moments |
| Retrograde | Motif played backwards | Twelve-tone period |
| Rhythmic variation | Same pitches, different rhythm | Throughout |

## Phrase Structure

| Period | Pattern | Description |
|--------|---------|-------------|
| Late Romantic | Irregular, long (8–16 bars) | Wagnerian "endless melody" |
| Atonal | Very short (1–4 bars); aphoristic | Compressed Expressionist fragments |
| Twelve-Tone | Row-length (12 pitches per phrase) | Phrase = row statement or segment |
