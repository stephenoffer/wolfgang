# Anton Webern — Melodic Style

Webern's melodies are not melodies in any traditional sense. They are constellations: individual pitch-points scattered across registers and timbres, connected by the listener's ear rather than by any single instrument's line. A "melody" might consist of one note in the flute (G5), one in the harp (Eb3), one in the violin (B4), one in the horn (D2) — separated by silences. The listener assembles the line. This is Klangfarbenmelodie (tone-color melody) taken to its extreme.

## Core Melodic Character by Period

| Feature | Early Tonal (1904–08) | Free Atonal (1908–24) | Serial (1924–43) |
|---------|----------------------|----------------------|-------------------|
| Source | Brahmsian motifs; tonal | Motivic cells; atonal | Twelve-tone row |
| Range | Moderate (octave) | Very wide (2+ octaves) | Extreme (3+ octaves) |
| Contour | Arching, directed | Angular, fragmented | Dispersed, pointillistic |
| Phrase length | 4–8 bars | 1–4 bars | Row-length (12 notes) |
| Continuity | Continuous line | Fragmented; rests between notes | Isolated tones; maximum fragmentation |
| Instrument | Single instrument plays the line | Line shared across instruments | Each note a different instrument |

## Klangfarbenmelodie — Melody Distributed Across Timbres

| Principle | Description |
|-----------|-------------|
| One note per instrument | Each instrument contributes 1–2 notes to the "melody" |
| The listener assembles | No single instrument plays the line; the ear connects the dots |
| Timbre as melodic parameter | The color of each note (flute vs. harp vs. muted trumpet) is part of the melody |
| Register as structural | Each note in a specific octave; the octave placement IS compositional |
| Silence between notes | Rest between each Klangfarbenmelodie note; the decay matters |

```abc
X:1
T:Klangfarbenmelodie — 6 Notes, 6 Instruments (Op. 10 character)
M:3/4
L:1/4
K:C clef=treble
%% Each note represents a different instrument:
%% Note 1 (Flute): G5; Note 2 (Harp): Eb3; Note 3 (Violin): B4
%% Note 4 (Horn): D2; Note 5 (Celesta): F#5; Note 6 (Muted Trumpet): A3
!ppp!G' z z|_E, z z|B z z|
!pp!D,, z z|^f' z z|A z z|
%% 6 notes, 6 bars — the melody exists only in the listener's perception
```

## Micro-Melodies

When Webern does write a melody in a single instrument, it is extremely short (3–6 notes), covers a wide range, and is immediately followed by silence.

| Feature | Description |
|---------|-------------|
| Length | 3–6 notes maximum before handing off or silence |
| Range | Wide: covers an octave or more in 3–6 notes |
| Intervals | Wide leaps: minor 9th, major 7th, tritone preferred |
| Articulation | Each note has a specific articulation (staccato, tenuto, accent) |
| Dynamic | Each note has its own dynamic (ppp, pp, sfz, etc.) |

```abc
X:2
T:Micro-Melody — Single Instrument, 5 Notes (Op. 9 character)
M:3/4
L:1/8
K:C clef=treble
%% 5 notes, each with different articulation and dynamic
!ppp!.B, z !pp!^G2|z !sfz!_E z !ppp!c|z z z z z z|
%% 5 notes spanning 2+ octaves; then silence; each note a separate event
```

## Register Leaps

Webern's melodies leap across extreme intervals as a fundamental technique — not for expressive climax (as in Romantic music) but as the normal mode of melodic motion.

| Leap Type | Interval | Frequency | Character |
|-----------|----------|-----------|-----------|
| Minor 9th | Octave + semitone | Very common | The Webern interval: compressed octave |
| Major 7th | Just below octave | Very common | Tension, near-resolution |
| Tritone | 6 semitones | Common | Axis of symmetry |
| Minor 6th / Major 6th | 8–9 semitones | Common | Wider; moderate tension |
| Perfect 4th / 5th | 5–7 semitones | Less common | "Too tonal" — used structurally |
| Minor 2nd | 1 semitone | In context | The smallest: concentrated |

```abc
X:3
T:Register Leaps — Wide Intervals as Normal Melodic Motion
M:4/4
L:1/8
K:C clef=treble
%% Minor 9th (B3 to C5), Major 7th (E2 to Eb3), Tritone (F#4 to C5)
!pp!B, z c' z|E,, z _E z|^F z c' z|
%% Every leap crosses at least an octave — this is standard Webern motion
```

## Row as Melody

In serial works, the twelve-tone row IS the melody. But Webern distributes the row across registers so widely that the "melody" becomes a spatial object, not a linear one.

| Strategy | Description | Where |
|----------|-------------|-------|
| Row in a single voice | All 12 pitches in one instrument, widely spaced | Piano Variations Op. 27 |
| Row distributed | Row pitches shared across 3–6 instruments | Symphony Op. 21, Concerto Op. 24 |
| Row as canon | Two voices stating the same row in staggered entries | Symphony Op. 21 (double canon) |
| Row fragments | 3–4 note segments as melodic cells | Throughout serial works |

```abc
X:4
T:Row Melody — Distributed and Wide-Spaced (Op. 21 character)
M:4/4
L:1/8
K:C clef=treble
%% 12 row pitches spread across 3 octaves; each in a different register
!ppp!^F z B,, z|_E' z G z|_A, z D z|^C' z F, z|A z _B z|E z C, z|
%% All 12 pitches; row completed; each in its own registral space
```

## Silence as Melodic Element

In Webern, silence between notes is as composed as the notes themselves. The rest is not a gap — it is the space in which the previous note resonates and dies, and the space in which the listener anticipates the next.

| Silence Type | Duration | Function |
|-------------|----------|----------|
| Inter-note rest | 1–4 beats | Each note resonates in silence before the next |
| Inter-phrase silence | 2–8 beats (or more) | Formal articulation; the phrase boundary |
| Structural silence | Multiple bars of rest in all instruments | The largest formal event: total silence |

## Phrase Structure

| Pattern | Period | Description |
|---------|--------|-------------|
| 3–6 notes, then silence | Free atonal | Aphoristic; complete thoughts in 3–6 notes |
| Row statement (12 notes) | Serial | One row = one phrase; phrase boundary = row completion |
| Canon entry | Serial | Two phrases overlapping; the canonic subject |
| Palindrome phrase | Serial | Second half mirrors first: A-B-C-C-B-A |

## Melodic Expression

| Quality | Description |
|---------|-------------|
| Not cold | Despite the abstraction, Webern's melodies have tenderness ("zart") |
| Not dramatic | No Romantic emotional surges; expression is contained, distilled |
| Luminous | The isolation of each note gives it a glowing quality |
| Fragile | The music sounds as if it might break if played too loudly |
| Natural | Webern compared his music to alpine flowers — small, perfect, alive |
