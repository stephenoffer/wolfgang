# Composer Profile: Igor Stravinsky (1882–1971)

## Period Overview

| Period | Years | Key Works | Harmonic Language |
|--------|-------|-----------|-------------------|
| Russian | 1908-1919 | Firebird, Petrushka, Rite of Spring | Folk modes, polytonality, octatonic |
| Neo-Classical | 1920-1954 | Pulcinella, Symphony of Psalms, Rake's Progress | Diatonic dissonance, pandiatonic |
| Serial | 1954-1968 | Agon, Threni, Requiem Canticles | Personal 12-tone, rotational arrays |

## Russian Period (1908–1919)

### Rhythmic Complexity

| Technique | Description | Example |
|-----------|-------------|---------|
| Additive rhythm | Irregular groupings: 2+3, 3+2+2 | Rite: Danse sacrale |
| Metric displacement | Accents shift against barline | Rite: Augures printaniers |
| Polyrhythm | Multiple rhythmic layers independent | Petrushka: Shrovetide Fair |
| Ostinato layers | Stacked repeating patterns, different lengths | Rite: Introduction |
| Irregular meter | Rapid meter changes: 5/8, 7/8, 3/16 | Rite: Glorification of Chosen |
| Stamping chords | Repeated chord with irregular accents | Rite: Augures printaniers |

```abc
X:1
T:Rite of Spring - Stamping Chords (reduction)
M:2/4
L:1/8
K:Eb
"^Irregular accents"!>![E_Bc]!>![E_Bc] [E_Bc][E_Bc] | [E_Bc]!>![E_Bc] [E_Bc]!>![E_Bc] |
!>![E_Bc] [E_Bc]!>![E_Bc] [E_Bc] | !>![E_Bc]!>![E_Bc]!>![E_Bc] [E_Bc] |
```

### Folk Modes and Scales

| Scale | Usage | Work |
|-------|-------|------|
| Octatonic (Mode 2) | Primary harmonic source | All Russian works |
| Dorian on various roots | Folk melody basis | Petrushka, Firebird |
| Phrygian | Dark folk color | Rite of Spring |
| Whole-tone fragments | Transitional passages | Firebird |
| Synthetic folk modes | Combining fragments | Rite, Les Noces |

### Ostinato Technique

| Layer Strategy | Description |
|----------------|-------------|
| Length variation | Ostinato layers of different bar lengths (3 vs 4 vs 5) |
| Pitch stasis | Ostinato stays fixed while harmony changes above |
| Accumulation | Layers added one at a time |
| Subtraction | Layers removed to thin texture |
| Collision | Two ostinati create unpredictable combined rhythm |

```abc

L:1/8

```

## Neo-Classical Period (1920–1954)

### Harmonic Techniques

| Technique | Description | Example |
|-----------|-------------|---------|
| Diatonic dissonance | Added tones to triads, no resolution needed | Pulcinella |
| Pandiatonicism | Free white-note combinations | Symphony in C |
| Wrong-note approach | Expected note shifted by semitone | Pulcinella |
| Polarity | Tonal center asserted by emphasis, not function | Symphony of Psalms |
| Superimposed triads | C major + E major simultaneously | Petrushka chord legacy |
| Octatonic-diatonic mix | Sections alternate between the two | Concerto for Piano |

```abc
X:4
T:Neo-Classical Theme (Pulcinella-style)
M:3/4
L:1/8
K:C
"^Clean melody"E2 DC BA | G2 FE DC | E2 GA Bc |
"^'Wrong' note"d2 ^ce dB |
```

### Motor Rhythm

| Feature | Description |
|---------|-------------|
| Steady pulse | Driving eighth or sixteenth notes |
| Irregular accent | Stress patterns shift within steady stream |
| Ostinato bass | Repetitive bass drives motion |
| Mechanical quality | Anti-Romantic, objective |
| Concerto-like brilliance | Piano, violin writing virtuosic but dry |

```abc
X:5
T:Motor Rhythm (Neo-Classical Stravinsky)
M:4/4
L:1/16
K:D
"^Driving 16ths"DEFE DEFE DEFE DEFE | ^CDFE ^CDFE ABED ^CDFE |
```

### Key Neo-Classical Works Structure

| Work | Form | Key Features |
|------|------|-------------|
| Pulcinella (1920) | Suite from Pergolesi | Baroque forms + modern harmony |
| Octet (1923) | Sonata allegro, Theme+Var, Fugal | Wind-only, contrapuntal |
| Symphony of Psalms (1930) | 3 movements: Prelude, Fugue, Psalm | Archaic + modern, no violins |
| Dumbarton Oaks (1938) | Concerto grosso | Brandenburg Concerto model |
| Symphony in C (1940) | 4 movements, classical layout | Beethoven/Haydn reinterpreted |
| Rake's Progress (1951) | Number opera, recit+aria | Mozart/Handel model |

## Serial Period (1954–1968)

### Stravinsky's Serial Method

| Feature | Description | Difference from Schoenberg |
|---------|-------------|---------------------------|
| Short rows | Often 5-8 note rows, not always 12 | Schoenberg always 12 |
| Rotational arrays | Row rotated and transposed systematically | Unique to Stravinsky |
| Vertical aggregates | Row segments stacked as chords | More harmonic focus |
| Hexachordal | Rows often split into hexachords | Influenced by Krenek/Babbitt |
| Rhythmic independence | Rhythm not serialized | Boulez serialized rhythm |
| Tonal residues | Row chosen for diatonic implications | Schoenberg avoided tonality |

```abc
X:6
T:Serial Period Theme (Agon-like, short row)
M:3/4
L:1/8
K:C
"^5-note row"C ^D G _A E | z2 "^Retrograde"E _A G ^D C |
```

## Orchestral Innovations

| Innovation | Description | Work |
|-----------|-------------|------|
| Anti-blending | Instruments in raw, exposed registers | All periods |
| Stratification | Independent layers, not blended | Rite of Spring |
| Bright, dry timbre | Preference for winds over strings | Neo-classical period |
| Extreme register | Bassoon opens Rite at very top of range | Rite of Spring |
| Antiphonal | Groups answer each other | Symphonies of Winds |
| Piano as percussion | Dry, staccato keyboard writing | Petrushka, Movements |
| No vibrato strings | Objective, non-expressive | Later works |
| Rhythmic unison | Full orchestra on same rhythm, different pitches | Rite, Symphony in 3 |

### Stravinsky's Preferred Orchestral Colors

| Combination | Character | Period |
|-------------|-----------|--------|
| Bassoon high + clarinets low | Dark, inverted | Russian |
| Trumpets + piano | Brilliant, percussive | Neo-classical |
| Solo strings without vibrato | Dry, exposed | Serial |
| Horn + English horn unison | Warm, pastoral | Neo-classical |
| Muted brass + woodwind staccato | Mechanical, witty | Neo-classical |
| Pizzicato strings + xylophone | Percussive, bright | All periods |

## Rhythmic Technique Summary

| Technique | Mechanism | Effect |
|-----------|-----------|--------|
| Syncopation of accent | Accent moves, pulse stays | Unpredictable energy |
| Added-value rhythm | Extra beat added to regular pattern | Asymmetry |
| Rhythmic cells | Short patterns repeated/varied | Building blocks |
| Polymetric ostinato | Two+ patterns in different meters | Complex texture |
| Metric modulation | Subdivision becomes new pulse | Tempo shift |
| Rhythmic canon | Same rhythm, staggered entries | Mechanical interlock |

```abc
X:7
T:Added-Value Rhythm
M:7/8
L:1/8
K:C
"^3+2+2"CDE FG AB | "^2+3+2"CD EFG AB | "^2+2+3"CD EF GAB |
```

## Style Markers for Generation

| Parameter | Russian | Neo-Classical | Serial |
|-----------|---------|---------------|--------|
| Harmony | Octatonic, bitonal | Pandiatonic, diatonic diss. | Row-derived |
| Rhythm | Irregular, additive | Motor rhythm, steady | Free, pointillistic |
| Texture | Layered ostinati | Contrapuntal, clear | Sparse, abstract |
| Form | Through-composed, block | Classical models | Short, concentrated |
| Orchestration | Full orchestra, extreme | Chamber, winds favored | Small ensemble |
| Melody | Folk-derived, modal | Diatonic, "wrong-note" | Intervallic, angular |
| Dynamics | Terraced, sudden changes | Moderate, classical | Wide range, precise |
| Expression | Primitive, ritualistic | Objective, witty | Abstract, crystalline |

## Key Compositional Fingerprints

| Fingerprint | All Periods |
|-------------|-------------|
| Repetition as structure | Ostinato/motor rhythm, not development |
| Anti-expression | Avoids Romantic sentiment |
| Clarity of line | Individual voices audible |
| Rhythmic primacy | Rhythm drives structure more than harmony |
| Block juxtaposition | Sections placed side by side, not transitioned |
| Octave displacement | Melodies displaced across octaves for color |
| Dry articulation | Staccato, marcato preferred over legato |
