# Igor Stravinsky — Melodic Style

Stravinsky's melodies are not Romantic singing lines — they are cells, fragments, objects. In the Russian period, melody derives from folk song: short, repetitive, pentatonic, confined to a narrow range. In the Neo-Classical period, melody is diatonic and Baroque-gestured but rhythmically displaced. In the serial period, melody dissolves into row statements. What connects all periods: melody is material to be placed, repeated, and juxtaposed — never developed in the Beethovenian sense.

## Core Melodic Character by Period

| Feature | Russian (1910–20) | Neo-Classical (1920–51) | Serial (1953–66) |
|---------|-------------------|-------------------------|-------------------|
| Source | Folk song, ritual chant | Baroque/Classical gesture | Tone row |
| Range | Narrow (4th–5th) | Moderate (octave) | Wide (row determines) |
| Contour | Circular, descending, repetitive | Arched, stepwise, scalic | Angular, disjunct, pointillistic |
| Phrase length | Irregular (3, 5, 7 bars) | Regular with displaced accents | Free; determined by row completion |
| Development | None — repetition and juxtaposition | Baroque sequence, variation | Row transformation (R, I, RI) |
| Expression | Impersonal, ritualistic | Ironic, witty, dry | Austere, liturgical |

## Russian Period — Folk-Derived Melody

| Technique | Description | Where It Appears |
|-----------|-------------|-----------------|
| Narrow-range cell | Melody confined to a 4th or 5th; 3–5 pitches | Rite of Spring opening bassoon solo (C#-D-E-D-C#) |
| Circular repetition | The same melodic cell repeats with minimal variation | Les Noces, Petrushka folk scenes |
| Pentatonic basis | Melody from {C, D, F, G, A} or transposition; no semitones | Firebird Berceuse, folk dances |
| Additive rhythm | Phrase lengths change by adding or subtracting one note | Rite of Spring "Augurs of Spring" melody |
| No countermelody | Melody is a single line; accompaniment is ostinato, not counterpoint | All Russian-period works |

```abc
X:1
T:Russian Period — Narrow Folk Cell (Rite of Spring character)
M:4/4
L:1/8
K:Dm
%% Bassoon-register melody: 5 pitches, narrow range, circular
!p!D2 EF ED C2|D2 EF E2 D2|D2 EF ED C2|D4 z4|
%% The cell D-E-F-E-D-C repeats with additive variation — never develops
```

```abc
X:2
T:Russian Period — Pentatonic Ritual Melody
M:7/8
L:1/8
K:C
%% Pentatonic: C-D-F-G-A only; 7/8 asymmetric; incantatory
!f!C2 D2 F2 G|A2 G2 F D2|C2 D2 F G2|A4 G2 F|
%% No semitones, no leading tones — the melody is modal, not tonal
```

## Neo-Classical Period — Displaced Diatonic Melody

| Technique | Description | Where It Appears |
|-----------|-------------|-----------------|
| Scalic runs | Diatonic scales as melodic material (C-D-E-F-G-A-B) | Octet, Symphony in C |
| Accent displacement | Melody accents fall off the beat; the "wrong" note is stressed | Throughout Neo-Classical works |
| Baroque gesture | Sequences, turns, mordents — 18th-century vocabulary | Pulcinella, Dumbarton Oaks |
| Ironic quotation | A "Classical" melody that is too perfect — the perfection is the joke | The Rake's Progress arias |
| Ostinato melody | A melody that functions as an ostinato — endlessly repeating without variation | Symphony of Psalms fugue subject |

```abc
X:3
T:Neo-Classical — Displaced Diatonic Melody (Octet character)
M:2/4
L:1/16
K:Bb
%% Scalic, Baroque-gestured, but the accent lands on beat 2
B,CDE !sfz!F2GA|!sfz!B2AG FEDC|B,CDE F2z2|
%% The sfz on F (beat 2) and B (beat 1 of bar 2) creates asymmetric accent
```

## Serial Period — Row-Based Melody

| Technique | Description | Where It Appears |
|-----------|-------------|-----------------|
| Row as melody | The 12-tone row stated as a linear melody | Threni, Movements |
| Partial rows | 5- or 6-note row segments used as melodic cells | Agon, Canticum Sacrum |
| Pointillistic distribution | Row notes distributed across instruments — no single instrument plays the "melody" | Movements for Piano and Orchestra |
| Chant-like declamation | Vocal lines that follow speech rhythm on row pitches | Threni, Requiem Canticles |

```abc
X:4
T:Serial Period — Sparse Row Statement (Requiem Canticles character)
M:4/4
L:1/4
K:C clef=treble
%% Each note isolated; wide intervals; many rests
!pp!C z _E z|^F z A z|_B z D z|
%% 6 notes of a row, each separated by silence — ritualistic, austere
```

## Melodic Intervals — Signature Shapes

| Interval | Russian Period | Neo-Classical | Serial |
|----------|---------------|---------------|--------|
| Minor 2nd | Avoided in melody | Common (chromatic neighbor) | Row-determined |
| Major 2nd | Primary melodic interval | Scalic motion | Row-determined |
| Minor 3rd | Folk character | Sequence steps | Common (octatonic) |
| Perfect 4th | Folk call, horn-like | Baroque gesture | Common (quartal) |
| Tritone | Structural (C-F#) | Cadential irony | Row-determined |
| Octave | Avoided (too Romantic) | Avoided (too expressive) | Occasional wide leap |

## Melodic Rhythm

| Principle | Description | All Periods |
|-----------|-------------|-------------|
| Rhythm drives melody | The rhythm is composed first; pitches fill the rhythmic pattern | Yes — Stravinsky's most fundamental principle |
| Additive process | Phrases grow by adding or subtracting one value (3+3+3 becomes 3+3+3+2) | Russian and Neo-Classical |
| No rubato | Melody is metronomic; expression comes from accent, not tempo change | All periods — anti-Romantic |
| Changing meter | Bar lengths change to follow the melodic accent | Russian period primarily |

## Phrase Structure

| Pattern | Period | Description |
|---------|--------|-------------|
| 3+3+2 or 2+3+2 | Russian | Asymmetric cells, additive |
| 4+4 with displaced accent | Neo-Classical | Regular length, irregular stress |
| Row-length phrase | Serial | Phrase = one row statement (or segment) |
| No phrase elision | All | Phrases are blocks; they don't overlap or elide |
