# Igor Stravinsky — Formal Approach

Stravinsky does not develop — he juxtaposes. Where Beethoven builds a movement from a single seed through motivic development, Stravinsky places contrasting blocks side by side and lets the listener experience form as collision, ritual, or architectural proportion. In the Neo-Classical period he inhabits Classical forms but fills them with modern rhythmic energy. In the serial period, row completion and liturgical structure replace both block form and sonata form.

## Core Formal Philosophy

| Principle | Description | Contrast with Tradition |
|-----------|-------------|------------------------|
| Block form (Russian) | Distinct musical blocks juxtaposed without transition | Sonata form: themes develop and transform |
| Ritual structure (Russian) | Formal order determined by ceremony, not argument | Symphonic: form driven by dramatic logic |
| Baroque containers (Neo-Classical) | Fugue, passacaglia, ritornello used as formal shells | Romantic: through-composed or programmatic |
| Row-determined form (Serial) | Row statements, rotations, and transformations create formal sections | Classical: key relationships determine form |
| No transitions | Blocks end; new blocks begin. Hard cut, no preparation | Romantic: elaborate transitions between sections |
| Repetition, not development | Material returns unchanged or with surface variation only | Beethoven: material develops, transforms, grows |

## Form Types by Period

### Russian Period: Block Form

| Element | Description | Example |
|---------|-------------|---------|
| Block A | Self-contained musical unit: specific tempo, meter, key, texture | Rite: "Augurs of Spring" — rhythmic ostinato block |
| Block B | Contrasting unit: different everything | Rite: "Ritual of Abduction" — running folk melody |
| Juxtaposition | A ends, B begins — no transition, no modulation | The cut between blocks is instantaneous |
| Return | Block A returns unchanged (or minimally varied) | Petrushka: the fair scene returns literally |
| Accumulation | Within a block, layers are added over a fixed ostinato | Rite: layers accumulate over 16–32 bars |

```abc
X:1
T:Block Form — Two Blocks, Hard Cut
M:4/4
L:1/8
K:Dm
%% BLOCK A: slow ostinato, bass register, pp
!pp!D,2 A,2 D,2 A,2|D,2 A,2 D,2 A,2|
%% HARD CUT — no transition
K:C
M:7/8
%% BLOCK B: fast folk melody, treble, ff
!ff!c2d2 e2f|g2f2 e d2|c2d2 e2f|g4 e2f|
%% The two blocks share nothing — the contrast IS the form
```

### Russian Period: Ritual/Tableau Structure

| Structural Principle | Description |
|---------------------|-------------|
| Tableaux, not movements | Sections are scenes in a ritual, not parts of an argument |
| Predetermined order | The ritual determines the sequence; it is not "logical" but ceremonial |
| Cyclic return | Certain blocks recur at ritually appropriate moments |
| Climax as accumulation | The climax is not a dramatic resolution but maximum density |

| Work | Structure |
|------|-----------|
| Rite of Spring, Part I | Tableau 1–7: Introduction, Augurs, Ritual of Abduction, Spring Rounds, Games, Procession, Earth Dance |
| Rite of Spring, Part II | Tableau 1–6: Introduction, Mystic Circles, Glorification, Evocation, Ritual Action, Sacrificial Dance |
| Petrushka | 4 Tableaux: The Shrovetide Fair, Petrushka's Room, The Moor's Room, The Shrovetide Fair (evening) |

### Neo-Classical Period: Baroque/Classical Containers

| Form | How Stravinsky Uses It | What Makes It Stravinsky |
|------|----------------------|--------------------------|
| Fugue | Subject + answer at correct interval; stretto, augmentation | Rhythmic displacement; subject accents fall off the beat |
| Passacaglia | Repeating bass; upper voices vary freely | Harmony is "wrong" — added notes, displaced |
| Ritornello | Orchestral refrain alternates with solo episodes | Refrain is exactly repeated; no Baroque elaboration |
| Concerto grosso | Solo group vs. tutti alternation | Dry, non-vibrato; the contrast is timbral, not dynamic |
| Sonata form | Exposition, development, recapitulation present | Development is short; recapitulation compressed or literal |
| Variation | Theme + variations; each variation changes texture/key | No Romantic character-variation; each variation is dry, architectural |

```abc
X:2
T:Neo-Classical Fugue Subject — Rhythmically Displaced
M:4/4
L:1/16
K:C
%% The subject is "correct" Bach-style counterpoint — but accents are Stravinsky
z4 !mf!C2DE F2GA|!sfz!B2AG z4 F2ED|C8 z8|
%% sfz on B (weak beat) creates the Stravinsky displacement within Baroque form
```

### Serial Period: Row and Liturgical Structure

| Principle | Description |
|-----------|-------------|
| Row as formal unit | Each complete row statement = one formal phrase |
| Rotation | Rows rotated (starting on different pitch) create new sections |
| Canonic structure | Row stated in canon (2–4 voices, staggered entries) |
| Liturgical text | In vocal works, the liturgical form determines the musical form |
| Silence as structure | Long rests separate row statements; silence is a formal element |

## Proportional Balance

| Period | Section Lengths | Principle |
|--------|----------------|-----------|
| Russian | Blocks: 8–32 bars; irregular proportions | Block length determined by ritual function, not symmetry |
| Neo-Classical | Regular: 8+8, 16+16; Classical proportions | Baroque/Classical formal balance deliberately maintained |
| Serial | Variable; row-determined | Row length (12 notes) as basic unit; form follows row |

## Multi-Movement Architecture

| Work | Movements | Structure |
|------|-----------|-----------|
| Symphony of Psalms | 3 mvts | Prelude (E minor) — Double Fugue (C minor) — Hymn of Praise (C major) |
| Symphony in C | 4 mvts | Moderato — Larghetto — Allegretto — Largo-Tempo giusto |
| Symphony in Three Movements | 3 mvts | Overture (sonata) — Andante (song form) — Con moto (rondo) |
| Agon | 12 sections | Pas de quatre — Double pas — Triple pas — Coda (symmetrical dance structure) |

## How Form Serves Expression

| Formal Strategy | Emotional Effect |
|----------------|-----------------|
| Block juxtaposition | Shock, surprise, the unexpected — form as collision |
| Ostinato accumulation | Hypnosis, trance, ritual ecstasy — form as incantation |
| Baroque container | Irony, wit, detachment — form as commentary on form |
| Serial structure | Austerity, transcendence, impersonality — form as ritual |
| Repetition without development | Stasis, timelessness — the rejection of narrative |
