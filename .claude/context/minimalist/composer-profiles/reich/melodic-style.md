# Steve Reich — Melodic Style

## Core Principle: Melody Emerges from Process

Reich does not compose melodies — melodies emerge from the interaction of patterns. The "tune" is a perceptual artifact: the listener's ear picks out accented notes within a constant stream and hears them as a melody.

## Melodic Types

| Type | Description | Works |
|------|-------------|-------|
| Resultant melody | Melody perceived from interlocking accents | *Piano Phase*, *Electric Counterpoint* |
| Speech melody | Melodic contour extracted from recorded speech | *Different Trains*, *The Cave* |
| Canonic melody | Melody stated in canon with itself | *Tehillim*, *Proverb* |
| Pattern melody | Short repeated cell IS the melody | *Drumming*, *Clapping Music* |

## Resultant Melody

When two players perform interlocking rhythmic patterns, the listener's ear groups certain notes together and perceives a melody that neither player is playing:

| Player 1 accents | Player 2 accents | Resultant melody heard |
|------------------|------------------|----------------------|
| E . C . G . E . | . G . E . C . G | E-G-C-E-G-E-C-G (continuous) |

```abc
X:1
T:Resultant Melody from Interlocking Patterns
M:4/4
L:1/8
K:C
%%staves {1 2 3}
V:1 name="Player 1 (accented notes)"
E z C z G z E z |
V:2 name="Player 2 (accented notes)"
z G z E z C z G |
V:3 name="Resultant melody (what you hear)"
EG CE GC EG |
% Neither player plays the resultant melody — it emerges from their interaction
```

## Speech Melody

Reich transcribes the melodic contour of recorded speech and uses it as musical material:

| Step | Process |
|------|---------|
| 1 | Record spoken words/phrases |
| 2 | Identify the melodic contour (pitch rises and falls of speech) |
| 3 | Notate as specific pitches on the nearest scale degree |
| 4 | Instruments double the speech melody |
| 5 | Tape and instruments play together |

```abc
X:2
T:Speech Melody — Different Trains Style
M:4/4
L:1/8
K:Am
V:1 name="Viola (doubling speech)"
A2 B2 C2 A2 | G2 A2 B4 |
w:from Chi-ca-go to New York from Chi-ca-go
% The melodic contour follows the natural speech pattern
```

## Pattern as Melody

In percussive works, the rhythmic pattern itself IS the melody — no pitched content needed:

| Pattern | Rhythmic Profile | Work |
|---------|-----------------|------|
| 12-beat pattern | x.x.xx.x.x.. | *Clapping Music* |
| 8-beat drum pattern | x.xx.x.x | *Drumming* |
| 6-beat marimba cell | x.x.xx | Various |

```abc
X:3
T:Clapping Music Pattern (pitched version for reference)
M:12/8
L:1/8
K:C
%%staves {1 2}
V:1 name="Clapper 1 (fixed)"
CzCz CCzC zCzz | CzCz CCzC zCzz |
V:2 name="Clapper 2 (shifting)"
CzCz CCzC zCzz | zCzC zCCz CzCz |
% Same pattern; Clapper 2 shifts by one beat each cycle
```

## Canonic Melody (Tehillim and Later)

In *Tehillim* (1981), Reich introduces composed melody for the first time — but presents it in strict canon:

| Feature | Description |
|---------|-------------|
| Melody type | Modal, psalm-derived, Middle Eastern inflection |
| Presentation | Sung in canon at the unison (voices enter at different times) |
| Harmony | Created by the canon itself (not separately composed) |
| Text | Hebrew psalms (Tehillim = "praises") |
| Innovation | First "real" melody in Reich's output |

```abc
X:4
T:Canonic Melody — Tehillim Style
M:7/8
L:1/8
K:Dm
%%staves {1 2}
V:1 name="Voice 1"
D E F G A G F | D E F G A G F |
V:2 name="Voice 2 (enters 2 beats later)"
z2 D E F G A | G F D E F G A |
% The melody is simple — the interest is in how the two voices interact in canon
```

## Melodic Range and Register

| Instrument/Voice | Typical Range | Function |
|-----------------|---------------|----------|
| Piano/keyboard | C3–C6 | Pattern instrument; middle register |
| Marimba | C3–C6 | Pattern + resultant melody |
| Vibraphone | F3–F6 | Shimmering color; high register patterns |
| Violin/viola | G3–E5 | Speech melody doubling; pulsing patterns |
| Cello | C2–A3 | Bass patterns; low register grounding |
| Soprano voice | C4–A5 | Canonic melody; psalm singing |

**Key principle:** Melodic range is narrow within any single pattern (usually within an octave). The patterns live in a comfortable middle register. Extreme high or low notes are avoided.

## Rhythmic Character of Melody

| Feature | Description |
|---------|-------------|
| Note values | Constant: all eighths or all sixteenths |
| Accents | Selective accents within the stream create melody |
| Meter | Often asymmetric (7/8, 11/8) especially in late works |
| Syncopation | Created by phase offset, not composed |
| Rubato | Never — the pulse is metronomic |

## Melodic Development

| What Reich Does | What Reich Does NOT Do |
|----------------|----------------------|
| Repeat patterns exactly | Develop themes (fragmentation, inversion, augmentation) |
| Phase patterns against themselves | Vary the melody |
| Add/subtract notes from patterns | Create contrasting melodies |
| Change the timbral presentation | Add ornaments or embellishments |
| Layer patterns for emergent melody | Write countermelody |
