# Steve Reich — Stylistic Evolution

## Four Periods Overview

| Period | Years | Core Technique | Emotional Character |
|--------|-------|---------------|---------------------|
| Tape/early phase | 1965–1971 | Tape loops, live phasing | Experimental, austere |
| Phase/percussion | 1971–1976 | Large percussion ensemble, phasing | Kinetic, propulsive, communal |
| Large ensemble | 1976–1988 | Pulsing chords, rich harmony, melody enters | Expansive, warm, hypnotic |
| Late documentary/orchestral | 1988–present | Speech sampling, orchestra, video opera | Reflective, narrative, darker |

## Period 1: Tape and Early Phase (1965–1971)

### Characteristics

| Feature | Description |
|---------|-------------|
| Medium | Tape manipulation; electronic; live performance of tape-derived ideas |
| Technique | Two identical tape loops gradually drifting apart |
| Harmony | None (speech sounds) or one chord (instrumental) |
| Melody | None — process creates all audible patterns |
| Forces | Tape recorders; then 2 pianos or 2 violins |
| Duration | 10–25 min per piece |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| *It's Gonna Rain* | 1965 | Discovery of phasing via tape loops |
| *Come Out* | 1966 | Speech phasing refined; stereo separation |
| *Piano Phase* | 1967 | First live-performance phasing |
| *Violin Phase* | 1967 | Phasing with sustained tones |
| *Pendulum Music* | 1968 | Microphones as pendulums; sound installation |
| *Four Organs* | 1970 | Gradual augmentation of a single chord |

```abc
X:1
T:Early Phase Period — Piano Phase Style
M:4/4
L:1/8
K:C
%%staves {1 2}
V:1 name="Piano 1 (fixed tempo)"
ECGC EGCE | ECGC EGCE |
V:2 name="Piano 2 (gradually faster)"
ECGC EGCE | ECGC EGCE |
% Two identical patterns — one begins to drift ahead, creating new rhythmic combinations
```

## Period 2: Phase and Percussion (1971–1976)

### The Shift

| From (Period 1) | To (Period 2) |
|-----------------|---------------|
| Tape or 2 players | 4–12 live percussionists |
| Pure phasing | Gradual addition + substitution + phasing |
| Electronic/acoustic split | Fully acoustic |
| Austere | Kinetic, energetic, warm |
| Short works | Long works (60–90 min) |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| *Drumming* | 1971 | 90 min; 4 sections; bongos → marimbas → glockenspiels → all |
| *Clapping Music* | 1972 | Two hand-clappers; no instruments; pure rhythm |
| *Music for Mallet Instruments, Voices and Organ* | 1973 | Combines mallet percussion with voices and organ |
| *Six Pianos* | 1973 | Interlocking patterns across 6 pianos |
| *Music for Pieces of Wood* | 1973 | 5 pairs of tuned claves; rhythmic building |

### African Influence (Ghana, 1970)

| Ewe Drumming Element | Reich Equivalent |
|---------------------|------------------|
| Master drummer as conductor | Cue patterns for section changes |
| Interlocking drum parts (kagan, kidi, sogo) | Interlocking mallet/piano patterns |
| Bell pattern (timeline) | Fixed rhythmic pattern as structural anchor |
| Polyrhythm (3 against 2, etc.) | Multiple pattern speeds simultaneously |
| Call-and-response | Gradual addition process |

```abc
X:2
T:African-Influenced Interlocking (Drumming style)
M:12/8
L:1/8
K:C
%%staves {1 2 3}
V:1 name="Pattern 1 (bell timeline)"
C z C z z C z C z z C z |
V:2 name="Pattern 2 (interlocking)"
z C z C C z C z C C z C |
V:3 name="Pattern 3 (counter-rhythm)"
z z C z C z z C z C z z |
% Three interlocking patterns that together fill all rhythmic positions
```

## Period 3: Large Ensemble (1976–1988)

### The Shift

| From (Period 2) | To (Period 3) |
|-----------------|---------------|
| Percussion-dominated | Mixed ensemble (keyboard, strings, winds, voices) |
| One chord throughout | Multiple chords; pulsing chord progressions |
| No melody | Melody enters (Tehillim, 1981) |
| Rhythmic process only | Harmonic richness added |
| 4–12 players | 18–30 players |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| *Music for 18 Musicians* | 1976 | 11 pulsing chords; arch form; 55 min; breakthrough |
| *Octet / Eight Lines* | 1979 | Strings enter Reich's ensemble |
| *Tehillim* | 1981 | Hebrew psalm setting; first composed melody |
| *The Desert Music* | 1984 | Orchestra + chorus; William Carlos Williams text |
| *Sextet* | 1985 | Percussion + keyboards; movement structure |
| *Electric Counterpoint* | 1987 | Electric guitar + pre-recorded canons |

```abc
X:3
T:Large Ensemble Period — Music for 18 Musicians Style
M:4/4
L:1/8
K:D
%%staves {1 2 3}
V:1 name="Voices (pulsing)"
[DF#A]2 [DF#A]2 [DF#A]2 [DF#A]2 |
V:2 name="Marimbas (pattern)"
D F# A D z F# A z |
V:3 name="Bass clarinet (cue)"
z8 |
% Rich pulsing texture — warmer, more harmonic than earlier works
```

## Period 4: Late Documentary and Orchestral (1988–present)

### The Shift

| From (Period 3) | To (Period 4) |
|-----------------|---------------|
| Process-driven form | Speech/documentary-driven form |
| Abstract pattern music | Narrative content (Holocaust, technology, terrorism) |
| Diatonic purity | Wider harmonic palette; occasional chromaticism |
| Large live ensemble | String quartet + tape; video opera; orchestra |
| Process as content | Process as backdrop for meaning |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| *Different Trains* | 1988 | String quartet + recorded speech + train sounds; Holocaust |
| *The Cave* | 1993 | Video opera; interview-based; Abraham/Ibrahim story |
| *City Life* | 1995 | Urban sound sampling + ensemble |
| *Three Tales* | 2002 | Video opera on technology (Hindenburg, Bikini, Dolly) |
| *Daniel Variations* | 2006 | Response to Daniel Pearl murder |
| *Radio Rewrite* | 2012 | Radiohead melodies as source material |
| *Runner* | 2016 | Late orchestral; most traditionally "classical" |
| *Music for Ensemble and Orchestra* | 2018 | First true orchestral work |

```abc
X:4
T:Late Period — Different Trains Style
M:4/4
L:1/8
K:Am
%%staves {1 2 3}
V:1 name="Vln 1 (speech melody)"
A2 B2 c2 A2 |
V:2 name="Vln 2 (pulsing)"
[AC] [AC] [AC] [AC] [AC] [AC] [AC] [AC] |
V:3 name="Vc (pedal)"
A,8 |
% String quartet + recorded speech — narrative enters Reich's world
```

## Evolution Comparison Table

| Parameter | Period 1 (1965–71) | Period 2 (1971–76) | Period 3 (1976–88) | Period 4 (1988+) |
|-----------|-------------------|-------------------|-------------------|-----------------|
| Harmony | One chord or none | One chord | Multiple chords | Richer, occasional chromatic |
| Melody | None | None (rhythm only) | Enters (Tehillim) | Speech melody; more lyrical |
| Forces | Tape, 2 players | 4–12 percussionists | 18–30 players | Quartet+tape, orchestra |
| Process | Phasing (audible) | Gradual addition | Pulsing chords | Process as backdrop |
| Content | Abstract | Abstract | Abstract + Hebrew text | Narrative, documentary |
| Dynamics | mp | mp–mf | p–f | pp–f |
| Duration | 10–25 min | 20–90 min | 20–60 min | 15–55 min |

## Constants Across All Periods

| Constant | Description |
|----------|-------------|
| Steady pulse | Never rubato; metronomic precision |
| Gradual process | Changes happen slowly, perceptibly |
| Diatonic foundation | Even late chromaticism is grounded in diatonicism |
| Interlocking parts | No solos; ensemble interdependence |
| Repetition | Central to all works in all periods |
