# Reich Composer Profile

## Phase Shifting

| Element | Description |
|---------|-------------|
| Principle | Two identical patterns gradually desynchronize |
| Method | One performer imperceptibly accelerates |
| Positions | Each offset = new composite pattern |
| Full cycle | All positions explored, return to unison |
| Resultant patterns | New melodies emerge from overlap |
| Key works | Piano Phase, Violin Phase, Clapping Music |

### Phase Shift Example
```abc
X:1
T:Piano Phase Pattern
M:6/8
K:C
| E ^F B ^c D | E ^F B ^c D |
```
(Both pianists play this; Piano 2 gradually shifts ahead by one note at a time)

### Phase Positions (6-note pattern)
```
Unison:    ABCDEF | ABCDEF
Phase +1:  ABCDEF | BCDEFA  -> new rhythm heard
Phase +2:  ABCDEF | CDEFAB  -> different melody emerges
Phase +3:  ABCDEF | DEFABC  -> another variant
...back to unison after 6 positions
```

## Clapping Music Concept

| Element | Description |
|---------|-------------|
| Instruments | Body percussion only (clapping) |
| Pattern | 12-beat pattern: X X X . X X . X . X X . |
| Process | Clapper 2 shifts by one beat each cycle |
| 12 positions | All rotations of pattern against itself |
| Model | Purest expression of phase concept |

### Clapping Music Pattern
```
Pattern: | x x x . x x . x . x x . | (12 pulses)
Clapper 1: Always steady
Clapper 2: Shifts by 1 pulse every 8-12 repetitions
```

## Process Music Philosophy

| Principle | Description |
|-----------|-------------|
| Audible process | Listener can hear what is happening |
| Impersonal | Composer sets process, doesn't intervene |
| Inevitable | Once begun, outcome is determined |
| Perceptual | Interest comes from hearing changing patterns |
| Anti-development | Not thematic development; mechanical transformation |
| Influence | Cage (chance), African drumming, Balinese gamelan |

## Tape Loop Techniques

| Technique | Description | Work |
|-----------|-------------|------|
| Loop + gradual phase | Two tape loops drift apart | It's Gonna Rain, Come Out |
| Speech melody extraction | Pitched content emerges from spoken words | Different Trains |
| Sample-based | Recorded speech generates melodic material | Different Trains, City Life |
| Multi-track layering | Loops stacked at different phase positions | Early tape pieces |

### Different Trains Technique
```
1. Record speech: "from Chicago to New York"
2. Extract pitch contour of speech
3. Notate as melody for string quartet
4. String quartet plays speech melody alongside recording
5. Tape + live performance = layered texture
```

## African Rhythm Influence

| Element | Reich Application |
|---------|-----------------|
| Polyrhythm | Multiple patterns at different rates |
| Bell pattern | Asymmetric timeline (12/8 bell pattern) |
| Interlocking | Patterns that fit together like puzzle pieces |
| Cross-rhythm | 3 against 2, 4 against 3 |
| Resultant rhythm | Combined patterns create new rhythm |
| Drumming | Direct influence: trip to Ghana, 1970 |

### African-Inspired Interlocking
```
Player 1: | x . x . x . | x . x . x . |  (steady 3s)
Player 2: | x . . x . . | x . . x . . |  (steady 2s)
Combined: | x . x x x . | x . x x x . |  (composite polyrhythm)
```

## Harmonic Language

| Feature | Description |
|---------|-------------|
| Diatonic only | Almost exclusively white-key or single-key |
| Modal | Dorian and major modes preferred |
| Slow chord changes | Harmony shifts after many pattern repetitions |
| Pulsing chords | Chords articulated as rhythmic patterns |
| No functional progression | Chords are centers, not steps |
| Breathing harmony | Music for 18: chord changes with vocal breaths |

### Reich Harmonic Rhythm
```
Chord 1: A minor (patterns continue for 2-4 minutes)
Transition: Gradual; some instruments shift to new notes
Chord 2: D major (patterns continue for 2-4 minutes)
(Entire piece may use only 4-6 chord areas)
```

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key/mode | D major, A minor; Dorian, major |
| Tempo | Steady; quarter = 160-200 (fast pulse) |
| Melody | Emerges from pattern overlap; not composed separately |
| Harmony | Diatonic, modal, very slow changes |
| Texture | Interlocking patterns; hocketed, phased |
| Form | Process-driven; phase or additive |
| Rhythm | Polyrhythm, interlocking, African-influenced |
| Instruments | Mallets, keyboards, clarinets, voices, strings |
| Dynamics | Gradual; process determines dynamics |
| Emotional tone | Hypnotic, energetic, rhythmically ecstatic |
| Avoid | Romantic melody, chord progressions, rubato, silence |
| Emphasize | Phase process, interlocking, polyrhythm, pulse |
