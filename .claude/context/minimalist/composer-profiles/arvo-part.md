## Tintinnabuli Method

| Element | Description |
|---------|-------------|
| M-voice (melodic) | Steps up or down through a scale |
| T-voice (tintinnabuli) | Selects nearest note from a single triad |
| Triad | One triad governs entire piece (usually minor) |
| Rule set | Strict rules determine T-voice note selection |
| Result | Two-voice texture: one stepwise, one triadic |
| Name origin | Latin tintinnabulum = bell (bell-like resonance) |

### Tintinnabuli Positions

| Position | T-voice Rule | Example (A minor triad, M-note = B) |
|----------|-------------|--------------------------------------|
| 1st superior | Nearest triad note ABOVE | C (nearest A-C-E above B) |
| 2nd superior | 2nd nearest triad note above | E |
| 1st inferior | Nearest triad note BELOW | A |
| 2nd inferior | 2nd nearest triad note below | E (below) |
| Alternating | Alternates above/below per note | Mixed |

### Tintinnabuli Example (Fur Alina Style)
```abc
X:1
T:Tintinnabuli (A minor, 1st position superior)
M:4/4
K:Am
V:1 name="M-voice"
| B2 c2 | d2 e2 | f2 e2 | d2 c2 | B2 A2 |
V:2 name="T-voice"
| C2 C2 | E2 E2 | E2 E2 | C2 C2 | C2 A2 |
```

### Tintinnabuli Calculation Table (A minor: A-C-E)

| M-voice note | 1st sup | 1st inf | 2nd sup | 2nd inf |
|-------------|---------|---------|---------|---------|

## Bell-Like Resonance

| Technique | Application |
|-----------|-------------|
| Open voicings | Wide-spaced triads, resonant |
| Low fundamentals | Bass provides "bell fundamental" |
| Overtone spacing | Upper voices at overtone-series intervals |
| Sustain | Long notes, letting sound ring |
| Decay | Notes naturally fade, not cut off |
| Tubular bells | Actual bells for structural markers |
| Piano resonance | Sustained pedal, letting strings vibrate |

### Bell Resonance Voicing
```
Cb:    A1 (fundamental)
Vc:    E2 (5th)
Vla:   A3 (octave)
Vln II: C4 (minor 3rd)
Vln I:  E5 (5th, upper)
= A minor triad voiced as bell overtones
```

## Sacred Minimalism (Holy Minimalism)

| Principle | Application |
|-----------|-------------|
| Spiritual intent | Music as prayer or meditation |
| Text setting | Latin liturgical texts, psalms |
| Simplicity | Deliberate restriction of means |
| Silence | Rests as sacred space |
| Consonance | Only triadic intervals |
| Slow tempo | Unhurried, contemplative |
| No ego | Composer absent; music serves higher purpose |

## Cantus in Memory of Benjamin Britten

| Element | Detail |
|---------|--------|
| Structure | Descending A-Aeolian scale in canon |
| Tempo | Each voice at different speed (proportional canon) |
| Instruments | String orchestra + tubular bell (A) |
| Bell | Single A, struck at beginning and structural points |
| Process | Voices enter one by one, descending at different rates |
| Culmination | All voices reach lowest register = maximum density |
| Ending | Bell alone, resonating |

### Proportional Canon (Cantus Model)
```
Vln I:    A ---- G ---- F ---- E ---- (slowest)
Vln II:   A -- G -- F -- E -- D -- C -- (medium)
Vla:      A G F E D C B A G F E D (fastest)
Vc:       A---G---F---E---D--- (slow)
Cb:       A---------G---------F--- (slowest)
Bell:     A (sustained ring throughout)
```

## Harmonic Language

| Feature | Description |
|---------|-------------|
| Single triad | One triad governs entire piece |
| A minor preference | Most iconic works in A minor |
| No chromaticism | Strictly diatonic to chosen mode |
| No modulation | Tonal center never changes |
| Consonance only | Major and minor triads, no dissonance |
| Silence as harmony | Rests integral to harmonic structure |

## Orchestration Preferences

| Feature | Detail |
|---------|--------|
| String orchestra | Primary ensemble (Cantus, Tabula Rasa) |
| Prepared piano | Tabula Rasa: piano with modified sound |
| Tubular bell | Structural marker, fundamental pitch |
| Choir | SATB, often a cappella (Te Deum, Magnificat) |
| Solo violin | Over string orchestra (Tabula Rasa, Fratres) |
| Organ | Sacred works, sustained tones |
| Minimal forces | Small ensembles preferred |

## Formal Approach

| Form | Application |
|------|-------------|
| Scale-based | Piece is a single scale traversal (Cantus) |
| Palindrome | Fratres: palindromic structure |
| Strophic | Repeated sections with tintinnabuli variations |
| Through-composed | Single arc from silence to silence |
| Text-determined | Choral works: text phrase = musical phrase |
| Proportional canon | Voices at different speeds = form |

## Fratres Model

| Element | Detail |
|---------|--------|
| Structure | Repeating section separated by percussion interludes |
| Versions | Multiple instrumentations (violin+piano, strings, etc.) |
| Harmony | Single triad universe |
| Percussion | Marks formal divisions (drum pattern) |
| Variation | Each statement slightly varied |
| Palindromic | Section reverses at midpoint |

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key/mode | A minor (Aeolian) primary; D minor, E minor |
| Tempo | Very slow; quarter = 40-60 |
| Melody | Stepwise M-voice, strictly following scale |
| Harmony | Single triad; tintinnabuli rules |
| Texture | 2-voice (M + T), expandable to proportional canon |
| Form | Scale-based, palindromic, or proportional canon |
| Dynamics | pp - p; rare mf at climax |
| Orchestration | Strings, bell, choir; spare |
| Silence | Essential; rests are part of the music |
| Emotional tone | Sacred, contemplative, austere, luminous |
| Avoid | Chromaticism, dissonance, complexity, loudness, ego |
| Emphasize | Tintinnabuli rules, bell resonance, simplicity, silence |
