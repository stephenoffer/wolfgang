# W.A. Mozart — Harmonic Language

Mozart's harmony is a study in the power of restraint. Within a largely diatonic framework, a single chromatic note can change the emotional temperature of an entire passage. Where Bach's chromaticism is structural and pervasive, Mozart's is surgical — one lowered sixth, one Neapolitan chord, one diminished seventh placed at exactly the right moment. The effect is devastating precisely because the surrounding language is so clear.

For shared Classical harmonic vocabulary (functional progressions, cadence types, sequences, voice-leading), see [classical-harmony.md](../../classical-harmony.md). This file covers what is distinctly Mozartian.

## Core Harmonic Character

| Feature | Description | Artistic Function |
|---------|-------------|-------------------|
| Diatonic clarity as default | 70-80% of harmony is I-IV-V-vi territory | Makes every chromatic event feel significant — contrast requires a norm |
| The "minor shadow" | Parallel minor intrusions in major contexts (iv, bVI, b6 scale degree) | A cloud crossing the sun — fleeting darkness that deepens the surrounding light |
| Chromatic inflection, not modulation | Single chromatic notes color a phrase without leaving the key | Emotional nuance without structural disruption |
| Neapolitan as tenderness | bII6 in slow movements = maximum emotional vulnerability | Not dramatic (as in Beethoven) but intimate — a whispered confession |
| Operatic harmonic rhythm | Harmony accelerates toward emotional peaks, relaxes afterward | Mirrors the pacing of dramatic speech and song |
| Key symbolism | Specific keys carry consistent emotional associations | D minor = demonic fate; G minor = lyric tragedy; Eb = Masonic solemnity |
| Diminished 7th as dramatic pivot | Fully diminished chords for sudden key shifts | Operatic — the moment the plot turns |
| Secondary dominants used sparingly | V/V most common; V/vi for tenderness; chains rare | Each applied dominant is an event, not routine |

## The Minor Shadow — Mozart's Signature Device

The single most Mozartian harmonic gesture: within a major-key phrase, one or two chords borrow from the parallel minor, then the major returns. The effect is like a memory of sadness passing through an otherwise contented moment.

| Shadow Type | Chord(s) Used | Scale Degree Affected | Emotional Color |
|-------------|--------------|----------------------|----------------|
| Flattened 6th in melody | — (melodic, not chordal) | b6 over I or V | Wistfulness — one note turns joy to bittersweetness |
| Borrowed iv | iv replacing IV | b3 and b6 | Plaintive, shadowed — the subdominant darkens |
| Borrowed bVI | bVI chord | b6, b3, 1 | Warm darkness — surprise that feels inevitable |
| Minor-mode episode | Full shift to i for 4-8 bars | All minor scale degrees | Storm cloud; the major return feels like relief |
| Diminished passing chord | vii°7 on chromatic bass | chromatic | Passing anxiety — resolved before it can settle |

```abc
X:1
T:The Minor Shadow in G Major
M:4/4
L:1/8
K:G
V:1 clef=treble
V:2 clef=bass
%% Bar 1-2: pure diatonic sunlight
[V:1] B2d2 g4|f2e2 d4|
[V:2] G,4 G,4|D,4 D,4|
%% Bar 3: the shadow — Eb appears (b6 of G major = borrowed from G minor)
[V:1] _e2d2 c2B2|B2A2 G4|
[V:2] C,4 D,4|G,,4 G,4|
%% Bar 3's Eb is the ENTIRE emotional argument. Remove it and the phrase is empty.
```

## Chromatic Techniques

| Technique | Frequency | Context | Example |
|-----------|-----------|---------|---------|
| b6 melodic inflection | Very common | Any major-key phrase — the signature shadow | K.550 mvt I: Eb in G major texture |
| Neapolitan 6th (bII6) | Moderate | Slow movements, minor-key cadences | K.488 Adagio (F# minor), Requiem Lacrimosa |
| Diminished 7th pivot | Moderate | Development sections, operatic transitions | Don Giovanni — the Commendatore scenes |
| Augmented 6th chords | Rare-moderate | Dramatic cadential moments, late works | K.491 first movement, Don Giovanni finale |
| Chromatic bass descent | Moderate | Lament, grief, slow introductions | K.465 "Dissonance" introduction |
| Enharmonic reinterpretation | Rare | Late works, development sections | K.550 development, Requiem |
| Secondary dominants | Common (V/V, V/vi) | Transitions, sequences | Standard in development; V/V at modulation |

### Chromatic Bass Descent — the Dissonance Quartet

```abc
X:2
T:K.465 "Dissonance" Quartet Opening (Adagio)
M:4/4
L:1/8
K:C
V:1 clef=treble
V:2 clef=bass
%% Descending chromatic bass creates dissonant clashes — Mozart pushing Classical harmony to its limit
[V:1] z8|z4 _A2G2|
[V:2] C,2C,2 C,2C,2|C,2B,,2 _A,,2G,,2|
%% The bass chromatic descent generates vertical dissonances the ear cannot classify — is this C? Ab?
%% The resolution to C major is the point: the journey through darkness makes the light meaningful
```

## Harmonic Rhythm Patterns

| Context | Typical Harmonic Rhythm | Emotional Effect |
|---------|------------------------|-----------------|
| Exposition first theme | 1-2 changes per bar | Stability, identity — the character is introduced |
| Transition | Accelerating to 2-4 per bar | Increasing tension — something is about to change |
| Second theme | 1 per bar, relaxed | New landscape; breathing room after the journey |
| Development | Irregular, often fast | Disorientation, adventure — keys shifting beneath the feet |
| Slow movement opening | 1 per 2 beats (very rich) | Intimacy — every harmonic change is savored |
| Opera buffa ensemble | Variable, character-dependent | Comedy = fast harmonic rhythm; sentiment = slow |
| Minuet | 1 per bar, regular | Dance regularity; the trio may change this |

## Cadential Vocabulary

| Cadence Type | Mozart's Usage | Typical Preparation |
|--------------|---------------|-------------------|
| PAC (V7-I) | Phrase endings, period closings | ii6 -> cad 6/4 -> V7 -> I |
| HC (->V) | Antecedent endings, mid-phrase pauses | I -> IV -> V (melody on scale degree 2 or 7) |
| Deceptive (V-vi) | Phrase extension — "not yet done" | Standard V7 -> vi; then real PAC follows |
| Neapolitan -> V -> i | Minor-key slow movements | iv -> bII6 -> cad 6/4 -> V -> i |
| Cadenza approach | Concertos: orchestra stops on I6/4 | Orchestra tutti -> I6/4 (held) -> solo cadenza -> trill -> V -> I |

```abc
X:3
T:Mozart Cadential Sequence — Deceptive then Authentic
M:4/4
L:1/4
K:C
V:1 clef=treble
V:2 clef=bass
%% V7 -> vi (deceptive — surprise!) then ii6 -> V7 -> I (real closure)
[V:1] [DF] [CE] | [CE] [DF] [DB] [EC]|
[V:2] G, A, | D, G,, G, C, |
%% V7 - vi (deceptive) - ii6 - V7 - I (authentic)
```
