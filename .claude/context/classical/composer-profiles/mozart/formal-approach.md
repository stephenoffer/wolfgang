# W.A. Mozart — Formal Approach

Mozart does not merely use forms — he inhabits them as a dramatist inhabits a stage. Sonata form is not an abstract architecture but a dramatic scenario: characters (themes) are introduced, sent on a journey (development), and brought home transformed (recapitulation). Every formal decision in Mozart has an operatic logic: when does the audience need surprise? tension? resolution? a laugh?

## Core Formal Principles

| Principle | Description | Artistic Function |
|-----------|-------------|-------------------|
| Opera as formal model | All instrumental forms mirror operatic pacing | The listener experiences narrative, not architecture |
| Proportional balance | Sections relate to each other by simple fractions or golden ratio | The form feels right physically — nothing overstays |
| Theme as character | Each theme has a personality (lyric, energetic, comic, tragic) | The form is a drama between characters, not a sequence of events |
| Surprise within convention | Every form has one moment where expectation is subverted | Deceptive cadences, unexpected modulations, phrase extensions |
| Cadential clarity | Structural cadences are unmistakable — arrival is felt, not analyzed | The listener knows where they are without theory training |
| Economy of means | A 4-note motive can generate an entire movement | Nothing wasted; every note serves the form |

## Sonata Form — Mozart's Dramatic Discourse

| Section | Mozart's Treatment | Operatic Parallel |
|---------|-------------------|-------------------|
| Introduction (if present) | Slow, mysterious, questioning — rare except in late symphonies | Overture — sets the mood before the curtain rises |
| Exposition — 1st theme (P) | Strong character statement, usually periodic (8 bars) | Protagonist's entrance aria |
| Transition (TR) | Energetic, modulatory; breaks the 1st theme's composure | Plot complication — the world shifts |
| 2nd theme (S) | Lyrical, contrasting character; often more complex | New character enters — dialogue begins |
| Closing (C) | Cadential confirmation, often lighthearted | Scene-ending ensemble; everyone agrees (for now) |
| Development | Themes fragmented, combined, sent through remote keys | The crisis — characters tested, conflicts escalated |
| Retransition | Dominant prolongation building toward return | The moment before resolution — maximum tension |
| Recapitulation | All themes return in tonic; 2nd theme "comes home" | Reconciliation — the drama resolves |
| Coda | Brief confirmation, sometimes with surprise | Final curtain; sometimes a last twist |

### Mozart's Sonata Form Proportions

| Section | Typical Proportion (% of total) | Bars (in a ~200-bar movement) |
|---------|-------------------------------|------------------------------|
| Exposition | 35-40% | 70-80 bars |
| Development | 20-30% | 40-60 bars |
| Recapitulation | 30-40% | 60-80 bars |
| Coda | 0-5% | 0-10 bars (Mozart's codas are brief) |

X:1
T:Mozart Sonata Exposition — Theme Character Contrast
M:4/4
L:1/8
K:G
V:1 clef=treble
V:2 clef=bass
%% First theme (P): energetic, rhythmic, forte — the extrovert
[V:1] G2B2 d4|c2B2 A2G2|
[V:2] G,,4 G,,4|D,,4 D,,4|
%% Second theme (S): lyric, piano, singing — the introvert (now in D major)
[V:1] ^f2a2 g2^f2|e4 d4|
[V:2] D,4 A,,4|G,,4 D,4|
%% Two characters, two emotions, one drama
```

## Concerto Form — Operatic Dialogue Made Explicit

Mozart's piano concerto is the purest expression of his dramatic instinct. The orchestra and soloist are two characters in a scene.

| Section | Function | Who Speaks |
|---------|----------|-----------|
| Orchestral ritornello | Introduces themes; sets the world | Orchestra alone — the collective |
| Solo exposition | Soloist enters, restates and transforms themes | Piano leads, orchestra accompanies |
| Solo passage work | Brilliant figuration, developmental | Piano alone or with light support |
| Wind dialogue | Winds and piano trade phrases | Intimate conversation between equals |
| Development | Themes explored in remote keys | Piano and orchestra collaborate |
| Recapitulation | Themes return; piano leads | Piano dominant, orchestra supportive |
| Cadenza | Soloist alone; improvised or composed | The monologue — most personal moment |
| Orchestral coda | Orchestra has final word | The collective reasserts; the world returns |

### Concerto First Movement — Mozart's Innovation

| Feature | Pre-Mozart Concerto | Mozart's Concerto |
|---------|-------------------|------------------|
| Ritornello | States all material; purely orchestral | States themes but withholds something for the solo |
| Solo entry | Repeats ritornello material | Transforms it — adds ornamentation, changes character |
| Development | Brief, formulaic | Full sonata-form development with both forces |
| Cadenza placement | Before final ritornello | After recapitulation, before orchestral coda |
| Wind role | Doubling strings | Independent characters who dialogue with piano |

## Aria Forms in Opera

| Aria Type | Structure | When Mozart Uses It |
|-----------|-----------|-------------------|
| Da capo (ABA) | Return to opening after contrasting section | Early operas (Idomeneo); abandoned in maturity |
| Rondo (ABACA) | Recurring theme with contrasting episodes | Lyric arias, especially in major keys |
| Sonata-aria | Sonata form applied to vocal number | Complex arias for leading characters |
| Two-tempo | Slow opening then fast conclusion | Character moves from reflection to action |
| Strophic | Same music, different verses | Simple characters, folk-like moments |
| Through-composed | No repetition; form follows text | Dramatic scenes, accompanied recitative |

X:2
T:Mozart Rondo Theme — Finale Character
M:2/4
L:1/16
K:D

%% The character smiles, bows, and re-enters — the audience recognizes them
D2F2 A2d2|c2B2 A2G2|F2E2 D2C2|D4 z4|
```

## String Quartet — Four Equal Voices

| Voice | Role in Mozart Quartet | Operatic Parallel |
|-------|----------------------|-------------------|
| Violin I | First among equals; initiates themes | Lead soprano — carries the primary melody |
| Violin II | Responsive partner; harmonizes, imitates | Second character — agrees, challenges, echoes |
| Viola | Harmonic center; occasionally emerges melodically | Supporting role that reveals new depths in late works |
| Cello | Bass foundation + melodic voice in dialogue passages | Bass — grounds everything; solos are moments of gravitas |

### The "Haydn" Quartets — Mozart Learning Form from Haydn

| Quartet | Key | Formal Innovation |
|---------|-----|------------------|
| K.387 | G major | Fugal finale — Bach meets Classical quartet |
| K.421 | D minor | Siciliano finale in minor — tragic quartet |
| K.428 | E-flat | Chromatic introduction; ambiguous tonality |
| K.458 "Hunt" | B-flat | Horn-call theme; operatic wit |
| K.464 | A major | Theme and variations finale of profound depth |
| K.465 "Dissonance" | C major | Slow introduction pushes chromaticism to the limit |

## Rondo Form — The Return of Joy

| Section | Key | Character |
|---------|-----|-----------|
| A | Tonic | The main character — always recognizable, always welcome |
| B | Dominant or relative | First contrast — new landscape, same cheerful energy |
| A | Tonic | Return — the audience relaxes into familiarity |
| C | Remote (vi, IV, minor) | Deeper contrast — a shadow, a storm, a minor-key excursion |
| A | Tonic | Final return — after the storm, the sun feels warmer |
| Coda | Tonic | Celebration — the form affirms itself one last time |
