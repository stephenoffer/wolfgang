# Joseph Haydn — Composer Profile

## Core Identity

| Attribute | Value |
|-----------|-------|
| Full name | Franz Joseph Haydn |
| Dates | 1732-1809 |
| Nationality | Austrian |
| Primary roles | Kapellmeister, composer |
| Key position | Esterhazy court (1761-1790), freelance London |
| Output | ~1,000+ works (Hoboken catalogue) |
| Titles | "Father of the Symphony," "Father of the String Quartet" |

## Period / Style Map

| Period | Years | Focus | Key works |
|--------|-------|-------|-----------|
| Early | 1750-1770 | Divertimenti, early symphonies/quartets | Symphonies 1-30, Op. 1/2 quartets |
| Sturm und Drang | 1768-1773 | Dramatic minor-key works | Symph. 44 "Trauer," 45 "Farewell," Op. 20 quartets |
| Middle | 1773-1784 | Refined, humorous, experimental | Symph. 45-80, Op. 33 "Russian" quartets |
| Mature | 1784-1790 | Paris Symphonies, Esterhazy opera | Symphonies 82-87, Stabat Mater |
| London | 1791-1795 | London Symphonies, late quartets | Symphonies 93-104, Op. 71/74 quartets |
| Late | 1796-1803 | Oratorio, late masses, quartets | The Creation, The Seasons, Op. 76/77 quartets |

## Monothematic Sonata Form

### Haydn's Approach vs Standard

| Feature | Standard (textbook) | Haydn's approach |
|---------|-------------------|-----------------|
| P theme | Distinct from S | Often same material for both |
| S theme | New, contrasting | P theme recast in dominant |
| Contrast source | Thematic contrast | Key, texture, register contrast |
| Development focus | S theme common | P theme exclusively |
| Thematic unity | Two themes, one idea | One theme, infinite variety |

### Monothematic ABC Example

## Wit and Surprise

### Types of Haydn Humor

| Device | Description | Example |
|--------|-------------|---------|
| False ending | Piece seems to end, then continues | "Joke" Quartet Op. 33/2 |
| Unexpected silence | Rest where music is expected | General pauses mid-phrase |
| Fortissimo surprise | Sudden loud chord in quiet passage | "Surprise" Symphony No. 94 |
| Wrong key return | Theme returns in unexpected key | False recapitulations |
| Metric displacement | Accents on wrong beats | Syncopation games |
| Extra/missing beats | Asymmetric phrases | 3-bar or 5-bar phrases |
| Thematic disguise | Theme hidden in new texture | Development sections |
| Ending with opening | Final bars = opening bars | Circular humor |
| Sudden stops | Music halts unexpectedly | Before cadence |
| Mood reversal | Major suddenly minor (or reverse) | Mid-phrase shifts |

```abc
L:1/8
K:C
!pp! E2E2 E2E2 | E2E2 E2E2 | !pp! E2E2 E2E2 | !ff! [CEGc]8 |
```

## String Quartet Innovations

### Evolution of Quartet Writing

| Period | Quartets | Innovation |
|--------|----------|------------|
| Op. 1-2 (1757-62) | Early divertimenti | 5 mvts, minuet-heavy |
| Op. 9 (1769-70) | First "real" quartets | 4 mvts, Vn I dominated |
| Op. 17 (1771) | Developing style | More equality between voices |
| Op. 20 (1772) | "Sun" quartets | Fugal finales, cello solos |
| Op. 33 (1781) | "New and special way" | Conversational, witty |
| Op. 50 (1787) | "Prussian" | Monothematic mastery |
| Op. 64 (1790) | "Tost" quartets | Virtuosic Vn I |
| Op. 71/74 (1793) | "Apponyi" | Concert hall scale |
| Op. 76 (1797) | Greatest set | Every technique refined |
| Op. 77 (1799) | Final completed | Summation of style |

### Four-Voice Equality

| Voice | Early Haydn role | Mature Haydn role |
|-------|-----------------|------------------|
| Violin I | Always melody | Melody, but yields to others |
| Violin II | Accompaniment | Independent melody, dialogue |
| Viola | Harmony filler | Melodic participant, solo moments |
| Cello | Bass only | Solo melody, thematic participant |

## Symphonic Development

### Haydn's Symphonic Innovations

| Innovation | Description | Example |
|-----------|-------------|---------|
| Slow introduction | Grand opening before allegro | London Symphonies |
| Monothematic development | Single idea transformed exhaustively | Most mature works |
| Developmental recapitulation | Recap continues development | Late symphonies |
| Expanded finale | Finale equals first movement weight | London Symphonies |
| Scherzo character | Minuet with fast tempo and humor | Op. 33 quartets onward |
| Orchestral crescendo | Extended buildup to climax | Symphony 103 intro |
| Pedal point drama | Long dominant pedals before recap | Development retransitions |
| Surprise modulations | Sudden remote-key shifts | Development sections |

### Development Section Techniques

| Technique | Description | Frequency |
|-----------|-------------|-----------|
| Fragmentation of P | Main theme broken into motives | Standard |
| Sequential treatment | Motive through circle of 5ths | Very common |
| Contrapuntal episodes | Imitative passage using motive | Moderate |
| Textural reduction | Drop to 2 voices then rebuild | Common |
| Harmonic surprise | Sudden enharmonic modulation | Effective |
| False recapitulation | P returns in wrong key (often IV or vi) | Signature device |
| Dominant preparation | Extended V pedal | Standard ending |
| New key exploration | Move to remote keys (bVI, iii) | Common |

## Folk-Like Themes

### Characteristics

| Feature | Description |
|---------|-------------|
| Simple intervals | Steps, 3rds, triadic outlines |
| Regular phrases | 4-bar phrases, symmetrical |
| Limited range | Often within an octave |
| Strong downbeat | Clear metric emphasis |
| Repetition | Internal motive repetition |
| Dance character | Landler, minuet, contredanse elements |
| Modal inflection | Occasional borrowed flat degrees |
| Drone implication | Open 5ths, pedal suggestions |

## Developmental Techniques

### Motive Transformation

| Method | Description | ABC notation |
|--------|-------------|-------------|
| Fragmentation | Isolate head of theme | `G2B2` from `G2B2d4c2B2` |
| Sequence (ascending) | Fragment up by step | `G2B2 \| A2c2 \| B2d2` |
| Sequence (descending) | Fragment down by step | `d2B2 \| c2A2 \| B2G2` |
| Inversion | Flip intervals | `G2B2` becomes `G2E2` |
| Augmentation | Double note values | `G2B2` becomes `G4B4` |
| Rhythmic shift | Change rhythm, keep pitch | `G2B2` becomes `G/B/G/B/` |
| Reharmonization | Same melody, new harmony | Minor instead of major |
| Texture change | Same motive, new scoring | Strings -> winds |

## Harmonic Language

### Characteristic Progressions

| Progression | Context |
|-------------|---------|
| I-V-I (prolonged) | Opening themes, simplicity |
| I-vi-ii-V-I | Standard cadential |
| I-IV-V-I | Basic, folk-like |
| V/vi-vi-V/V-V-I | Extended approach to cadence |
| I-bVI (sudden) | Dramatic surprise |
| I-iii (chromatic) | Unusual color |
| Pedal V -> I | Retransition climax |
| Circle of 5ths | Sequential development |

### Compared to Mozart

| Feature | Haydn | Mozart |
|---------|-------|--------|
| Themes | Monothematic, motive-based | Dual themes, lyrical |
| Development | Exhaustive, long | Concise, efficient |
| Chromaticism | Less pervasive | More chromatic |
| Surprise | Structural (false recap, metric) | Harmonic (deceptive, chromatic) |
| Humor | Constant, architectural | Occasional, operatic |
| Texture | Developmental | Vocal/lyrical |
| Wind writing | Functional, improving in late works | Soloistic from early on |
| Form | Experimental, flexible | Elegant, proportional |

## Orchestral Techniques

| Technique | Description |
|-----------|-------------|
| Tutti unison | All instruments on melody, powerful |
| String tremolo buildup | Gradual crescendo for drama |
