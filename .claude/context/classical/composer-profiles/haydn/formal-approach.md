# Joseph Haydn — Formal Approach

Haydn did not merely use Classical forms — he invented them. The symphony, the string quartet, sonata form itself: these are Haydn's creations, refined through hundreds of works over four decades. But "form" for Haydn is never a template. It is a game: establish the rules, then break them with such perfect timing that the broken rule becomes the point.

---

## Forms and How Haydn Inhabits Them

| Form | Haydn's Contribution | What Makes It Haydnesque |
|------|---------------------|--------------------------|
| Sonata form | Monothematic variant; false recapitulation | The "second theme" is the first theme in disguise; recap arrives in wrong key |
| Minuet and Trio | Humor, asymmetric phrases, rustic character | Not a courtly dance but a vehicle for rhythmic jokes and harmonic surprises |
| Slow movement | Variation form as primary vehicle | Theme + ornamental variations; each variation a new character |
| Rondo finale | Sonata-rondo hybrid | Rondo refrain with developmental episodes; wit in comic timing |
| String quartet form | Four-movement plan as standard | Standardized I: Allegro, II: Slow, III: Minuet, IV: Finale |
| Symphony form | Slow introduction + four movements | London symphonies establish the template Beethoven inherits |

## Sonata Form — Haydn's Game

### Standard Sonata Form with Haydn Modifications

| Section | Textbook | Haydn's Version | Structural Effect |
|---------|----------|-----------------|-------------------|
| Exposition: PT | Main theme in I | Simple, folk-like theme — easy to fragment later | Accessibility as strategy |
| Exposition: TR | Modulating transition | May use PT material; energetic, driving | Monothematic economy |
| Exposition: ST | New theme in V | Often PT restated in V (monothematic) | Unity instead of contrast |
| Exposition: CL | Closing material | Cadential flourishes, sometimes new melodic material | Confirms new key |
| Development | Fragmentation, modulation | Extreme fragmentation; remote keys; dominant pedal buildup | The theme's DNA revealed |
| Recapitulation | PT in I, then ST in I | False recapitulation (wrong key); may reorder or omit material | The structural joke |
| Coda | Brief confirmation | May introduce new developmental material | Last surprise before close |

### False Recapitulation Types

| Type | What Happens | Effect | Examples |
|------|-------------|--------|---------|
| Wrong key | Theme returns in IV or vi, then corrects to I | Double homecoming — relief arrives twice | Symphonies 55, 93, 102 |
| Wrong theme | Secondary material returns first, then PT follows | Structural disorientation | Quartets Op. 33/2, Op. 76/1 |
| Too early | Theme sneaks in during development, then disappears | False hope — was that the recap or not? | Symphony 104 |
| Too quiet | Recap begins pp where forte was expected | Subverted climax — the return whispers | Symphony 94, 99 |

```abc
X:1
T:Haydn Sonata — Monothematic Exposition
M:4/4
L:1/8
K:D
%% PT in tonic (D major)
!f!D2F2 A2d2|c2B2 A4|G2F2 E2D2|E2F2 G4|
%% TR (transition) — using PT material, modulating
A2B2 c2d2|e2d2 c2B2|A2^G2 A2B2|
%% ST in dominant (A) — same theme, new key
K:A
!p!A,2C2 E2A2|G2F2 E4|D2C2 B,2A,2|B,2C2 D4|
```

## Minuet and Trio — Haydn's Comic Stage

The minuet is where Haydn's humor is most concentrated. The inherited courtly dance becomes a vehicle for asymmetric phrases, off-beat accents, and harmonic non sequiturs.

| Feature | Courtly Minuet | Haydn's Minuet |
|---------|---------------|----------------|
| Phrase length | Regular 4+4 bars | 3+5, 5+3, 4+6 — deliberately irregular |
| Character | Elegant, measured | Rustic, stomping, comic |
| Harmony | Predictable I-V-I | Sudden remote chords; deceptive cadences |
| Trio contrast | Same character, new key | Contrasting character — pastoral, lyrical, or folk |
| Dynamic | Moderate, even | Subito forte/piano; fp accents on wrong beats |
| Hemiola | Rare | Frequent — 3/4 becomes 2/4 feeling |

```abc
X:2
T:Haydn Minuet — Asymmetric Phrases and Rustic Character
M:3/4
L:1/8
K:G
%% 3-bar phrase (irregular!)
!f!G4 B2|d4 B2|G2A2B2|
%% 5-bar phrase answers (also irregular!)
!p!c4 A2|F4 D2|G2A2B2|c2B2A2|G4 z2|
```

## Slow Movement Forms

Haydn preferred variation form for slow movements — a lyrical theme transformed through ornamental, textural, and harmonic variation.

| Form | How Haydn Uses It | Frequency |
|------|-------------------|-----------|
| Theme and variations | Theme (8-16 bars) + 3-5 variations, each adding ornament | Very common |
| ABA (ternary) | Lyrical A, contrasting B (often minor), A returns decorated | Common |
| Sonata form (slow) | Reduced sonata; less development, more lyricism | Moderate |
| Double variation | Two alternating themes, each varied (major/minor pair) | Late works (Sym. 103) |

### Variation Technique Progression

| Variation | Typical Treatment | Effect |
|-----------|------------------|--------|
| Theme | Simple, lyrical, 8-16 bars | Establishes the melody the listener will follow |
| Var. 1 | Melodic ornamentation (turns, passing tones) | Theme blossoms |
| Var. 2 | Minor mode (or major if theme was minor) | Shadow and light |
| Var. 3 | New texture (solo wind, pizzicato strings) | Orchestrational surprise |
| Var. 4 | Faster figuration, more elaborate | Climactic display |
| Coda | Return to simplicity, or unexpected harmonic twist | Satisfying close with a final surprise |

```abc
X:3
T:Haydn Slow Movement — Theme and Ornamented Variation
M:3/4
L:1/16
K:C
%% Theme: simple, singing
!p!E4 G4 c4|d4 c4 B4|A4 G4 F4|E8 z4|
%% Variation 1: ornamented return
E2F2 G2A2 c2B2c2d2|d2e2 c2d2 B2A2B2c2|A2B2 G2A2 F2E2F2G2|E8 z4|
```

## Finale — The Wittiest Movement

Haydn's finales are typically faster, lighter, and more humorous than first movements. The rondo and sonata-rondo are his preferred forms.

| Finale Type | Structure | Tempo | Character |
|-------------|-----------|-------|-----------|
| Rondo (ABACA) | Catchy refrain alternating with episodes | Presto | Folk-like, dancing, comic |
| Sonata-rondo (ABACABA) | Rondo refrain with sonata development | Allegro | Wit + structural depth |
| Sonata form | Full sonata with Presto pacing | Presto | Virtuosic, driven |
| Fugal finale | Contrapuntal tour de force | Allegro | Op. 20 quartets — proving mastery |
| Variation finale | Theme + increasingly wild variations | Moderate→Fast | Theme transformed beyond recognition |

### Rondo Refrain Techniques

| Technique | What Haydn Does | Effect |
|-----------|----------------|--------|
| Varied return | Refrain comes back with new orchestration or dynamics | Fresh each time |
| Truncated return | Refrain shortened — only first phrase | Accelerating toward the end |
| Wrong-key return | Refrain starts in unexpected key, corrects | Formal subversion in the finale too |
| Extended coda | After final refrain, a Presto coda with new material | The party's not over yet |

```abc
X:4
T:Haydn Rondo Finale — Catchy Refrain (Presto)
M:2/4
L:1/16
K:D
%% Refrain: folk-like, energetic
!p!D2F2 A2d2|c2B2 A2G2|F2E2 D2^C2|D4 z4|
%% Episode: contrasting character
!f!a4 f4|e4 d4|^c4 B4|A4 z4|
%% Refrain return — same tune, new dynamic
!pp!D2F2 A2d2|c2B2 A2G2|F2E2 D2^C2|D4 z4|
```

## The Slow Introduction (London Symphonies)

A Haydn innovation that became standard: the Adagio or Largo opening that sets a mood of mystery and expectation before the Allegro breaks free.

| Feature | Typical Treatment |
|---------|------------------|
| Tempo | Adagio or Largo; grave, measured |
| Key | Often ambiguous; may start in minor or on a non-tonic chord |
| Harmony | Chromatic, searching; dominant preparation at the end |
| Dynamic | p to pp; building toward the Allegro |
| Connection | Dominant chord held or paused on; Allegro erupts |
| Length | 10-30 bars (shorter than Beethoven's) |

```abc
X:5
T:Haydn Slow Introduction — Mystery into Energy
M:4/4
L:1/8
K:D
%% Adagio: searching, chromatic, quiet
!p!D4 ^C4|D2F2 A2d2|!pp!c2_B2 A2G2|^F4 z4|
%% Pause on dominant...
!p!A,8-|A,8|
%% Allegro erupts!
!f!D2D2 F2A2|d4 A4|F2D2 A,2D2|D4 z4|
```
