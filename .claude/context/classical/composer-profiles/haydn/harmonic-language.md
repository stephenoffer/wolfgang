# Joseph Haydn — Harmonic Language

Haydn's harmony is a game of expectations. Where Bach's harmony emerges from counterpoint and Mozart's from vocal beauty, Haydn's harmony exists to set up the listener — and then spring the trap. A cadence arrives in the wrong key. A dominant seventh resolves to silence. A development section passes through exactly the key you didn't expect. The wit IS the harmony.

For shared Classical harmonic vocabulary (functional harmony, cadence types, sequences, voice-leading), see [classical-harmony.md](../../classical-harmony.md). This file covers what is distinctly Haydnesque.

## Core Harmonic Character

| Feature | Description | Artistic Function |
|---------|-------------|-------------------|
| Functional clarity as setup for surprise | Establishes tonic-dominant polarity clearly so that departures register as jokes | The listener must feel "at home" before the rug can be pulled |
| False recapitulation | Recapitulation begins in the wrong key (often IV or vi), then corrects | The structural joke — the listener thinks they're home but aren't |
| Deceptive cadence as punchline | V resolves to vi (or bVI) at the moment of maximum expectation | Timing is everything — too early and it's a mistake, too late and it's boring |
| Remote key detours in development | Sudden shifts to distant keys (bVI, bII, iii) without modulatory preparation | Adventure, disorientation — the development as harmonic journey |
| Monothematic harmonic recontextualization | Same theme in new harmonic context sounds like new material | Proves that harmony, not melody, creates character |
| Silence as harmony | A fermata on a dissonant chord, followed by silence, then quiet resolution | The silence carries more harmonic weight than any chord |
| Pedal-point wit | Extended dominant pedal where resolution is repeatedly delayed | Builds comic or dramatic tension through harmonic suspension |

## Harmonic Fingerprints

| # | Device | What It Sounds Like | Typical Context |
|---|--------|---------------------|-----------------|
| 1 | False recapitulation | Theme returns in wrong key, then corrects to tonic | Sonata recapitulation — the signature Haydn joke |
| 2 | Subito dynamic shift on unexpected harmony | Fortissimo chord where piano was expected (or reverse) | Any structural moment — the "Surprise" principle |
| 3 | Deceptive cadence with comic timing | V-vi where V-I was expected, followed by pause | Phrase endings, codas, transitions |
| 4 | Monothematic key change | First theme restated in dominant as "second theme" | Sonata expositions — Haydn's alternative to contrast |
| 5 | Remote key in development | Sudden arrival in bVI, bII, or enharmonic territory | Development sections — harmonic adventure |
| 6 | Dominant pedal with delays | Bass holds V for 8-16 bars while upper voices avoid resolution | Pre-recapitulation, coda buildups |
| 7 | Cadential expansion via deception | Multiple deceptive cadences before the real PAC | Extending movements beyond expected length |
| 8 | Harmonic non sequitur | Unrelated chord follows without preparation | Comedy, surprise — especially in minuets |

## Harmonic Devices in Practice

### The False Recapitulation

The most Haydnesque harmonic gesture: the theme returns after the development, but in the subdominant or some other wrong key. The listener relaxes — then realizes something is off. The real recapitulation follows, and the relief is doubled.

```abc
X:1
T:Haydn False Recapitulation — Theme Returns in IV, Then Corrects
M:4/4
L:1/8
K:C
%% Development ends on V...
!f!G,4 G,4|
%% Theme enters in F (IV) — wrong key!
!p!F2A2 c2f2|e2d2 c4|
%% Correction: real recapitulation in C (I)
C2E2 G2c2|B2A2 G4|
```

### Monothematic Sonata Harmony

Haydn often presents the "second theme" as the first theme transposed to the dominant. The novelty is harmonic, not melodic — the same tune sounds different because the harmonic context has shifted.

| Sonata Location | Theme | Key | Effect |
|----------------|-------|-----|--------|
| Exposition PT | Main theme | I (C major) | Stable, assertive, home |
| Exposition ST | Same theme | V (G major) | Lighter, brighter — same notes, different world |
| Development | Theme fragments | vi, ii, bVI | Disoriented, adventurous |
| Recapitulation | Both statements | I (C major) | Unity — the theme was always one thing |

```abc
X:2
T:Monothematic Sonata — Same Theme, Two Keys
M:4/4
L:1/8
K:C
%% Main theme in tonic (C)
C2E2 G2E2|D2F2 A2F2|E2G2 c2G2|A2G2 F2E2|
%% Same theme as "second theme" in dominant (G)
K:G
G2B2 d2B2|A2c2 e2c2|B2d2 g2d2|e2d2 c2B2|
```

### Deceptive Cadence as Structural Humor

| Setup | Expected | Actual | What Follows | Comic Effect |
|-------|----------|--------|-------------|-------------|
| V7 chord, full texture | I (PAC) | vi (deceptive) | Pause, then retry | "Not yet!" |
| V7 chord, crescendo | I (triumphant) | Silence | pp resolution | "Gotcha" |
| V7 chord, third time | I (finally) | bVI (remote!) | New harmonic territory | "Did you really think...?" |

## Harmonic Rhythm

| Context | Haydn's Typical Pattern | Artistic Effect |
|---------|------------------------|-----------------|
| Allegro exposition | 1-2 chords per bar; accelerates pre-cadence | Forward drive with cadential punchlines |
| Slow movement | 2-4 per bar; rich inner voice motion | Expressive warmth; harmonic "breathing" |
| Minuet | 1 per bar; sudden shifts at phrase boundaries | Dance regularity disrupted by surprise |
| Finale (Presto) | 1 per bar; long passages on tonic or dominant | Speed demands simplicity — wit is in timing, not complexity |
| Development | Rapid key changes; sequences through remote areas | Maximum harmonic adventure in minimum time |

## Development Section Harmonic Strategies

| Strategy | How It Works | Example Symphonies |
|----------|-------------|-------------------|
| Sequential descent through 5ths | Theme fragment sequenced: vi-ii-V-I-IV-vii-iii | 88, 94, 104 |
| Remote key arrival | Sudden leap to bVI or bII without preparation | 97, 103 |
| Dominant pedal buildup | 8-16 bars of V pedal, upper voices create tension | 99, 101, 104 |
| Enharmonic surprise | dim7 reinterpreted to reach distant key | 102, 103 |
| Minor-mode shadow | Theme in tonic minor (i instead of I) | 94 (development), 100 |

```abc
X:3
T:Haydn Development — Sequential Fragmentation Through Keys
M:4/4
L:1/16
K:C
%% Theme fragment sequenced downward
c2B2A2G2 F4 E4|B2A2G2F2 E4 D4|A2G2F2E2 D4 C4|
%% Arrival on dominant pedal
G,8 G,8|G,8 G,8|
```

## Mode Mixture in Haydn

Haydn uses mode mixture sparingly compared to Beethoven, which makes each instance potent. A moment of minor within a major-key movement feels like a shadow crossing sunlight.

| Borrowed Chord | Frequency in Haydn | Typical Usage |
|---------------|-------------------|---------------|
| iv (minor subdominant) | Moderate | Slow movement coloring; codas |
| bVI | Low-moderate | Development surprises; dramatic deceptive cadences |
| bVII | Rare | Approach to tonic in late works |
| i (tonic minor) | Moderate | Theme variation; development shadows |
