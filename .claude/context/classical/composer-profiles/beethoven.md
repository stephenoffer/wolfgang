# Ludwig van Beethoven — Composer Profile

## Core Identity

| Attribute | Value |
|-----------|-------|
| Full name | Ludwig van Beethoven |
| Dates | 1770-1827 |
| Nationality | German (Bonn), active Vienna |
| Primary roles | Composer, pianist |
| Key positions | Freelance, aristocratic patronage (Vienna) |
| Output | ~722 works (opus numbers 1-138 + WoO) |

## Three-Period Division

| Period | Years | Character | Formal approach |
|--------|-------|-----------|----------------|
| Early | 1792-1802 | Classical models, Haydn/Mozart influence | Standard forms, refined |
| Middle ("Heroic") | 1803-1814 | Expansion, drama, motivic power | Extended, transformed forms |
| Late | 1815-1827 | Introspective, fugal, transcendent | Fragmented, fused, unprecedented |

## Early Period (1792-1802)

### Characteristics

| Feature | Description |
|---------|-------------|
| Models | Haydn, Mozart, C.P.E. Bach |
| Form | Standard sonata, rondo, variation |
| Harmony | Mostly diatonic, clean functional progressions |
| Surprises | Unexpected sforzandi, remote key excursions |
| Melody | Shorter motives rather than long melodies |
| Already distinctive | Rhythmic energy, dynamic extremes, motivic economy |

### Key Works

| Genre | Works | Innovation |
|-------|-------|------------|
| Piano sonatas | Op. 2 (3), Op. 10 (3), Op. 13 "Pathetique" | Extended introductions, dramatic scope |
| Symphonies | 1, 2 | Expanded coda, scherzo instead of minuet |
| Quartets | Op. 18 (6) | Dramatic range within Classical frame |
| Concertos | Piano 1-3 | Increased orchestral weight |
| Chamber | Septet Op. 20, Trios | Popular, accessible |

## Middle Period — "Heroic" (1803-1814)

### Characteristics

| Feature | Description |
|---------|-------------|
| Scale | Massively expanded forms, longer movements |
| Drama | Extreme dynamic contrasts, titanic struggles |
| Motivic development | Entire movements from tiny motives |
| Rhythmic drive | Relentless forward momentum |
| Harmony | Distant key relationships, prolonged dissonance |
| Coda | Coda becomes "second development" |
| Orchestral force | Expanded brass, timpani prominence |
| Narrative arc | Struggle -> triumph pattern |

### Key Works

| Genre | Works | Innovation |
|-------|-------|------------|
| Symphonies | 3 "Eroica," 5, 6 "Pastoral," 7, 8 | Each unique formal plan |
| Piano sonatas | "Waldstein" Op. 53, "Appassionata" Op. 57 | Technical/emotional extremes |
| Concertos | Piano 4, 5 "Emperor"; Violin; Triple | Piano 4: solo enters first |
| Opera | Fidelio | Rescue opera, moral drama |
| Quartets | "Razumovsky" Op. 59, "Harp" Op. 74 | Symphonic quartet scope |
| Overtures | Leonore 3, Egmont, Coriolan | Symphonic drama |

### Motivic Development (Fifth Symphony model)

| Principle | Implementation |
|-----------|---------------|
| Short motive | 4 notes: short-short-short-LONG |
| Rhythmic identity | Rhythm more important than pitch |
| Pervasive use | Motive in every voice, every section |
| Transformation | Motive in major, minor, augmented, inverted |
| Structural role | Motive generates transitions, episodes |
| Cross-movement | Same motive links movements |

### Motivic ABC Example (Fifth Symphony type)
```abc
X:2

%% Motive statement

%% Motive in sequence

%% Motive inverted
z C, C, C, | _E,6 | z D, D, D, | F,6 |
```

### Expanded Coda

| Feature | Classical coda | Beethoven middle coda |
|---------|---------------|----------------------|
| Length | 4-16 bars | 40-100+ bars |
| Function | Confirm tonic | New development + confirmation |
| Material | Closing figures | Returns to P, new transformations |
| Key | Tonic only | May explore keys before final tonic |
| Drama | Closing | Climactic; can be movement's apex |

## Late Period (1815-1827)

### Characteristics

| Feature | Description |
|---------|-------------|
| Introspection | Personal, spiritual, philosophical |
| Fugue | Fugal writing as structural principle |
| Variation | Extended variation sets as movement type |
| Contrast extremes | Juxtaposition of bagatelle and fugue |
| Lyricism | New depth of songful expression (Heiliger Dankgesang) |
| Form | Conventions dissolved; unique solutions per work |
| Cyclic unity | Movements linked thematically or attacca |
| Silence | Rests and pauses as structural elements |
| Register extremes | Very high and very low simultaneously |

### Key Works

| Genre | Works | Innovation |
|-------|-------|------------|
| Symphonies | 9 "Choral" | Voices in symphony, massive scale |
| Piano sonatas | Op. 101, 106 "Hammerklavier," 109, 110, 111 | Fugue movements, variation finales |
| Quartets | Op. 127, 130, 131, 132, 135 | 7-movement form (131), Grosse Fuge |
| Missa Solemnis | Op. 123 | Symphonic mass, transcendent |
| Diabelli Variations | Op. 120 | 33 variations, encyclopedic |
| Bagatelles | Op. 126 | Miniatures with profound depth |

### Late Fugal Writing

| Feature | Description |
|---------|-------------|
| Scale | Full-movement fugues (Hammerklavier, Grosse Fuge) |
| Integration | Fugue within sonata form |
| Dissonance | Harsh clashes for expressive purpose |
| Subject complexity | Chromatic, angular subjects |
| Freedom | Breaks fugal rules for emotional effect |
| Culmination | Fugue as spiritual climax |

## Signature Techniques (All Periods)

### Motif as Building Block

| Principle | Implementation |
|-----------|---------------|
| Economy | Maximum effect from minimum material |
| Saturation | Motive in every voice and register |
| Transformation | Inversion, augmentation, diminution, fragmentation |
| Rhythmic primacy | Rhythmic identity more important than pitch |
| Structural generation | Themes, transitions, accompaniment all from one motive |
| Cross-movement | Motivic connections across movements |

### Subito Dynamics

| Effect | Notation | Context |
|--------|----------|---------|
| sf / sfz | Single accent | On any beat, any dynamic |
| fp | Forte then immediate piano | Dramatic contrast |
| pp subito | Sudden pianissimo | After forte or crescendo |
| ff subito | Sudden fortissimo | After quiet passage |
| crescendo to p | Crescendo resolves to piano | Frustrated expectation |
| dim. -> ff | Diminuendo interrupted by fortissimo | Shocking return |

### Dynamic ABC Example


### Rhythmic Drive

| Technique | Description | Example works |
|-----------|-------------|---------------|
| Motor rhythm | Constant 8ths or 16ths, relentless | Symphony 7/I, Waldstein/I |
| Off-beat sforzandi | Accents disrupting meter | Symphony 3 scherzo |
| Hemiola chains | Extended metric disruption | Symphony 7 finale |
| Syncopation | Sustained tension against pulse | Op. 18/4, Op. 59/2 |
| Rhythmic unison | Entire orchestra on one rhythm | Symphony 5 opening |
| Metrical ambiguity | Bar lines seem wrong | Symphony 3 scherzo |
| Accelerating fragments | Motive compresses in time | Development sections |

### Formal Expansion

| Element | Classical norm | Beethoven's expansion |
|---------|--------------|----------------------|
| Introduction | 4-8 bars | 12-62 bars (Symphony 7) |
| Exposition | 50-80 bars | 100-150 bars |
| Development | 40-60 bars | 100-250 bars (Eroica) |
| Coda | 10-20 bars | 50-140 bars (Eroica) |
| Total movement | 150-250 bars | 300-700 bars |
| Symphony length | 20-30 min | 30-70 min |
| Slow movement | 50-100 bars | Up to 200 bars |
| Finale weight | Lighter than I | Equal or greater |

## Harmonic Language

### Key Relationships

| Relationship | Type | Example |
|-------------|------|---------|
| I - V | Standard dominant | Early works |
| I - bVI | Mediant, dramatic | "Waldstein" (C -> Ab) |
| I - bIII | Chromatic mediant | "Emperor" Concerto (Eb -> B as Cb) |
| I - III | Major mediant | Late quartets |
| I - bII | Neapolitan relationship | Rare, powerful |
| i - bvi | Minor submediant | Dramatic |
| Enharmonic dim7 | Pivot to remote keys | Development sections |
| Enharmonic Ger+6 | V7 reinterpreted | Modulation device |

### Characteristic Progressions

| Progression | Context |
|-------------|---------|
| C major -> C minor (modal shift) | Dramatic darkening |
| Prolonged V pedal (20+ bars) | Retransition buildup |
| bVI -> V (semitone bass descent) | Dramatic cadence approach |
| I -> V/vi -> vi -> V/V -> V -> I | Extended cadential |
| Diminished 7th sequences | Chromatic development passages |
| Neapolitan -> cad 6/4 -> V -> I | Climactic minor cadences |
| Chains of 3rds (C-Ab-E-C) | Late period explorations |

## Orchestral Innovations

| Innovation | Description | First appears |
|-----------|-------------|---------------|
| Expanded brass | 3 horns, then 4; trombones in symphony | Eroica (3 horns), 5th (trombones) |
| Piccolo in symphony | Extreme high register | Symphony 5 finale |
| Contrabassoon | Extreme low register | Symphony 5 finale, 9th |
| Timpani as soloist | Independent, tuned in octaves | Violin Concerto, Symphony 9 |
| Orchestral crescendo | Pages-long buildup | Eroica development |
| Silence as element | Grand pauses structurally placed | Throughout |
| Scherzo replaces minuet | Fast 3/4, rough humor | Symphony 2 onward |
| Voices in symphony | Choral finale | Symphony 9 |

## Beethoven vs Predecessors

| Feature | Haydn/Mozart | Beethoven |
|---------|-------------|-----------|
| Motive | Theme-based | Motive-based (shorter cells) |
| Development | Within sections | Permeates entire movement |
| Dynamic range | p-f, occasional ff/pp | pppp to fff, constant sfz |
| Coda | Brief confirmation | Second development section |
| Slow movement | Song-like, aria | Hymn-like, variation, meditation |
| Finale | Light, fast | Equal weight to first movement |
| Key relations | Close keys | Remote 3rd relations |
| Form | Regular | Expanded, modified, unique |
| Rhythm | Regular pulse | Disrupted, driving, syncopated |
| Silence | Occasional pause | Structural element |
