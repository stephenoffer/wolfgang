# W.A. Mozart — Composer Profile

## Core Identity

| Attribute | Value |
|-----------|-------|
| Full name | Wolfgang Amadeus Mozart |
| Dates | 1756-1791 |
| Nationality | Austrian (Salzburg, then Vienna) |
| Primary roles | Composer, pianist, violinist |
| Key positions | Salzburg court, freelance Vienna |
| Output | ~626 works (Kochel catalogue) |

## Period / Style Map

| Period | Years | Focus | Key works |
|--------|-------|-------|-----------|
| Child prodigy | 1762-1773 | Symphonies, early operas | Symphonies 1-25, Bastien und Bastienne |
| Salzburg maturity | 1773-1781 | Concertos, church music | Violin Concertos, Mass in C minor |
| Vienna early | 1781-1786 | Opera, piano concertos | Figaro, Concertos K. 466-491 |
| Vienna late | 1786-1791 | Opera, symphonies, chamber | Don Giovanni, Magic Flute, Jupiter, Requiem |

## Melodic Gift

### Characteristics

| Feature | Description |
|---------|-------------|
| Vocal quality | All melodies singable, even instrumental ones |
| Balanced phrases | 4+4 or 8+8 bar periods, elegant symmetry |
| Chromatic inflection | Expressive chromatic passing tones, appoggiaturas |
| Grace and elegance | Effortless-sounding melodic flow |
| Operatic influence | Instrumental themes have operatic character |
| Ornamental variety | Turns, trills, appoggiaturas integrated into melody |
| Rhythmic suppleness | Subtle rhythmic variety within regular phrases |

| Gesture | Description | ABC example |
|---------|-------------|-------------|
| Sighing appoggiatura | Descending step on strong beat | `B2A2` (dissonant B resolving) |

## Chromaticism

### Mozart's Chromatic Techniques

| Technique | Description | Context |
|-----------|-------------|---------|
| Chromatic passing tones | Inner voice chromatic motion | Everywhere |
| Secondary dominants | V/ii, V/V, V/vi | Standard practice |
| Augmented 6th chords | Italian, German types | Dramatic moments |
| Diminished 7th chains | Rapid chromatic modulation | Development, opera |
| Mode mixture | Borrowed chords from parallel minor | Emotional darkening |
| Neapolitan 6th | bII6 in minor | Dramatic cadences |
| Chromatic bass descent | Lament-like chromatic bass | Slow movements, minor keys |
| Enharmonic shifts | Exploiting dim7 ambiguity | Remote modulations |

## Wind Writing

### Mozart's Wind Innovations

| Innovation | Description |
|-----------|-------------|
| Clarinet as principal | First to feature clarinet prominently (from ~1781) |
| Wind serenade | Independent wind ensemble writing |
| Concerto winds | Winds as soloistic in concerto accompaniment |
| Wind dialogue | Winds converse with strings, not just double |
| Basset horn | Unique color in Requiem, Masonic music |
| Chalumeau register | Exploits clarinet's dark low register |

### Wind Roles in Mozart Orchestra

| Instrument | Mozart's typical use | Signature moments |
|-----------|---------------------|-------------------|
| Flute | Gentle melodies, doubling Vn I at octave | Flute Concertos, Magic Flute |
| Oboe | Expressive solo, doubling in tutti | Concerto K. 314, opera arias |
| Clarinet | Warm melody, chalumeau darkness | Concerto K. 622, Quintet K. 581 |
| Bassoon | Comic solo, bass support, independent melody | Concerto K. 191, opera buffa |
| Horn | Sustained pedals, heroic calls, solo melody | Concertos K. 417/447/495 |

## Formal Elegance

### Mozart's Formal Characteristics

| Feature | Description |
|---------|-------------|
| Perfect proportions | Sections in balanced proportions |
| Clear articulation | Phrase boundaries unmistakable |
| Smooth transitions | Modulations elegant, never forced |
| Two-theme exposition | Contrasting P and S themes |
| Lyrical S theme | Secondary theme always singing |
| Concise development | Efficient, not overly long |
| Faithful recapitulation | Returns adjusted, not radically altered |
| Coda as summation | Brief, elegant confirmation |

## Piano Concerto Innovations

### Mozart's Concerto Contributions

| Innovation | Description |
|-----------|-------------|
| Symphonic integration | Orchestra is full partner, not accompaniment |
| Wind-solo dialogue | Piano converses with individual winds |
| Emotional range | From tragic (K. 466) to festive (K. 503) |
| S theme for solo | New theme introduced by solo in exposition |
| Orchestral commentary | Orchestra comments on solo passages |
| Slow movement depth | Aria-like, deeply personal |
| Finale sophistication | Beyond simple rondo; sonata-rondo, variation |

### Piano Concerto Texture Types

| Texture | Description | Example context |
|---------|-------------|-----------------|
| Solo display | Piano alone, virtuosic | After orchestral tutti |
| Piano + winds | Dialogue, chamber-like | S theme area |
| Piano + strings | Accompanied melody | Lyrical passages |
| Tutti with piano | Full orchestra, piano adds | Climactic moments |
| Piano + single wind | Intimate duet | Slow movements |

## Harmonic Surprises

| Surprise | Description | Example |
|---------|-------------|---------|
| Sudden minor | Major theme shifts to minor | Development sections |
| Deceptive cadence to bVI | V resolves to bVI instead of I | Dramatic moments |
| Chromatic slide | Root motion by semitone | C major -> Db major |
| Unexpected modulation | Remote key arrives seamlessly | Fantasy K. 475 |
| Modal mixture chord | bVI, bVII, iv in major context | Darkening effect |
| Silence after buildup | Grand pause for dramatic effect | Opera and concerto |
| Picardy major ending | Minor piece ends with major chord | Some slow movements |

## Texture Preferences

| Genre | Typical texture |
|-------|----------------|
| Piano sonata | Melody + Alberti bass; dialogue between hands |
| Symphony | Homophonic tutti; lyrical strings in S theme |
| String quartet | Conversational; all 4 voices active |
| Piano concerto | Solo-tutti alternation; wind dialogues |
| Opera aria | Voice over orchestral accompaniment; obbligato winds |
| Opera ensemble | Multiple vocal lines, independent characters |
| Serenade | Light, divertimento-like; wind solos |
| Church music | Choral homophony and fugal counterpoint |

## Rhythmic Characteristics

| Pattern | Context |
|---------|---------|
| Steady 8th-note Alberti | Piano sonata accompaniment |
| Dotted rhythms (French style) | Overtures, ceremonial |
| Triplets vs duplets | Expressive tension |
| Syncopated inner voices | Enriching texture |
| Hemiola before cadences | Triple meter movements |
| Alla breve | Fugal passages, church music |
| Lombard rhythm | Galant expression |
| Compound meter (6/8) | Finales, pastoral character |

## Operatic Influence on Instrumental Music

| Principle | Implementation |
|-----------|---------------|
| Melody as character | Each theme has a distinct personality |
| Dramatic contrast | Sharp juxtapositions of mood |
| Recitative-like passages | Free, declamatory moments in sonatas |
| Ensemble texture | Multiple "characters" interacting |
| Aria form in slow movements | ABA with ornamented return |
| Comic timing | Unexpected pauses, rhythmic wit |
| Dramatic silence | General pauses for emphasis |
