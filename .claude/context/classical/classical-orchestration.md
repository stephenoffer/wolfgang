## Instrument Roles

| Instrument | Primary role | Secondary role | Notes |
|-----------|-------------|---------------|-------|
| Violin I | Melody | Virtuosic passages | Leading voice |
| Violin II | Accompaniment, harmony | Doubling Vn I at octave/unison | Often Alberti patterns |
| Viola | Harmony fill | Melody (rare) | Often neglected in early Classical |
| Cello | Bass line | Melody (soloistic) | Independent from bass in mature style |
| Double bass | Bass reinforcement | Rarely independent | Sounds octave below cello |
| Flute | Melody (high register) | Doubling Vn I at octave | Weak low register |
| Oboe | Melody, sustained tone | Doubling Vn I | Penetrating sound |
| Clarinet | Melody, warmth | Harmony fill, chalumeau register | Mozart's favorite |
| Bassoon | Bass line doubling | Solo melody, comic effects | Most agile bass wind |
| Horn | Sustained harmony (3rd, 5th) | Heroic melody (limited notes) | Natural horn: harmonic series |
| Trumpet | Fanfare, reinforcement | Rhythmic punctuation | Natural: limited pitches |
| Timpani | Rhythmic reinforcement | Dramatic rolls | Tonic + dominant only |

### Doubling Principles

| Principle | Implementation |
|-----------|---------------|
| Winds double strings in forte | Oboes on Vn I, bassoon on cello |
| Winds independent in piano | Solo colors, dialogue |
| Horns sustain harmony | Hold 3rd and 5th of chord |
| Trumpets + timpani together | Added for festive/loud passages |
| Clarinet replaces oboe | For warmth, legato passages |
| Flute at octave above Vn I | Brilliance in high register |
| Bassoon + cello unison | Standard bass reinforcement |

## Classical Tutti vs Solo

### Orchestral Tutti (forte)

| Layer | Instruments | Function |
|-------|------------|----------|
| Melody | Vn I + Fl + Ob I (octave or unison) | Primary line |
| Harmony | Vn II + Ob II + Vla | Chord fill |
| Bass | Vc + Cb + Bsn | Foundation |
| Sustain | Hn I + Hn II | Pedal tones, 3rd/5th |
| Punctuation | Tpt + Timp | Rhythmic accent |

### Piano Passage

| Layer | Instruments | Function |
|-------|------------|----------|
| Melody | Vn I alone (or with Fl) | Exposed, lyrical |
| Accompaniment | Vn II + Vla | Light figuration |
| Bass | Vc (without Cb) or pizz | Delicate |
| Color | Solo wind (Cl, Ob, or Fl) | Dialogue, commentary |

## Mannheim Orchestra Effects

| Effect | Description | Scoring | Context |
|--------|-------------|---------|---------|
| Mannheim crescendo | Extended crescendo, p to ff | Gradual instrument addition | Opening gestures |
| Mannheim rocket | Ascending arpeggio, rapid | Strings in unison | Energetic themes |
| Mannheim roller | Sustained crescendo on one chord | Tremolo strings + adding winds | Dramatic buildup |
| Mannheim sigh | Descending appoggiatura, decrescendo | Upper strings, winds | Expressive moments |
| Grand pause | Sudden silence after loud passage | All instruments | Dramatic contrast |

## Serenade / Divertimento Scoring

| Ensemble type | Instruments | Movements | Character |
|--------------|------------|-----------|-----------|
| String serenade | Vn I, Vn II, Vla, Vc, Cb | 4-7 | Light, outdoor |
| Wind serenade (Harmoniemusik) | 2 Ob, 2 Cl, 2 Hn, 2 Bsn | 4-7 | Outdoor entertainment |
| Mixed divertimento | Strings + winds (varied) | 3-6 | Flexible |
| Cassation | Strings or mixed | 5-7 | Includes march |
| Notturno | Small ensemble | 3-4 | Evening, intimate |

## Chamber Music Texture Patterns

### String Quartet Roles

| Texture | Vn I | Vn II | Vla | Vc |
|---------|------|-------|-----|-----|
| Melody + accomp | Melody | Repeated notes/chords | Repeated notes/chords | Bass |
| Dialogue | Melody -> | -> Melody | Harmony | Bass |
| Fugal | Subject | Answer | Subject | Answer |
| Hymn-like | Soprano | Alto | Tenor | Bass |
| Accompanied solo | Solo melody | Tremolo | Tremolo | Pizzicato |
| Conversation | Fragment | Fragment | Fragment | Fragment |

## Dynamic Markings (Classical usage)

| Marking | Meaning | Context |
|---------|---------|---------|
| pp | Very soft | Special, rare effect |
| p | Soft | Default for lyrical passages |
| mp | Moderately soft | Uncommon in early Classical |
| mf | Moderately loud | Uncommon in early Classical |
| f | Loud | Default for tutti |
| ff | Very loud | Climactic, special |
| fp | Loud then immediately soft | Sforzando effect |
| sfz | Sudden accent | Single-note emphasis |
| cresc. | Gradually louder | Extended buildup |
| dim. | Gradually softer | Wind-down |
| calando | Dying away | Phrase endings |

## Orchestration Checklist

| Check | Description |
|-------|-------------|
| Natural horn notes | Only available harmonics in chosen crook |
| Trumpet limitations | Same as horn; no chromatic passages |
| Timpani tuning | Only 2 pitches; must match key |
| Clarinet transposition | Bb or A; choose for fewest accidentals |
| Horn transposition | Match key of movement |
| Flute low register | Weak below D4; don't use in tutti |
| Oboe endurance | Rest frequently; tiring instrument |
| String crossings | Playable bowing patterns |
| Bass doubling | Cello + bass normally move together |
| Wind sustain | Breathing points required |
