# Late Romantic Harmony Reference

## Era Span
~1880–1920. Wagner mature works through early Schoenberg/Strauss. Tonality stretched to breaking point.

## Extended Tonality

### Tonal Ambiguity Techniques
| Technique | Method | Effect |
|---|---|---|
| Chromatic saturation | All 12 tones in close proximity | Tonal center obscured |
| Wandering tonality | Key changes every 2-4 bars | No stable center |
| Deceptive resolution chains | V -> not-I -> V -> not-I... | Perpetual avoidance |
| Suspended tonality | Dominant-quality chords without resolution | Floating tension |
| Tonal parenthesis | Brief stable key within ambiguous context | Island of clarity |
| Enharmonic fog | Respelled chords prevent clear analysis | Multiple interpretations |

### Wagner's Chromatic Harmony

#### The Tristan Chord
| Component | Analysis | Note |
|---|---|---|
| Spelling | F-B-D#-G# | Enharmonically ambiguous |
| As half-dim7 | F-Ab-Cb-Eb (= ii half-dim in Eb) | Functional reading |
| As Fr+6 | F-B-D#-G# in A minor | Augmented 6th reading |
| As altered V | G#-B-D#-F (= V7b5 of A?) | Dominant reading |
| Resolution | -> E-B-D#-G# (V7 of A minor) | Appoggiaturas resolve |
| Significance | Multiple valid analyses = tonal ambiguity | Defines late Romantic |

```abc
X:1
T:Tristan Chord and Resolution
M:6/8
L:1/8
K:Am
[F,=BD^G] z [E,=BD^G] | [E,CEA] z3 |
w: Tristan V7 Am
```

#### Wagner Chromatic Techniques
| Technique | Description | Example |
|---|---|---|
| Chromatic sequence | Patterns move by semitone | Leitmotif development |
| Appoggiatura chords | Every chord has non-chord tones | Continuous tension |
| Dominant chains | V7 resolves to another V7 | Infinite postponement |
| Elision | Cadence note = start of new phrase | Continuous flow |
| Chromatic voice leading | All voices move by semitone | Smooth, inevitable |
| Tritone substitution | bII7 replaces V7 | Remote color |

```abc
X:2
T:Wagnerian Chromatic Sequence
M:4/4
L:1/4
K:C
[CEGBb] [^CE^G=B] | [DF_Ac] [^DF^A^c] | [E^GBd] z2 z |
w: C7 C#7 D7 D#7 E7
```

## Massive Tonal Arcs

### Long-Range Harmonic Planning
| Scale | Technique | Description |
|---|---|---|
| Phrase level | Standard progressions | 4-8 bars, functional |
| Period level | Key area establishment | 16-32 bars, modulation |
| Section level | Key relationship | Minutes-long, structural |
| Movement level | Tonal narrative | 15-30 min, progressive |
| Multi-movement | Tonal journey | Full symphony, 60-90 min |

### Key Relationship Types (Late Romantic)
| Relationship | Distance | Effect | Usage |
|---|---|---|---|
| Semitone | m2 up/down | Dramatic shift | Climaxes, surprise |
| Major 3rd | M3 up/down | Chromatic mediant | Color change |
| Minor 3rd | m3 up/down | Relative/parallel | Standard connection |
| Tritone | TT | Maximum distance | Shock, inversion |
| Perfect 5th | P5 | Traditional | Still functional |
| Whole tone | M2 | Subtle shift | Gradual drift |

## Advanced Chromatic Techniques

### Enharmonic Reinterpretation
| Chord | Reading 1 | Reading 2 | Pivot function |
|---|---|---|---|
| Diminished 7th | viio7 of C | viio7 of Eb/F#/A | 4 keys accessible |
| German 6th | Ger+6 in C | V7 of Db | Semitone modulation |
| Augmented triad | I+ in C | I+ in E / I+ in Ab | 3 keys accessible |
| French 6th | Fr+6 in C | Fr+6 in F# | Tritone modulation |
| Dominant 9th | V9 in C | V9 (incomplete) of others | Multiple resolutions |

### Non-Functional Chord Succession
| Type | Principle | Effect |
|---|---|---|
| Parallel planing | All voices move same direction/interval | Coloristic |
| Chromatic slide | Hold common tones, slide others by m2 | Smooth, eerie |
| Third chains | Root moves by 3rds continuously | Kaleidoscopic |
| Tritone oscillation | Alternating tritone-related chords | Hovering, unresolved |
| Omnibus variants | Contrary chromatic motion | Voice-leading driven |
| Pedal-bound | Remote chords over static bass | Tension accumulation |

```abc
X:5
T:Third Chain (Late Romantic)
M:4/4

K:C
[CEG] [_A,C_E] | [E,^G=B] [C,EG] | [_A,,C_E] [E,,^GB,] |
w: C Ab E C Ab E
```

| Alteration | Chord | Sound | Resolution tendency |
|---|---|---|---|
| V7b9 | G-B-D-F-Ab | Dark, minor-mode | -> i strongly |
| V7#9 | G-B-D-F-A# | Blues-tinged | -> I or i |

## Leitmotif Harmonic Association
| Technique | Description |
|---|---|
| Motif + specific harmony | Each leitmotif carries its own harmonic world |
| Harmonic transformation | Motif's harmony changes with dramatic context |
| Harmonic collision | Two leitmotifs' harmonies clash = dramatic conflict |
| Harmonic resolution | Motif finally gets proper resolution = dramatic resolution |

## Cadence Avoidance Techniques
| Technique | Method | Result |
|---|---|---|
| Deceptive resolution | V -> not-I | Continuation forced |
| Evaded cadence | V -> I becomes V -> I6 or IV6 | Weakened arrival |
| Interrupted cadence | New phrase interrupts before resolution | Breathless |
| Elided cadence | Arrival = new departure | Continuous flow |
| Plagal substitution | IV replaces V for cadence | Softer closure |
| Modal cadence | Aeolian: bVII -> i | Archaic, open |
| Dissolution | Harmony dissolves rather than resolves | Evaporation |
