# Film Score Forms Reference

## Core Principle
Film score form is determined by the visual narrative. Musical structure follows scene structure, not abstract musical logic. The score must be flexible enough to hit specific timecodes while maintaining musical coherence.

## Scene-Based Structure

| Element | Description |
|---------|-------------|
| Cue | Individual piece of score for a specific scene |
| Hit point | Exact moment music must align with visual event |
| Underscore | Music beneath dialogue or action |
| Source music | Music that exists within the film world (diegetic) |
| Tempo map | Tempo adjustments to align hits with picture |
| Streamers and punches | Visual guides for conductor sync |

### Typical Cue Structure
```
Entrance (2-4 bars): Establish mood
Body (variable): Support scene arc
Hit point(s): Align with key visual moments
Exit (1-4 bars): Transition or fade
```

## Montage Form

| Element | Description |
|---------|-------------|
| Character | Music unifies disparate visual shots |
| Rhythm | Musical pulse drives the visual editing |
| Structure | Self-contained musical piece with clear arc |
| Typical arc | Build, climax, resolution matching visual narrative |
| Harmony | Steady progression, usually building |
| Length | 1-5 minutes typical |

### Montage Arc Template
```
Opening:    Establish rhythm/theme (A)
Building:   Add layers, increase energy (A -> B)
Climax:     Maximum orchestral force (C)
Resolution: Return or settle (A' or new quiet)
```

## Main Title Format

| Section | Duration | Function |
|---------|----------|----------|
| Opening gesture | 4-8 bars | Establish mood/world (studio logos) |
| Main theme statement | 16-32 bars | Present primary leitmotif |
| Development/bridge | 8-16 bars | Transition to secondary material |
| Secondary theme | 8-16 bars | Love theme or secondary leitmotif |
| Recapitulation | 8-16 bars | Main theme return, possibly varied |
| Closing gesture | 4-8 bars | Resolve or transition to first scene |

### Main Title Template (Williams Style)
```
|: Brass fanfare (4 bars) :| Full theme — strings + brass (16 bars) |
| Woodwind bridge (8 bars) | Lyric 2nd theme — strings (16 bars) |
| Theme 1 return — full orch (8 bars) | Climactic close (4 bars) |
```

## End Credits Suite

| Section | Content | Duration |
|---------|---------|----------|
| Opening | Main theme, full statement | 30-60 sec |
| Theme 2 | Love/secondary theme | 30-60 sec |
| Medley | Other significant cues | 1-3 min |
| Climactic restatement | Main theme, triumphant | 30-60 sec |
| Fade | Quiet version or fragment | 15-30 sec |
| Total | | 3-8 min |

## Through-Composed Dramatic Underscore

| Principle | Application |
|-----------|-------------|
| No repetition | Music follows scene, not musical form |
| Continuous transformation | Leitmotifs morphed throughout |
| Tempo flexibility | Accelerando/ritardando follow drama |
| Dynamic following | Music intensity matches scene intensity |
| Hit points | Musical events sync to visual events |
| Transitions | Music bridges between scenes seamlessly |

### Through-Composed Cue Map
```
0:00 - Solo piano, pp (character alone)
0:15 - Strings enter (emotion builds)
0:32 - HIT: Door opens — brass chord
0:35 - Tension ostinato (confrontation)
0:58 - HIT: Revelation — cymbal + key change
1:02 - Leitmotif in minor (sad truth)
1:25 - Decrescendo to silence
1:30 - End cue
```

## Cue Types

| Cue Type | Musical Character | Duration |
|----------|------------------|----------|
| Stinger | Single chord, sudden | 1-3 sec |
| Sting + tail | Chord + short aftermath | 3-10 sec |
| Short cue | Brief mood piece | 15-60 sec |
| Medium cue | Scene underscore | 1-4 min |
| Long cue | Extended sequence (battle, chase) | 4-10 min |
| Suite | Concert arrangement of score | 5-15 min |

## Mickey-Mousing vs. Emotional Scoring

| Approach | Description | When to Use |
|----------|-------------|-------------|
| Mickey-mousing | Music mimics every on-screen action | Comedy, animation |
| Emotional scoring | Music reflects emotional undercurrent | Drama, serious |
| Counterpoint scoring | Music contrasts with visual | Irony, tension |
| Ambient scoring | Music provides atmosphere, not narrative | Thriller, horror |
| Source scoring | Diegetic music serves narrative purpose | Realism |

## Tempo and Sync

| Technique | Description |
|-----------|-------------|
| Click track | Fixed tempo for conductor/musicians |
| Free timing | Conductor watches screen, adjusts | 
| Tempo map | Varying click tempo to hit points |
| Rubato within click | Written accelerando/ritardando to hit sync |
| Bar length adjustment | Add/subtract beats to align |
| Fermata | Hold note until visual cue |

## Form Selection Guide

| Scene Type | Recommended Form | Duration |
|-----------|-----------------|----------|
| Opening credits | Main title format | 2-5 min |
| Dialogue scene | Through-composed underscore | Variable |
| Action sequence | Continuous, hit-point driven | 2-8 min |
| Montage | Self-contained musical arc | 1-5 min |
| Love scene | ABA, lyric theme | 2-4 min |
| End credits | Suite/medley | 3-8 min |
| Transition | Short bridge cue | 10-30 sec |
| Shock moment | Stinger | 1-5 sec |
| Establishing shot | Atmospheric cue | 15-45 sec |
