# John Williams — Harmonic Language

## Core Principle: Post-Romantic Tonal Mastery

Williams uses the full vocabulary of late-Romantic tonal harmony — functional progressions, chromatic mediants, modal mixture, enharmonic reinterpretation — in service of cinematic storytelling. Every harmonic choice tells the audience what to feel.

## Harmonic Vocabulary

| Element | Description |
|---------|-------------|
| Foundation | Functional tonal harmony (I-IV-V-I available) |
| Chromatic mediants | Major 3rd shifts for wonder/magic |
| Modal mixture | Borrowed chords from parallel minor/major |
| Lydian inflection | Raised 4th for discovery/wonder |
| Leitmotif harmony | Each theme has its own harmonic identity |
| Modulation | Frequent; by half-step for escalation, by mediant for transformation |

## Signature Harmonic Moves

| Move | Function | Intervals | Example Context |
|------|----------|-----------|-----------------|
| bVI → I | Magic / wonder / arrival | Db → C (in C major) | E.T. flying, Star Wars throne room |
| Lydian #4 | Discovery / transcendence | F# in C major context | Superman fanfare, Close Encounters |
| i → bVI → bVII → I | Epic minor-to-major triumph | Cm → Ab → Bb → C | Victory sequences |
| Chromatic mediant (M3 up) | Brightening / transformation | C → E major | Magical reveals |
| Chromatic mediant (M3 down) | Darkening / mystery | C → Ab major | Ominous discoveries |
| Tritone relation | Villain / threat | C → F# | Imperial theme contexts |
| Half-step modulation | Escalation / urgency | C → Db → D → Eb | Chase sequences, rising tension |

```abc
X:1
T:The bVI-I "Wonder" Cadence
M:4/4
L:1/2
K:C
%%staves {1 2}
V:1 name="Upper voices"
[_DF_A]2 [CEG]2 |
V:2 name="Bass"
_D,2 C,2 |
% Db major → C major: the clouds part. Magic arrives. The Williams signature.
```

```abc
X:2
T:Lydian #4 — Discovery/Wonder
M:4/4
L:1/4
K:C
V:1 name="Brass"
C E G ^F | G2 C2 |
% The raised F# in C major creates the "shining" Lydian quality — Superman, Close Encounters
```

## Leitmotif Harmonic Identity

| Character Type | Harmonic Color | Key Area | Example |
|---------------|----------------|----------|---------|
| Hero (noble) | Major triads, open 5ths, Lydian | Bright keys (Bb, C, D) | Star Wars main theme |
| Villain (dark) | Minor, diminished, tritone, march | Dark keys (Cm, Em, Dm) | Imperial March |
| Love / heart | Major 7ths, suspensions, added 6ths | Warm keys (Eb, Ab, F) | Across the Stars |
| Mystery / magic | Chromatic mediants, whole tone | Shifting, no stable key | Hedwig's Theme |
| Nature / wonder | Open 5ths, Lydian, plagal | Pastoral keys (F, Bb) | Jurassic Park theme |
| Danger / fear | Minor 2nds, ostinato, chromatic | Low register, no stable key | Jaws motif |

```abc
X:3
T:Villain Harmony — Imperial March Style
M:4/4
L:1/4
K:Gm
V:1 name="Brass (march)"
G2 G2 | _E2 _B2 | G2 G2 | _E2 _B2 |
% Minor key, brass, march rhythm, tritone lurking — unmistakable villain color
```

## Modal Mixture

| Borrowed Element | From | Effect | Usage |
|-----------------|------|--------|-------|
| bVI chord | Aeolian | Melancholy, fate, wonder | Very frequent |
| bVII chord | Mixolydian | Epic, anthemic | Frequent |
| iv chord | Aeolian | Sadness within major context | Emotional moments |
| bIII chord | Aeolian | Broadening, expansion | Transitions |
| #IV (Lydian) | Lydian | Wonder, floating, discovery | Signature move |

```abc
X:4
T:Modal Mixture Sequence — Hero in Danger
M:4/4
L:1/2
K:C
[CEG]2 | [_A,C_E]2 | [_B,DF]2 | [CEG]2 |
% I → bVI → bVII → I: the hero faces darkness (bVI) and rises through (bVII) to triumph (I)
```

## Modulation Techniques

| Technique | Speed | Usage | Example |
|-----------|-------|-------|---------|
| Half-step up | 1 bar | Escalation, rising tension | Chase sequences |
| Enharmonic pivot | 1–2 bars | Surprise recontextualization | Plot twists |
| Chromatic mediant | Instant | Scene mood shifts | Wonder/magic reveals |
| Pivot chord | 2–4 bars | Smooth scene transitions | Dialogue to action |
| Direct (no preparation) | Immediate | Hard cuts between scenes | Scene changes |
| Sequential (up by step) | Every 4–8 bars | Building excitement | Finale buildups |

## Harmonic Rhythm by Scene Type

| Scene Type | Chord Changes | Character |
|-----------|---------------|-----------|
| Dialogue underscoring | Every 2–4 bars | Gentle, unobtrusive |
| Emotional scene | Every 1–2 bars | Rich, moving |
| Action/chase | Every beat or half-bar | Driving, urgent |
| Fanfare/march | Every 1–2 bars | Strong, rhythmic |
| Wonder/discovery | Every 2–4 bars | Slow, spacious |
| Climax/resolution | Held chords (2–4 bars each) | Weight, arrival |

## Voice Leading

| Principle | Application |
|-----------|------------|
| Smooth bass motion | Bass moves by step or 4th/5th; rarely leaps |
| Inner voice connections | Common tones held; chromatic motion in inner voices |
| Contrary motion at cadences | Bass descends as melody ascends at arrival points |
| Brass chord voicing | Close position (3rds/4ths) for power; open for grandeur |

```abc
X:5
T:Smooth Voice Leading — Love Theme Progression
M:3/4
L:1/4
K:Eb
V:1 name="Melody"
G A B | c B A | G F E | G3 |
V:2 name="Inner voices + bass"
[E,G,B,]3 | [_A,C_E]3 | [B,,_D,F,]3 | [E,,G,,B,,]3 |
% I → IV → V → I in Eb: smooth, warm, every voice moves minimally
```
