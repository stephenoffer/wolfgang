# Ennio Morricone — Stylistic Evolution

## Four Periods Overview

| Period | Years | Core Output | Signature Sound |
|--------|-------|-------------|-----------------|
| Avant-garde + early TV | 1958–1963 | Gruppo improvisation, TV/pop arranging | Experimental + commercial craft |
| Spaghetti Western | 1964–1975 | Leone partnership, Western genre | Eclectic timbres, silence, whistling |
| International art film | 1976–1999 | *The Mission*, *Cinema Paradiso*, global reach | Lyrical melody, orchestral beauty |
| Late concert + legacy | 2000–2020 | Concert tours, *Hateful Eight*, late scores | Refined, retrospective, darker |

## Period 1: Avant-Garde and Early Commercial (1958–1963)

### Characteristics

| Feature | Description |
|---------|-------------|
| Gruppo di Improvvisazione | Free improvisation with noise, extended techniques |
| TV/pop arranging | Hundreds of arrangements for Italian radio and records |
| First film scores | Light comedies, minor dramas |
| Dual identity | Avant-garde experimentalist BY DAY; commercial arranger BY NIGHT |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| Gruppo recordings | 1958–80 | Free improvisation; all members equal; no notation |
| RAI TV arrangements | 1950s–60s | Craft: learning to write for any style, any deadline |
| *Il Federale* | 1961 | First film score; conventional but skilled |

```abc
X:1
T:Gruppo Period — Free Improvisation (concept)

K:C
V:1 name="Free voices (no fixed pitch)"
^C _D z ^G | _B z z ^F | z z _E ^A |
% No tonal center, no meter — pure sound exploration
```

## Period 2: Spaghetti Western (1964–1975)

### The Shift

| From (Period 1) | To (Period 2) |
|-----------------|---------------|
| Avant-garde abstraction | Applied experimentalism within film |
| Anonymous commercial work | Signature sound recognized worldwide |
| Free improvisation | Controlled eccentricity |
| No film identity | THE Spaghetti Western sound |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| *A Fistful of Dollars* | 1964 | Whistling, whip, electric guitar = new film language |
| *For a Few Dollars More* | 1965 | Music box / carillon as leitmotif; pocket watch theme |
| *The Good, the Bad and the Ugly* | 1966 | Three-voice countermelody; "wah-wah" vocal |
| *Once Upon a Time in the West* | 1968 | Harmonica as character; temporal scoring; pre-composed |
| Giallo scores | 1970s | Avant-garde techniques applied to horror/thriller |

### Spaghetti Western Sonic Vocabulary

| Sound | Function | Dramatic Purpose |
|-------|----------|-----------------|
| Whistling | Main theme delivery | Intimate, human, lonely |
| Whip crack | Rhythmic punctuation | Violence, the frontier |
| Jaw harp | Rhythmic texture | Rustic, comic, raw |
| Electric guitar (reverb) | Arpeggiated accompaniment | The vast Western landscape |
| Solo trumpet (distant) | Military/herald | Distance, approach, announcement |
| Silence (2–4 bars) | Structural event | Tension, the pause before violence |
| Vocal "wah-wah" | Textural layer | Surreal, iconic |

```abc
X:2
T:Spaghetti Western Full Texture
M:4/4
L:1/8
K:Am
%%staves {1 2 3}

V:3 name="Vocal 'wah' + whip (texture)"
z4 z4 | z4 z4 |
% Whistle + guitar + vocal effects: the complete Spaghetti Western palette
```

## Period 3: International Art Film (1976–1999)

### The Shift

| From (Period 2) | To (Period 3) |
|-----------------|---------------|
| Genre specialist (Westerns) | Universal film composer |
| Eclectic/experimental | More lyrical, classically beautiful |
| Leone partnership dominant | Multiple directors, international |
| Small forces, eclectic | Full orchestra + eclectic solos |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| *Days of Heaven* | 1978 | Pastoral orchestral scoring; Malick collaboration |
| *Once Upon a Time in America* | 1984 | Pan-flute nostalgia; 4-hour magnum opus |
| *The Mission* | 1986 | *Gabriel's Oboe*: sacred melody mastery |
| *The Untouchables* | 1987 | American orchestral drama; broader palette |
| *Cinema Paradiso* | 1988 | Nostalgia theme: global cultural icon |
| *Bugsy* | 1991 | Jazz-inflected Hollywood scoring |

### Period 3 Characteristics

| Feature | Description |
|---------|-------------|
| Melody | More lyrical, arching; Classical beauty |
| Orchestration | Full orchestra + characteristic solo (oboe, pan-flute) |
| Harmony | Richer modal harmony; less open-5th starkness |
| Silence | Less prominent; more continuous scoring |
| International reach | British, American, French productions |
| Emotional range | Warmer, more nostalgic, less violent |

## Period 4: Late Concert and Legacy (2000–2020)

### The Shift

| From (Period 3) | To (Period 4) |
|-----------------|---------------|
| Active film scoring | Fewer films; more concerts |
| 30+ scores per year | Selective scoring |
| Writing new material | Conducting retrospective concerts |
| Multiple styles | Return to darker, more austere palette |

### Key Works

| Work | Year | Innovation |
|------|------|-----------|
| Concert tours | 2000s–2010s | Morricone conducts worldwide; 2-hour retrospectives |
| *Voci dal Silenzio* (concert) | 2002 | Serious concert composition |
| *The Hateful Eight* | 2015 | Return to Western genre; first competitive Oscar (age 87) |
| Late concert works | 2010s | Darker, more abstract; Gruppo influence resurfaces |

```abc

```

## Evolution Comparison Table

| Parameter | Period 1 (1958–63) | Period 2 (1964–75) | Period 3 (1976–99) | Period 4 (2000–20) |
|-----------|-------------------|-------------------|-------------------|-------------------|
| Melody | Experimental / pop | Whistled, folk, eclectic | Lyrical, Classical beauty | Darker, austere |
| Harmony | Avant-garde / pop | Open 5ths, modal, silence | Richer modal | Sparse, darker |
| Instruments | Gruppo: anything | Whistle, guitar, harmonica | Orchestra + solo | Orchestra, austere |
| Silence | Part of improv | Central structural element | Less prominent | Returns |
| Films/year | 5–10 | 15–30 | 10–20 | 2–5 |
| Emotional range | Abstract | Vast, violent, lonely | Warm, nostalgic, sacred | Reflective, dark |

## Constants Across All Periods

| Constant | Description |
|----------|-------------|
| Singable melody | Every period has simple, memorable themes |
| Unexpected timbres | "Wrong" instruments always present |
| Countermelody | Multiple independent layers in all periods |
| Silence | Even when less prominent, always structural |
| Avant-garde undercurrent | Gruppo training surfaces in every period |
| Prolific output | 500+ film scores; extraordinary productivity |
