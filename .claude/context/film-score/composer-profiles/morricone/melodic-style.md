# Ennio Morricone — Melodic Style

## Core Principle: Singable Simplicity, Eclectic Delivery

Morricone's melodies are simple enough to whistle — but delivered by unexpected instruments (harmonica, ocarina, wordless soprano, electric guitar). The melody is folk-simple; the timbre is surprising.

## Melodic Types

| Type | Description | Instrument | Examples |
|------|-------------|-----------|----------|
| Whistled theme | Simple, folk-like melody | Human whistle | *The Good, the Bad and the Ugly* |
| Oboe cantilena | Lyrical, arching, Classical beauty | Solo oboe | *Gabriel's Oboe* (*The Mission*) |
| Vocal wordless | Soprano sings without text | Female voice | *Once Upon a Time in the West* |
| Guitar theme | Arpeggiated or picked | Acoustic/electric guitar | *Cinema Paradiso* |
| Harmonica solo | Raw, bluesy, character-specific | Diatonic harmonica | *Once Upon a Time in the West* |
| Trumpet call | Distant, military, lonely | Solo trumpet | *The Good, the Bad and the Ugly* |
| Pan-flute | Nostalgic, innocent, pastoral | Pan-flute | *Once Upon a Time in America* |

```abc
X:1
T:Whistled Theme (Good Bad Ugly style)
M:4/4
L:1/8
K:Am
V:1 name="Whistle"
A2 E2 A2 E2 | G2 F2 E2 C2 | A2 E2 A2 G2 | E4 z4 |
% Simple enough to whistle after one hearing — THIS is the Morricone melodic standard
```

```abc
X:2
T:Oboe Cantilena (Gabriel's Oboe style)
M:4/4
L:1/8
K:D
V:1 name="Solo oboe"
D2 F2 A2 d2 | c2 B2 A2 F2 | D2 E2 F2 A2 | B4 A4 |
% Lyrical, stepwise, arching — Classical beauty delivered through a single solo voice
```

## Melodic Construction Principles

| Principle | Description |
|-----------|-------------|
| Singability | Must be hummed or whistled by anyone |
| Stepwise predominance | Mostly steps and 3rds; leaps for emphasis only |
| Short phrases | 4–8 bar phrases, clearly punctuated |
| Modal roots | Melody sits in a mode, not a key signature |
| One memorable interval | Each theme has ONE signature leap (the "hook" interval) |
| Repetition | Theme repeats many times with varied orchestration |
| Vocal quality | Even instrumental melodies sound like they could be sung |

## Interval Vocabulary

| Interval | Usage | Character | Example |
|----------|-------|-----------|---------|
| Minor 3rd | Most common leap | Melancholy, folk | Western themes |
| Perfect 4th | Open, calling | Trumpet calls, distance | *Good Bad Ugly* |
| Perfect 5th | Spacious, noble | Opening intervals | *The Mission* |
| Minor 2nd | Tension, approaching | Standoff music | Tension cues |
| Major 2nd | Gentle step | Flowing melody | *Cinema Paradiso* |
| Octave | Expansive, dramatic | Rare; climactic use | Peak moments |

## Countermelody Architecture

Morricone's defining textural technique: 2–3 simultaneous independent melodic layers, all singable:

| Layer | Function | Register | Dynamic | Instrument |
|-------|----------|----------|---------|-----------|
| Melody 1 (primary) | Main theme, most prominent | Middle-high | mp–mf | Voice, whistle, oboe |
| Melody 2 (counter) | Independent contrasting line | Low-middle | p–mp | Cello, bass trumpet, baritone |
| Ostinato (rhythmic) | Repeated pattern beneath both | Low | pp–p | Guitar, low strings |

```abc
X:3
T:Three-Layer Countermelody (Good Bad Ugly style)
M:4/4
L:1/8
K:Am
%%staves {1 2 3}
V:1 name="Layer 1: Whistle (melody)"
A2 E2 A2 E2 | G2 F2 E4 |
V:2 name="Layer 2: Bass (countermelody)"
C2 D2 E2 C2 | D2 E2 A,4 |
V:3 name="Layer 3: Guitar (ostinato)"
A,E A,E A,E A,E | A,E A,E A,E A,E |
% Three independent singable layers — each complete alone; extraordinary together
```

## Vocal Writing

| Type | Technique | Examples |
|------|-----------|---------|
| Wordless soprano | Pure vowel sounds ("aah"), floating above orchestra | *Once Upon a Time in the West* |
| Vocal "wah-wah" | Rhythmic vocal interjection; part of the texture | *Good Bad Ugly* |
| Choral chanting | Simple syllables, rhythmic unison | Western scores |
| Solo male voice | Baritone or tenor; folk-song quality | Italian-influenced cues |

```abc
X:4
T:Wordless Soprano (Once Upon a Time in the West style)
M:3/4
L:1/4
K:Em
V:1 name="Soprano (wordless: 'aaah')"
E G B | A G E | D E G | E3 |
% No words — the voice is an instrument, carrying pure emotion through pitch and breath
```

## Thematic Economy

| Feature | Description |
|---------|-------------|
| Notes per theme | 6–12 (almost never more) |
| Rhythmic simplicity | Mostly quarter and eighth notes; no complex rhythm |
| Repetition | Theme stated 4–8 times in a 3-minute cue |
| Variation | Orchestration changes (new instrument), not melodic changes |
| Development | Rare in Western sense; the melody is fixed |

## Silence Within Melody

| Silence Type | Function |
|-------------|----------|
| Between phrases | Breathing space; creates expectation |
| Mid-phrase pause | Dramatic effect; the note you're waiting for |
| Before the theme | Silence, then the melody enters from nothing |
| After the theme | The melody ends; its echo hangs in the silence |

```abc
X:5
T:Silence Within Melody (Western style)
M:4/4
L:1/4
K:Am
V:1 name="Trumpet (distant)"
A z E z | A z G z | E2 z2 | z4 |
% Every other beat is silence — the melody breathes as much as it sings
```

## Melodic Anti-Patterns

| Avoid | Why |
|-------|-----|
| Complex, hard-to-sing melodies | Morricone's themes must be whistleable |
| Chromatic passages | His melodies are modal, not chromatic |
| Long unbroken phrases (16+ bars) | Short phrases with breathing space between |
| Melodic development (fragmentation, inversion) | The melody is fixed; orchestration varies |
| Ornaments (classical trills, mordents) | Clean, folk-like delivery |
