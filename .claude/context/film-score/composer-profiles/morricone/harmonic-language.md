# Ennio Morricone — Harmonic Language

## Core Principle: Simple Tonal Foundation with Avant-Garde Touches

Morricone's harmony is fundamentally simple — folk-like, modal, singable. But his avant-garde training (Petrassi, Gruppo) means that dissonance, cluster chords, or atonal passages can erupt without warning, creating extreme emotional contrasts within a single cue.

## Harmonic Vocabulary

| Element | Description |
|---------|-------------|
| Foundation | Modal/tonal; folk-derived |
| Chord types | Triads, open 5ths, suspended chords |
| Functional harmony | Sometimes present (I-IV-V), but never academic |
| Modal inflection | Dorian, Phrygian, Aeolian common |
| Avant-garde intrusion | Clusters, free atonality, noise — erupting within tonal context |
| Harmonic rhythm | Slow to moderate; silence between changes |

## Characteristic Harmonic Approaches

| Approach | Description | Films |
|----------|-------------|-------|
| Open-fifth foundation | Root + 5th, no 3rd — ambiguous, vast | Western scores |
| Modal folk harmony | Dorian or Aeolian progressions, simple | *The Mission*, *Cinema Paradiso* |
| Suspended tension | Sus4 or sus2 chords, unresolved | Western "standoff" music |
| Avant-garde eruption | Clusters, atonal passages, noise | Giallo films, horror |
| Pedal-point stasis | Sustained bass, melody moves above | Most lyrical themes |
| Chromatic descent | Bass descending by half-step | Ominous, fate-driven |

```abc
X:1
T:Open-Fifth Foundation — Western Vast Space
M:4/4
L:1/2
K:Am
%%staves {1 2}
V:1 name="Guitar/strings (open 5th)"
[A,E]2 [A,E]2 |
V:2 name="Bass"
A,,4 |
% No 3rd — is it major or minor? The ambiguity IS the open-space sound
```

```abc
X:2
T:Suspended Tension — Standoff Harmony
M:4/4
L:1/2
K:Am
V:1 name="Full ensemble"
[A,DA]2 [A,DA]2 | [A,DA]2 [A,CE]2 |
% Asus4 sustained for 3 bars before resolving to Am — the standoff, then the draw
```

## Modal Harmony

| Mode | Character | Films |
|------|-----------|-------|
| A Aeolian | Gentle sadness, nostalgia | *Cinema Paradiso* |
| D Dorian | Warm, folk-like, timeless | *The Mission* |
| E Phrygian | Dark, Spanish, exotic | Western standoff cues |
| G Mixolydian | Earthy, grounded | Folk-derived themes |
| Pentatonic | Universal, simple, ancient | Pan-flute themes |

### Characteristic Modal Progressions

| Mode | Progression | Character |
|------|-------------|-----------|
| Aeolian | i → bVI → bVII → i | Epic sadness |
| Dorian | i → IV → i → IV | Warm oscillation |
| Phrygian | i → bII → i | Dark tension |
| Pentatonic | I → IV → I (no leading tone) | Folk purity |

```abc
X:3
T:Dorian Oscillation (The Mission style)
M:4/4
L:1/4
K:Dm
V:1 name="Oboe"
D F A d | c A F D |
V:2 name="Guitar (Dorian: i → IV)"
[DFA]4 | [GBd]4 |
% Dm → G major oscillation: warm, modal, folk-like — the Dorian sound
```

## Silence as Harmonic Element

| Silence Type | Function | Duration |
|-------------|----------|----------|
| Between chord statements | Tension; the pause IS the drama | 1–4 bars |
| After melody phrase | Space for resonance | 1–2 bars |
| Structural silence | No music at all; the film breathes | 4–16 bars |
| Before climax | The gap before the gun draws | 2–4 bars |

```abc
X:4
T:Silence as Harmony (Western standoff)
M:4/4
L:1/2
K:Em
V:1 name="Sparse texture"
[E,B,]2 z2 | z4 | [E,B,]2 z2 | z4 |
% Open 5th — 2 bars silence — open 5th — silence. The silence IS half the score.
```

## Avant-Garde Harmonic Intrusion

When Morricone's Gruppo training surfaces:

| Technique | Usage | Context |
|-----------|-------|---------|
| Tone clusters | Stacked semitones in strings or piano | Horror, psychological tension |
| Free atonality | No tonal center; pitches chosen for color | Giallo films, dream sequences |
| Prepared piano | Objects on strings alter timbre | Experimental cues |
| Noise elements | Non-pitched sounds as harmonic texture | Violence, chaos |

```abc
X:5
T:Avant-Garde Eruption Within Tonal Context
M:4/4
L:1/8
K:Am
V:1 name="Tonal (melody)"
A2 B2 c2 B2 |
V:1 name="Avant-garde (cluster intrusion)"
[A^AB_Bc]8 |
V:1 name="Return to tonal"
A2 G2 F2 E2 |
% Tonal → cluster chaos → tonal return. The contrast IS the Morricone moment.
```

## Pedal Point Usage

| Type | Bass Note | Above | Films |
|------|----------|-------|-------|
| Tonic pedal | Root sustained | Melody moves freely above | *Cinema Paradiso* |
| Dominant pedal | 5th sustained | Building to resolution | Western climaxes |
| Chromatic pedal | Bass descends by half-step | Increasing tension | Thriller scores |
| Drone (guitar) | Open string repeated | Modal melody above | Western themes |

## Harmonic Contrast (Within Single Cue)

| Section | Harmony | Dynamic | Effect |
|---------|---------|---------|--------|
| Opening | Single note or silence | ppp | Isolation, vastness |
| Theme entry | Simple modal | p–mp | Human warmth |
| Climax | Full tonal, rich voicing | f | Emotional peak |
| Interruption | Cluster or atonal burst | ff | Violence, shock |
| Return | Simple modal, one instrument | p | Recovery, aftermath |
