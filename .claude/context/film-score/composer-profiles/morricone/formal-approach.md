# Ennio Morricone — Formal Approach

## Core Principle: Theme and Variations with Eclectic Mixing

Morricone's primary form is a simple theme stated and restated with changed orchestration. Within a single cue, he freely mixes styles — folk, avant-garde, classical — creating extreme emotional contrasts.

## Primary Formal Types

| Form Type | Structure | Usage |
|-----------|-----------|-------|
| Theme + reorchestration | Same melody, different instruments each time | Most themes across all genres |
| Standoff / temporal scoring | Music synchronized to on-screen time (pre-composed) | Leone films |
| Eclectic collage | Different styles juxtaposed within one cue | Complex dramatic scenes |
| Through-composed | Continuous, evolving, following scene | Dramatic underscore |
| Binary (A-B) | Theme + contrasting section | Short cues |
| Silence-framed | Silence → theme → silence | Western themes |

## Theme and Reorchestration Form

| Statement | Instrument | Dynamic | Character |
|-----------|-----------|---------|-----------|
| 1 | Solo instrument (whistle, harmonica, oboe) | p | Intimate, exposed |
| 2 | Solo + light accompaniment (guitar or strings) | mp | Growing warmth |
| 3 | Orchestral arrangement (strings carry theme) | mf | Full emotion |
| 4 | Full forces + voice/choir | f | Climactic |
| 5 (optional) | Return to solo, quieter than statement 1 | pp | Nostalgia, fading |

```abc
X:1
T:Theme Reorchestration — Statement 1 (Solo) → Statement 3 (Orchestra)
M:4/4
L:1/8
K:Am
V:1 name="Statement 1: Solo oboe"
A2 B2 c2 B2 | A2 G2 E4 |
V:1 name="Statement 3: Strings + oboe"
A2 B2 c2 B2 | A2 G2 E4 |
% Same melody — first alone, then with full strings. The form IS the reorchestration.
```

## Leone Temporal Scoring

Morricone composed music BEFORE Leone filmed. Leone played the music on set. This created a unique formal relationship:

| Element | Process |
|---------|---------|
| Pre-composition | Morricone writes the full score from the script |
| On-set playback | Leone plays the music during filming; actors perform to it |
| Scene pacing | The music's tempo determines the scene's pacing |
| Silence placement | Morricone's silences become Leone's pauses |
| Edit to music | Leone edits the film to match the pre-existing score |

### Standoff Form (The Leone-Morricone Structure)

| Phase | Music | Visual | Duration |
|-------|-------|--------|----------|
| Approach | Sparse: open 5th, distant trumpet | Wide shot; characters approach | 1–2 min |
| Silence 1 | Complete silence | Close-up: eyes | 10–30 sec |
| Tension | Single sustained note or slow ostinato | Extreme close-ups: hands, eyes | 30–60 sec |
| Silence 2 | Complete silence | Hand reaching for gun | 5–15 sec |
| Resolution | Sudden full theme or single gunshot | The draw; resolution | 5–15 sec |
| Aftermath | Theme enters gently, one solo instrument | Wide shot; aftermath | 30–60 sec |

```abc
X:2
T:Standoff Form — Approach + Silence + Resolution
M:4/4
L:1/4
K:Em
V:1 name="Approach (distant trumpet)"
E z B, z | E z z2 |
V:1 name="Silence (2 bars)"
z4 | z4 |
V:1 name="Resolution (full theme explodes)"
E G B e | d B G E |
% Sparse approach → silence → full theme. The silence is the most tense moment.
```

## Eclectic Collage Form

Within a single 3–5 minute cue, Morricone may juxtapose:

| Section | Style | Duration | Transition |
|---------|-------|----------|-----------|
| A | Folk melody (guitar, whistle) | 30–60 sec | Gentle |
| B | Avant-garde eruption (clusters, noise) | 15–30 sec | Abrupt |
| A' | Folk melody returns, different instrument | 30–60 sec | Abrupt return |
| C | Orchestral romantic sweep | 30–60 sec | Gradual build |
| Silence | Complete rest | 5–15 sec | Cut |
| A'' | Folk melody, softest version | 15–30 sec | From silence |

The contrasts are EXTREME — folk simplicity next to avant-garde chaos next to Romantic beauty. No other film composer mixes styles this freely.

## Variation Techniques

| Variation | Change | What Stays the Same |
|-----------|--------|-------------------|
| Reorchestration | New instrument carries theme | Melody, harmony, rhythm |
| Dynamic variation | Same instrument, different dynamic | Melody, harmony, instrument |
| Register shift | Theme moved up/down an octave | Melody, rhythm |
| Textural change | Solo → ensemble or ensemble → solo | Melody |
| Rhythmic augmentation | Theme slowed down (halved values) | Pitch content |
| Countermelody added | New layer beneath existing theme | Original melody on top |

## Proportions

| Element | Typical Duration | Notes |
|---------|-----------------|-------|
| Main theme statement | 8–16 bars | Clear, unadorned |
| Silence between statements | 2–8 bars | Structural breathing |
| Reorchestrated variation | 8–16 bars | Same length as original |
| Contrasting section | 8–16 bars | Different style/mood |
| Full cue | 2–5 minutes | Rarely longer in Westerns |
| Extended concert arrangement | 5–10 minutes | *Cinema Paradiso* suite |

## How a Morricone Cue Ends

| Ending Type | Description | Context |
|-------------|-------------|---------|
| Fade to silence | Solo instrument diminuendo to nothing | Most lyrical themes |
| Abrupt cut | Music stops suddenly (often mid-phrase) | Violence, shock |
| Resolution to tonic | Simple authentic cadence | Rare; gentle conclusions |
| Sustained note | Single note held and fading | Vast space, aftermath |
| Return to silence | The music came from silence; returns to it | Most Western cues |

```abc
X:3
T:Ending — Fade to Silence
M:4/4
L:1/4
K:Am
V:1 name="Solo harmonica (fading)"
A G E C | A, z z2 | z4 | z4 |
% The harmonica fades into silence. The landscape remains.
```
