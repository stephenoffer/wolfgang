# Film Score Harmony Reference

## Core Principle
Film score harmony serves narrative. Every chord choice supports the emotional arc of the scene. Techniques borrowed from Romantic, Impressionist, Modern, and Minimalist traditions are combined freely in service of dramatic storytelling.

## Leitmotif System

| Element | Description |
|---------|-------------|
| Definition | Short musical theme associated with a character, place, or idea |
| Length | 4-12 notes typical |
| Recognizability | Must be instantly identifiable on return |
| Transformation | Motif changes with character's emotional state |
| Harmonic identity | Each leitmotif has characteristic harmony |
| Layering | Multiple leitmotifs can combine in complex scenes |

### Leitmotif Transformation Table

| Scene Context | Transformation Technique |
|--------------|------------------------|
| Hero triumphant | Major key, brass, forte, full orchestration |
| Hero in danger | Minor key, tremolo strings, fragmented |
| Love scene | Slower tempo, warm strings, legato |
| Death/loss | Minor, solo instrument, pp, augmented rhythm |
| Memory/flashback | Celesta/harp, distant dynamic, simplified |
| Corruption/villain | Distorted intervals, chromatic alteration |
| Victory | Full orchestra, original key, fff |

### Leitmotif Example
```abc
X:1
T:Hero Leitmotif
M:4/4
K:Bb
| B2 d2 | f3 e | d2 B2 | F4 |
```

## Dramatic Modulation

| Type | Description | Dramatic Use |
|------|-------------|-------------|
| Truck-driver's modulation | Up a half/whole step, abrupt | Energy boost, "one more time" |
| Pivot chord | Shared chord between keys | Smooth scene transition |
| Chromatic mediant | Third-related shift (C to E, C to Ab) | Wonder, new vista, revelation |
| Enharmonic pivot | Reinterpret chord function | Twist, surprise |
| Direct juxtaposition | No transition, new key | Hard scene cut |
| Deceptive resolution | V -> vi or V -> bVI | Subverted expectation |
| Sequence | Pattern repeated at new pitch level | Building excitement |

## Chromatic Mediant Relationships

| Relationship | Example | Emotional Quality |
|-------------|---------|-------------------|
| Upper major 3rd | C -> E | Bright wonder, awe |
| Lower major 3rd | C -> Ab | Dark wonder, mystery |
| Upper minor 3rd | C -> Eb | Shadowy, ominous |
| Lower minor 3rd | C -> A | Warm, nostalgic |
| Chromatic (shared note) | C major -> E major (share E) | Smooth, magical |
| Chromatic (no shared note) | C major -> Db major | Jarring, disorienting |

### Chromatic Mediant Shift
```abc
X:2
T:Wonder Modulation (C to E)
M:4/4
K:C
| [C4E4G4] | [E4^G4B4] |
```

## Bitonal Tension

| Technique | Application |
|-----------|-------------|
| Two triads superimposed | Anxiety, inner conflict |
| Melody in one key, accompaniment in another | Dreamlike disconnect |
| Polytonal cluster | Maximum tension, chaos |
| Bitonal ostinato | Unsettled recurring figure |
| Resolution to unison | Conflict resolved into single key |

## Unresolved Suspense Chords

| Chord Type | Construction | Suspense Level |
|-----------|-------------|----------------|
| Suspended 4th | 1-4-5 | Mild tension |
| Half-diminished 7th | 1-b3-b5-b7 | Moderate mystery |
| Augmented triad | 1-3-#5 | Floating unease |
| Tritone dyad | 1-b5 | Sharp tension |
| Minor-major 7th | 1-b3-5-7 | Creeping dread |
| Dominant b9 | 1-3-5-b7-b9 | High tension |
| Diminished + pedal | dim7 over foreign bass | Maximum suspense |
| Cluster (chromatic) | Adjacent semitones | Horror, shock |

### Suspense Chord Escalation
```
Level 1: Cm (minor triad — unease)
Level 2: Cm(maj7) (minor-major 7 — creeping)
Level 3: Cdim7 (diminished — spinning)
Level 4: C-F# (tritone — maximum tension)
Level 5: Chromatic cluster (horror stinger)
```

## Victory Cadence Patterns

| Cadence | Progression | Emotional Quality |
|---------|-------------|-------------------|
| Authentic triumph | IV - V - I (major, fff) | Classic victory |
| Plagal triumph | IV - I (with brass fanfare) | Noble, hymnlike |
| Deceptive then authentic | V - vi - V - I | Earned triumph (almost failed) |
| Chromatic approach | bVI - bVII - I | Epic, massive |
| Truck-driver + authentic | Key up half step, then V-I | Maximum climax |
| Tierce de Picardie | iv - V - I (minor to major) | Hope from darkness |
| Double plagal | bVII - IV - I | Sweeping, cinematic |

### Victory Cadence
```abc
X:3
T:Triumphant Cadence
M:4/4
K:Bb
| [_A2_A2c2_e2] [_B2_B2d2f2] | [B,4B4d4f4b4] |
```

## Horror/Tension Harmonies

| Technique | Description | Intensity |
|-----------|-------------|-----------|
| Tritone ostinato | Repeated tritone interval | Moderate |
| Chromatic descent | Bass creeps down chromatically | Building dread |
| Cluster crescendo | Chromatic cluster, growing louder | High |
| Stinger chord | Sudden loud dissonance | Maximum (jump scare) |
| Col legno + tremolo | String texture, no clear pitch | Atmospheric dread |
| Whole-tone drift | Whole-tone chords, no gravity | Disorientation |
| Quartal stacking | Stacked 4ths, ambiguous | Unease |
| Reverse resolution | Consonance to dissonance | Dread from comfort |
| Silence then attack | Long pause, sudden loud chord | Jump scare |

### Horror Progression
```
Ambient: sustained Cm(maj7), pp, tremolo strings
Building: chromatic bass descent C - B - Bb - A, cluster growing
Stinger: [C-Db-E-F-Ab] ffff, full orchestra
Aftermath: silence... then solo high harmonic, ppp
```

## Scene-Specific Harmonic Palettes

| Scene Type | Harmonic Approach |
|-----------|-------------------|
| Love/romance | Major 7ths, add9, warm progressions, slow rhythm |
| Action/chase | Minor, driving ostinato, chromatic, fast changes |
| Mystery | Unresolved chords, whole-tone, quartal, pp |
| Comedy | Major, simple progressions, bouncy rhythm |
| Tragedy | Minor, chromatic descent, slow, unresolved |
| Adventure | Brass triads, open 5ths, fanfare, major |
| Fantasy/wonder | Chromatic mediant shifts, celesta, harp |
| Sci-fi | Quartal, whole-tone, electronic, atonal elements |
| War/battle | Aggressive minor, massive brass, pounding rhythm |
| Nostalgia | Add6, add9, major with minor inflection |

## Common Film Score Progressions

| Category | Progression | Usage |
|----------|-------------|-------|
| Adventure | I - V - vi - IV | Williams-style heroic |
| Epic | I - bIII - bVII - I | Massive, cinematic |
| Sad | i - bVI - bIII - bVII | Descending, melancholy |
| Tension | i - bII - i | Phrygian oscillation |
| Wonder | I - bVI - bVII - I | Magical, Spielberg |
| Romance | IVmaj7 - V7 - Imaj7 | Warm resolution |
| Dark power | i - bVI - iv - V | Villain authority |
| Chase | i - iv - bVII - bVI (fast) | Action drive |
| Resolution | bVI - bVII - I | Arrival, sunrise |
| Mysterious | Whole-tone drift, no root | Floating |

## Harmonic Rhythm in Film Context

| Scene Pacing | Harmonic Rhythm | Example |
|-------------|----------------|---------|
| Contemplative | 1 chord per 4-8 bars | Dialogue, quiet drama |
| Building tension | Accelerating changes | Approaching danger |
| Action peak | Rapid changes or static ostinato | Chase, battle |
| Resolution | Decelerating, settling | After climax |
| Time-lapse/montage | Regular, moderate changes | Scene transitions |
