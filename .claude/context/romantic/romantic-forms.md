# Romantic Forms Reference

## Era Span
~1820–1900. Expanding Classical models toward programmatic and cyclic structures.

## Expanded Sonata Form

### Standard Romantic Sonata vs Classical
| Element | Classical | Romantic |
|---|---|---|
| Exposition keys | I -> V (or i -> III) | I -> iii, bVI, bIII, any mediant |
| Transition | Modulating, efficient | Expanded, may have own theme |
| Development | Fragmentation + modulation | Extended, episodic, new themes possible |
| Recapitulation | Both themes in I | May reorder, reharmonize, truncate |
| Coda | Brief or absent | Massive "second development" |
| Length ratio Expo:Dev:Recap:Coda | 1:0.7:1:0.2 | 1:1:0.9:0.6 |

### Romantic Sonata Key Relationships
| Exposition pair | Effect | Example |
|---|---|---|
| I -> III (major 3rd up) | Bright, expansive | Schubert sonatas |
| I -> bVI (major 3rd down) | Dark, rich | Brahms Symphony 3 |
| i -> III (relative major) | Standard minor mode | Chopin Sonata 2 |
| I -> bII (semitone up) | Dramatic | Liszt Sonata |
| i -> v (minor dominant) | Dark, archaic | Brahms Piano Quintet |

### Three-Key Exposition
| Section | Key area | Function |
|---|---|---|
| Primary theme (PT) | I (tonic) | Establish key and character |
| Transition | Modulatory | Build tension |
| Secondary theme 1 (ST1) | III or other mediant | Contrast |
| Secondary theme 2 (ST2) | V or another key | Further contrast |
| Closing theme (CT) | V or key of ST2 | Cadential confirmation |

```
Typical layout (Schubert model):
|: PT (I) -> TR -> ST1 (III) -> ST2 (V) -> CT (V) :|
   Dev (modulatory, multiple keys)
   PT (I) -> TR -> ST1 (I or VI) -> ST2 (I) -> CT (I)
   Coda (I, may recall Dev material)
```

## Symphonic Poem (Tone Poem)

### Structure Principles
| Principle | Description |
|---|---|
| Program driven | Form follows narrative/image |
| Thematic transformation | Themes morph to represent different moods |
| Single movement | Usually 10-30 minutes |
| Hybrid form | Combines sonata, rondo, variation elements |
| Tonal narrative | Key changes reflect emotional journey |

### Common Tone Poem Layouts
| Type | Structure | Example |
|---|---|---|
| Sonata-based | Modified sonata with programmatic deviations | Liszt: Les Preludes |
| Rondo-narrative | Recurring theme between episodes | Smetana: Moldau |
| Episodic | Sequential scenes | Saint-Saens: Danse macabre |
| Arch | A-B-C-B'-A' mirroring narrative | Liszt: Tasso |
| Through-composed | Continuous unfolding | Strauss (later) |

### Thematic Transformation Table
| Transformation | Method | Expressive change |
|---|---|---|
| Augmentation | Double note values | Noble, grand |
| Diminution | Halve note values | Agitated, hurried |
| Mode change | Major <-> minor | Bright <-> dark |
| Reharmonization | New harmonic context | Changed meaning |
| Orchestral recolor | Different instruments | New character |
| Rhythmic change | New meter/rhythm | Dance, march, etc. |
| Inversion | Flip intervals | Shadowed version |
| Fragmentation | Use head motif only | Development, dissolution |

```abc
X:1
T:Thematic Transformation Example
M:3/4
L:1/8
K:C
%% Theme - lyrical
!p!!cantabile! E2 G2 c2 | d3 c B2 | A4 G2 | E6 |
%% Transformed - march
!f!!marcato! [K:Cm] E2 G2 c2 | d3 c B2 | _A4 G2 | E6 |
%% Transformed - triumphant (augmented, major)
!ff! [K:C] [M:4/4] E4 G4 | c4 d4 | c2B2 A4 | G8 |
```

## Character Piece (Klavierstuck)

### Types and Templates
| Type | Form | Character | Composers |
|---|---|---|---|
| Nocturne | ABA' | Lyrical, nighttime | Chopin, Field |
| Ballade | Narrative, multi-section | Epic, dramatic | Chopin, Brahms |
| Scherzo | ABA (Scherzo-Trio) | Turbulent or humorous | Chopin, Brahms |
| Impromptu | ABA or rondo-like | Spontaneous | Schubert, Chopin |
| Rhapsody | Free sectional | Folk-inspired, virtuosic | Liszt, Brahms |
| Intermezzo | ABA' | Intimate, reflective | Brahms |
| Romance | ABA' or strophic | Singing, tender | Schumann |
| Etude | Continuous figuration | Technical + musical | Chopin, Liszt |
| Prelude | Free, brief | Mood piece | Chopin |
| Moment musical | ABA or ternary | Brief character | Schubert |
| Capriccio | Free | Whimsical | Brahms, Mendelssohn |

### Ternary Form (ABA') Romantic Expansion
| Section | Content | Key | Length |
|---|---|---|---|
| A | Main theme, complete period | I | 16-32 bars |
| Bridge | Transitional passage | -> new key | 4-8 bars |
| B | Contrasting theme/texture | Related key | 16-32 bars |
| Retransition | Dominant preparation | -> V of I | 4-16 bars |
| A' | Return, varied/intensified | I | 16-32+ bars |
| Coda | Reflective or climactic | I | 8-24 bars |

## Song Form (Lied)

### Lied Formal Types
| Type | Structure | Piano role | Example |
|---|---|---|---|
| Strophic | A-A-A-A | Same music each verse | Schubert: Heidenroslein |
| Modified strophic | A-A'-A'' | Varied each verse | Schubert: Die Forelle |
| Through-composed | A-B-C-D | Music follows text | Schubert: Erlkonig |
| Bar form | A-A-B | Two stollen + abgesang | Wolf lieder |
| Rondo-lied | A-B-A-C-A | Recurring refrain | Brahms lieder |

### Piano-Voice Relationship
| Type | Description | Example |
|---|---|---|
| Piano as accompanist | Chordal or arpeggiated support | Simple lieder |
| Piano as equal partner | Independent melodic line | Schumann lieder |
| Piano as scene-painter | Pictorial figuration | Schubert: Erlkonig (galloping) |
| Piano as commentator | Postludes, interludes | Wolf lieder |
| Piano as orchestra | Full quasi-orchestral texture | Brahms, Strauss lieder |

## Piano Concerto Innovations

### Romantic Concerto vs Classical
| Element | Classical | Romantic |
|---|---|---|
| Opening | Orchestral exposition | May open with piano solo |
| Double exposition | Standard | Often merged into one |
| Cadenza | Improvised or written, before coda | Written, often integrated |
| Relationship | Dialogue/competition | Piano as protagonist |
| Virtuosity | Balanced with form | Display passages expanded |
| Movements | 3 (fast-slow-fast) | 3 (may link movements) |

### Romantic Piano Concerto Movement Plan
| Movement | Tempo | Form | Key |
|---|---|---|---|
| I | Allegro/Moderato | Sonata (modified) | Tonic |
| II | Adagio/Andante | Ternary or variation | Subdominant or mediant |
| III | Allegro/Vivace | Rondo or sonata-rondo | Tonic |

### Linking Techniques
| Technique | Description | Example |
|---|---|---|
| Attacca | No break between movements | Schumann Piano Concerto |
| Transition passage | Bridge connecting movements | Mendelssohn Violin Concerto |
| Shared theme | Same theme across movements | Liszt Concerto 1 |
| Continuous structure | One-movement design | Liszt Concerto 2 |

## Cyclical Form

### Principles
| Principle | Implementation |
|---|---|
| Motto theme | Theme appears in all movements |
| Thematic recall | Earlier themes return in finale |
| Progressive transformation | Theme evolves across movements |
| Key narrative | Tonal journey across movements |
| Finale synthesis | Final movement combines all themes |

### Cyclical Techniques
| Technique | Description | Example |
|---|---|---|
| Idee fixe | Fixed theme recurring transformed | Berlioz: Symphonie fantastique |
| Motto | Brief motif in each movement | Tchaikovsky: Symphony 5 |
| Thematic recall in finale | Quotes from earlier movements | Brahms: Symphony 3 |
| Thematic derivation | All themes from one cell | Liszt: Sonata in B minor |
| Progressive tonality | Start/end in different keys | Mahler (later) |

```abc
X:2
T:Cyclical Motto Example
M:4/4
L:1/8
K:Cm
%% Movement I - dark, fate-like
!ff! G4- G2 _A2 | G4 z4 |
%% Movement II - transformed, lyrical
[K:Eb] !p!!dolce! [M:3/4] G4 _A2 | B4 c2 | _d6 |
%% Movement III - triumphant
[K:C] !fff!!maestoso! [M:4/4] c4- c2 d2 | e4 f2 g2 | c'8 |
```

## Program Symphony

### Structure
| Movement | Program function | Musical form |
|---|---|---|
| I | Setting/conflict introduction | Sonata form |
| II | Lyrical interlude / scene | Slow ternary or variation |
| III | Dance/scherzo / genre scene | Scherzo-trio or march |
| IV | Resolution / catastrophe | Sonata, rondo, or free |
| V (optional) | Apotheosis or conclusion | Free / triumphal |

### Program Symphony vs Absolute Symphony
| Feature | Program | Absolute |
|---|---|---|
| Extra-musical content | Explicit narrative | None declared |
| Form | Modified by program | Conventional |
| Key scheme | Driven by narrative | By convention |
| Thematic treatment | Characters/ideas | Abstract development |
| Audience expectation | Follow story | Follow form |

## Romantic Variation Forms

### Theme and Variations (Romantic)
| Type | Description | Example |
|---|---|---|
| Character variations | Each variation = new character piece | Brahms: Handel Variations |
| Free variations | Theme heavily disguised | Brahms: Haydn Variations |
| Continuous variations | Chaconne/passacaglia | Brahms: Symphony 4, iv |
| Double variations | Alternating two themes | Haydn/Brahms model |

### Variation Techniques
| Technique | Method |
|---|---|
| Melodic embellishment | Add ornaments, passing tones |
| Harmonic recoloring | New chords under same melody |
| Textural change | Thick -> thin, or vice versa |
| Rhythmic transformation | New subdivision or meter |
| Mode change | Major <-> minor |
| Tempo change | Fast <-> slow variation |
| Register change | High <-> low |
| Contrapuntal | Add canon, fugato |
| Character change | March, waltz, nocturne, etc. |
| Culmination | Final variation as climax + coda |

## Form Decision Matrix
| If the piece is... | Consider form... |
|---|---|
| Orchestral, 20-45 min | Symphony (4 movements) |
| Orchestral, 8-20 min | Tone poem / Overture |
| Piano solo, 5-15 min | Ballade, Scherzo, Fantasy |
| Piano solo, 2-5 min | Nocturne, Intermezzo, Prelude |
| Piano + orchestra, 25-40 min | Concerto (3 movements) |
| Voice + piano, 2-5 min | Lied (strophic or through-composed) |
| Voice + piano, 5-15 min | Ballad or scene |
| Chamber, 20-35 min | Sonata or multi-movement |
| Orchestral with narrative | Program symphony or tone poem |

## Character Piece Structural Details

### Nocturne Structure (ABA')
| Section | Character | Harmony | Texture |
|---|---|---|---|
| A (16-24 bars) | Lyrical melody over arpeggiated accompaniment | Tonic, diatonic | Singing melody + broken-chord LH |
| B (16-32 bars) | Contrasting — more agitated, chromatic, or passionate | Remote key or parallel mode | Thicker texture, faster figuration |
| A' (16-24 bars) | Return of melody, often with added ornamentation | Tonic, cadential elaboration | Embellished version of A |
| Coda (4-16 bars) | Dying away, reflective | Tonic, often plagal close | Thinning, morendo |

### Ballade Structure (multi-sectional narrative)
| Section | Function | Typical treatment |
|---|---|---|
| Introduction | Sets mood, may preview motifs | Slow, dramatic or mysterious |
| Episode 1 | First narrative event | Theme A, tonic key |
| Episode 2 | Contrasting event/character | Theme B, new key |
| Development | Conflict, transformation | Themes combined, fragmented |
| Climax | Narrative peak | Maximum intensity, tempo, dynamics |
| Denouement | Resolution or tragic close | Return of A material or new synthesis |
| Coda | Final commentary | Quiet reflection or dramatic final gesture |

### Scherzo Structure (ABA with Trio)
| Section | Character | Tempo |
|---|---|---|
| Scherzo (A) | Turbulent, demonic, or humorous | Fast, often 3/4 |
| Trio (B) | Lyrical contrast, often major mode | Slower or same tempo, different character |
| Scherzo da capo (A) | Exact or varied return | Same as A |
| Coda | May combine Scherzo and Trio elements | Accelerating or emphatic |

## Song Cycle Form

### Structural Principles
| Element | Function |
|---|---|
| Key narrative | Cycle may trace a tonal journey (e.g., starting in D major, ending in D minor) |
| Thematic recall | Motifs from early songs return in later songs |
| Emotional arc | Songs arranged to create overall narrative (not random) |
| Piano interludes | Between-song passages connecting emotional states |
| Framing | First and last songs often related musically |

### Song Cycle Models
| Cycle | Composer | Structure | Arc |
|---|---|---|---|
| Winterreise | Schubert | 24 through-composed songs | Hope → despair → madness |
| Dichterliebe | Schumann | 16 songs, piano postlude | Love → betrayal → burial of pain |
| Frauenliebe und -leben | Schumann | 8 songs, piano epilogue | Meeting → love → loss |
| Liederkreis Op. 39 | Schumann | 12 songs, circular key scheme | Wandering → nature → return |

## Form as Expression

Romantic composers characteristically bent or broke formal conventions to serve emotional narrative:

| Convention-Breaking | Technique | Effect | Example |
|---|---|---|---|
| Recapitulation avoidance | Development leads directly to coda | No formal "return" — forward momentum only | Liszt Sonata |
| Key mismatch | Recapitulation in "wrong" key | Unresolved tension | Schubert late sonatas |
| Thematic substitution | New theme replaces expected return | Surprise, narrative twist | Chopin Ballade 4 |
| Formal elision | One section overlaps the next | Continuous flow | Schumann |
| Interpolated movement | Movement within a movement | Disruption, dream sequence | Berlioz Symphonie fantastique |
| Reversed recapitulation | Themes return in opposite order | Chiastic symmetry | Brahms symphonies |
