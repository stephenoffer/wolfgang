# Composer Profile: Felix Mendelssohn (1809–1847)

## Style Summary
Classical clarity with Romantic color. Elfin scherzo style, masterful choral writing, overture form innovator, fairy/supernatural musical language, orchestral lightness and transparency. Bridges Classical elegance and Romantic expression.

## Melodic Style

### Characteristics
| Feature | Description |
|---|---|
| Classical proportion | Regular 4+4 bar phrases, balanced antecedent-consequent |
| Singing quality | Lieder-influenced, naturally vocal |
| Clarity | Clean, uncluttered melodic lines |
| Motivic derivation | Themes built from small, clear cells |
| Scalar passages | Rapid running passages, often in scherzo contexts |
| Grace | Lightness even in emotional moments |
| Diatonic preference | Less chromatic than Chopin/Schumann |
| Cadential clarity | Strong, clear phrase endings |

```abc
X:1
T:Mendelssohn-style Lyrical Theme
M:4/4
L:1/8
K:A
!p!!cantabile! c2 e2 a2 f2 | e4 d2 c2 | B2 A2 F2 E2 | A6 z2 |
c2 e2 a2 b2 | c'4 b2 a2 | g2 f2 e2 d2 | c6 z2 |
```

### Elfin Scherzo Melody
| Feature | Description |
|---|---|
| Staccato articulation | Light, detached notes |
| Rapid tempo | Presto or Vivace |
| Soft dynamics | pp to p, rarely above mf |
| Scalar runs | Fast scale fragments |
| Leaping figures | Quick, light interval jumps |
| Trill-like motifs | Rapid alternation effects |
| Fluttering figuration | Tremolo-like rapid notes |

## Harmonic Language

### Characteristic Progressions
| Progression | Context | Effect |
|---|---|---|
| I -> vi -> ii -> V -> I | Clean diatonic | Classical clarity |
| I -> IV -> ii6 -> Cad64 -> V -> I | Standard cadential | Formal, balanced |
| i -> III -> iv -> V -> i | Minor mode basic | Clear minor |
| I -> V/vi -> vi -> V/ii -> ii -> V -> I | Sequential circle | Flowing movement |
| I -> iii -> IV -> V -> I | Mediant color | Gentle warmth |
| i -> bVI -> Cad64 -> V -> i | Romantic minor cadence | Expressive depth |

### Harmonic Features
| Feature | Description |
|---|---|
| Diatonic foundation | Harmony primarily diatonic, chromatic as spice |
| Clear cadences | PAC, HC, DC clearly articulated |
| Light chromaticism | Chromatic passing tones, less than peers |
| Secondary dominants | Applied V and viio7 for color |
| Mode mixture | Major/minor alternation, tasteful |
| Dominant pedals | Clear dominant preparation sections |
| Transparent voicing | Open spacing, less doubling |
| Tierce de Picardie | Major resolution of minor works |

## Orchestral Style

### Orchestral Preferences
| Feature | Description |
|---|---|
| Transparency | Clear textures, no over-doubling |
| Classical balance | Mozart-influenced lightness |
| String virtuosity | Demanding but idiomatic string parts |
| WW solo color | Each woodwind as distinct character |
| Light brass | Brass supports, rarely dominates |
| Timpani | Precise, classical usage |
| Harp | Occasional fairy-tale color |
| No excess | Avoids massive Romantic scoring |

### Scherzo Orchestration
| Layer | Instruments | Role |
|---|---|---|
| Melody | Flute, staccato strings | Light, fleet |
| Harmony | Sustained WW, light horns | Support |
| Bass | Pizz bass, light cello | Rhythmic anchor |
| Color | Triangle, light percussion | Sparkle |
| Full scherzo | Strings pp staccato, WW interjections | Characteristic sound |

### Overture Orchestration
| Section | Scoring approach |
|---|---|
| Slow introduction | Sustained WW chords, horn calls |
| Allegro theme | Strings lead, WW punctuate |
| Second theme | Solo WW or light strings |
| Development | Building layers, polyphonic |
| Climax | Full orchestra, brass prominent |
| Coda | Return to opening character |

## Choral Writing

### Choral Style Features
| Feature | Description |
|---|---|
| Bach influence | Contrapuntal mastery, chorale settings |
| Clear part writing | Each voice independent yet balanced |
| Syllabic setting | Text clarity paramount |
| Fugal passages | Well-crafted fugue sections in oratorios |
| Hymn-like homophony | Block chords for solemn moments |
| A cappella sections | Unaccompanied choral passages |
| Oratorio form | Elijah, St. Paul: dramatic choral narratives |

### SATB Voicing Principles
| Principle | Application |
|---|---|
| Range respect | Each voice in comfortable tessitura |
| Spacing | Open voicing preferred for clarity |
| Doublings | Root and 5th doubled, 3rd for color |
| Voice crossing | Avoided for clarity |
| Leaps | Prepared and resolved |
| Text declamation | Natural speech rhythm |

## Formal Tendencies
| Form | Mendelssohn's approach |
|---|---|
| Sonata form | Classical proportions, clear key areas |
| Overture | Concert overture as independent form |
| Scherzo | Lightning-fast, pp, fairy character |
| Slow movement | Song without Words style, ABA' |
| Finale | Energetic, often lighter than opening |
| Concerto | Linked movements, cadenza before recap |
| Song without Words | ABA miniature, piano Lied |
| Oratorio | Bach-influenced dramatic choral |
| Fugue | Well-crafted, academic yet expressive |

### Concert Overture Form
| Section | Content | Key |
|---|---|---|
| Slow intro (optional) | Sets atmosphere | Tonic or dominant |
| Exposition | Two theme groups | I -> V |
| Development | Thematic working | Modulatory |
| Recapitulation | Both themes | I |
| Coda | Often recalls intro | I |

### Song without Words Template
| Section | Bars | Content |
|---|---|---|
| A (theme) | 8-16 | Song melody + piano accompaniment |
| A' (varied) | 8-16 | Theme with embellishment |
| B (contrast) | 8-16 | New key, contrasting material |
| A'' (return) | 8-16 | Theme returns, possible climax |
| Coda | 4-8 | Cadential extension |

## Generation Guidelines
| Parameter | Guideline |
|---|---|
| Melody | Singable, balanced phrases, Classical clarity |
| Harmony | Primarily diatonic, chromatic as accent |
| Rhythm | Clear pulse, light articulation for scherzo |
| Orchestration | Transparent, balanced, no over-scoring |
| Dynamic | Moderate range, pp for fairy music |
| Form | Classical models respected, clean proportions |
| Scherzo character | pp, staccato, rapid, elfin if appropriate |
| Choral | Clear part writing, Bach-influenced counterpoint |
| Character | Elegant, graceful, never heavy-handed |
| Endings | Clean, decisive; or ethereal fade for fairy music |
