# Felix Mendelssohn — Orchestration

Mendelssohn's orchestra is transparent. Every instrument is audible, every line purposeful, every doubling deliberate. Where Berlioz expanded the orchestra outward and Wagner thickened it, Mendelssohn refined it inward — achieving maximum clarity with Classical forces. His orchestration descends from Mozart and Beethoven, not from the Romantic appetite for mass.

## Core Orchestral Character

| Feature | Description | Where It Appears |
|---------|-------------|-----------------|
| Transparency | Every section audible; no muddying | All orchestral works |
| String primacy | Strings carry 80%+ of melodic content | Standard Mendelssohn texture |
| Light woodwind coloring | Woodwinds double melody at octave, or provide sustained harmonic fill | Throughout |
| Restrained brass | Brass enters for structural punctuation, not sustained color | Arrivals, climaxes, codas |
| Timpani as architecture | Timpani marks structural points (downbeat of recap, final cadence) | Sonata-form movements |
| Classical forces | Standard double-wind orchestra; no exotic instruments | All symphonies and overtures |

## Standard Orchestral Palette

| Section | Role | Typical Writing |
|---------|------|----------------|
| Violin 1 | Primary melody carrier | Lyrical cantabile or elfin staccato; high register |
| Violin 2 | Harmonic support, occasional imitation | Sustained chords or rhythmic figuration; rarely independent |
| Viola | Inner voice, harmonic binding | Sustained notes, arpeggiated figures; the "glue" |
| Cello | Bass melody, lyrical countermelody | Rich cantabile in tenor register; also harmonic bass |
| Double bass | Harmonic foundation | Mostly doubles cello at octave below; independent only at cadences |
| Flute | Doubling violin 1 at octave; solo color | Elfin passages; high shimmer in scherzi |
| Oboe | Pastoral solo color; harmonic sustain | Sustained notes over string texture; gentle solo melodies |
| Clarinet | Warm middle-register fill; occasional solo | Less prominent than in Weber or Brahms; supportive role |
| Bassoon | Bass reinforcement; occasional solo humor | Doubles cello/bass; staccato passages in scherzi |
| Horn | Sustained harmonic pedals; hunting calls | Held notes across bar lines; heroic calls in outer movements |
| Trumpet | Structural punctuation only | Enters at fff arrivals; silent in pp passages |
| Trombone | Chorale weight; structural climaxes | Often in 3-part chorale; reserved for moments of grandeur |
| Timpani | Rhythmic and structural marker | Downbeat emphasis; rolls at climaxes; always purposeful |

## The Fairy-Scherzo Texture

Mendelssohn's defining orchestral innovation — a texture no one else achieved.

| Parameter | Specification |
|-----------|--------------|
| Strings | Divisi violins, staccato, pp, high register; no vibrato implied |
| Woodwinds | Flute doubles violin 1; oboe and clarinet sustain single notes |
| Brass | Silent or single held note (horn) |
| Timpani | Silent or single pp stroke on downbeat |
| Dynamic | pp to ppp throughout; f only at structural cadence (2-3 bars) |
| Texture | Homophonic — melody + light accompaniment; no counterpoint |

```abc
X:1
T:Mendelssohn Fairy-Scherzo Orchestral Texture (reduced)
M:2/4
L:1/16
K:E
V:1 name="Vln 1 + Fl"
V:2 name="Vln 2 + Vla"
[V:1]!pp! efed cBAG|FGAB AGFE|DEFG FEDC|B,4 z4|
[V:2]!pp! E4 E4|D4 D4|C4 C4|B,4 z4|
%% Violin 1 + flute: fleet staccato melody; Violin 2 + viola: single sustained notes
%% Brass: tacet. Timpani: tacet. The texture is air and light.
```

## Lyrical Orchestral Texture

| Layer | Instruments | Function |
|-------|-------------|----------|
| Melody | Violin 1 (or cello in tenor register) | Cantabile, espressivo |
| Counter-melody | Cello (or oboe) | Gentle, complementary line — fills rests in the melody |
| Harmonic fill | Violin 2 + viola, sustained or tremolo | Warm harmonic carpet |
| Bass | Cello + bass, pizzicato or sustained | Harmonic foundation, 1 note per bar |
| Color | Horn held note, or clarinet sustained 3rd | Adds warmth without weight |

```abc
X:2
T:Mendelssohn Lyrical Orchestral Texture (Violin Concerto character)
M:4/4
L:1/8
K:Em
V:1 name="Solo Violin"
V:2 name="Strings"
[V:1]!p! B,2 E2 G2 B2|A2 G2 ^F2 E2|!mf!D2 G2 B2 e2|^d2 e2 B4|
[V:2] [E,B,E]4 [E,B,E]4|[A,,C,E,]4 [B,,^D,F,]4|[G,,B,,D,]4 [E,,G,,B,,]4|[B,,^F,B,]4 [E,,B,,E,]4|
%% Solo violin sings; strings provide transparent harmonic support — one chord per bar
```

## Doubling Principles

| Guideline | Mendelssohn Practice |
|-----------|---------------------|
| Melody doubling | Flute at octave above violin 1 for brightness; oboe at unison for warmth |
| Avoid thick doubling | Never 3+ instruments on the same pitch; prefer octave spacing |
| Bass doubling | Cello + bass in octaves; bassoon joins only in forte |
| Harmonic doubling | Horns sustain chord tones; clarinets fill inner voices |
| Tutti vs. solo | Clear alternation; full orchestra only at structural arrivals |

## Dynamic Orchestration

| Dynamic | Typical Scoring |
|---------|----------------|
| pp | Strings alone, or strings + single woodwind |
| p | Strings + woodwinds (flute and/or oboe doubling) |
| mp | Full woodwinds + strings; horns enter |
| mf | Full woodwinds + strings + horns |
| f | Add trumpets and timpani |
| ff | Full orchestra; trombones enter for weight |
| fff | Rare — full orchestra with tremolo strings and sustained brass |

## Orchestral Textures by Genre

| Genre | Characteristic Texture |
|-------|----------------------|
| Overture (fairy) | Elfin staccato strings, woodwind shimmer, minimal brass |
| Overture (dramatic) | Full Beethovenian sonata orchestra with clear sections |
| Symphony slow mvt | Singing strings, woodwind solos, horn pedals |
| Symphony scherzo | Fairy-scherzo OR robust dance (saltarello in Italian Symphony) |
| Concerto | Solo instrument against reduced orchestra; dialogue, not competition |
| Oratorio | Chorus as primary mass; orchestra supports, does not overwhelm |

## String Writing Specifics

| Technique | Mendelssohn Usage | Context |
|-----------|------------------|---------|
| Tremolo | Rare; reserved for dramatic tension in overtures | Hebrides storm, Fingal's Cave |
| Pizzicato | Accompaniment in barcarolles; light bass in scherzi | Songs Without Words orchestral style |
| Divisi | Violin 1 divisi in fairy-scherzo for pp texture | Midsummer Night's Dream |
| Sul ponticello | Implied in fairy-scherzo passages (ethereal tone) | Scherzi |
| Con sordino | Slow movements for intimate color | Rare but effective |
| Arco sustained | Default; the singing tone | All lyrical passages |
