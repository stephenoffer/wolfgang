# Franz Liszt — Orchestration

Liszt invented the symphonic poem and with it a new approach to the orchestra: color as narrative. Where Berlioz orchestrated for spectacle and Wagner for continuous flow, Liszt orchestrated for transformation — the same theme must sound completely different when passed from strings to brass to woodwinds, because each timbral change IS a transformation. His piano writing is also orchestration: the piano produces three or four simultaneous "sections" (bass, tenor, alto, soprano) that map onto orchestral choirs.

---

## Orchestral Forces

### Standard Liszt Symphonic Poem Orchestra

| Section | Instruments | Role |
|---------|------------|------|
| Woodwinds | 2 Fl, 2 Ob, 2 Cl (Bb), 2 Bsn | Lyrical transformations; pastoral color; doubling |
| Brass | 4 Hn (F), 3 Tpt (C/Bb), 3 Tbn, Tuba | Heroic transformations; chorale; climax weight |
| Percussion | Timp (3), Cymbals, Triangle, Bass Drum | Punctuation; climactic moments; Hungarian color |
| Strings | Vln I, Vln II, Vla, Vc, Cb | Foundation; all transformations; tremolo; arco/pizz contrast |
| Optional | Harp (1-2), Organ (sacred works) | Arpeggiated color; sacred gravity |

### Faust Symphony Expanded Forces

| Addition | Purpose |
|----------|---------|
| Piccolo | Mephistopheles scherzo — shrill, mocking |
| Cor anglais | Gretchen movement — warm, feminine |
| Bass clarinet | Dark color in Faust movement |
| Tenor chorus + solo | Final Chorus Mysticus (optional ending) |
| Organ | Sacred authority in final bars |

## Orchestral Texture Strategies

| Texture | Scoring | Character | Example |
|---------|---------|-----------|---------|
| Heroic unison | Strings + brass in octaves, ff | Triumphant theme statement | Les Preludes climax |
| Pastoral lyric | Solo woodwind (Ob or Cl) + light string accompaniment | Gentle transformation | Les Preludes pastoral |
| Tremolo storm | String tremolo + brass punctuation + timpani rolls | Dramatic turbulence | Mazeppa ride section |
| Chorale | Brass choir, homophonic, sustained | Sacred/noble transformation | Faust Symphony ending |
| Chamber reduction | Solo strings or solo woodwind + harp | Intimate; Gretchen character | Faust Symphony mvt 2 |
| Full tutti | All forces, ff-fff | Climactic arrival | Symphonic poem perorations |
| Pizzicato underpinning | Strings pizz + woodwind melody | Light, dance-like | Scherzo passages |
| Divided strings | Vln I/II/Vla divisi; layered sustained chords | Atmospheric shimmer | Slow introductions |

## Thematic Transformation Through Orchestration

The same theme changes character by changing who plays it.

| Transformation | Instrument(s) | Articulation | Dynamic | Character |
|---------------|--------------|-------------|---------|-----------|
| Heroic | Brass (Hn + Tpt) + Strings unison | Marcato, tenuto | ff | Triumphant |
| Lyrical | Solo Ob or Cl over string arpeggios | Legato, espressivo | p | Tender |
| Pastoral | Fl + Cl in 3rds, harp arpeggios | Dolce | mp | Idyllic |
| Demonic | Low strings (Vc/Cb) + bass clarinet | Staccato, sfz accents | pp-f subito | Sinister |
| Funeral | Muted brass + timpani; low strings | Pesante | pp | Grief |
| Sacred chorale | Full brass choir, organ | Sostenuto | mf-f | Transcendent |
| Dance (Hungarian) | Vln solo + pizz strings; triangle, cymbal | Sharp accents on 1 | f | Wild |

## Piano-as-Orchestra Mapping

Liszt's piano writing maps directly onto orchestral sections.

| Piano Register/Technique | Orchestral Equivalent | Example |
|-------------------------|----------------------|---------|
| LH bass octaves (C1-C3) | Cellos + Basses + Tuba | B minor Sonata opening |
| LH arpeggiated chords (C2-C4) | Violas + Cellos arco | Liebestraum accompaniment |
| RH melody soprano (C5-C7) | First violins or solo flute | Lyrical themes |
| RH octave melody (C4-C6) | Horns + first violins in unison | Heroic themes |
| Both hands tremolo | String tremolo (full section) | Storm passages |
| Rapid LH cross-hand arpeggios | Harp glissando | Cadenza moments |
| Thick chordal texture (10-note chords) | Full orchestra tutti | Climactic moments |
| Single-line unaccompanied | Solo violin or oboe | Recitative passages |

## Transcription Principles

Liszt's hundreds of transcriptions reveal his orchestral thinking in reverse: orchestra-to-piano.

| Orchestral Element | Piano Transcription Technique |
|-------------------|------------------------------|
| Sustained wind chord | Rolled chord with pedal; re-struck at intervals |
| String tremolo | Measured or unmeasured tremolo between hands |
| Brass fanfare | Octave + chord texture, marcato, ff |
| Solo woodwind melody | Single-line RH, una corda, cantabile |
| Orchestral crescendo | Texture thickens: single line -> octaves -> full chords |
| Timpani roll | LH bass tremolo on single note or octave |
| Harp arpeggios | Wide LH arpeggios crossing registers |

## Dynamic and Articulation Palette

| Dynamic Level | Orchestral Usage | Piano Equivalent |
|--------------|-----------------|-----------------|
| ppp | Muted strings, single instrument | Una corda, lightest touch |
| pp | Chamber reduction; solo + minimal accompaniment | Delicate; high register |
| p | Lyrical woodwinds + light strings | Singing tone, moderate touch |
| mf | Full strings, moderate brass | Warm, balanced |
| f | Strings + brass; full woodwinds | Full tone, hands together |
| ff | Full orchestra, accented | Octaves, thick chords |
| fff | Tutti with percussion, culmination | Maximum force, full keyboard span |
