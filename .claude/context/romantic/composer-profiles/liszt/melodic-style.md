# Franz Liszt — Melodic Style

Liszt does not write melodies — he writes themes that are born to transform. A Liszt melody is a seed containing within itself a march, a lament, a scherzo, and a hymn. Where Chopin's melody sings like a soprano and Brahms' melody breathes like a cello, Liszt's melody declaims like a tragic actor — then changes costume and becomes something else entirely. The technique of thematic transformation means the melody IS the form: the same intervallic skeleton reappears in every section wearing new rhythmic, dynamic, and textural clothing.

---

## Core Melodic Characteristics

| Feature | Description | Typical Usage |
|---------|-------------|--------------|
| Thematic transformation seed | Melody designed with clear interval skeleton that survives rhythmic/dynamic change | Every symphonic poem; B minor Sonata |
| Declamatory octaves | Melody in unison octaves, both hands, ff — the piano announces | Opening themes; heroic transformations |
| Hungarian augmented 2nds | Scale step with augmented interval (Eb-F# in A Gypsy minor) | Hungarian Rhapsodies; secondary color everywhere |
| Virtuosic figuration AS melody | Rapid arpeggios, scales, tremolos that carry the melodic line within them | Transcendental Etudes; Mephisto Waltz |
| Wide leaps | Octave+ jumps within melody; dramatic, not vocal | Separates Liszt from Chopin's stepwise bel canto |
| Sequential repetition | Melody stated, then repeated a step higher/lower with intensification | Building passages; pre-climax sequences |
| Recitative-like freedom | Rubato melody over sustained harmony; speech rhythm, not dance | Slow introductions; lassan passages |
| Motto themes | Short (3-5 note) motifs that can expand into full themes | Faust Symphony: 4 augmented triads = Faust's questioning |

## Thematic Transformation: The Core Technique

One theme generates an entire work by changing its character while preserving its interval pattern.

### Transformation Types

| Transformation | Changes | Preserves | Character Shift | Example |
|---------------|---------|-----------|----------------|---------|
| Heroic march | Tempo to Maestoso; dotted rhythms; ff; bass octaves | Pitch skeleton; key intervals | Neutral -> triumphant | Les Preludes main theme |
| Lyrical song | Tempo to Andante; p; legato; arpeggiated accompaniment | Pitch contour; interval direction | Neutral -> tender | Les Preludes pastoral section |
| Scherzo/demonic | Tempo to Vivace; staccato; pp; tritone transposition | Interval sizes (inverted or retrograde) | Neutral -> sinister | Faust Symphony Mephisto mvt |
| Funeral march | Tempo to Lento; minor mode; low register; bare texture | Pitch skeleton in augmentation | Neutral -> grief | Heroide funebre |
| Chorale/hymn | Tempo to Largo; homophonic; organ-like voicing | Basic melodic outline | Neutral -> sacred | Faust Symphony choral ending |
| Hungarian dance | Tempo to Allegro vivace; dotted rhythm; augmented 2nds added | Core intervals | Neutral -> wild | Hungarian Rhapsodies |

```abc
X:1
T:Liszt Thematic Transformation — Neutral Seed
M:4/4
L:1/8
K:C
%% The neutral theme: moderate, clear intervals
!mf!C2 E2 G2 c2|B2 A2 G2 E2|F2 A2 c2 f2|e4 d4|
```

```abc
X:2
T:Same Theme — Heroic March Transformation
M:4/4
L:1/8
K:C
%% Same pitches; dotted rhythm; octave doubling; ff
!ff!C3C E3E G3G c3c|B3B A3A G3G E3E|F3F A3A c3c f3f|e6 d2|
%% The shy child has become a general
```

```abc
X:3
T:Same Theme — Lyrical Song Transformation
M:3/4
L:1/4
K:Ab
%% Same intervals transposed; slow; legato; ornamented
!p!C {D}E G|{A}c B A|G E F|{G}A2 z|
%% The general has removed his armor and is weeping
```

## Melodic Contour Patterns

| Contour | Shape | Emotional Arc | Example Context |
|---------|-------|--------------|-----------------|
| Ascending sequence | Step-up repetitions building to peak | Intensification, aspiration | Pre-climax passages |
| Arch (rise-fall) | Ascend to peak note, descend mirror | Complete statement, nobility | Main themes |
| Declamatory leap-step | Large leap up, stepwise descent | Dramatic announcement then resolution | Opening gestures |
| Chromatic slide | Semitone motion up or down, no clear direction | Ambiguity, searching, Mephistophelean irony | Development, demonic passages |
| Tremolo-embedded | Melody notes surrounded by rapid oscillation | The melody shimmers inside the texture | Transcendental Etudes |
| Recitative fall | Leap up, then free rhythmic descent | Speech-like, improvisatory | Hungarian lassan openings |

## Hungarian/Gypsy Melodic Idiom

| Scale | Notes (on A) | Characteristic Interval | Mood |
|-------|-------------|----------------------|------|
| Hungarian minor | A-B-C-D#-E-F-G#-A | Two augmented 2nds (C-D#, F-G#) | Fiery, exotic, passionate |
| Gypsy scale | A-B-C-D#-E-F#-G-A | One augmented 2nd (C-D#) | Dance-like, wild |
| Verbunkos melodic pattern | Long note -> dotted figures -> rapid ornamental turn -> cadence on 5th or 1st | Grace notes before main beat | Improvisatory, proud |

```abc
X:4
T:Liszt Hungarian Melodic Idiom — Rhapsody Character
M:2/4
L:1/16
K:Am
%% Augmented 2nd (C-D#), rapid ornamental turns, cadence on A
!f!A4 B2C2|{CD}^D4 E4|F2^G2 A2B2|{cBA}A8|
%% The melody reaches for the augmented 2nd like a hand reaching through fire
```

## Melody and Register

| Register | Usage | Character |
|----------|-------|-----------|
| Extreme high (C6-C8) | Ethereal tremolo; bell-like repeated notes | Transcendence, vision |
| High soprano (C5-C6) | Primary singing melody; lyrical themes | Nobility, tenderness |
| Middle (C3-C5) | Thematic statements; inner voice melodies | Warmth, conversation |
| Low bass (C1-C3) | Octave unison themes; ominous announcements | Power, darkness, fate |
| Full keyboard span | Arpeggiated melody spanning 5+ octaves | Orchestral sweep, climax |

---

## Melodic Rhythm Patterns

| Pattern | Rhythmic Character | Context |
|---------|-------------------|---------|
| Dotted march | Dotted quarter + eighth (or dotted eighth + sixteenth) | Heroic transformations |
| Flowing triplets | Even triplet subdivisions | Lyrical transformations; pastoral |
| Recitative rubato | Free rhythm; long notes followed by rapid groups | Introductions; cadenza passages |
| Tremolo melody | Melody notes alternating with upper/lower neighbor rapidly | Transcendental Etudes texture |
| Augmented rhythm | Theme in double note values (half notes become wholes) | Grand statements; final returns |
| Diminished rhythm | Theme in half note values (quarters become eighths) | Scherzo transformations; acceleration |
