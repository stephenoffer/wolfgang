# Nationalistic Forms Reference

## Core Principle
Nationalistic forms adapt or replace classical structures with forms derived from folk music, narrative programs, and national identity. Freedom from strict sonata allegiance is characteristic.

## Symphonic Poem (Tone Poem)

| Element | Description |
|---------|-------------|
| Origin | Liszt; adopted by Smetana, Sibelius, Dvorak |
| Structure | Single movement, program-driven |
| Length | 10-25 minutes typical |
| Formal basis | Loose sonata, rondo, or free sectional |
| Unifying device | Thematic transformation of 1-3 main motifs |
| Program types | Landscape, legend, historical event, literary source |

### Typical Symphonic Poem Layout
```
Section:    Intro  |  A (theme)  |  B (contrast)  |  Development  |  A' (transformed)  |  Coda
Program:    Scene  |  Hero/Place |  Conflict/New   |  Journey      |  Return/Victory     |  Epilogue
Dynamics:   pp     |  mf         |  f              |  ff           |  fff                |  pp
```

### Smetana "Moldau" Model
```
Flute ripples (source) -> River theme (strings) -> Forest hunt (brass) ->
Peasant wedding (dance) -> Moonlight (winds) -> Rapids (tutti) ->
Broad river theme (triumphant) -> Fading to distance
```

## Rhapsody Form

| Element | Description |
|---------|-------------|
| Character | Improvisatory, virtuosic, folk-derived |
| Structure | Sectional with contrasting tempos |
| Typical pattern | Slow introduction (lassu) -> Fast section (friss) |
| Key use | Hungarian, Slavic, Spanish rhapsodies |
| Thematic source | Folk tunes or folk-style original melodies |

### Rhapsody Tempo Map
```
Section:  Lento    |  Andante   |  Allegro    |  Presto
Mood:     Brooding |  Lyrical   |  Dance-like |  Virtuosic climax
Duration: 15%      |  30%       |  35%        |  20%
```

## Suite of National Dances

| Element | Description |
|---------|-------------|
| Model | Dvorak Slavonic Dances, Grieg Peer Gynt Suite |
| Movements | 4-8, each a distinct dance or character piece |
| Key plan | Contrasting keys, often alternating major/minor |
| Tempo plan | Alternating fast/slow or grouped by energy |

### Typical Dance Suite Layout

| Movement | Dance Type | Tempo | Character |
|----------|-----------|-------|-----------|
| 1 | Festive opening dance | Allegro | Brilliant, major key |
| 2 | Slow lyric dance | Andante | Tender, minor key |
| 3 | Vigorous stamping dance | Vivace | Rhythmically complex |
| 4 | Melancholy waltz/dumka | Lento | Nostalgic |
| 5 | Comic/rustic dance | Presto | Light, playful |
| 6 | Grand finale dance | Allegro con fuoco | Climactic |

## Folk-Inspired Variations

| Element | Description |
|---------|-------------|
| Theme | Folk melody (quoted or original) |
| Variation types | Ornamental, rhythmic, modal, orchestral |
| Structure | Theme + 5-12 variations + coda |
| Key feature | Theme retains recognizability throughout |

### Variation Techniques in National Style

| Variation Type | Technique | Example |
|---------------|-----------|---------|
| Ornamental | Add grace notes, turns to folk melody | Grieg |
| Modal | Shift theme between major/minor/modes | Dvorak |
| Rhythmic | Change meter (3/4 to 2/4), add syncopation | Czech dances |
| Orchestral | Re-score theme for different instruments | Rimsky-Korsakov |
| Tempo | Slow theme becomes fast dance (or reverse) | Hungarian lassu/friss |
| Contrapuntal | Add countermelody derived from folk material | Bartok |
| Harmonic | Reharmonize with increasingly chromatic chords | Mussorgsky |
| Textural | Theme in augmentation under fast figuration | Sibelius |

## Dumka Form (Dvorak Specialty)

| Element | Description |
|---------|-------------|
| Origin | Ukrainian lament form |
| Character | Alternation of slow melancholy and fast dance |
| Structure | A (slow, minor) - B (fast, major) - A' - B' - A'' |
| Tempo shifts | Abrupt, dramatic contrast |
| Emotional arc | Grief interrupted by manic energy |

## Ballade Form (Nordic/Slavic)

| Element | Description |
|---------|-------------|
| Origin | Narrative folk song tradition |
| Structure | Strophic variation (verse structure with development) |
| Character | Epic, storytelling |
| Typical arc | Introduction - narrative verses - dramatic climax - epilogue |

## Fantasia on Folk Themes

| Element | Description |
|---------|-------------|
| Structure | Free sectional, potpourri-like |
| Content | Multiple folk tunes loosely connected |
| Transitions | Often abrupt or linked by cadenzas |
| Use | Concert showpiece, patriotic display |

## Form Selection Guide

| Desired Effect | Recommended Form | Model Work |
|---------------|-----------------|------------|
| Landscape narrative | Symphonic poem | Smetana: Ma Vlast |
| Virtuosic folk display | Rhapsody | Liszt: Hungarian Rhapsodies |
| Multi-dance showcase | Dance suite | Dvorak: Slavonic Dances |
| Deep folk exploration | Theme and variations | Brahms: Haydn Variations |
| Emotional extremes | Dumka | Dvorak: Piano Quintet Op. 81 |
| Epic narrative | Ballade | Grieg: Ballade Op. 24 |
| Patriotic celebration | Fantasia | Glinka: Kamarinskaya |
| Symphonic integration | Symphony with folk themes | Dvorak: Symphony No. 9 |
