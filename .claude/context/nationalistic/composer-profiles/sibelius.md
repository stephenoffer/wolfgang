# Sibelius Composer Profile

## Quick ID
| Attribute | Value |
|-----------|-------|
| Full name | Jean Sibelius (1865-1957) |
| Nationality | Finnish |
| Period | Late Romantic / Nationalistic / Early Modern |
| Key works | Symphonies 1-7, Finlandia, Violin Concerto, Tapiola, Karelia Suite |
| Signature traits | Organic thematic growth, Nordic modal harmony, nature mysticism, orchestral austerity |

## Melodic Language

| Feature | Description |
|---------|-------------|
| Fragment-to-theme | Short motifs coalesce into full themes over time |
| Modal ambiguity | Melodies avoid clear major/minor definition |
| Pedal-tone melodies | Themes rotate around a single pitch |
| Wide spacing | Large intervals (5ths, octaves) suggest landscape |
| Brass chorale themes | Hymn-like, massive, slow-moving |
| Woodwind bird calls | Short, naturalistic motifs |

## Organic Symphonic Development

| Principle | Description |
|-----------|-------------|
| Thematic rotation | Themes recur in varied order, not recapitulated literally |
| Gradual assembly | Fragments presented separately, then combined |
| Continuous transition | Sections flow into each other; few hard boundaries |
| Telescoping | Recapitulation compressed or merged with development |
| Culmination technique | Long buildup to single climactic statement |
| Dissolution | Themes break apart at end of movement |

### Development Arc
```
Fragments (pp) -> Gradual combination -> Building intensity ->
Climactic full statement (fff) -> Dissolution or sustained plateau
```

## Harmonic Signature

| Technique | Frequency | Effect |
|-----------|-----------|--------|
| Pedal points (very long) | Signature | Grounded, vast |
| Modal harmony (Dorian/Aeolian) | Constant | Nordic darkness |
| Tritone relationships | Frequent | Tension, ambiguity |
| Bare octaves and 5ths | Characteristic | Austere grandeur |
| Slow chromatic voice leading | Frequent | Glacial harmonic shifts |
| Sudden key change | Moderate | Landscape shift |
| Unresolved dominants | Frequent | Open-ended, searching |

## Nature Mysticism in Sound

| Natural Element | Musical Device |
|----------------|----------------|
| Forest | String tremolo pp, fragmented woodwind |
| Ice/cold | High sustained strings, bare 5ths |
| Storm | Timpani + brass crescendo, driving ostinato |
| Dawn | Gradual orchestral build from silence |
| Lake | Sustained string chords, harp, stillness |
| Wind | Chromatic scales in flutes, string ponticello |

## Orchestration Preferences

| Feature | Detail |
|---------|--------|
| Strings | Core of sound; long sustained passages, divisi tremolo |
| Brass | Massive chorale climaxes; horns for nature calls |
| Woodwinds | Soloistic, bird-like; often fragmented |
| Timpani | Prominent; rumbling pedal, dramatic rolls |
| Harp | Sparse; atmospheric moments only |
| Percussion | Minimal beyond timpani |
| Overall | Increasing austerity through career; Sym. 7 is most concentrated |

## Symphony Progression (Evolution of Style)

| Symphony | Key Feature | Character |
|----------|------------|-----------|
| No. 1 | Tchaikovsky influence, dramatic | Romantic nationalist |
| No. 2 | Heroic, folk-adjacent themes | Finnish independence spirit |
| No. 3 | Classicizing, leaner | Transitional |
| No. 4 | Dark, austere, tritone-saturated | Modernist crisis |
| No. 5 | Organic growth, horn theme climax | Mature nature mysticism |
| No. 6 | Polyphonic, modal, Palestrina-influenced | Pure, austere beauty |
| No. 7 | Single movement, continuous arc | Ultimate compression |

## Key Progressions (Sibelius Fingerprints)

```
Opening pedal:     D pedal with shifting modal chords above
Building:          i -> bIII -> bVI -> bVII -> i (modal ascent)
Climax:            Sudden arrival on major chord after long minor passage
Dissolution:       V -> fragments -> single sustained note -> silence
Tritone tension:   C major area <-> F# minor area
```

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key choices | D minor, C major, Bb major, A minor |
| Tempo | Allegro moderato, Adagio, Andante mosso |
| Melody | Fragmentary at first, assembling over time |
| Harmonic rhythm | Very slow; pedal-based |
| Texture | Austere; avoid over-scoring |
| Dynamics | Long crescendos, sudden pp, massive climaxes |
| Emotional tone | Vast, dark, nature-immersed, ultimately affirmative or stoic |
| Avoid | Quick harmonic changes, decorative figuration, sentimentality |
| Emphasize | Pedal points, modal color, organic growth, bare sonority |
