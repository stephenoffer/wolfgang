# Bedrich Smetana — Orchestration

Smetana's orchestra tells stories. The strings ripple like water, the brass fanfares like castle battlements, the woodwinds sing like village musicians, the harp arpeggios like a bard's opening gesture. This is programmatic orchestration: every timbre choice serves the narrative, whether the subject is a river, a legend, or a polka.

## Core Orchestral Character

| Feature | Description | How It Sounds |
|---------|-------------|--------------|
| Programmatic timbre | Each instrument family represents a narrative element (water, heroes, villagers) | The orchestra paints scenes, not abstractions |
| String figuration as landscape | Rapid string arpeggiation = water; tremolo = tension; sustained = pastoral calm | Ma vlast is built on string landscape painting |
| Brass fanfare as heroism | Horns and trumpets in dotted rhythms, P4/P5 intervals = castles, warriors, national pride | Vysehrad, Blanik, Libuse |
| Woodwind folk melody | Flute, oboe, clarinet carry folk-like themes over string texture | Village scenes; pastoral episodes |
| Harp as narrative frame | Harp arpeggiation opens and closes Ma vlast; the bard's instrument | Vysehrad: harp solo opens the entire cycle |
| Clear doublings | Melody doubled in octaves or 3rds; no ambiguity about foreground | Opera training — the voice (theme) must project |
| Dance orchestration | Light, rhythmic scoring; pizzicato bass; staccato woodwinds | Polka and furiant sections; The Bartered Bride |

## Standard Smetana Orchestra

| Section | Instruments | Role |
|---------|------------|------|
| Strings | Vln I, Vln II, Vla, Vc, Cb | Landscape textures (figuration, tremolo); melody in cantabile passages |
| Woodwinds | 2 Fl (+Picc), 2 Ob, 2 Cl, 2 Bsn | Folk melody solos; pastoral color; dance lightness |
| Brass | 4 Hn, 2 Tpt, 3 Tbn (+Tuba) | Heroic fanfare; Hussite chorale; weight at climaxes |
| Percussion | Timpani, Triangle, Cymbals | Structural accent; dance punctuation; climactic reinforcement |
| Harp | 1–2 Harps | Narrative framing; water texture; castle arpeggiation |

## Instrument Roles — Detailed

### Strings

| Instrument | Smetana's Use | Character |
|-----------|-------------|-----------|
| Violin I | Primary melody carrier; rapid figuration (water, wind); virtuosic passages | Clear, singing, projecting — operatic violin writing |
| Violin II | Accompaniment figuration; doubling Vln I in 3rds/6ths; inner harmony | Active accompaniment — not subordinate but supportive |
| Viola | Inner harmony; occasional melody in darker passages; rhythmic fill | Warmer middle voice; more active than Classical practice |
| Cello | Cantabile melody in lyrical passages; bass line in dance; octave doubling with Cb | The singer of the orchestra — Smetana loves cello melody |
| Double Bass | Dance bass (pizzicato oom-pah); pedal points; foundation | The heartbeat of the polka; the ground of the landscape |

### Woodwinds

| Instrument | Smetana's Use | Signature Moments |
|-----------|-------------|-------------------|
| Flute | Folk melody in high register; birdsong; pastoral | Vltava village scene; From Bohemian Fields and Forests |
| Piccolo | Brightness at climaxes; shrillness in dance | Dance scenes in The Bartered Bride |
| Oboe | Pastoral solo; folk-like melody; plaintive character | Vltava melody first statement |
| Clarinet | Warm folk melody; dance theme carrier; chalumeau depth | Village scenes; The Bartered Bride arias |
| Bassoon | Bass voice in winds; comic character in opera; harmonic fill | The Bartered Bride comedy; doubling cello bass |

### Brass

| Instrument | Smetana's Use | Character |
|-----------|-------------|-----------|
| Horn (4) | Sustained pedal; forest calls; heroic melody; drone | Vysehrad, Sarka — the heroic brass voice |
| Trumpet (2) | Fanfare; dotted-rhythm heroic themes; climactic brightness | Vysehrad opening; Blanik culmination |
| Trombone (3) | Hussite chorale; dark weight; bass reinforcement | Tabor, Blanik — the Hussite warrior sound |
| Tuba | Foundation at fff; rare; always with trombones | Climactic passages only |

## Orchestral Texture Types

| Texture | Description | Where It Appears |
|---------|-------------|-----------------|
| Water figuration | Rapid string arpeggiation (sextuplets or triplets) rocking between two pitches | Vltava — the defining Smetana texture |
| Fanfare with harp | Brass dotted-rhythm theme over harp arpeggiation | Vysehrad — the opening of Ma vlast |
| Dance scoring | Melody in winds; pizzicato bass; staccato strings | Polka/furiant sections throughout |
| Pastoral | Sustained string chords; solo woodwind melody; horn pedal | From Bohemian Fields and Forests |
| Hussite chorale | Brass choir (hn + tbn) in hymn-like homophony; strings reinforce | Tabor, Blanik — the warrior tradition |
| Opera tutti | Full orchestra with vocal line projecting above; clear texture | All operas — the singer must be heard |
| Nocturnal | Muted strings; solo cello or clarinet; minimal texture | Vltava moonlight scene; quiet opera moments |

```abc
X:1
T:Smetana — Water Figuration (Vltava opening texture)
M:6/8
L:1/16
K:Em
V:1 name="Violin I (river surface)"
V:2 name="Violin II (river surface)"
V:3 name="Cello/Bass" clef=bass
%% Two streams merging — the birth of the Vltava
[V:1] z8 z4|E2G2B2 E2G2B2|E2G2B2 E2G2B2|
[V:2] E2G2B2 E2G2B2|z8 z4|E2G2B2 E2G2B2|
[V:3] E,6 E,6|E,6 E,6|E,6 E,6|
%% Two violin parts enter separately (two streams), then merge
```

```abc
X:2
T:Smetana — Brass Fanfare (Vysehrad character)
M:4/4
L:1/4
K:C
V:1 name="Trumpets + Horns"
V:2 name="Trombones" clef=bass
%% The castle on the hill — heroic, dotted, majestic
[V:1] !ff!C3/2 D/2 E G|c3/2 B/2 A G|E3/2 D/2 C2|
[V:2] C,2 E,2|C,2 E,2|C,4|
%% Dotted rhythm, P4/P5 intervals — the Czech heroic voice
```

## Dynamic Approach

| Dynamic Level | Smetana Character | Orchestral Realization |
|--------------|-----------------|----------------------|
| pp | River source, nocturnal, mystery | Solo instrument or thin string texture; minimal forces |
| p | Pastoral, village life at a distance | Woodwind solo + light strings; no brass |
| mp | Folk melody, gentle dance | Winds carry melody; strings accompany; warm |
| mf | Dance in full swing; landscape broadening | Full winds + strings; horns sustain |
| f | Heroic statement; river in full flow | Full orchestra; brass prominent; timpani active |
| ff | National climax; battle; apotheosis | Tutti with brass chorale; cymbals; harp glissando |

## Doubling Principles

| Principle | How | Why |
|-----------|-----|-----|
| Melody in octaves at climax | Vln I + Fl (octave above) or Vln I + Vc (octave below) | Clarity and projection — operatic instinct |
| Wind melody over string texture | Oboe or flute melody; strings provide figuration or sustained chords | Foreground-background separation; scene-painting |
| Brass self-contained | Horns + trombones as complete harmonic unit | The heroic element stands apart from the pastoral |
| Dance bass in pizzicato | Cb + Vc pizzicato; no bass arco in dance sections | Lightness; the polka hop needs lift, not weight |
| Harp + strings for landscape | Harp arpeggiation + string tremolo or sustained | Water, castle, legend — the narrative textures |
