# Bedrich Smetana — Melodic Style

Smetana's melodies are the sound of Czech speech set free in music. The polka's dotted hop, the furiant's cross-rhythm, the singable village tune — these are not folk quotations but the melodic DNA of a nation's musical identity. His themes are direct, diatonic, and designed to be remembered: the Vltava melody is known by every Czech child.

## Core Melodic Character

| Feature | Description | Where It Appears |
|---------|-------------|-----------------|
| Czech speech rhythm | Trochaic stress (STRONG-weak) of Czech language reflected in melodic accent | Throughout — Czech prosody shapes the melody's breathing |
| Polka melody | Dotted-note rhythm (dotted eighth + sixteenth), 2/4, bright and hopping | The Bartered Bride, Czech Dances, dance episodes in Ma vlast |
| Singable diatonic lines | Stepwise motion with occasional 3rd/4th leaps; narrow range; folk simplicity | Vltava theme, opera arias, pastoral themes |
| Folk-song contour | 8-bar balanced phrases (4+4); antecedent-consequent; clear tonal direction | Most themes in operas and tone poems |
| Fanfare melody | Dotted rhythms, P4/P5 intervals, brass character; heroic | Vysehrad, Blanik, Libuse — national/heroic subjects |
| Hussite chorale | Hymn-like, syllabic, minor key, grave; based on actual Hussite hymns | Tabor, Blanik — the warrior tradition |
| Autobiographical melody | Chromatic, fragmented, anguished — late works only | String Quartet No. 2; the disintegrating mind |

## Melodic Construction Principles

| Principle | How Smetana Applies It | Effect |
|-----------|----------------------|--------|
| Question-answer phrasing | 4 bars up (question) + 4 bars down (answer) | Balanced, memorable, folk-natural |
| Repetition with variation | Theme stated, then repeated with slight melodic or harmonic change | The listener learns the tune on first hearing |
| Dance as melody | The rhythmic pattern of the dance IS the melody — inseparable | Polka rhythm generates the melodic contour |
| Landscape description | Melody follows the imagined shape of water, hills, forest | Vltava: melody rises and falls like the river's course |
| Vocal origin | Even orchestral melodies feel singable; vocal range, vocal phrasing | Opera training shapes all melodic thinking |

```abc
X:1
T:Smetana — The Vltava Theme (the most famous Czech melody)
M:6/8
L:1/8
K:Em
%% The river's melody: flowing, folk-like, minor turning to major
!mf!E2G B2A|G2F E2D|E2G B2d|e3-e2z|
d2B G2E|D2E G2B|A2G F2E|E3-E2z|
%% 8 bars, balanced, singable — the Czech countryside in melody
```

```abc
X:2
T:Smetana — Polka Melody (The Bartered Bride character)
M:2/4
L:1/16
K:G
%% Bright, dotted, hopping — the Czech polka in art music
!f!B3A G2A2|B3c d2B2|A3G F2G2|A4 z4|
B3A G2A2|B3c d2e2|d3c B2A2|G4 z4|
%% Dotted rhythm IS the melody; the hop IS the character
```

## Melodic Intervals — Signature Shapes

| Interval | Frequency | Expressive Use | Example Context |
|----------|-----------|---------------|-----------------|
| Rising 3rd (minor/major) | Very common | Opening gesture, folk call; warmth | Vltava theme opening, opera themes |
| Falling 2nd | Very common | Phrase endings, sighing, Czech inflection | End of every polka phrase |
| Rising P4 | Common | Fanfare, heroic opening | Vysehrad, Blanik |
| Rising P5 | Common | Open, majestic, declarative | Libuse prophecy, national themes |
| Falling 3rd | Common | Gentle descent, pastoral | Pastoral sections of Ma vlast |
| Dotted-note figure | Ubiquitous | THE Czech rhythmic-melodic cell | Polka, furiant, march — Czech DNA |
| Augmented 2nd | Rare | Exotic; avoided in Czech style | Reserved for non-Czech characters in opera |

## Dance Melodies — Rhythm as Melodic Generator

### Polka Melody

| Feature | Pattern | Character |
|---------|---------|-----------|
| Meter | 2/4, fast (quarter = 120–160) | Bright, energetic |
| Rhythmic cell | Dotted-eighth + sixteenth + quarter | The "hop" — the polka's DNA |
| Contour | Rising to mid-phrase, falling to cadence | 4-bar arcs, balanced |
| Register | Middle (comfortable singing range) | Communal — everyone can join |

### Furiant Melody

| Feature | Pattern | Character |
|---------|---------|-----------|
| Meter | 3/4 with 2/4 hemiola disruption | Fierce, proud, cross-rhythmic |
| Rhythmic cell | 3 quarter notes vs. dotted half (hemiola) | Metric ambiguity = Czech fire |
| Contour | Angular, accented, wide leaps | More aggressive than polka |
| Register | Higher, more forceful | Heroic dance — not gentle |

```abc
X:3
T:Smetana — Furiant Melody with Hemiola
M:3/4
L:1/8
K:D
%% 3/4 with hemiola disruption — the fierce Czech dance
!f!D2 F2 A2|d4 A2|F2 D2 A,2|D4 z2|
%% Now hemiola (2/4 feeling in 3/4):
D2F2 A2d2 A2F2|D6|
%% The metric conflict IS the furiant's character
```

## Landscape Melody — Nature as Melodic Source

| Landscape | Melodic Character | Technique |
|-----------|------------------|-----------|
| River (Vltava) | Flowing, continuous sixteenth-note figuration; melody floats above | Rocking arpeggiation generates the melodic line |
| Forest | Horn-call intervals (P4, P5); echo effects | Call-and-response between instruments |
| Village | Polka/folk melody; singable, diatonic | Direct folk quotation or close imitation |
| Castle | Harp arpeggiation; broad, descending melody | Majesty through simplicity |
| Battle | Hussite chorale; march rhythm; minor key | Hymn-derived; syllabic; communal |

## Phrase Structure

| Pattern | Description | Where |
|---------|-------------|-------|
| 4+4 (balanced) | Standard folk-song phrasing; question-answer | Most themes — Smetana's default |
| 4+4+4 (extended) | Third phrase as development or codetta | Opera arias; Vltava theme extended |
| 2+2+4 (sentence) | Short motifs leading to longer phrase | Dance themes; polka development |
| Hemiola disruption | Regular phrasing broken by 3-against-2 | Furiant; moments of rhythmic energy |
| Elided at cadence | New phrase begins on final note of previous | Opera scenes; continuous flow in tone poems |

## Vocal vs. Instrumental Melody

| Dimension | Opera (Vocal) | Tone Poem (Instrumental) |
|-----------|--------------|-------------------------|
| Range | Comfortable voice range (octave + 3rd) | Wider; instruments can exceed vocal limits |
| Text rhythm | Czech speech stress determines rhythm | Dance or landscape determines rhythm |
| Phrasing | Breath-length phrases | Can be extended through instrumental sustain |
| Character | Individual character expression | Landscape or national expression |
| Ornamentation | Syllabic; minimal decoration | More figuration; instrumental idiom |
