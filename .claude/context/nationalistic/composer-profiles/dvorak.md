# Dvorak Composer Profile

## Quick ID
| Attribute | Value |
|-----------|-------|
| Full name | Antonin Dvorak (1841-1904) |
| Nationality | Czech (Bohemian) |
| Period | Late Romantic / Nationalistic |
| Key works | Symphony No. 9 "New World", Cello Concerto, Slavonic Dances, String Quartet No. 12 "American" |
| Signature traits | Pentatonic themes, Czech dance rhythms, dumka form, lyric warmth |

## Melodic Language

| Feature | Description |
|---------|-------------|
| Pentatonic base | Many themes built on 5-note scale, giving folk universality |
| Wide intervals | Leaps of 4th/5th/octave in theme heads |
| Syncopated rhythm | Czech speech-rhythm syncopation in melodies |
| Singing quality | All instruments treated as voices |
| Modal inflection | Frequent major/minor 3rd ambiguity |

## Dumka Form Usage

| Section | Tempo | Mode | Character |
|---------|-------|------|-----------|
| A | Lento | Minor | Melancholic, yearning |
| B | Vivace | Major | Wild dance, energetic |
| A' | Lento | Minor | Deepened sadness |
| B' | Vivace | Major | More intense dance |
| A'' | Lento | Minor | Final resignation or hope |

Key works using dumka: Piano Quintet Op. 81, Piano Trio "Dumky", Slavonic Dances

## Harmonic Signature

| Technique | Frequency | Example |
|-----------|-----------|---------|
| Plagal cadences (IV-I) | Very frequent | Warm, folk finality |
| Mediant relationships | Frequent | C major to Ab major shifts |
| Modal mixture | Constant | i and I freely alternated |
| Added 6th chords | Characteristic | Warmth in lyric passages |
| Dominant 9th | Moderate | Lush Romantic color |
| Pedal points | Frequent | Anchoring folk harmony |

## Rhythmic Patterns

| Dance | Meter | Pattern | Use |
|-------|-------|---------|-----|
| Polka | 2/4 | Quarter + 2 eighths | Fast movements |
| Furiant | 3/4 (with hemiola) | Shifting 3/4 vs 6/8 | Scherzo movements |
| Sousedska | 3/4 | Slow waltz-like | Lyric slow dances |
| Skocna | 2/4 | Leaping, fast | Finales |
| Dumka | Variable | Slow-fast alternation | Slow movements |

## Orchestration Preferences

| Feature | Detail |
|---------|--------|
| English horn | Signature solo voice (New World, mvt. 2) |
| Cello melody | Rich, singing lines in middle register |
| Horn calls | Nature/forest associations |
| Clarinet warmth | Lyric secondary themes |
| String tremolos | Atmospheric scene-setting |
| Full brass chorale | Climactic national hymn moments |
| Timpani pedal | Anchoring drone in folk passages |

## New World Influence (American Period)

| Element | Integration |
|---------|-------------|
| Pentatonic emphasis | Strengthened by African-American spiritual influence |
| Flatted 7th | Blues-adjacent coloring |
| "Scotch snap" rhythm | Short-long pattern (sixteenth-dotted eighth) |
| Open 5ths | Prairie/landscape spaciousness |
| Syncopation | Intensified by American folk music exposure |

## Key Progressions (Dvorak Fingerprints)

```
Lyric theme:     I - vi - IV - V - I
Dance theme:     I - IV - V - I (simple, sturdy)
Dumka transition: i - bVI - bVII - i (aeolian descent)
New World color:  I - bVII - IV - I (pentatonic harmony)
Climax:          iv - bVI - bVII - I (minor to blazing major)
```

## Form Preferences

| Genre | Typical Approach |
|-------|-----------------|
| Symphony | Classical 4-movement, folk themes within sonata form |
| Chamber | Dumka form frequent, folk dance scherzos |
| Concerto | Lyric, singing approach; cadenzas optional |
| Opera | Continuous folk-inflected vocal writing |
| Overture | Sonata form with folk thematic material |

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key choices | Db major (pentatonic warmth), E minor, G major |
| Tempo markings | Allegro con fuoco, Lento, Vivace |
| Melody range | Wide (often exceeds octave in theme) |
| Harmonic rhythm | Moderate; faster in dance, slower in lyric |
| Orchestral weight | Medium to full; transparency in chamber textures |
| Emotional tone | Warm, nostalgic, rhythmically vital |
