# Grieg Composer Profile

## Quick ID
| Attribute | Value |
|-----------|-------|
| Full name | Edvard Grieg (1843-1907) |
| Nationality | Norwegian |
| Period | Late Romantic / Nationalistic |
| Key works | Piano Concerto, Peer Gynt Suites, Lyric Pieces, Holberg Suite, String Quartet |
| Signature traits | Norwegian folk modes, Hardanger fiddle imitation, miniature forms, chromatic harmony |

## Melodic Language

| Feature | Description |
|---------|-------------|
| Norwegian folk scales | Lydian raised 4th, Mixolydian lowered 7th |
| Narrow range themes | Many melodies span a 5th or 6th |
| Drone-based melody | Melody hovers around a sustained tone |
| Ornamental turns | Grace notes imitating Hardanger fiddle ornamentation |
| Pentatonic fragments | Embedded in longer diatonic lines |
| Descending contour | Many themes descend, giving melancholy weight |

## Hardanger Fiddle Techniques in Orchestra

| Fiddle Technique | Orchestral Translation |
|-----------------|----------------------|
| Sympathetic strings | Open string drones in violin II / viola |
| Double stops | Solo violin in parallel 3rds/6ths over drone |
| Ornamental turns | Acciaccaturas, mordents on solo violin |
| Scordatura | Open-string resonance emphasized |
| Dance bowing | Spiccato with accent patterns |

## Harmonic Signature

| Technique | Frequency | Effect |
|-----------|-----------|--------|
| Chromatic inner voices | Very frequent | Restless, expressive color |
| Added 6th and 9th chords | Characteristic | Atmospheric warmth |
| Diminished 7th chains | Frequent | Dramatic tension |
| Sudden modal shifts | Characteristic | Folk surprise |
| Pedal points with chromatic harmony above | Signature | Grounded yet colorful |
| Parallel 3rds and 6ths | Very frequent | Norwegian folk interval |
| Augmented triads | Moderate | Mysterious, transitional |

## Lyric Pieces Style (Piano Miniatures)

| Feature | Description |
|---------|-------------|
| Length | 1-4 minutes typical |
| Form | ABA or AABA, simple ternary |
| Texture | Melody + accompaniment, occasional counterpoint |
| Character types | Dance, nocturne, waltz, folk scene, nature picture |
| Pedal use | Rich sustain, atmospheric resonance |
| Difficulty | Moderate; expressive, not virtuosic |

## Key Progressions (Grieg Fingerprints)

```
Opening:        i - bVII - bVI - V (descending Norwegian)
Lyric theme:    I - vi - ii - V7 - I (warm diatonic)
Chromatic:      i - #iv dim7 - V - VI - iv - V - i
Modal shift:    A minor -> A major (sudden Picardy)
Cadential:      iv - I (plagal, folk weight)
```

## Orchestration Preferences

| Feature | Detail |
|---------|--------|
| Solo piano | Primary instrument; concerto and miniatures |
| Strings | Warm, singing; frequent divisi |
| Solo oboe | Pastoral folk voice |
| Horn | Mountain/nature calls |
| Flute | Light, high-altitude air |
| Harp | Atmospheric punctuation |
| Light orchestration | Avoids heavy brass; transparency preferred |

## Norwegian Dance Rhythms

| Dance | Meter | Character |
|-------|-------|-----------|
| Springar | 3/4 (uneven beats) | Lively, asymmetric |
| Gangar | 2/4 or 6/8 | Walking dance, moderate |
| Halling | 2/4 | Vigorous, leaping (male) |
| Bridal march | 4/4 | Stately processional |

## Form Preferences

| Genre | Approach |
|-------|----------|
| Concerto | Romantic single-arch within 3 movements |
| Suite | Character pieces arranged by contrast |
| Song | Strophic or modified strophic, folk-like |
| Piano miniature | Simple ternary, evocative title |
| String music | Holberg Suite: neo-baroque + folk fusion |

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key choices | A minor, G major, E minor, D major |
| Tempo | Allegretto, Andante, Allegro moderato |
| Melody range | Moderate (5th to octave) |
| Harmonic rhythm | Moderate with chromatic passing chords |
| Texture | Transparent; melody always prominent |
| Emotional tone | Nostalgic, intimate, occasionally dramatic |
| Avoid | Heavy orchestration, long development sections |
| Emphasize | Color chords, modal shifts, miniature perfection |
