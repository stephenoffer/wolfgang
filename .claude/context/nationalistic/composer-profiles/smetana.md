# Smetana Composer Profile

## Quick ID
| Attribute | Value |
|-----------|-------|
| Full name | Bedrich Smetana (1824-1884) |
| Nationality | Czech (Bohemian) |
| Period | Romantic / Nationalistic |
| Key works | Ma Vlast (My Fatherland), The Bartered Bride, String Quartet No. 1 "From My Life" |
| Signature traits | Czech program music, polka rhythms, Moldau-style pictorialism, operatic lyricism |

## Melodic Language

| Feature | Description |
|---------|-------------|
| Singing lyricism | Opera-influenced, long-breathed phrases |
| Czech speech rhythm | Dotted patterns matching Czech language stress |
| Dance-derived themes | Polka and furiant rhythms embedded in melody |
| Pictorial motifs | Short figures representing nature (river, forest) |
| Diatonic clarity | Mostly stepwise, accessible melody |

## Pictorialism Techniques

| Scene | Musical Device | Example |
|-------|---------------|---------|
| Flowing river | Undulating string figuration in 6/8 | Moldau opening |
| Forest | Horn calls, woodwind bird motifs | Moldau hunt scene |
| Castle/fortress | Brass fanfare, dotted rhythms | Vysehrad |
| Peasant dance | Full orchestra polka | Moldau wedding |
| Moonlight | Muted strings, flute melody, harp | Moldau night |
| Rapids | Accelerating tutti, chromatic scales | Moldau rapids |
| Sunrise/dawn | Gradual orchestral build, major key | Scene transitions |
| Battle | Martial brass, snare drum, driving rhythm | Tabor |

| Technique | Frequency | Effect |
|-----------|-----------|--------|

## Czech Dance Rhythms

| Dance | Meter | Rhythmic Feature | Character |
|-------|-------|-------------------|-----------|
| Polka | 2/4 | Eighth-eighth-quarter | Lively, celebratory |
| Furiant | 3/4 | Hemiola (3 vs 2 groupings) | Fiery, proud |
| Sousedska | 3/4 | Gentle waltz-like | Tender, nostalgic |
| Skocna | 2/4 | Leaping, energetic | Boisterous finale |

|----------|---------|-------------------|

| Sarka | Amazon legend | Dramatic contrasts, battle |
| From Bohemia's Fields | Pastoral landscape | Folk dance, pastoral woodwind |

| Blanik | Heroic legend | Chorale transformed triumphantly |

## Key Progressions (Smetana Fingerprints)

```
Scenic opening:   Gradual build from single instrument to tutti
Dance theme:      I - V - I - IV - V - I (sturdy, clear)
Dramatic shift:   Major -> minor via diminished 7th pivot
Triumphant close: iv - bVI - V - I (minor subdominant to major resolution)
River flow:       Stepwise bass, undulating upper voices in 6/8
```

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key choices | E minor (river), D major (dance), Bb major (heroic) |
| Tempo | Allegro vivo (dance), Andante (lyric), Moderato (scenic) |
| Melody | Lyric, song-like, diatonic with clear phrase structure |
| Harmonic rhythm | Moderate to fast; follows dramatic pacing |
| Texture | Clear orchestral layers; melody always audible |
| Program | Always narratively driven; scenes, landscapes, stories |
| Emotional tone | Patriotic warmth, scenic beauty, dramatic narrative |
| Avoid | Abstract development, heavy chromaticism |
| Emphasize | Pictorialism, dance rhythms, lyric singing quality |
