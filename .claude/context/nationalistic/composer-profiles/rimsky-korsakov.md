## Key Progressions (Rimsky-Korsakov Fingerprints)

```
Octatonic shift:   C major -> Eb major -> F# major -> A major (minor 3rd cycle)
Scheherazade link: Solo violin cadenza bridges any two keys
Folk dance:        I - IV - V - I (clear, sturdy diatonic)
Exotic color:      i - bII - i (Phrygian oscillation)
Magic scene:       Whole-tone glissando -> sudden tonal arrival
Climactic:         Chromatic ascent in bass -> fff major chord
```

## Scheherazade as Structural Model

| Movement | Character | Orchestral Feature |
|----------|-----------|-------------------|
| I: The Sea and Sindbad's Ship | Wave motion, narrative | Undulating strings, brass fanfare |
| II: Kalendar Prince | Storytelling, exotic | Solo bassoon, violin cadenza |
| III: The Young Prince and Princess | Love, lyric | Singing strings, delicate winds |
| IV: Festival at Baghdad / Shipwreck | Climactic, tutti | All themes combined, storm |

**Unifying device**: Solo violin (Scheherazade) theme returns between movements.

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key choices | E major, A minor, Db major (exotic color keys) |

| Melody | Soloistic, ornamental, scale-driven |
| Harmonic palette | Octatonic for magic, diatonic for folk, whole-tone for sea |
| Texture | Brilliant, transparent even in tutti |
| Orchestration | Color-coded by scene; showcase individual instruments |
| Emotional tone | Vivid, colorful, narrative, spectacular |
| Avoid | Thick doubling, murky textures, academic development |
| Emphasize | Timbral brilliance, exotic scales, fairy-tale contrast |
