# Antonin Dvorak — Melodic Style

Dvorak's supreme gift is melody. His themes have the quality of folk songs — simple, singable, immediately memorable — as if they existed in the collective imagination before he wrote them down. This is not naivety; it is a specific skill: composing original melodies that sound discovered rather than invented. Every Dvorak piece, from the most complex symphony to the simplest dance, has a tune.

## Core Melodic Character

| Feature | Description | Where It Appears |
|---------|-------------|-----------------|
| Pentatonic construction | Melodies built from 5-note scales (no semitones): C-D-E-G-A | New World Symphony, American Quartet, Cello Concerto |
| Folk-song contour | Arch shape: rise in first half, fall in second; question-answer phrasing | Everywhere — the default Dvorak melody shape |
| Singable range | Most themes stay within an octave; comfortable vocal range | All periods; even instrumental themes are "singable" |
| Immediate memorability | The melody works on first hearing; no preparation needed | The defining Dvorak quality |
| Dance character | Melodies carry rhythmic identity of specific dances (furiant, dumka, polka) | Slavonic Dances, scherzo movements, finales |
| Repetition with variation | A phrase stated, then repeated with slight melodic or rhythmic change | Folk song practice absorbed into symphonic writing |
| Major/minor modal shift | Same melody in major, then minor (or vice versa) — the dumka principle | Across all periods; emotional duality |

## Melodic Intervals — Signature Shapes

| Interval | Frequency | Expressive Use | Example Context |
|----------|-----------|---------------|-----------------|
| Rising 3rd (major) | Very common | Warmth, optimism, folk simplicity | New World opening theme, Slavonic Dances |
| Falling 3rd | Very common | Tenderness, sighing, folk cadence | Phrase endings everywhere |
| Rising 5th (perfect) | Common | Open, spacious, horn-call quality | American period themes |
| Falling 5th | Common | Settling, cadential, conclusive | Phrase endings, coda themes |
| Rising octave | Moderate | Declaration, joy, climactic | Dance climaxes, scherzo themes |
| Pentatonic leap (minor 3rd) | Very common | Folk character; gaps in pentatonic scale | Defines the pentatonic style |
| Stepwise motion | Dominant | The foundation — most Dvorak melody is stepwise | Throughout |

```abc
X:1
T:Dvorak Pentatonic Theme — New World Largo Character
M:4/4
L:1/8
K:Db
%% The paradigm: pentatonic, arch-shaped, singable, unforgettable
!pp!F4 A4|f4 e4|d4 B4|A8|
%% Only Db-Eb-F-Ab-Bb (pentatonic) — no Gb, no C — maximum simplicity
%% Rising first phrase (F-A-f), falling second (f-e-d-B-A)
```

## Folk-Song Construction

### The Question-Answer Principle

| Element | Description | Bars |
|---------|-------------|------|
| Question (antecedent) | First 4 bars: melody rises, ends on dominant or 3rd | 1-4 |
| Answer (consequent) | Next 4 bars: melody falls, ends on tonic | 5-8 |
| Repetition | Phrase repeated with variation (orchestral, dynamic, or slight melodic change) | 9-16 |

```abc
X:2
T:Dvorak Folk-Song Construction — Question and Answer
M:2/4
L:1/8
K:G
%% Question: rises, ends on D (dominant)
!mf!G2 B2|d2 e2|d2 B2|A4|
%% Answer: falls, ends on G (tonic)
d2 B2|A2 G2|F2 A2|G4|
%% 8 bars, complete, singable, folk-like — the Dvorak template
```

## Dance Melodies

### Furiant (Fast, Hemiola)

| Feature | Description |
|---------|-------------|
| Meter | 3/4, fast (dotted half = 54-60 or quarter = 126-160) |
| Hemiola | Bars 1-2 in clear 3/4; bars 3-4 regroup as 2+2+2 eighths (implied 2/4) |
| Accent | Strong downbeat, marcato; the stamping quality |
| Contour | Short, angular, repeated motives — not lyrical |

```abc
X:3
T:Dvorak Furiant Melody — Hemiola Pattern
M:3/4
L:1/8
K:D
%% Bars 1-2: clear 3/4 grouping
!f!D2 F2 A2|d4 A2|
%% Bars 3-4: hemiola — 2+2+2 eighth notes against 3/4
d2 c2 B2|A2 G2 F2|
%% The rhythmic shift IS the furiant character
```

### Dumka (Slow-Fast Alternation)

| Section | Character | Tempo | Mode | Melody |
|---------|-----------|-------|------|--------|
| A (slow) | Melancholy, lyrical, deeply felt | Lento/Andante | Minor | Long sustained notes, narrow range, falling contour |
| B (fast) | Dance-like, energetic, celebratory | Vivace/Presto | Major | Short, rhythmic, rising, staccato |
| A return | Deeper melancholy (varied) | Lento | Minor | Original melody, possibly ornamented |

```abc
X:4
T:Dvorak Dumka — Slow and Fast Sections
M:4/4
L:1/8
K:Em
%% Mesto — the Ukrainian/Czech lament
!pp!E4 G4|B4 A4|G4 F4|E8|
%% Long notes, narrow range, falling at the end — pure melancholy
```

## Melodic Development Techniques

| Technique | How Dvorak Uses It | Contrast with Brahms |
|-----------|-------------------|---------------------|
| Sequential repetition | Phrase repeated a step higher (folk-sequence) | Brahms: developing variation. Dvorak: folk repetition |
| Orchestral variation | Same melody, different instrument/register | Dvorak's primary development method — not motivic transformation |
| Modal shift | Melody restated in minor after major (or vice versa) | The dumka principle applied to symphonic form |
| Extension | 4-bar phrase extended to 6 or 8 by repeating the cadential figure | Folk song practice; less systematic than Brahms |
| Fragmentation (rare) | Short motives extracted for development sections | Less common than in Brahms; Dvorak prefers complete melodies |

## Phrase Structure

| Pattern | Description | Frequency |
|---------|-------------|-----------|
| 4+4 (regular) | Balanced question-answer; folk-song standard | Very common — more regular than Brahms |
| 4+4+4+4 | Double period; the full folk stanza | Slavonic Dances, song-like themes |
| 4+6 | Consequent phrase extended by cadential repetition | Moderate — lyrical themes |
| 2+2+4 | Short fragments leading to longer phrase | Dance themes, development |
| Elided | Rare; Dvorak prefers clear phrase boundaries | Development sections only |

## Thematic Types by Genre

| Genre | Melody Character | Scale | Register |
|-------|-----------------|-------|----------|
| Symphony (first theme) | Energetic, rising, often minor | Diatonic or pentatonic | Middle (viola/cello range often) |
| Symphony (second theme) | Lyrical, singing, major | Pentatonic or hexatonic | Upper (violin, woodwind) |
| Slavonic Dance | Rhythmic, dance-specific, accented | Mixolydian or modal | Full range |
| Dumka movement | Alternating lyrical and rhythmic | Minor pentatonic (slow); major (fast) | Low for slow; high for fast |
| Slow movement | Long-breathed, cor anglais or cello solo | Pentatonic | Middle — the "singing" register |
| Cello Concerto | Wide-spanning, passionate, chromatic | Full chromatic with pentatonic core | Tenor to high cello |
