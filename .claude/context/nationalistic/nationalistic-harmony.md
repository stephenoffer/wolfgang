# Nationalistic Harmony Reference

## Core Principle
Nationalistic harmony fuses Western tonal practice with folk-derived scales, modes, and melodic contours. The goal is local color within a functional framework.

## National Scale Patterns

| Tradition | Scale / Mode | Interval Pattern (semitones) | Character |
|-----------|-------------|------------------------------|-----------|
| Hungarian minor | C D Eb F# G Ab B C | 2-1-3-1-1-3-1 | Augmented 2nds give exotic tension |
| Hungarian major | C D# E F# G A Bb C | 3-1-2-1-2-1-2 | Bright yet eastern |
| Russian (Dorian emphasis) | D E F G A B C D | 2-1-2-2-2-1-2 | Warm, melancholic folksong |
| Russian octatonic | C Db Eb E F# G A Bb | 1-2-1-2-1-2-1-2 | Rimsky / Stravinsky color |
| Nordic (Lydian inflection) | C D E F# G A B C | 2-2-2-1-2-2-1 | Open, luminous landscape |
| Czech (Mixolydian) | G A B C D E F G | 2-2-1-2-2-1-2 | Dance-like, pastoral |
| Pentatonic (anhemitonic) | C D E G A | 2-2-3-2-3 | Universal folk base |
| Scottish/Celtic gap scale | C D E G A (=major pent.) | 2-2-3-2-3 | Open, bagpipe quality |
| Spanish Phrygian | E F G A B C D E | 1-2-2-2-1-2-2 | Flamenco color |

## Folk Melody Integration Techniques

| Technique | Description | Use Case |
|-----------|-------------|----------|
| Direct quotation | Literal folk tune in orchestral texture | Theme statement, variation set |
| Stylistic imitation | Original melody following folk contour rules | Primary themes |
| Modal harmonization | Folk tune harmonized with modal, not functional chords | Sustaining folk flavor |
| Heterophonic layering | Multiple instruments play melody variants simultaneously | Russian choral style |
| Call-and-response | Soloist states phrase, ensemble answers | Dance movements |
| Drone accompaniment | Sustained 5th below melody | Bagpipe/hurdy-gurdy imitation |

## Modal Inflection Patterns

### Switching Between Major and Minor 3rd
Common in Czech and Russian music. The 3rd degree fluctuates freely.

```abc
X:1
T:Modal 3rd Fluctuation
M:4/4
K:C
|: E2 G2 | _E2 G2 | C4 | C4 :|
```

### Lydian 4th Inflection (Nordic)
Raised 4th creates luminous, open quality.

```abc
X:2
T:Lydian Inflection
M:3/4
K:C
| C2 D | E2 ^F | G3 | E3 |
```

### Phrygian 2nd (Spanish/Eastern European)
Lowered 2nd for dark, exotic color.

```abc
X:3
T:Phrygian Inflection
M:4/4
K:Am
| A2 _B2 | A2 G2 | F2 E2 | A4 |
```

## Pentatonic Usage

| Application | Example Pattern | Tradition |
|-------------|----------------|-----------|
| Theme construction | Melody uses only 5 notes | Dvorak, Grieg |
| Harmonic stacking | Triads built from pentatonic set | Impressionist-national overlap |
| Ostinato | Repeating pentatonic figure | Bartok, Kodaly |
| Gap-fill melody | Pentatonic skeleton, chromatic passing tones | Mature national style |

### Dvorak-style Pentatonic Theme
```abc
X:4
T:Pentatonic Theme (Dvorak style)
M:4/4
K:Db
| F2 A2 | f2 e2 | d2 B2 | A4 |
```

## Nationalistic Cadential Patterns

| Cadence Type | Progression | National Origin | Effect |
|-------------|-------------|-----------------|--------|
| Plagal emphasis | IV - I (often minor iv - I) | Russian, Czech | Hymnlike, folk gravity |
| Modal half cadence | i - VII (natural minor) | Nordic | Open, unresolved landscape |
| Phrygian half cadence | iv6 - V | Spanish, Hungarian | Exotic tension |
| Picardy tierce | i - I (minor to major final) | Pan-European folk | Warm resolution |
| Lydian cadence | II - I (major II) | Nordic, Polish | Bright, lifted |
| Double plagal | bVII - IV - I | Celtic, folk-general | Broad, sweeping |
| Aeolian cadence | bVI - bVII - i | Russian, English | Dark grandeur |
| Hungarian cadence | V with #4 scale degree | Hungarian | Sharp, gypsy |

### Russian Plagal Cadence
```abc
X:5
T:Russian Plagal Cadence
M:4/4
K:Am
| [D2F2A2] [D2F2A2] | [C2E2A2] [C2E2A2] | [A,4C4E4] |
```

## Harmonic Rhythm in National Styles

| Style | Typical Harmonic Rhythm | Reasoning |
|-------|------------------------|-----------|
| Czech dance | Changes every bar or half-bar | Matches polka/furiant pulse |
| Russian epic | Very slow, pedal-based | Reflects vast landscape, liturgy |
| Nordic | Slow with sudden shifts | Landscape, seasonal change |
| Hungarian | Fast near cadence, slow in lyric | Verbunkos tradition |
| Spanish | Repetitive oscillation (i-bII-i) | Flamenco ostinato |

## Characteristic Chord Voicings

| Voicing | Structure | Use |
|---------|-----------|-----|
| Open 5th drone | Root + 5th, no 3rd | Bagpipe/folk instrument imitation |
| Stacked 4ths | Quartal voicing over drone | Nordic, archaic color |
| Added 6th | Major triad + 6th | Pastoral warmth (Dvorak) |
| Minor with major 7th | Root-b3-5-7 | Ambiguous, folk-chromatic |
| Parallel triads | Root position triads moving stepwise | Modal planing (Mussorgsky) |

## Key Modulation Techniques

| Technique | Description | Typical Use |
|-----------|-------------|-------------|
| Modal shift | Same tonic, different mode | Major theme returns in minor |
| Mediant shift | Move by 3rd (C to Eb, C to Ab) | Dramatic color change |
| Folk-sequence | Repeat phrase up a step (not strict sequence) | Building energy in dance |
| Pivot on drone | Harmony shifts while bass holds | Slow movements |
| Abrupt juxtaposition | No transition, new key arrives | Mussorgsky block form |

## Common Progressions by Tradition

### Czech
```
i - iv - V - i (minor dance)
I - IV - I - V - I (polka)
I - vi - IV - V - I (lyric theme)
```

### Russian
```
i - iv - i - V (modal minor)
i - bVI - bVII - i (aeolian)
i - iv - bVI - bVII - i (epic)
```

### Nordic
```
I - II - I (Lydian inflection)
i - bVII - bVI - V (descending)
I - IV - I (plagal, open)
```

### Hungarian
```
i - bII - V - i (Phrygian)
i - iv(#4) - V - i (Hungarian minor)
I - V/V - V - I (verbunkos cadential)
```

## Voice Leading Principles in National Harmony

| Principle | Application |
|-----------|-------------|
| Parallel motion acceptable | Modal harmony allows parallel 5ths/octaves for folk color |
| Drone independence | Bass drone does not participate in voice leading |
| Doubled 3rds in folk texture | Thickens melody, acceptable in folk harmonization |
| Cross-relations tolerated | Simultaneous major/minor 3rd creates folk ambiguity |
| Stepwise bass in Russian style | Bass moves by step under block chords |
