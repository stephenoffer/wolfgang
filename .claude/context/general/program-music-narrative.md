# Program Music & Musical Narrative — Telling Stories Through Sound

## Narrative-to-Form Mapping

| Narrative Type | Best Musical Form(s) | Rationale | Key Scheme Strategy |
|---------------|---------------------|-----------|---------------------|
| Quest/Journey | Sonata, rondo | Departure (expo), trials (dev), return (recap) | Tonic → distant → tonic |
| Tragedy | Sonata (no recap resolution), passacaglia | Descent is inevitable; ground bass = fate | Major → minor, no full return |
| Transformation | Through-composed, theme & variations | Each section is a new state; no exact return | Progressive tonality (start ≠ end key) |
| Conflict/Duel | Sonata (two-theme), double fugue | Two opposing themes; development = battle | Two competing key areas |
| Cycle/Eternal return | Rondo, arch form (ABCBA) | Return to opening = cyclical nature | Tonic returns repeatedly |
| Meditation | Passacaglia, strophic variation | Repetition with deepening; no dramatic arc | Single key center, modal shifts |
| Love story | Ternary (ABA'), sonata | Meeting, separation, reunion | Two keys converge; shared resolution |
| Descent/Fall | Continuous form, ground bass | Relentless downward; chromatic bass descent | Gradual descent; no strong return |
| Comedy/Farce | Rondo, scherzo-trio | Episodes of mishap; recurring refrain | Bright keys; unexpected modulations |
| Epic | Multi-movement symphony | Scale demands multiple chapters | Each movement = chapter key area |
| Mystery/Revelation | Free form, fantasia | Clues scattered; resolution withheld | Tonal ambiguity → clear cadence |
| Rebirth/Dawn | Two-part (slow intro → allegro) | Darkness precedes light | Minor → relative or parallel major |

| Scene | Tempo | Texture | Harmony | Rhythm | Register | Key Device |
|-------|-------|---------|---------|--------|----------|------------|
| Departure | Allegro moderato | Thinning, then building | Tonic → dominant direction | Walking, forward motion | Mid, expanding | Rising sequence |
| Arrival | Broadening | Full, warm | Strong PAC in new key | Broadening, augmented | Full range | Emphatic cadence |
| Confrontation | Allegro agitato | Dense counterpoint | Bitonal, dissonant | Driving, syncopated | Extreme contrasts | Competing themes |

| Chase | Presto | Building layers, ostinato | Minor, dominant pedal | Perpetual motion, 16ths | Rising | Accelerating sequence |

## Tone Poem Design Framework

### Single-Movement Narrative Structure

```
PROLOGUE ──> EPISODE 1 ──> EPISODE 2 ──> DEVELOPMENT ──> CLIMAX ──> EPILOGUE
 (intro)      (theme A)     (theme B)    (conflict)     (peak)    (resolution)
  4-16 bars    16-40 bars    16-40 bars   40-80 bars    8-24 bars   8-32 bars
```

| Section | Function | Techniques |
|---------|----------|-----------|
| Prologue | Set atmosphere, foreshadow | Slow, atmospheric; motif fragments; key established |
| Episode 1 | Introduce protagonist/main idea | Primary theme, full statement; character established |
| Episode 2 | Introduce contrast/antagonist | Secondary theme; new key, contrasting character |
| Development | Conflict, journey, interaction | Fragmentation, combination, modulation, climax build |
| Climax | Peak of narrative tension | Thematic collision or apotheosis; loudest, densest |
| Epilogue | Resolution, reflection | Theme returns transformed; quieting; final cadence |

### Pacing Models

**Linear narrative** (Smetana Moldau model):
```
Scene1 → Scene2 → Scene3 → Scene4 → Climax → Resolution
pp         p        mf       f        ff       mp→pp
```

**Conflict narrative** (Strauss tone poem model):
```
Hero → Adversary → Struggle → Crisis → Victory/Defeat → Reflection
  A        B         A+B dev.   climax      A triumphant    A quiet
```

**Cyclical narrative** (seasonal/life cycle):
```
Spring → Summer → Autumn → Winter → Spring (transformed)
  A         B        C        D        A' (changed)
```

## Musical Scene Painting

Techniques for depicting specific phenomena, cross-genre.

| Phenomenon | Instruments | Technique | ABC Pattern Hint |
|-----------|-------------|-----------|-----------------|
| Water (flowing) | Flute, harp, strings | Arpeggiated 16ths, 6/8 lilting | `CEGc \| egce` flowing arpeggios |
| Water (still) | Harp harmonics, celesta | Sustained open 5ths, gentle ripples | Whole notes + occasional grace note |
| Storm | Full orch., timpani | Tremolo, chromatic scales, sfz | Rapid chromatic runs + timpani rolls |
| Wind | Flute, strings | Ascending/descending scale runs, flutter | Rapid scalic passages, hairpins |
| Fire | High strings, brass | Rapid tremolo, trills, leaping figures | Fast repeated notes + ascending leaps |
| Dawn/Sunrise | Solo flute → oboe → strings | Rising line from low, crescendo | Gradual ascent C,→C over 16 bars |
| Night | Low strings, muted brass | Sustained, dark, slow harmonic rhythm | Low pedal tones, sparse melody |
| Birds | Flute, piccolo, clarinet | Trills, grace notes, fragments | Short staccato phrases, high |
| Mountains | Horn, broad strings | Open 5ths, broad melody, wide spacing | Horn call: `G, C E G \| c G E C` |
| Forest | Horns, woodwinds | Horn calls, rustling strings | Hunting motif + tremolo |
| Crowds/City | Full orch., diverse motifs | Polyphonic, layered, dense | Multiple competing rhythms |
| Solitude | Solo instrument, silence | Unaccompanied, pauses | Melody with rests |
| Darkness | Low register, muted | Diminished, chromatic, pp | Bass clarinet, muted trombone |
| Light | High register, open | Major, bright orchestration | Flute + violin in octaves, ff |
| Distance | Offstage, ppp, echo | Dynamic reduction, reverb effect | Phrase repeated softer, higher |
| Speed | Fast tempo, perpetual motion | 16th-note runs, metric drive | Moto perpetuo |
| Stillness | Sustained chord, no rhythm | Whole-note chord, ppp | Single held chord, 4+ bars |

## Time Manipulation in Musical Narrative

| Technique | Musical Device | Bars Needed | Effect |
|-----------|---------------|-------------|--------|
| Flashback | Modal shift, thinner texture, theme quotation from earlier | 4-16 | Audience recognizes past; nostalgia/memory |
| Foreshadowing | Brief motif quotation (2-3 notes) of a future theme | 1-2 | Seeds recognition; unconscious preparation |
| Time compression | Diminution, montage (theme fragments cycled rapidly) | 8-16 | Events passing quickly; accelerated narrative |
| Slow motion | Augmentation, sustained harmony, reduced orchestration | 8-16 | Critical moment stretched; emotional weight |
| Freeze/Tableau | Sustained chord, silence, fermata | 1-4 | Time stops; shock or revelation |
| Parallel timelines | Two themes alternating in different tempi/keys | 16-32 | Simultaneous narratives; cross-cutting |
| Cyclical time | Theme returns identically; ground bass | Full section | Eternity, recurrence, inescapability |
| Aging/Decay | Gradual tempo decrease, texture thinning, lower register | 16-32 | Passage of time; entropy |
