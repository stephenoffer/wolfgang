# Musical Form Overview

## Binary Form (AB)

| Section | Key area | Description |
|---|---|---|
| A | I -> V (or relative major if minor) | Opens, modulates away from tonic |
| B | V -> I (returns home) | Contrasting or developmental, cadences in tonic |

- Both sections usually repeated: `||: A :||: B :||`
- **Rounded binary:** B section ends with return of A material (A -> B -> A'), precursor to sonata form
- Common in Baroque dance movements (allemande, courante, sarabande, gigue)

---

## Ternary Form (ABA)

| Section | Key | Function |
|---|---|---|
| A | Tonic | Main theme, complete in itself |
| B | Contrasting key or mode | New material, contrast |
| A (da capo or written out) | Tonic | Return of opening, may be ornamented |

- Distinct from rounded binary: A section is self-contained with its own cadence
- Common in minuet/trio, scherzo/trio, character pieces, arias

---

## Sonata Form (most important Classical form)

### Structure

| Section | Subsection | Key (major) | Key (minor) | Function |
|---|---|---|---|---|
| **Exposition** | 1st theme (P) | I | i | Establishes tonic |
| | Transition (TR) | I -> V | i -> III | Modulates; energy builds |
| | 2nd theme (S) | V | III (or v) | Contrasting character in new key |
| | Closing (C) | V | III | Confirms new key |
| **Development** | — | Unstable, remote keys | Unstable | Fragments, sequences, modulations of expo. material |
| **Recapitulation** | 1st theme (P) | I | i | Return of tonic |
| | Transition (TR) | I -> I (adjusted) | i -> i | Modified to stay in tonic |
| | 2nd theme (S) | I | i (or I) | NOW in tonic — resolves tonal tension |
| | Closing (C) | I | i | Confirms tonic |
| **Coda** (optional) | — | I | i | Final confirmation, extra closure |

### Key Principles
- The **tonal drama** is: exposition creates key-area tension, recapitulation resolves it
- Development typically uses: fragmentation, sequence, contrapuntal techniques, distant keys
- **Introduction** (slow, in tonic) may precede exposition (Haydn, Beethoven)
- Exposition repeat is standard in Classical period; often dropped in Romantic
- Development may introduce new themes (rare in Classical, more common in Romantic)

## Sonata-Rondo Form

Hybrid: `A B A C A B A` with sonata-like tonal plan.

| Section | Function | Key |
|---|---|---|
| A (refrain) | Main theme | I |
| B (1st episode) | Second theme | V |
| A | Refrain return | I |
| C (2nd episode) | Development-like | Unstable |
| A | Refrain return | I |
| B | Second theme | I (now resolved, like recap) |
| A + Coda | Final refrain | I |

Common in Classical finales (Mozart, Beethoven concerto last movements).

---

## Rondo Form

| Type | Structure | Description |
|---|---|---|
| 5-part rondo | A B A C A | Refrain alternates with contrasting episodes |
| 7-part rondo | A B A C A B A | Extended version; B returns |

- Refrain (A) always in tonic
- Episodes (B, C) in contrasting keys
- Light, energetic character; typical finale form

---

## Theme and Variations

```
Theme (A) -> Var.1 (A') -> Var.2 (A'') -> ... -> Var.N -> [Coda]
```

| Variation technique | Description |
|---|---|
| Melodic ornamentation | Original melody embellished |
| Rhythmic transformation | Note values altered (diminution, augmentation) |
| Harmonic recoloring | Mode change (major/minor), reharmonization |
| Textural change | Different voicing, register, accompaniment pattern |
| Character change | Tempo/style shift (e.g., march, waltz, fugue) |
| Tempo variation | Slow variation, fast variation |

- Theme usually a simple binary or rounded binary form
- Structure of theme typically preserved in each variation (same length, same phrase structure)
- Final variation often a coda or culminating transformation

## Fugue

| Section | Description |
|---|---|
| Exposition | Subject enters in each voice successively (tonic -> dominant -> tonic -> dominant) |
| Answer | Subject transposed to dominant; **real** (exact) or **tonal** (adjusted to stay in key) |
| Countersubject | Recurring countermelody that accompanies the answer/subject |
| Episodes | Developmental passages between subject entries; modulating, sequential |
| Middle entries | Subject in related keys, possibly inverted, augmented, or diminished |
| Stretto | Overlapping subject entries (entries begin before previous completes) |
| Final entry | Subject in tonic, often with pedal point; decisive cadence |

**Fugal devices:** Inversion (upside down), Augmentation (longer values), Diminution (shorter values), Retrograde (backwards), Stretto (overlapping entries).

## Ritornello Form

Used in Baroque concerto grosso and solo concerto movements.

| Element | Performer | Key |
|---|---|---|
| Ritornello 1 | Tutti (full ensemble) | Tonic (complete) |
| Solo episode 1 | Soloist(s) | Modulating |
| Ritornello 2 | Tutti | New key (often V), partial |
| Solo episode 2 | Soloist(s) | Modulating |
| ... | Alternating | Various keys |
| Final ritornello | Tutti | Tonic (complete or near-complete) |

- Ritornello = recurring orchestral theme, often fragmented after first statement
- Solo episodes: virtuosic, may develop ritornello material or introduce new ideas

---

## Da Capo Aria (ABA)

| Section | Key | Description |
|---|---|---|
| A | Tonic, may modulate to V | Main text and melody; orchestral ritornello frames it |
| B | Contrasting key (relative minor/major, iv, etc.) | New text, shorter, simpler texture |
| A (da capo) | Tonic | Exact repeat with improvised ornamentation by singer |

Standard in Baroque opera and oratorio (Handel, Bach).

---

## Strophic Form

Same music repeated for each stanza/verse: `A A A A ...`
- Common in hymns, folk songs, simple Lieder
- **Modified strophic:** Small changes between strophes (Schubert)

---

## Through-Composed

No large-scale repetition; music evolves continuously with text.
- Common in dramatic Lieder (Schubert's "Erlkonig"), operatic scenes
- Each section has new or substantially transformed material

---

## Concerto Form (Classical)

### Typical 3-Movement Structure

| Movement | Tempo | Typical form |
|---|---|---|
| I | Fast (Allegro) | Sonata form with double exposition |
| II | Slow (Adagio/Andante) | Ternary, theme & variations, or sonata without development |
| III | Fast (Allegro/Presto) | Rondo or sonata-rondo |

### First Movement: Double Exposition

| Section | Description |
|---|---|
| Orchestral exposition | Tutti presents themes, stays mostly in tonic |
| Solo exposition | Soloist enters, restates themes; modulates to V as in standard sonata |
| Development | Shared between soloist and orchestra |
| Recapitulation | Both themes in tonic |
| Cadenza | Near end, on I64; soloist alone, virtuosic, improvised or composed |
| Orchestral coda | Tutti closes the movement after cadenza (signaled by trill on V) |

---

## Symphony Structure (Classical 4-Movement Plan)

| Movement | Tempo | Form | Key | Character |
|---|---|---|---|---|
| I | Fast (often with slow intro) | Sonata form | Tonic | Dramatic, weighty |
| II | Slow | Sonata, ternary, or theme & variations | Subdominant, dominant, or relative | Lyrical, expressive |
| III | Moderate (dance) | Minuet & trio (Haydn/Mozart) or Scherzo & trio (Beethoven+) | Tonic | Dance-like or humorous |
| IV | Fast | Sonata, rondo, or sonata-rondo | Tonic | Brilliant, conclusive |

**Romantic-era expansions:** 5 movements (Berlioz), cyclic thematic return across movements (Brahms, Franck), programmatic content, scherzo before slow movement or vice versa.
