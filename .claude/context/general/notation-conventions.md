# Notation Conventions

## Enharmonic Spelling by Key

| Principle | Rule | Example |
|---|---|---|
| Spell within key signature | Use the accidental form that fits the key | In Eb major: Ab (not G#) |
| Ascending = sharps | Chromatic ascending passages prefer sharps | C C# D D# E |
| Descending = flats | Chromatic descending passages prefer flats | E Eb D Db C |
| Preserve scale degrees | Each letter name should appear once per scale | D major scale: F# (not Gb) |
| Double sharps/flats | Use when key demands it to preserve letter-name logic | G# minor: F## (not G natural) |
| Diminished intervals | Spell to show the interval quality | dim7 chord on B: B D F Ab (not G#) |

**Common enharmonic pairs:** C#/Db, D#/Eb, F#/Gb, G#/Ab, A#/Bb. Choose based on harmonic context.

## Accidental Simplification Rules

| Rule | Detail |
|---|---|
| Courtesy accidentals | Restate a natural after an accidental in the same measure (or next measure) for clarity |
| Accidental scope | Applies only to the specific octave in which it appears (modern convention) |
| Tied notes | Accidental carries through the tie; no restatement needed |
| Key signature overrides | Accidentals from key signature apply to all octaves |
| Simplify when possible | Avoid double sharps/flats if a simpler enharmonic works without breaking spelling logic |

## Tie vs. Slur

| Notation | Connects | Meaning | Visual cue |
|---|---|---|---|
| Tie | Same pitch, same note | Sustain duration; do not re-attack | Curved line between noteheads of same pitch |
| Slur | Different pitches | Legato; smooth connection, one bow/breath | Curved line over/under a phrase of varying pitches |
| Phrase mark | Group of notes | Larger interpretive grouping | Long curved line spanning a phrase |

## Tempo Markings

| Marking | BPM range | Character |
|---|---|---|
| Grave | 20-40 | Very slow, solemn |
| Largo | 40-60 | Slow, broad |
| Larghetto | 60-66 | Somewhat slow |
| Adagio | 66-76 | Slow, at ease |
| Andante | 76-108 | Walking pace |
| Andantino | 80-108 | Slightly faster than andante (debated) |
| Moderato | 108-120 | Moderate |
| Allegretto | 112-120 | Moderately fast, lighter than allegro |
| Allegro | 120-156 | Fast, lively |
| Vivace | 156-176 | Lively, brisk |
| Presto | 176-200 | Very fast |
| Prestissimo | 200+ | As fast as possible |

### Tempo Modifiers

| Modifier | Meaning |
|---|---|
| molto | Very (molto allegro = very fast) |
| poco | A little (poco adagio = a little slow) |
| assai | Very/enough |
| non troppo | Not too much (allegro non troppo) |
| ma | But (andante ma non troppo) |
| piu | More (piu mosso = more motion) |
| meno | Less (meno mosso = less motion) |
| accelerando (accel.) | Gradually faster |
| ritardando (rit.) | Gradually slower |
| rallentando (rall.) | Gradually slower (synonym of rit.) |
| a tempo | Return to original tempo |
| rubato | Flexible tempo for expression |

## Articulation Marks

| Mark | Name | Effect | Symbol |
|---|---|---|---|
| . | Staccato | Short, detached (~50% of value) | Dot above/below note |
| - | Tenuto | Held full value, slight stress | Horizontal line above/below |
| > | Accent | Strong attack | > above/below note |
| ^ | Marcato | Strong, forceful accent | ^ above note |
| . under slur | Portato (mezzo-staccato) | Slightly separated within legato | Dots under a slur |
| v | Up-bow (strings) | Push stroke | V above note |
| n | Down-bow (strings) | Pull stroke | Pi-shape above note |
| tr | Trill | Rapid alternation with note above | tr above note, wavy line |
| ~ | Turn / mordent | Ornamental figure | Various symbols above note |
| fermata | Fermata | Hold beyond written value | Bird's eye above note |
| pizz. | Pizzicato | Pluck string (strings) | Text marking |
| arco | Arco | Return to bowing (strings) | Text marking |

## Rehearsal Mark Conventions

| Convention | Description | When to use |
|---|---|---|
| Letters | A, B, C... (boxed) | Standard orchestral parts |
| Numbers | 1, 2, 3... (boxed) | Alternative to letters |
| Measure numbers | Placed at start of each system + key structural points | Universally useful reference |
| Placement | At major structural boundaries (new sections, tempo changes) | Every 8-20 bars or at form divisions |
| Double barline | Placed at section boundaries | Key changes, tempo changes, major divisions |
| Final barline | Double barline with thick right line | End of piece only |
| Repeat signs | `||: ... :||` with dots | Repeated sections |
| Segno / Coda | Navigation markers for jumps | Dal segno, coda jumps |
