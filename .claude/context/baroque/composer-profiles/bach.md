# J.S. Bach (1685-1750) -- Composer Profile

## Overview

| Parameter         | Value                                              |
|-------------------|----------------------------------------------------|
| Full name         | Johann Sebastian Bach                              |
| Active period     | 1703-1750                                          |
| Primary locations | Arnstadt, Weimar, Cothen, Leipzig                  |

## Harmonic Language

### Core Characteristics

| Feature                  | Description                                        | Frequency |
|--------------------------|----------------------------------------------------|-----------|
| Circle-of-fifths seq.    | ii-V-I chains, often chromaticized                 | Very high |
| Secondary dominants       | V/V, V/vi, V/ii, V/IV all common                  | Very high |
| Chromatic passing tones   | Fills in leaps, decorates stepwise motion           | Very high |
| Neapolitan chord (bII6)  | Pre-dominant in minor, dramatic color               | Moderate  |
| Augmented 6th chords     | It+6, Fr+6, Ger+6 approaching dominant             | Moderate  |
| Diminished 7th chords    | Pivots, passing chords, intensifiers                | High      |
| Pedal points             | Tonic and dominant, esp. in codas/preludes          | High      |
| Mode mixture             | Borrowed chords from parallel major/minor           | Moderate  |
| Suspensions              | 4-3, 7-6, 9-8, chains of suspensions               | Very high |
| Deceptive cadences       | V-vi to extend phrases                              | Moderate  |
| Cross-relations          | Accepted between voices for chromatic color         | Moderate  |

### Typical Chord Progressions

```
Major: I - IV - viio/V - V - vi - ii - V7 - I
Minor: i - iv - VII - III - VI - iio - V - i
Sequence: I - IV - viio - iii - vi - ii - V - I (descending 5ths)
Chromatic: i - iio - bII6 - V - i (Neapolitan approach)
Chromatic: i - iv - Ger+6 - V - i (augmented 6th approach)
Lament: i - v6 - iv6 - III6 - iio6 - i6/4 - V - i (chromatic descent)
```

### Chorale Harmonization Principles

| Principle                      | Application                                       |
|--------------------------------|---------------------------------------------------|
| One chord per melody note min. | Often 2+ chords per note with passing harmonies   |
| Bass line melodic              | Independent, often stepwise or sequential         |
| Inner voices active            | Alto and tenor have melodic interest              |
| Passing tones on weak beats    | Extensive non-chord tones                         |
| Suspensions at cadences        | 4-3 standard at every cadence                     |
| Key variety                    | Modulate to related keys within short chorale     |
| Fermata = cadence              | Each fermata marks a phrase-ending cadence         |

## Melodic Style

### Core Characteristics

| Feature                  | Description                                         |
|--------------------------|-----------------------------------------------------|
| Fortspinnung             | Short motif spun out into long continuous lines      |
| Instrumental character   | Even vocal lines feel instrumental; wide leaps OK    |
| Motivic spinning         | Short motif developed by sequence, inversion, aug.   |
| Sequence-heavy           | Melodic sequences drive continuity (2-3 bar units)   |
| Wide range               | Uses full instrument range, often 2+ octaves         |
| Ornamental integration   | Turns, mordents, trills integral to melody line      |
| Chromatic inflection     | Chromatic neighbor tones, passing tones frequent      |
| Hidden polyphony         | Single-line melodies imply multiple voices           |
| Compound melody          | One line implies 2-3 independent voices              |

### Fortspinnung Construction

| Phase               | Description                       | Bars (typical) |
|---------------------|-----------------------------------|----------------|
| Vordersatz (head)   | Motif stated, establishes key     | 1-2            |
| Fortspinnung (spin) | Motif developed sequentially      | 2-6            |
| Epilog (cadence)    | Cadential arrival                 | 1-2            |

### Typical Intervals

| Interval        | Usage                               | Frequency |
|-----------------|-------------------------------------|-----------|
| Steps (2nds)    | Primary motion, scalewise runs      | Very high |
| 3rds            | Arpeggiation, skips within harmony  | High      |
| 4ths/5ths       | Subject heads, structural leaps     | Moderate  |
| 6ths            | Expressive leaps, especially minor 6th | Moderate |
| 7ths            | Diminished 7th for drama            | Low-mod   |
| Octave          | Structural, opening gestures        | Moderate  |

### ABC Example -- Fortspinnung Melody (D minor)

```abc
X:2

%% Epilog (cadential)

```

### Fugue Subject Characteristics

| Type            | Features                                    | Examples           |
|-----------------|---------------------------------------------|--------------------|
| Scalar          | Stepwise, often with one defining leap       | WTC I C major      |
| Arpeggiated     | Outlines chord, rhythmic profile matters     | WTC I C minor      |
| Chromatic        | Uses half-steps prominently                 | WTC I C# minor     |
| Dance-like      | Clear metric profile, often gigue-style      | WTC I F major      |
| Compact         | Short (1-2 bars), dense, highly malleable    | WTC II F minor     |
| Extended         | Long (4+ bars), complex, episodic feel      | Art of Fugue       |
| Declamatory      | Bold, dramatic leaps                        | St. Anne Fugue     |

## Counterpoint Techniques

| Technique              | Description                                | Frequency    |
|------------------------|--------------------------------------------|--------------|
| Imitation              | Voices enter successively with same material | Constant    |
| Invertible counterpoint| Voices swappable at octave, 10th, or 12th  | Very common  |
| Canon                  | Strict imitation at fixed interval/distance | Common       |
| Stretto                | Subject overlaps with itself               | Fugue climaxes|
| Augmentation           | Subject in longer note values              | Late entries  |
| Diminution             | Subject in shorter note values             | Developmental |
| Retrograde             | Subject backwards                          | Rare, learned |
| Mirror inversion       | Subject upside-down                        | Moderate      |
| Double/triple fugue    | Multiple subjects combined                 | Grand fugues  |
| Pedal + counterpoint   | Free voices over sustained bass            | Conclusions   |

## Rhythmic Characteristics

| Feature               | Description                                       |
|-----------------------|---------------------------------------------------|
| Motoric drive         | Constant motion in at least one voice              |
| Steady pulse          | Strong underlying pulse, rarely interrupted         |
| Rhythmic counterpoint | Different rhythmic layers in different voices       |
| Hemiola               | At cadences in triple meter                        |
| Lombard rhythm        | Short-long (Scotch snap) occasionally              |
| Dotted rhythms        | French overture style where appropriate             |

### Texture Principles

| Principle                   | Application                                      |
|-----------------------------|--------------------------------------------------|
| Independent voice leading   | Every part has melodic interest                   |
| Obbligato accompaniment     | Accompaniment is thematic, not just chordal       |
| Continuo omnipresent        | Bass + keyboard in virtually all ensemble works   |
| Doubling for color          | Oboe doubles violin in tutti, separates in solo   |
| Colla parte                 | Instruments double vocal lines in chorales        |
| Terraced dynamics           | Dynamic changes via adding/removing instruments   |

## Composition Parameters for AI Generation

| Parameter                 | Value / Range                                |
|---------------------------|----------------------------------------------|
| Harmonic rhythm (fast)    | 1-2 chords per beat (preludes, toccatas)     |
| Harmonic rhythm (normal)  | 1-2 chords per bar (fugues, dances)          |
| Harmonic rhythm (slow)    | 1 chord per bar (sarabandes, adagios)        |
| Voice independence        | HIGH -- each voice has own rhythm + contour   |
| Dissonance tolerance      | HIGH -- suspensions, passing tones, appoggiaturas |
| Chromaticism              | MODERATE-HIGH (~25% chromatic, ~75% diatonic) |
| Sequence frequency        | VERY HIGH -- primary developmental technique  |
| Modulation range          | MODERATE -- related keys, occasional remote   |
| Cadential weight          | HIGH -- clear cadences structure phrases       |
| Motivic density           | VERY HIGH -- everything derives from core motifs|
| Texture                   | Polyphonic primary, homophonic in chorales    |
| Dynamic contrast          | Terraced, not gradual                         |
| Continuous motion         | Avoid stopping; phrases elide                 |
| Counterpoint minimum      | At least 2 independent voices at all times    |
| Bass line quality         | Bass must be a singable, independent melody   |
