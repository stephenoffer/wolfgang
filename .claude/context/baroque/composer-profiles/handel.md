# G.F. Handel (1685-1759) -- Composer Profile

## Overview

| Parameter         | Value                                                  |
|-------------------|--------------------------------------------------------|
| Full name         | Georg Friedrich Handel                                 |
| Active period     | 1703-1759                                              |
| Primary locations | Halle, Hamburg, Italy, London                          |
| Style keywords    | vocal mastery, grand gestures, clear harmony, dramatic contrast, ceremonial power |

## Harmonic Language

### Core Characteristics

| Feature                  | Description                                        | Frequency |
|--------------------------|----------------------------------------------------|-----------|
| Strong functional harmony| I-IV-V-I backbone, clear phrase structure            | Very high |
| Dominant pedal points    | Extended V pedals building to resolution             | High      |
| Diatonic sequences       | Descending 5ths, ascending stepwise, mostly diatonic | High      |
| Secondary dominants      | V/V most common, V/vi for deceptive motion           | Moderate  |
| Chromatic passing tones  | Less frequent than Bach, used for text painting       | Low-mod   |
| Suspensions              | 4-3, 7-6, primarily at cadences                      | Moderate  |
| Deceptive cadences       | V-vi for dramatic extension                          | Moderate  |
| Mode mixture             | Picardy third at final cadences in minor             | High      |
| Hemiola cadence          | Metric shift 6/8 to 3/4 at cadences                  | High      |
| Neapolitan chord         | Occasional in minor, less than Bach                   | Low       |
| Augmented 6th chords     | Rare compared to Bach                                 | Low       |

### Typical Chord Progressions

```
Major: I - V - I - IV - V - I
Major (richer): I - vi - IV - ii - V - I
Minor: i - iv - V - i - VII - III - V - i
Sequence: I - IV - viio - iii - vi - ii - V - I (descending 5ths, diatonic)
Dramatic: i - iv - V - VI (deceptive) - iv - V - i
Extended: I -> V (phrase 1) -> I (phrase 2) -- simple binary organization
```

## Melodic Style

### Core Characteristics

| Feature                  | Description                                         |
|--------------------------|-----------------------------------------------------|
| Vocal orientation        | Melodies sing naturally, even in instrumental works  |
| Broad phrases            | Long, arching phrases (4-8 bars typical)             |
| Memorable tunes          | Simple, immediate hook quality                       |
| Diatonic emphasis        | Mostly stepwise with strategic leaps                 |
| Sequence as extension    | Sequences lengthen phrases, less obsessive than Bach |
| Text painting            | Melodic shape mirrors meaning of text                |
| Ornamented da capo       | Singers expected to ornament A section repeat         |
| Repeated notes           | Declamatory effect in vocal writing                   |
| Syllabic clarity         | Melodies designed around text, even in instr. works  |
| Triadic motion           | Frequent arpeggiated, chord-outlining melodies       |

### Typical Intervals

| Interval        | Usage                               | Frequency |
|-----------------|-------------------------------------|-----------|
| Steps (2nds)    | Primary motion, lyrical flow        | Very high |
| 3rds            | Triadic motion, warm character      | High      |
| 4ths            | Upward for strength, opening leaps  | Moderate  |
| 5ths            | Heroic leaps, fanfare figures       | Moderate  |
| 6ths            | Expressive, yearning quality        | Moderate  |
| Octave          | Dramatic emphasis, power            | Moderate  |
| 7ths+           | Rare, used for extreme drama        | Low       |

## Rhythmic Characteristics

| Feature               | Description                                         |
|-----------------------|-----------------------------------------------------|
| Strong metric clarity | Clear downbeats, unambiguous meter                   |
| Dance rhythms         | Suite movements, even in non-dance contexts          |
| Dotted French style   | Overture style, majestic movements                   |
| Hemiola               | Very characteristic at cadences in triple meter      |
| Motor rhythm          | Less constant than Bach, more dramatic contrast      |
| Silence as drama      | Strategic rests (General Pauses) for theatrical effect|
| Unison attacks        | Powerful chordal/unison openings                     |

### Hemiola Pattern (at Cadences in Triple Meter)

```abc
X:5
T:Handel Hemiola
M:3/4
L:1/4
K:G
|d2 B|c2 A|
%% Hemiola: next two bars regroup as 3/2
B G A|B3|
%% BGA = group 1, B-- = group 2 (two dotted-half beats across barline)
```

## Orchestration

### Instrument Usage

| Instrument       | Role                           | Range (ABC)        | Handel Specifics               |
|------------------|--------------------------------|--------------------|--------------------------------|
| Violin I         | Lead melodic                   | G, - d'''          | Brilliant but less virtuosic   |
| Violin II        | Harmonic support, doubling     | G, - a''           | Often doubles V1 in 3rds/6ths |

| Cello/Bass       | Bass line                      | C,, - c'           | Strong, simple bass lines      |
| Oboe I/II        | Double violins in tutti        | c - d'''           | Idiomatic writing              |
| Bassoon          | Doubles bass, occasional solo  | B,, - e'           | Continuo reinforcement         |
| Trumpet I/II     | Festive, fanfare               | c' - d'''          | D major works primarily        |
| Timpani          | With trumpets                  | D, and A,          | Standard pairing               |
| Horn I/II        | Hunting, pastoral, festive     | c - c'''           | Water Music, concerti          |
| Flute (traverso) | Gentle, pastoral color         | d' - a'''          | Solo arias, pastoral scenes    |
| Recorder         | Pastoral, supernatural         | f' - g'''          | "Bird" scenes, magic           |

| Harpsichord      | Continuo                       | F,, - f'''         | Standard continuo role         |
| Harp             | Special color                  | C, - g'''          | Rare, specific effects         |

### Choral Writing Textures

| Texture          | Usage                                | Character           |
|------------------|--------------------------------------|---------------------|
| Homophonic block | Declarative moments, "Hallelujah"    | Power, majesty      |
| Fugal            | Choruses, "And with His stripes"     | Learned, energetic   |
| Antiphonal       | Double choir effects                 | Spatial drama        |
| Unison/octave    | Emphasis, text painting              | Urgency, unanimity   |
| Soloists + choir | Alternation for variety              | Dramatic contrast    |

### Texture Principles

| Principle                    | Application                                     |
|------------------------------|--------------------------------------------------|
| Clarity over complexity      | Fewer independent lines than Bach                 |
| Dramatic contrast            | Thin/thick texture changes for effect             |
| Doubling for weight          | Instruments double vocal/string lines in tutti    |
| Terraced dynamics            | Dynamic change via orchestration change            |
| Tutti vs solo contrast       | Concertino/ripieno, soloist/chorus alternation     |
| Theatrical silence           | General pauses for dramatic punctuation            |

### Oratorio Structure (Messiah Model)

| Component   | Handel's Approach                                    |
|-------------|------------------------------------------------------|
| Overture    | French overture (slow-fast)                          |
| Recitative  | Secco for narration; accompagnato for drama          |
| Aria        | Da capo; virtuosic, expressive                       |
| Chorus      | Structural pillars; grand, varied textures           |
| Pacing      | Builds to choral climaxes                            |
| English text| Clear text-setting, natural word stress              |

## Comparison: Handel vs Bach

| Parameter             | Handel                              | Bach                              |
|-----------------------|-------------------------------------|-----------------------------------|
| Primary orientation   | Vocal/theatrical                    | Instrumental/intellectual         |
| Harmonic complexity   | Clear, functional                   | Rich, chromatic                   |
| Contrapuntal density  | Moderate (when used, effective)     | Very high (constant)              |
| Melodic character     | Singable, memorable                 | Instrumental, motivic             |
| Rhythmic approach     | Metric clarity, dramatic pauses     | Motoric drive, constant motion    |
| Texture               | Homophonic primary, fugal secondary | Polyphonic primary                |
| Dynamic contrasts     | Theatrical, sudden                  | Terraced, architectural           |
| Chromaticism          | Moderate, text-driven               | High, structurally integrated     |
| Audience appeal       | Immediate, emotional                | Intellectual, cumulative          |
