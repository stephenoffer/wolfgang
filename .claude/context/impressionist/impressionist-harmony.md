# Impressionist Harmony Reference

## Core Principle
Impressionist harmony treats chords as autonomous color events rather than functional steps in a progression. Dissonance is emancipated; resolution is optional. Atmosphere replaces argument.

## Foundational Scales

| Scale | Pitches (from C) | Interval Pattern | Character |
|-------|------------------|-----------------|-----------|
| Whole-tone | C D E F# G# A# | 2-2-2-2-2-2 | Floating, dreamlike, no gravity |
| Major pentatonic | C D E G A | 2-2-3-2-3 | Open, pastoral, Eastern |
| Minor pentatonic | C Eb F G Bb | 3-2-2-3-2 | Darker, folk-adjacent |
| Dorian | C D Eb F G A Bb | 2-1-2-2-2-1-2 | Archaic, warm |
| Lydian | C D E F# G A B | 2-2-2-1-2-2-1 | Bright, suspended |
| Mixolydian | C D E F G A Bb | 2-2-1-2-2-1-2 | Relaxed, pastoral |
| Phrygian | C Db Eb F G Ab Bb | 1-2-2-2-1-2-2 | Spanish, dark |
| Octatonic (H-W) | C Db Eb E F# G A Bb | 1-2-1-2-1-2-1-2 | Symmetrical, ambiguous |
| Acoustic scale | C D E F# G A Bb | 2-2-2-1-2-1-2 | Overtone-derived, luminous |

## Parallel Chord Motion (Planing)

| Type | Description | Example |
|------|-------------|---------|
| Diatonic planing | Chords move stepwise within a scale | Cmaj - Dm - Em (all white keys) |
| Chromatic planing | Identical chord quality moves by semitone | Cmaj - Dbmaj - Dmaj |
| Whole-tone planing | Chords move by whole step | Cmaj - Dmaj - Emaj |
| Quartal planing | Stacked 4ths move in parallel | (C-F-Bb) - (D-G-C) - (E-A-D) |
| Mixed planing | Alternating diatonic and chromatic | Free color mixing |

### Parallel Triads Example
```abc
X:1
T:Diatonic Planing
M:4/4
K:C
| [CEG]2 [DFA]2 | [EGB]2 [FAc]2 | [GBd]2 [FAc]2 | [CEG]4 |
```

## Extended Chords as Color

| Chord Type | Construction | Color Quality | Usage |
|-----------|-------------|---------------|-------|
| Major 7th | 1-3-5-7 | Warm, luminous | Resting sonority |
| Major 9th | 1-3-5-7-9 | Lush, spacious | Primary color chord |
| Minor 9th | 1-b3-5-b7-9 | Dark warmth | Melancholy color |
| 11th chord | 1-3-5-7-9-11 | Open, quartal quality | Suspended atmosphere |
| 13th chord | 1-3-5-7-9-11-13 | Maximum richness | Climactic color |
| Added 6th | 1-3-5-6 | Sweet, nostalgic | Debussy signature |
| Added 9th (no 7th) | 1-3-5-9 | Clean sparkle | Lighter texture |
| Augmented triad | 1-3-#5 | Whole-tone, floating | Transition, mystery |

## Non-Functional Harmony Techniques

| Technique | Description | Effect |
|-----------|-------------|--------|
| Color chord succession | Chords chosen for timbre, not function | Floating, non-directional |
| Common-tone linking | Adjacent chords share 1-2 tones | Smooth, connected |
| Bass pedal with moving chords | Upper voices shift over static bass | Grounded yet colorful |
| Chromatic mediant | Third-related chords (C to E, C to Ab) | Sudden color shift |
| Modal interchange | Borrowing from parallel modes | Expanded palette |
| Tritone substitution | Replace V with bII | Smooth chromatic motion |
| Oscillation | Two chords alternating | Shimmering, static |
| Sideslip | Approach target chord from semitone above/below | Elegant slide |

### Non-Functional Color Progression
```
Cmaj9 -> Ebmaj7 -> Gbmaj9 -> Amaj7 -> Cmaj9
(major 3rd cycle — no functional relationship, pure color)
```

## Whole-Tone Harmony

| Element | Detail |
|---------|--------|
| Only 2 whole-tone sets | WT0: C-D-E-F#-G#-A# / WT1: Db-Eb-F-G-A-B |
| Chords available | Augmented triads, dominant 7#5 |
| No half steps | Creates weightless, directionless quality |
| No perfect 5ths | Removes tonal anchoring |
| Exit strategy | Step outside to any diatonic chord |

```abc
X:2
T:Whole-Tone Passage
M:4/4
K:C
| C2 D2 | E2 ^F2 | ^G2 ^A2 | c4 |
```

## Pentatonic Harmony

| Application | Technique |
|-------------|-----------|
| Melody | Pentatonic tune over rich harmony |
| Chord construction | Stack pentatonic notes (e.g., C-G-D-A) |
| Ostinato | Repeating pentatonic figure as accompaniment |
| Layered pentatonics | Different pentatonic sets in different voices |
| Gamelan effect | Pentatonic layering at different speeds |

```abc
X:3
T:Pentatonic Ostinato
M:4/4
K:C
| CDEG | AEGC | CDEG | AEGC |
```

## Modal Mixture Techniques

| Mixture Type | Example | Effect |
|-------------|---------|--------|
| Major/minor oscillation | C major chord -> C minor chord | Bittersweet shimmer |
| Dorian in major context | Use of A natural in C minor | Warm darkness |
| Lydian coloring | F# in C major context | Ethereal brightness |
| Borrowed bVI | Ab major in C major | Rich, dark warmth |
| Borrowed bII | Db major in C major | Neapolitan color |
| Parallel mode chords | Any chord from parallel minor/major | Free palette expansion |

## Unresolved Dissonance

| Principle | Application |
|-----------|-------------|
| Dominant 7ths unresolved | V7 used as stable sonority, no resolution to I |
| Suspended tones held | Sus4, sus2 never resolve — they ARE the chord |
| Added-tone stability | 9ths, 11ths, 13ths are consonances, not dissonances |
| Appoggiatura chords | "Wrong" notes become the main harmony |
| Cluster adjacency | Seconds within chords accepted as color |
| Tritone as color | Tritone interval is atmospheric, not demanding resolution |

## Added-Note Chords

| Chord | Notes | Voice-Leading Tip |
|-------|-------|-------------------|
| C add9 | C-E-G-D | Place D above G for clarity |
| C add6 | C-E-G-A | A on top for sweetness |
| C add#11 | C-E-G-F# | F# creates Lydian sparkle |
| Cm add9 | C-Eb-G-D | D creates Dorian warmth |
| C add2 (close) | C-D-E-G | Cluster effect in lower register |

## Bitonality Hints

| Technique | Example | Effect |
|-----------|---------|--------|
| Superimposed triads | C major + F# major | Shimmering tension |
| Melody in one key, harmony in another | Melody in G, chords in Db | Dreamlike disconnect |
| Left hand / right hand split | LH: Bb major, RH: E major | Piano color effect |
| Pedal in foreign key | C pedal under Gb major chords | Grounded dissonance |

## Characteristic Progressions by Composer

### Debussy
```
Cmaj9 -> Dbmaj9 (semitone slide)
C5 -> Db5 -> D5 (parallel 5ths, medieval)
Pentatonic cluster -> Whole-tone chord -> Pentatonic
Am7 -> Dm7 -> Gm7 -> Cm7 (parallel minor 7ths)
```

### Ravel
```
Cmaj7 -> Am9 -> Fmaj7 -> Dm9 (functional but colorful)
Gmaj7#11 -> C#maj7#11 (tritone planing)
I9 -> IV9 -> bVII9 -> bIII9 (circle in 9th chords)
```

## Harmonic Rhythm

| Context | Typical Rhythm | Effect |
|---------|---------------|--------|
| Atmospheric opening | Very slow (1 chord per 2-4 bars) | Spacious, meditative |
| Melodic passage | Moderate (1-2 per bar) | Supportive, flowing |
| Climactic build | Accelerating changes | Growing intensity |
| Cadential moment | Sudden stop or deceleration | Arrival by cessation |
| Ostinato passage | Static (1 chord sustained) | Trance-like |

## Voice Leading Conventions

| Convention | Detail |
|-----------|--------|
| Parallel motion | Acceptable and characteristic (breaks common practice rules) |
| Common tones | Prioritize shared notes between chords |
| Stepwise outer voices | Smooth soprano and bass lines preferred |
| Close spacing | Upper voices clustered for warmth |
| Wide spacing | Open voicing for spacious atmosphere |
| Bass independence | Bass may sustain pedal while upper voices move freely |

## Cadential Patterns

| Cadence Type | Progression | Effect |
|-------------|-------------|--------|
| Plagal drift | IV(maj7) -> I(maj7) | Soft, non-conclusive |
| Whole-tone dissolution | Whole-tone chord -> silence | Evaporating |
| Pentatonic settling | Activity reduces to pentatonic notes | Natural rest |
| Pedal resolution | Moving chords settle onto pedal note | Grounded arrival |
| Fadeout | Diminuendo to niente on any chord | No formal close |
| Modal cadence | bVII -> I or bII -> I | Archaic, non-dominant |
| Sideslip cadence | Db major -> C major (semitone above) | Elegant arrival |
