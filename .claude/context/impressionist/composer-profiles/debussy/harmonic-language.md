# Claude Debussy — Harmonic Language

Debussy's harmony is not a system but a palette. Chords are colors, not functions. A dominant seventh need not resolve; it can simply exist, warm and complete, before giving way to an unrelated sonority. The entire apparatus of tension-and-resolution that powered Western music from Bach to Wagner is set aside — not angrily, but with a shrug. What replaces it is sensation: the sound of water, the weight of silence, the shimmer of light through leaves.

For shared Impressionist harmonic vocabulary, see [impressionist-harmony.md](../../impressionist-harmony.md). This file covers what is distinctly Debussyan.

## Core Harmonic Character

| Feature | Description | Artistic Function |
|---------|-------------|-------------------|
| Non-functional chord succession | Chords chosen for color, not for tonal direction | Music exists in states, not progressions — the listener floats |
| Parallel chord movement (planing) | Entire chord shapes slide in parallel motion | Voices move together like light shifting across a surface |
| Whole-tone scale as harmonic field | C-D-E-F#-G#-A# — no half steps, no gravity | Dreamlike ambiguity; the ear cannot find "home" |
| Pentatonic as default melody/harmony | Five-note scales without semitone tension | Pastoral warmth; Eastern inflection; removal of tonal pull |
| Added-note chords as consonances | 9ths, 11ths, 13ths are stable, not requiring resolution | Richer sonorities treated as resting places |
| Pedal-point harmony | Static bass with moving upper voices | Grounded shimmer — movement without progression |
| Modal rather than tonal thinking | Dorian, Lydian, Phrygian, Mixolydian | Archaic, folk, or exotic color without chromatic complexity |

## The Three Harmonic Worlds

Debussy operates in three overlapping harmonic spaces. A single piece may shift between all three.

| World | Scales Used | Chord Types | Character | Example Works |
|-------|-------------|-------------|-----------|--------------|
| Pentatonic | C-D-E-G-A (major) or C-Eb-F-G-Bb (minor) | Added 6ths, open 5ths, quartal stacks | Pastoral, Eastern, warm, open | Pagodes, La fille aux cheveux de lin |
| Whole-tone | C-D-E-F#-G#-A# | Augmented triads, dom7#5 | Floating, dreamlike, disoriented | Voiles (first section), La Mer fog passages |
| Modal/Chromatic | Church modes, chromatic inflections | Parallel triads, parallel 7ths, unrelated juxtapositions | Archaic, mysterious, sensuous | La cathédrale engloutie, Pelléas |

## Parallel Chord Movement — The Signature Device

Classical voice-leading forbids parallel fifths and octaves. Debussy made parallel EVERYTHING into his primary technique. The chord is not a vertical harmony to be resolved — it is a timbral object that slides.

| Planing Type | Chord Quality Preserved | Motion Pattern | Effect |
|-------------|------------------------|----------------|--------|
| Whole-tone planing | Major triads, dom7, maj7 | Up/down by whole step | Floating, no tonal center |
| Chromatic planing | Any chord quality | Up/down by semitone | Shimmering chromatic wash |
| Diatonic planing | Quality changes with scale | Stepwise within a mode | Modal, archaic |
| Quartal planing | Stacked perfect 4ths | Any interval | Open, spacious, modern |
| Mixed planing | Free | Alternating step sizes | Unpredictable color shifts |

```abc
X:1
T:Debussy — Parallel Major Triads (Chromatic Planing)
M:4/4
L:1/4
K:C
%% Four major triads sliding down by semitone — same voicing, different root
[CEG] [B,^D^F] [_B,DF] [A,^CE] | [CEG]4 |
%% Classical "error" elevated to primary language. No resolution. The slide IS the music.
```

## Whole-Tone Harmony

Only two whole-tone collections exist. Debussy uses them for passages of ambiguity, unreality, or the uncanny — never for entire pieces.

| Property | Detail |
|----------|--------|
| WT-0 | C - D - E - F# - G# - A# |
| WT-1 | Db - Eb - F - G - A - B |
| Available triads | Augmented only (C-E-G#, D-F#-A#, etc.) |
| Available 7ths | Dominant 7th #5 (C-E-G#-Bb) |
| No perfect 5ths | Cannot anchor tonally |
| No half steps | No leading-tone pull |
| Exit strategy | Step outside to any diatonic chord — the "awakening" |

```abc
X:2
T:Debussy — Whole-Tone Passage (Voiles character)
M:4/4
L:1/8
K:C
%% All pitches from WT-0: C D E F# G# A#
C2D2 E2^F2 | ^G2^A2 ^G2E2 | D2C2 D2E2 | ^F4 z4 |
%% No note pulls toward another. The ear floats. Exit to a pentatonic chord = awakening.
```

## Pentatonic Harmony

| Application | Technique | Example |
|-------------|-----------|---------|
| Melody over rich bass | Pentatonic tune (C-D-E-G-A) above chromatically-shifting bass | La fille aux cheveux de lin |
| Quartal stacking | Build chords from pentatonic: C-G-D-A = stacked 5ths | Pagodes, gamelan-influenced passages |
| Layered pentatonics | Different pentatonic sets in RH and LH | Creates gentle bitonality without harshness |
| Ostinato | Repeating pentatonic figure as shimmering accompaniment | Pagodes bell-patterns |
| Cadential settling | Activity reduces to bare pentatonic notes | Natural rest without dominant-tonic closure |

## Non-Functional Chord Successions

| Technique | How It Works | Emotional Effect |
|-----------|-------------|-----------------|
| Tritone juxtaposition | Chords a tritone apart placed side by side (Bbmaj7 → Emaj7) | Sudden color shift — like walking from one room into different light |
| Chromatic mediant | Third-related chords (Cmaj → Emaj, Cmaj → Abmaj) | Rich, unexpected warmth or coolness |
| Common-tone pivot | Adjacent chords share 1-2 notes; other voices move freely | Smooth connection between unrelated harmonies |
| Oscillation | Two chords alternate repeatedly | Shimmering, static — light on water |
| Sideslip | Approach target chord from semitone above or below | Elegant arrival without dominant preparation |
| Pedal + color | Bass sustains while upper chords change freely above | Grounded freedom — the bass anchors; everything else floats |

```abc
X:3
T:Debussy — Non-Functional Succession (Oscillating Color)
M:6/8
L:1/8
K:C
%% Two unrelated chords alternate — Cmaj7 and Gbmaj7 — tritone apart
[CEGBd]3 [_G_Bd_f_a]3 | [CEGBd]3 [_G_Bd_f_a]3 |
%% No resolution. No progression. Two colors in alternation — light on moving water.
```

## Added-Note Chords

| Chord | Notes | Debussy's Usage |
|-------|-------|-----------------|
| C add6 | C-E-G-A | Sweet, nostalgic — his most characteristic sonority |
| C add9 | C-E-G-D | Spacious, open — pentatonic implications |
| Cmaj7 | C-E-G-B | Luminous resting sonority — NOT a dominant function |
| C9 (no resolution) | C-E-G-Bb-D | Warm dominant color used as stable chord |
| C add#11 | C-E-G-F# | Lydian sparkle — bright, floating |
| Quartal: C-F-Bb | Stacked 4ths | Open, spacious, modern — gamelan-adjacent |

## Cadential Behavior

Debussy does not cadence in the Classical sense. Phrases end by:

| Ending Type | Technique | Character |
|------------|-----------|-----------|
| Fadeout | Diminuendo to niente on any chord | Evaporation — the sound dissolves |
| Pentatonic settling | Texture thins to bare pentatonic notes | Natural rest without closure |
| Pedal arrival | Moving chords settle onto a sustained bass | Grounding — but not resolution |
| Modal cadence | bVII → I or bII → I (no dominant) | Archaic, non-tonal closure |
| Silence | Music simply stops — a rest IS the cadence | Mallarmé's white space |
| Whole-tone exit | Step from whole-tone to diatonic | Awakening — gravity returns |
