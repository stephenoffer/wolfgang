# Debussy Composer Profile

## Quick ID
| Attribute | Value |
|-----------|-------|
| Full name | Claude Debussy (1862-1918) |
| Nationality | French |
| Period | Impressionist |
| Key works | Prelude a l'apres-midi d'un faune, La Mer, Preludes (Books I & II), Pelleas et Melisande, String Quartet, Images |
| Signature traits | Whole-tone scale, pentatonic melody, parallel chords, arabesque lines, gamelan influence |

## Harmonic Language

| Technique | Description | Frequency |
|-----------|-------------|-----------|
| Whole-tone chords | Augmented triads, dom7#5 | Signature |
| Parallel triads | Root-position triads moving stepwise | Signature |
| Parallel 7ths/9ths | Extended chords moving in parallel | Very frequent |
| Pentatonic harmony | Chords built from pentatonic set | Frequent |
| Unresolved dominants | V7 as color, not function | Constant |
| Added 6th chords | Maj triad + 6th as stable sonority | Characteristic |
| Modal cadences | bVII-I, bII-I replacing V-I | Frequent |
| Pedal-based harmony | Chords shift over sustained bass | Very frequent |
| Tritone relationships | Keys a tritone apart juxtaposed | Moderate |
| Quartal voicings | Stacked 4ths, open sound | Moderate |

## Melodic Style

| Feature | Description |
|---------|-------------|
| Arabesque contour | Sinuous, curving lines with turns and ornaments |
| Pentatonic themes | 5-note scale melodies, often in flute or oboe |
| Narrow range | Many melodies span a 5th or 6th |
| Modal inflection | Dorian, Lydian, Phrygian coloring |
| Fragmented phrases | Short motifs rather than long melodies |
| Rhythmic freedom | Flexible rhythm, rubato feel, triplet groups |
| Silence as punctuation | Rests within phrases, breathing |

## Gamelan Influence

| Element | Debussy Translation |
|---------|-------------------|
| Layered ostinatos | Multiple repeating patterns at different speeds |
| Pentatonic pitch set | Melody and harmony from same 5 notes |
| Metallic resonance | Harp, celesta, piano overtones |
| No functional harmony | Chords as color, not progression |
| Stratified texture | Independent layers, not counterpoint |
| Gong-cycle | Low bell-tone marks formal points |

### Gamelan-Inspired Texture
```
Layer 1 (fast):    Celesta - pentatonic arpeggios, continuous
Layer 2 (medium):  Flute - pentatonic melody, moderate
Layer 3 (slow):    Harp - bass note every 2 bars
Layer 4 (pedal):   Low strings - sustained drone
```

## Piano Writing

| Technique | Effect |
|-----------|--------|
| Sustained pedal washes | Overtone blending |
| Parallel chords in both hands | Full, organ-like color |

| Single melody over arpeggiated LH | Intimate song |

## Orchestration Preferences

| Feature | Detail |
|---------|--------|
| Flute | Primary melodic voice; low register for warmth |
| Oboe/English horn | Pastoral solo, melancholy |
| Clarinet | Warm middle-ground, lyric |
| Harp (2) | Essential; glissandi, arpeggios, harmonics |
| Divided strings | Tremolo, harmonics, sul tasto for shimmer |
| Horns | Muted, sustained, distant |
| Brass (general) | Minimal, understated |
| Celesta | Sparkle doublings |
| Timpani | Rare, soft rolls only |
| Antique cymbals | Pitched, bell-like accents |

## Formal Approach

| Principle | Application |
|-----------|-------------|
| Free sectional | Sections defined by color, not cadence |
| ABA' with transformation | Return is always changed |
| Through-composed | Forward motion with motif recall |
| No sonata development | Never fragments/recombines themes |
| Proportional balance | Golden ratio often approximated |
| Fadeout endings | Most pieces dissolve rather than conclude |

## Texture Types

| Texture | Scoring | Use |
|---------|---------|-----|
| Solo + shimmer | Single wind over tremolo strings | Intimate statement |
| Layered pedal | 4-5 layers at different registers | Atmospheric wash |
| Pointillist | Short notes scattered across instruments | Dance, sparkle |
| Unison melody | Multiple instruments on one line | Rare climactic statement |
| Harp + wind duet | Arpeggiated harp with wind melody | Pastoral |

## Key Progressions (Debussy Fingerprints)

```
Parallel motion:      Cmaj -> Dbmaj -> Dmaj -> Ebmaj (chromatic planing)
Pentatonic drift:     C-D-E-G-A notes as source for all chords
Whole-tone cloud:     C aug -> D aug -> E aug (whole-tone triads)
Modal cadence:        Bbmaj -> Cmaj (bVII -> I, no dominant)
Tritone shift:        C major area -> F# major area
Common-tone link:     Cmaj7 (E as common tone) -> Amaj7
Color oscillation:    Dm9 <-> Ebmaj9 (semitone shimmer)
```

## Rhythmic Characteristics

| Feature | Detail |
|---------|--------|
| Flexible meter | Frequent meter changes (3/4, 4/4, 5/4) |
| Triplet figures | Constant; creates flowing quality |
| Avoids strong downbeats | Syncopation, anacrusis, tied notes |
| Rubato feel | Even metered music sounds free |
| Ostinato independence | Repeating figure continues through changes |
| Cross-rhythms | 3 against 2, 4 against 3 |

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key/mode | Pentatonic, whole-tone, Dorian, Lydian; avoid plain major/minor |
| Tempo | Modere, Lent, Anime; always flexible |
| Melody | Arabesque, pentatonic, narrow range, fragmented |
| Harmony | Non-functional; parallel motion, color chords |
| Texture | Layered, transparent, shimmer-based |
| Dynamics | pp-mf default; f only at brief climaxes |
| Orchestration | Winds lead, strings shimmer, brass minimal |
| Form | Free sectional or ABA' with transformation |
| Endings | Dissolve, fade, morendo |
| Avoid | Strong cadences, loud brass, thick textures, literal repetition |
| Emphasize | Color, atmosphere, floating quality, timbral beauty |
