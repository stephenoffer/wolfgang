# Satie Composer Profile

## Quick ID
| Attribute | Value |
|-----------|-------|
| Full name | Erik Satie (1866-1925) |
| Nationality | French |
| Period | Proto-Impressionist / Proto-Minimalist |
| Key works | Gymnopedies, Gnossiennes, Pieces froides, Parade, Socrate, Vexations |
| Signature traits | Simplicity, modal harmony, furniture music concept, static repetition |

## Harmonic Language

| Technique | Description | Frequency |
|-----------|-------------|-----------|
| Modal harmony | Church modes, especially Dorian and Mixolydian | Constant |
| Unresolved 7ths/9ths | Extended chords as stable, floating sonorities | Signature |
| Parallel motion | Triads and 7ths moving in parallel | Frequent |
| Static harmony | Same chord or oscillation sustained | Characteristic |
| No dominant function | V-I cadences deliberately avoided | Constant |
| Open voicings | Wide spacing, sparse notes | Signature |
| Pedal bass | Single bass note under shifting upper chords | Frequent |

## Melodic Style

| Feature | Description |
|---------|-------------|
| Simple, unadorned | Few notes, no virtuosity |
| Modal scales | Avoid leading tone; no chromatic tension |
| Repetitive | Phrases repeat with minimal variation |
| Narrow range | Often within a 6th |
| Slow, deliberate | Quarter and half notes predominate |
| No development | Melody stated, not transformed |
| Speech-like phrasing | Short phrases, natural breathing |

## Gymnopedie Style Template

| Element | Specification |
|---------|--------------|
| Tempo | Lent et douloureux (slow and sorrowful) |
| Meter | 3/4 |
| LH pattern | Bass note (beat 1) + mid-register chord (beats 2-3) |
| RH | Simple modal melody, mostly quarter/half notes |
| Dynamics | pp throughout |
| Harmony | Major 7th and minor 7th chords, no resolution |
| Texture | 3-layer: bass, chord, melody |
| Length | ~3 minutes, minimal contrast |

## Furniture Music (Musique d'Ameublement)

| Principle | Description |
|-----------|-------------|
| Concept | Music as background, not demanding attention |
| Repetition | Short phrases loop without development |
| Dynamics | Constant, low volume |
| Harmony | Static, non-progressive |
| Form | No formal structure; continuous loop |
| Historical impact | Precursor to ambient music, minimalism |

## Gnossienne Style

| Element | Specification |
|---------|--------------|
| Meter | Free (no bar lines in original) |
| Mode | Usually Aeolian or Dorian |
| Texture | Melody + simple LH accompaniment |
| Character | Mysterious, archaic, exotic |
| Text annotations | Unusual verbal directions ("with astonishment") |
| Rhythm | Flexible, speech-like |

## Formal Approach

| Principle | Application |
|-----------|-------------|
| Extreme simplicity | No development, no complex form |
| Strophic repetition | Verse-like structure, minimal variation |
| AAB or ABB | Simple section arrangement |
| Anti-Romantic | Deliberately avoids emotional arc |
| Brevity | Many pieces under 3 minutes |
| No transitions | Sections juxtaposed without linkage |

## Orchestration (When Orchestrated)

| Feature | Detail |
|---------|--------|
| Piano primary | Most works for solo piano |
| Spare orchestration | Parade: unusual instruments (typewriter, siren) |
| Socrate style | Voice + small orchestra, extreme simplicity |
| No doubling | Each instrument independent |
| Found sounds | Parade introduces noise as music |

## Key Progressions (Satie Fingerprints)

```
Gymnopedie:     Dmaj7 -> Gmaj7 -> Dmaj7 -> Amaj7 (floating, no cadence)
Gnossienne:     Dm -> Gm -> Am -> Dm (modal circle)
Static:         Cmaj7 -> Cmaj7 -> Cmaj7 (literally unchanged)
Oscillation:    Dm7 <-> Em7 (two-chord loop)
```

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key/mode | Dorian, Aeolian, Mixolydian; avoid conventional major/minor |
| Tempo | Slow; Lent, Grave, Modere at most |
| Melody | Simple, modal, narrow range, repetitive |
| Harmony | Static or slow-moving; unresolved extended chords |
| Texture | Sparse; 2-3 layers maximum |
| Dynamics | pp-p; no dramatic contrasts |
| Form | Strophic or AAB; very short sections |
| Rhythm | Simple; quarter/half notes, occasional triplet |
| Avoid | Complexity, development, virtuosity, loudness, thick texture |
| Emphasize | Stillness, repetition, modal color, deliberate simplicity |
