# Gabriel Faure — Orchestration

Faure is not an orchestrator in the Ravel or Debussy sense. His natural medium is the piano, the voice, and the string quartet — chamber textures where every line is transparent and every voice sings. When he writes for orchestra (Pelleas et Melisande, Requiem, Masques et Bergamasques), the scoring is deliberately restrained: small forces, muted colors, no display. The Requiem famously omits most of the brass, all of the woodwinds in early versions, and the entire Dies Irae sequence. Faure's orchestration is the sound of someone who does not need to fill the room.

## Instrumental Forces

| Category | Faure's Practice | Contrast |
|----------|-----------------|----------|
| Primary instruments | Piano, voice, strings | Debussy: orchestra, piano equally |
| Orchestra size | Small; often chamber orchestra | Strauss/Mahler: massive forces |
| Texture layers | 2-3: melody + accompaniment (+ bass line) | Ravel: 5-6 independent layers |
| Doublings | Rare — each part independent | Brahms: systematic doublings |
| Brass | Minimal or absent; horns preferred over trumpets | Wagner: full brass section as primary color |
| Percussion | Timpani only, or none | Standard Romantic: timpani + extras |
| Dynamic ceiling | mf as normal maximum; f rare; ff almost never | Full Romantic range expected |

## Piano Writing

The piano is Faure's primary instrument. His piano writing is always idiomatic — the hand fits the keyboard naturally.

| Texture | Description | Example Works |
|---------|-------------|---------------|
| Arpeggiated accompaniment | Flowing broken chords in LH, 6/8 or 9/8, under melody in RH | Nocturnes, Barcarolles |
| Triplet carpet | Continuous triplet eighths creating rhythmic haze | Nocturne No.6, Ballade |
| Chordal song accompaniment | Simple block or broken chords supporting vocal melody | Early melodies |
| Late sparse texture | Bare two-voice writing, widely spaced, few chords | Nocturne No.13, late Barcarolles |
| Contrapuntal piano | Two or three independent lines, no "accompaniment" | Late period (Op.104+) |

### Piano Register Usage

| Register | Use | Period |
|----------|-----|--------|
| Bass (A1-C3) | Pedal tones, bass of broken chords | All periods — anchoring |
| Tenor (C3-G3) | Lower part of arpeggiated accompaniment | Primary accompaniment zone |
| Middle (G3-C5) | Melody; inner voices; the "singing" range | All periods |
| Upper (C5-C6) | Melodic peaks; high arpeggiation points | Middle period especially |
| High (above C6) | Rare — crystalline effects | Occasional in Barcarolles |

```abc
X:1
T:Faure — Nocturne Piano Texture (arpeggiated accompaniment)
M:6/8
L:1/8
K:Eb
V:1 clef=treble name="RH"
V:2 clef=bass name="LH"
%% Melody over flowing broken-chord accompaniment
[V:1] !p!B,2E G2B|A2G F2E|B,2E G2B|A6|
[V:2] E,B,G B,GE,|F,CA, CCA,|E,B,G B,GE,|A,,E,C E,CA,,|
%% The LH never accents a note; the pattern breathes like tide
```

## Song Accompaniment

Faure composed ~100 melodies (art songs). The piano accompaniment in songs is a compositional art equal to the vocal line.

| Accompaniment Type | Character | Examples |
|-------------------|-----------|---------|
| Gently rocking | 6/8 or 9/8 barcarolle rhythm | "Les Berceaux," "Clair de lune" |
| Sustained chords | Simple, warm, hymnal | "Apres un reve," "Lydia" |
| Flowing arpeggios | Continuous motion, neither fast nor slow | "Les Roses d'Ispahan" |
| Independent countermelody | Piano has its own melody alongside the voice | "La Bonne Chanson" (late songs) |
| Late austerity | Bare, sometimes monophonic, no comfort | "L'Horizon chimerique" Op.118 |

```abc
X:2
T:Faure — Song Accompaniment (gently rocking barcarolle)
M:6/8
L:1/8
K:Gm
%% The accompaniment IS the atmosphere — not accompaniment but co-creation
!pp!G,DG DGd|G,DG DGd|F,CF CFc|F,CF CFc|
%% No chord is accented; the pattern is the sonic equivalent of rocking
```

## Orchestral Writing

### Requiem Op.48

The most revealing orchestral score: Faure's rejection of conventional orchestral drama.

| Element | Standard Requiem (Verdi, Berlioz) | Faure's Requiem |
|---------|----------------------------------|-----------------|
| Brass | Full brass section; trumpets for Dies Irae | Horns + trumpets only; no trombones in early version |
| Woodwinds | Full; often prominent | Absent in original version; added later for publication |
| Percussion | Dramatic timpani | Timpani only, pp |
| Strings | Full section, dynamic extremes | Divided, muted, pp-p range |
| Chorus | Massive, declamatory | Gentle, legato, never above mf |
| Dies Irae | Central dramatic movement | Omitted entirely — "I see death as a happy deliverance" |
| Organ | Optional or dramatic | Central — the sustained harmonic foundation |

### Pelleas et Melisande Suite

| Instrument | Faure's Use | Character |
|-----------|------------|-----------|
| Strings | Primary; divided, muted, con sordino | Veiled, intimate, nocturnal |
| Flute | Solo melody; the Sicilienne | Pastoral, innocent |
| Oboe | Brief solo color | Tender, distant |
| Horns | Sustained tones, background warmth | Never heroic — always soft |
| Harp | Gentle arpeggios | Fairy-tale quality |
| Full tutti | Almost never | The orchestra whispers |

## Chamber Music Textures

### String Quartet Op.121

| Texture | Description |
|---------|-------------|
| Monophonic unison | All four strings on the same line — extreme austerity |
| Two-part counterpoint | First violin + cello; inner voices silent | 
| Homophonic chorale | Four-part chords, hymn-like |
| Free counterpoint | Four independent lines, no "accompaniment" layer |
| Accompanied melody | One voice sings, three accompany — but the accompaniment is lean |

### Piano Quartets/Quintets

| Element | Faure's Treatment |
|---------|-------------------|
| Piano | Equal partner, not soloist; often provides the harmonic carpet |
| Strings | Sing independently; the violin melody is vocal in character |
| Cello | Autonomous bass line that is also melodic — never merely harmonic support |
| Texture density | 3-4 voices maximum, even with 5 instruments |
| Dynamic | Chamber dynamic throughout — the piano never overwhelms the strings |

## Dynamic Practice

| Dynamic Level | Frequency in Faure | Context |
|--------------|-------------------|---------|
| pp | Very common | Song accompaniments, Requiem, late works |
| p | The default | Most melodic passages |
| mp | Common | Transitional warmth |
| mf | The effective maximum for most works | Phrase peaks, moments of inner warmth |
| f | Rare | Extended climactic passages only |
| ff | Very rare | Momentary — immediately subsides |
| Crescendo | Gentle, long, leading to mf | Builds slowly, never erupts |
| Diminuendo | Very common — phrases fade rather than close | The Faure ending: diminuendo to pp |
