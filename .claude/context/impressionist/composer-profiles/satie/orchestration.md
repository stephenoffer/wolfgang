# Erik Satie — Orchestration

Satie is primarily a piano composer. His orchestral works are few but significant: Parade (1917), Socrate (1918), Relache (1924), and orchestrations of the Gymnopedies by Debussy. When Satie does orchestrate, the principle is the same as his piano writing: economy, transparency, no display. The orchestra is stripped to essentials — and sometimes deliberately filled with non-musical sounds.

## Instrumental Forces

| Category | Satie's Practice | Contrast |
|----------|-----------------|----------|
| Primary instrument | Piano — solo, always | Debussy: piano AND orchestra equally |
| Orchestra size | Small to medium; never late-Romantic scale | Strauss: 100+ players |
| Texture layers | 2-3 maximum: melody + accompaniment (+ bass) | Ravel: 5-6 independent layers |
| Doublings | Minimal — each instrument has its own line or is silent | Brahms: extensive doublings for warmth |
| Percussion | Either absent or radically expanded (Parade) | Traditional: timpani only |
| Dynamic range | pp to mf in serious works; any dynamic in humorous works | Mahler: pppp to ffff |

## Piano Writing

| Technique | Description | Example |
|-----------|-------------|---------|
| Gymnopedie texture | LH: bass note (beat 1) + chord (beats 2-3). RH: single-note melody | Gymnopedies 1-3 |
| Gnossienne texture | LH: broken chord or sustained harmony. RH: free melody, no bar lines | Gnossiennes 1-6 |
| Block chords | Simple chordal writing, hymn-like, no arpeggiation | Ogives, Sonneries |
| Staccato miniature | Short detached notes, rests as structural elements | Sports et Divertissements |
| Two-voice counterpoint | Only in Schola-period works; fugal texture | En Habit de Cheval |

### Piano Register Usage

| Register | Use | Frequency |
|----------|-----|-----------|
| Bass (A1-C3) | Single bass notes on beat 1; open 5ths | Every Gymnopedie/Gnossienne |
| Tenor (C3-G3) | Chord voicings, beats 2-3 in Gymnopedie pattern | Primary accompaniment register |
| Middle (G3-C5) | Melody; the "speaking" register | 90% of melodic content |
| Upper (C5-C6) | Rare — occasional melodic peak | Brief moments only |
| Extreme (beyond C6) | Never | 0% |

```abc
X:1
T:Satie — Gymnopedie Piano Texture
M:3/4
L:1/4
K:D
V:1 clef=treble name="RH"
V:2 clef=bass name="LH"
%% The complete texture: 2 layers, transparent, unchanging
[V:1] !pp!F E D|E F G|F E D|D3|
[V:2] [D,2]z|[G,B,E] [G,B,E]|[D,2]z|[F,A,D] [F,A,D]|
%% RH: single notes. LH: bass + chord. Nothing else.
```

## Orchestral Writing (Parade, 1917)

Parade introduced non-musical sound into the orchestral palette — not as novelty but as cubist collage.

| Element | Instruments/Sounds | Role |
|---------|-------------------|------|
| Melody | Clarinet, flute, trumpet (solo, not doubled) | Simple tunes, often folk-like or ragtime |
| Harmony | Strings (reduced), piano | Static chords, repeated patterns |
| Rhythm | Percussion expanded | Driving pulse, mechanical quality |
| Found sounds | Typewriter, lottery wheel, pistol shots, siren | Collage elements — treated as equal to musical sounds |

### Parade Orchestral Palette

| Instrument | Satie's Use | Character |
|-----------|------------|-----------|
| Flute | Solo melody, thin, exposed | Childlike simplicity |
| Clarinet | Solo melody, warmer register | Cabaret character |
| Trumpet | Brief fanfares, muted | Ironic grandeur |
| Strings | Sustained chords, pizzicato | Background texture only |
| Piano | Rhythmic ostinato | Mechanical, ragtime |
| Percussion | Typewriter, siren, lottery wheel | Cubist sound-objects |

```abc
X:2
T:Satie — Parade Ragtime Character
M:2/4
L:1/16
K:C
%% Flat, mechanical, ironic — not jazz but a Frenchman's idea of ragtime
!mf!c2c2 e2c2|d2B2 G4|c2c2 e2c2|d2c2 c4|
%% No swing, no blue notes — deliberately stiff, like a music box
```

## Orchestral Writing (Socrate, 1918)

The opposite of Parade: extreme austerity. Four sopranos and chamber orchestra delivering Plato's text without expression.

| Element | Treatment | Principle |
|---------|-----------|-----------|
| Voice | Soprano, syllabic, narrow range, no vibrato requested | Anti-operatic: the voice serves the text |
| Strings | Sustained, soft, transparent | Background wash — not melody, not counterpoint |
| Winds | Occasional solo color — oboe, flute | Brief, isolated, returning to silence |
| Brass | Absent or minimal | No weight, no ceremony |
| Dynamic | pp throughout, never louder than p | The death of Socrates delivered in a whisper |

## Furniture Music (Musique d'Ameublement, 1920)

| Principle | Application |
|-----------|-------------|
| Not to be listened to | Music for the intervals between acts; ambient sound |
| Short loops | 4-8 bar phrases repeated indefinitely |
| Small ensemble | Clarinet, trombone, piano (or similar ad hoc group) |
| No development | The loop repeats without variation, without ending |
| Volume | Soft enough to be ignored; loud enough to be present |

## Texture Classification

| Texture Type | Layers | Where Used |
|-------------|--------|-----------|
| Melody + chordal accompaniment | 2 | Gymnopedies, Gnossiennes (95% of piano works) |
| Monophonic chant | 1 | Ogives passages |
| Block chords | 1 (homophonic) | Sonneries, Rose+Croix works |
| Cubist collage | 3-5 (disjunct) | Parade |
| White-note austerity | 2 (voice + sparse accompaniment) | Socrate |
| Ambient loop | 1-2 | Furniture music |

## Dynamic Practice

| Dynamic Level | Frequency in Satie | Context |
|--------------|-------------------|---------|
| pp | Very common | Gymnopedies, Socrate — the default Satie dynamic |
| p | Common | Gnossiennes, general piano works |
| mp | Occasional | Transitional moments |
| mf | Rare | Brief emphasis, immediately subsiding |
| f | Very rare | Parade only; humorous/ironic works |
| ff | Almost never | Parade climactic moments only |
| Crescendo/diminuendo | Almost never | Satie does not build or recede; the dynamic is constant |
