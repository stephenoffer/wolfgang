# Erik Satie — Melodic Style

Satie's melodies are the opposite of Romantic melody. Where Chopin spins long, ornamented lines and Tchaikovsky builds sweeping arcs, Satie writes short, bare, repetitive phrases that refuse to develop. The melody is not simple because Satie lacks skill — it is simple because simplicity is the aesthetic. What remains after everything unnecessary is removed is not poverty but essence.

## Core Melodic Character

| Feature | Description | Where It Appears |
|---------|-------------|-----------------|
| Stepwise motion | Melodies move by step (2nds); leaps larger than a 4th are rare | Gymnopedies, Gnossiennes, Socrate |
| Narrow range | Most melodies span a 5th to an octave | All piano works |
| Repetition without development | Phrases repeat unchanged or with minimal variation | Gymnopedies: same phrase structure every 8 bars |
| Modal inflection | Melodies use church modes, not major/minor scales | Dorian (Gymnopedies), Phrygian (Ogives) |
| No ornamentation | Zero trills, mordents, grace notes, turns | All works — explicitly marked "sans ornement" |
| Anti-climactic contour | Melodies do not build toward high points | The emotional temperature is constant |
| Syllabic rhythm | One note per beat or per half-beat; no melismatic passages | Socrate vocal line, piano melodies |

## Melodic Contour Types

| Contour | Shape | Character | Example Work |
|---------|-------|-----------|-------------|
| Gentle arch | Rises a 3rd-4th, descends back | Calm, breathing | Gymnopedie No.1 |
| Circular | Returns to starting note within 2-3 bars | Hypnotic, self-contained | Gnossienne No.1 |
| Descending step | Stepwise descent through 4th-5th | Melancholy without drama | Gnossienne No.3 |
| Static oscillation | Alternates between 2-3 adjacent notes | Trance-like | Vexations melody |
| Monotone with inflection | Repeated note with occasional step | Liturgical, chant-like | Socrate vocal declamation |

```abc
X:1
T:Satie — Gymnopedie Melodic Type (gentle arch)
M:3/4
L:1/4
K:D dorian
%% Stepwise, narrow range, one note per beat, no ornament
!pp!F E D|E F G|F E D|C D E|D3|
%% Range: C to G — a 5th. The melody breathes, does not soar.
```

```abc
X:2
T:Satie — Gnossienne Melodic Type (circular, unmeasured)
M:none
L:1/8
K:Am
%% No bar lines in the original; the melody circles around A-B-C
A2 B2 C2 B2|A2 G2 A2 B2|A4 z4|
%% The melody returns where it started. It could repeat forever.
```

## Phrase Structure

| Parameter | Satie's Practice | Contrast with Romantic |
|-----------|-----------------|----------------------|
| Phrase length | 4 bars, repeated | 8-16 bars, developing |
| Phrase ending | Open — no cadential melody | Closed — cadential descent or resolution |
| Phrase connection | Juxtaposition (A then A again) | Transition (A leads to B) |
| Motivic development | None — the phrase is stated, then restated | Fragmentation, augmentation, sequence |
| Climax | None — dynamic and registral level constant | Built toward peak in second half |
| Breathing | Regular, clock-like | Irregular, expressive rubato |

## Melodic Rhythm

| Rhythm Type | Description | Where Used |
|-------------|-------------|-----------|
| Equal values | All quarter notes or all half notes | Gymnopedies, Socrate |
| Gentle dotted | Dotted quarter + eighth, creating soft lilt | Gnossiennes |
| Unmeasured | No time signature; durations implied by notation | Gnossiennes (original editions) |
| Staccato fragments | Short detached notes with rests | Humorous pieces (Sports et Divertissements) |
| Monotone pulse | Repeated same pitch at regular intervals | Vexations bass line |

## Register and Range

| Register | Satie's Use | Frequency |
|----------|------------|-----------|
| Middle (C4-C5) | Primary melodic register — intimate, speaking voice | 80% of melodic writing |
| Upper (C5-G5) | Occasional — for the highest point of an arch | 15% — never extreme |
| Low (below C4) | Almost never melodic — reserved for bass | 5% |
| Extreme high/low | Never | 0% — Satie stays in the conversational register |

## Text Setting (Socrate, Songs)

| Principle | Application |
|-----------|-------------|
| Syllabic | One note per syllable, always |
| Flat declamation | The text is delivered, not dramatized; no word-painting |
| Narrow range | Vocal line stays within a 6th for extended passages |
| No repetition of words | The text is set once; no operatic repetition |
| Anti-expressive | The voice does not color the words; the words exist as sound |

```abc
X:3
T:Satie — Socrate Vocal Style (monotone with inflection)
M:4/4
L:1/4
K:C
%% Plato's text delivered as if reading aloud — no drama
C C D C|B, C D C|C C C B,|C4|
%% Range: B3 to D4 — a minor 3rd. The voice barely moves.
```

## Performance Directions as Melody Commentary

Satie's scores contain prose directions instead of standard Italian markings. These are part of the melodic meaning.

| Direction (French) | Translation | Melodic Implication |
|-------------------|-------------|-------------------|
| "Avec etonnement" | With astonishment | Play the simple melody as if discovering it |
| "Du bout de la pensee" | From the tip of the thought | The melody is barely there — a whisper of intent |
| "Questionnez" | Question | The phrase is interrogative; do not resolve |
| "Tres perdu" | Very lost | The melody has no direction; accept this |
| "Sans ornement" | Without ornament | Literal: do not add anything |
| "Postulez en vous-meme" | Postulate within yourself | The melody is internal; do not project |
