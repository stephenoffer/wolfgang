# Erik Satie — Harmonic Language

Satie's harmony is the negation of functional tonality — not through complexity (as in Wagner or Schoenberg) but through simplicity. Chords exist as colors, not functions. Nothing resolves because nothing needs to. The harmony is static, modal, and deliberately un-dramatic: furniture for the ear.

For shared Impressionist harmonic vocabulary (planing, extended chords, whole-tone), see [impressionist-harmony.md](../../impressionist-harmony.md). This file covers what is distinctly Satie.

## Core Harmonic Character

| Feature | Description | Where It Appears |
|---------|-------------|-----------------|
| Static harmony | Same chord or two-chord oscillation sustained indefinitely | Gymnopedies, Gnossiennes, Vexations |
| Parallel chord movement | All voices move in the same direction, same interval | Gymnopedies (parallel 7ths/9ths), Sarabandes |
| Non-functional chords | Chords chosen for color, not for resolution tendency | Everywhere — the defining Satie trait |
| Modal basis | Dorian, Phrygian, Mixolydian — church modes, not major/minor | Gymnopedies (D Dorian feel), Ogives (Gregorian) |
| Rootless voicing | Bass note is the 5th or 3rd, not the root — the chord floats | Gymnopedies LH: bass is 5th below the triad |
| Unresolved dissonance | 7ths, 9ths, 4ths left hanging — they ARE the harmony | Sarabandes (unresolved 9th chords, 1887) |
| No cadential drive | Phrases end by stopping, not by resolving | All works — Satie does not write V-I |

## The Gymnopedie Harmonic Model

The founding harmonic gesture: two chords alternating in 3/4 time, neither resolving to the other, the bass note destabilizing the root.

| Element | Detail |
|---------|--------|
| Chord 1 | Major 7th or major 9th — e.g., Gmaj7 |
| Chord 2 | Major 7th or major 9th a step away — e.g., Dmaj7 |
| Bass | NOT the root — typically the 5th below, creating first-inversion or rootless feel |
| Motion | Oscillation — 1-2-1-2-1-2 — no progression, no arrival |
| Duration | Entire piece on these two chords (with slight variants) |

```abc
X:1
T:Gymnopedie Harmonic Model — Two-Chord Oscillation
M:3/4
L:1/4
K:D
%% LH pattern: bass on 1, chord on 2-3; bass is 5th, not root
[D,2]z|[G,B,E] [G,B,E]|[D,2]z|[F,A,D] [F,A,D]|[D,2]z|[G,B,E] [G,B,E]|
%% D in bass under G chord = G/D (second inversion); floating, not grounded
```

## Parallel Chord Movement

Satie anticipated Debussy's planing by a decade. The Sarabandes of 1887 move 9th chords in parallel — a technique that outraged the Conservatoire and delighted no one at the time.

| Type | Chord Quality | Example | Effect |
|------|--------------|---------|--------|
| Parallel 9ths | Major or dominant 9ths | Cmaj9-Dmaj9-Emaj9 | Blurred tonality; color wash |
| Parallel 7ths | Major 7ths | Cmaj7-Dbmaj7-Dmaj7 | Chromatic shimmer without function |
| Parallel triads | Major triads | C-Db-D-Eb | Medieval organum quality |
| Parallel quartal | Stacked 4ths | (C-F-Bb)-(D-G-C)-(E-A-D) | Open, hollow, archaic |

```abc
X:2
T:Satie — Parallel 9th Chords (Sarabande character, 1887)
M:3/4
L:1/2
K:C
%% All voices move together — no voice-leading, no function, only color
[CEGBd]3/2|[DFAce]3/2|[EGBdf]3/2|[FAceg]3/2|
%% Each chord is a color; no chord is more important than any other
```

## Modal Palette

| Mode | Satie's Use | Character | Key Example |
|------|------------|-----------|-------------|
| Dorian | Primary melodic mode; raised 6th in minor context | Warm, archaic, timeless | Gymnopedie No.1 melody |
| Phrygian | Flat-2nd gives archaic, almost Eastern quality | Dark, ancient, mystical | Ogives, Sonneries |
| Mixolydian | Flat-7th weakens dominant function | Relaxed, non-resolving | Gnossienne passages |
| Aeolian | Natural minor without leading tone | Soft, folk-like | Gnossienne No.1 |
| Gregorian (mixed) | Free modal mixture as in plainchant | Ecclesiastical, medieval | Rose+Croix works |

```abc
X:3
T:Satie — Phrygian Modal Melody (Ogives character)
M:4/4
L:1/4
K:E phrygian
%% Gregorian chant influence: stepwise, narrow range, no accidentals
E F G A|G F E F|G A G F|E4|
%% The F natural (flat 2nd) is the Phrygian signature — ancient, not modern
```

## Harmonic Stasis Techniques

| Technique | Description | Duration |
|-----------|-------------|----------|
| Single-chord drone | One chord sustained or repeated, no change | Entire sections (Vexations: 840 repetitions) |
| Two-chord oscillation | Alternation without progression | Entire piece (Gymnopedies) |
| Pedal point | Bass note held while upper voice moves modally | Extended passages (Gnossiennes) |
| Chord loop | 3-4 chord cycle repeated without variation | Furniture music pieces |
| Melodic stasis | Melody circles the same 3-4 notes | Gnossienne melodies |

## Harmonic Rhythm

| Context | Typical Rate | Satie Signature |
|---------|-------------|-----------------|
| Gymnopedie | 1 chord per bar (3/4) | Hypnotic regularity; no acceleration, no ritardando |
| Gnossienne | Free, unmeasured | No bar lines; the harmony changes when it changes |
| Humorous pieces | Quick, irregular | Brief gestures, silences, non sequiturs |
| Socrate | Very slow — 1 chord per 2-4 bars | White-note austerity; maximum stillness |
| Furniture music | Static — same loop indefinitely | The harmony is wallpaper, not architecture |

## Key Preferences

| Preference | Keys/Modes | Character |
|-----------|------------|-----------|
| Most characteristic | D major/Dorian, G major, F major | Warm, middle-register, modal ambiguity between major and Dorian |
| Mystic works | E Phrygian, A Aeolian | Archaic, ecclesiastical |
| Late austerity | C major (white notes only) | Socrate: stripped to essence |
| Avoided | Remote sharps, chromatic complexity | Satie does not modulate in the traditional sense |

## Cadential Patterns (or Lack Thereof)

| "Cadence" Type | How Satie Ends Phrases | Effect |
|---------------|----------------------|--------|
| Cessation | The music simply stops | No closure; the piece ends because it ends |
| Loop return | The cycle starts again | No ending; the piece could continue forever |
| Fade to silence | Diminuendo to nothing | The music evaporates |
| Modal drift | Final chord is not the "tonic" — or there is no tonic | Harmonic openness |
| Repeat sign | Literally: go back to the beginning | Vexations: 840 times; the absence of ending IS the piece |
