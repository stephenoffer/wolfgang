# Ravel Composer Profile

## Quick ID
| Attribute | Value |
|-----------|-------|
| Full name | Maurice Ravel (1875-1937) |
| Nationality | French (Basque heritage) |
| Period | Impressionist / Neoclassical |
| Key works | Bolero, Daphnis et Chloe, Piano Concerto in G, La Valse, String Quartet, Gaspard de la Nuit, Ma Mere l'Oye |
| Signature traits | Precision, Spanish color, jazz influence, brilliant orchestration, mechanical textures |

## Harmonic Language

| Technique | Description | Frequency |
|-----------|-------------|-----------|
| Extended tertian chords | 9ths, 11ths, 13ths as stable sonorities | Constant |
| Functional + color | Traditional progressions with added-note chords | Signature |
| Bitonality (mild) | Two tonal areas superimposed | Moderate |
| Spanish Phrygian | bII-I oscillation, Phrygian dominant | Frequent |
| Jazz chords | Dom9, min9, 6/9 voicings | Later works |
| Pedal-based harmony | Rich chords over sustained bass | Frequent |
| Chromatic mediant | Third-related key shifts | Characteristic |
| Major 7th as dissonance | Maj7 used for biting color | Signature |
| Augmented 6th chords | French, German, Italian +6 for color | Moderate |
| Parallel motion | Like Debussy but more controlled | Frequent |

## Melodic Style

| Feature | Description |
|---------|-------------|
| Long-breathed phrases | More sustained than Debussy |
| Diatonic clarity | Often clearly tonal melody |
| Spanish ornaments | Acciaccaturas, grace-note turns |
| Modal inflection | Dorian, Phrygian, Mixolydian |
| Stepwise motion | Predominantly conjunct |
| Jazz blue notes | b3, b7 in later works |
| Mechanical repetition | Same phrase repeated with harmonic shifts beneath |

## Jazz Influence (Late Works)

| Element | Application |
|---------|-------------|
| Blue notes | b3 and b7 in major context |
| Walking bass | Stepwise bass in moderate tempo |
| Swing feel | Dotted rhythms suggesting jazz phrasing |
| 9th/13th voicings | Standard jazz chord extensions |
| Piano concerto | LH: jazz bass patterns; RH: Gershwin-adjacent runs |
| Trumpet solo | Muted, intimate, jazz-club character |

## Orchestration Mastery

| Technique | Application |
|-----------|-------------|
| Solo instrument showcase | Each instrument used at its most characteristic |
| Transparent layering | Every line audible even in tutti |
| Timbral invention | Novel combinations for new colors |
| Dynamic orchestral crescendo | Bolero: same melody, growing orchestration |
| Percussion integration | Snare, castanets, tam-tam as structural elements |
| Harp as structural voice | Not just color; rhythmic and harmonic function |
| Celesta for fairy-tale | Ma Mere l'Oye signature |
| String harmonics | Atmospheric sparkle |

### Ravel Orchestration Color Map

| Mood | Primary Instruments | Support |
|------|--------------------|---------| 
| Fairy-tale | Celesta, flute, muted strings | Harp, piccolo |
| Spanish | Solo trumpet/oboe, castanets, harp | Guitar-style strings |
| Jazz | Muted trumpet, clarinet, piano | Walking bass, brushed snare |
| Waltz | Strings (lush), solo winds | Harp punctuation |
| Mechanical | Repetitive woodwinds, snare drum | Layered entries |
| Pastoral | Solo flute, oboe, English horn | Sustained strings |
| Dramatic | Full brass, driving strings | Timpani, cymbals |

## Mechanical Textures

| Feature | Description |
|---------|-------------|
| Bolero principle | Unchanging rhythm, cumulative orchestration |
| Ostinato-driven | Repeating figures as structural foundation |
| Clock-like regularity | Precise rhythmic patterns, metronomic |
| Layered entry | Instruments enter one by one, same material |
| Music-box quality | Celesta/glockenspiel in simple patterns |
| Perpetual motion | Continuous sixteenth-note figuration |

## Piano Writing

| Technique | Effect |
|-----------|--------|
| Virtuosic arpeggiation | Gaspard: extreme difficulty, shimmering |
| Toccata figuration | Rapid, repeated notes (Le Tombeau) |
| Wide-spread voicings | Full piano resonance |
| Precise pedaling | Clean, not blurred |
| Bimanual melody | Both hands share melody notes |
| Orchestral piano | Piano imitates orchestra |

## Formal Approach

| Principle | Application |
|-----------|-------------|
| Classical forms respected | Sonata, rondo, ternary used with sophistication |
| Clarity over ambiguity | Sections clearly delineated (more than Debussy) |
| Variation principle | Bolero = extreme theme-and-orchestration variation |
| Dance-based | Waltz, minuet, forlane, rigaudon structures |
| Arch forms | Some works build symmetrically |
| Strong endings | Unlike Debussy, Ravel often ends decisively |

## Key Progressions (Ravel Fingerprints)

```
Functional color:    I9 -> IV9 -> V13 -> I9 (jazz-adjacent)
Spanish:             i -> bII -> i (Phrygian)
Chromatic mediant:   C major -> E major -> Ab major
Waltz:               I -> V7 -> I with added 6ths and 9ths
Bitonal hint:        C major melody over F# major accompaniment
Cadential:           ii9 -> V13 -> I (add6) (warm, conclusive)
Modal:               Dorian i -> IV -> i (no dominant)
```

## Ravel vs. Debussy Key Differences

| Aspect | Debussy | Ravel |
|--------|---------|-------|
| Harmony | Non-functional, floating | Functional + colorful |
| Form | Free, ambiguous | Clear, classical |
| Melody | Fragmented, atmospheric | Long-breathed, vocal |
| Rhythm | Flexible, rubato | Precise, mechanical |
| Orchestration | Atmospheric | Brilliant, virtuosic |
| Endings | Dissolve | Definitive close |
| Emotional tone | Suggestive | Precise emotion |

## Generation Guidelines

| Parameter | Recommendation |
|-----------|---------------|
| Key/mode | Clear tonal center; modes, Spanish Phrygian |
| Tempo | Precise; metronome markings respected |
| Melody | Lyric, long-breathed, clear phrasing |
| Harmony | Rich extended chords with functional backbone |
| Texture | Transparent, brilliant, every voice audible |
| Dynamics | Full range; pp to fff with precision |
| Orchestration | Showcase individual instruments; varied colors |
| Form | Classical structures with colorful content |
| Rhythm | Precise, often mechanical or dance-based |
| Avoid | Vagueness, muddy textures, sloppy voice leading |
| Emphasize | Precision, brilliance, Spanish color, jazz chords, transparency |
